# معيار ISO 3166 للدول - الدليل الكامل

## 1. نظرة عامة
معيار ISO 3166 هو معيار دولي لتسمية الدول وترميزها، صادر عن المنظمة الدولية للتوحيد القياسي (ISO). يُستخدم في منصة NQP لتوحيد رموز الدول في جميع أنحاء النظام.

## 2. أجزاء المعيار

| الجزء | الوصف | الاستخدام في NQP |
| :--- | :--- | :--- |
| **ISO 3166-1** | رموز الدول (Alpha-2, Alpha-3, Numeric) | ✅ يُستخدم |
| **ISO 3166-2** | رموز التقسيمات الفرعية (المدن، الولايات) | ❌ غير مستخدم |
| **ISO 3166-3** | رموز الدول السابقة (الملغاة) | ❌ غير مستخدم |

## 3. تنسيقات الرموز

| التنسيق | الطول | مثال | الاستخدام |
| :--- | :--- | :--- | :--- |
| **Alpha-2** | حرفان | `SD` | الأكثر استخداماً (في نماذج السفر). |
| **Alpha-3** | ثلاثة أحرف | `SDN` | استخدام في الأنظمة القديمة (IHR). |
| **Numeric** | ثلاثة أرقام | `729` | استخدام في بعض الأنظمة الحكومية. |

## 5. التحقق من صحة رموز ISO 3166 في Django

# apps/countries/validators.py
from django.core.exceptions import ValidationError

def validate_iso_alpha2(value):
    valid_codes = ['SD', 'EG', 'SA', ...]  # قائمة جميع الرموز
    if value not in valid_codes:
        raise ValidationError(f'{value} ليس رمز ISO 3166-1 صحيح.')
