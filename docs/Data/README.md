# البيانات المرجعية والرئيسية (Data Reference & Master Data) - NQP

## 1. الهدف
يحتوي هذا المجلد على جميع البيانات المرجعية (Master Data) المستخدمة في منصة NQP، بما في ذلك (رموز الدول، رموز المطارات، رموز الأمراض، ICD-11، ISO 3166، وغيرها). هذه البيانات هي العمود الفقري لتشغيل المنصة بشكل صحيح ومتسق، وتُستخدم في جميع البوابات والأنظمة الداعمة.

## 2. هيكل المجلدات

```text
Data/
├── README.md                    # هذا الملف
├── Country_Codes.md             # رموز الدول (ISO 3166)
├── Airport_Codes.md             # رموز المطارات (IATA)
├── Disease_Codes.md             # رموز الأمراض (ICD-11)
├── ICD11.md                     # التصنيف الدولي للأمراض (الإصدار 11)
├── ISO3166.md                   # معيار ISO 3166 للدول
├── Master_Data.md               # البيانات الرئيسية العامة
├── Naming_Convention.md         # اصطلاحات التسمية للبيانات
└── Validation_Rules.md          # قواعد التحقق من صحة البيانات

3. أهمية البيانات المرجعية

    التوحيد: ضمان استخدام نفس الرموز والمعايير في جميع أنحاء المنصة.

    الاتساق: منع التضارب في البيانات الناتج عن استخدام أسماء مختلفة لنفس المفهوم.

    التكامل: تسهيل تبادل البيانات مع الأنظمة الخارجية (وزارة الصحة، WHO، الجمارك).

    الامتثال: الالتزام بالمعايير الدولية (ISO، IATA، ICD).

    الكفاءة: تسريع عمليات البحث والتصفية باستخدام الرموز بدلاً من النصوص الطويلة.

4. مصادر البيانات
البيانات          	المصدر    	التحديث
رموز الدول (ISO 3166)  	المنظمة الدولية للتوحيد القياسي (ISO)	سنوي
رموز المطارات (IATA)	اتحاد النقل الجوي الدولي (IATA)	دوري
رموز الأمراض (ICD-11)	منظمة الصحة العالمية (WHO)	دوري
بيانات الدول	وزارة الصحة السودانية	عند التغيير

5. إدارة البيانات المرجعية

    الإضافة: تتم إضافة البيانات المرجعية عبر Django Admin (بوابة الإدارة الاتحادية 8).

    التحديث: يتم تحديث البيانات عبر مزامنة تلقائية مع المصادر الخارجية (WHO، ISO) أو يدوياً عبر المسؤولين.

    التحقق: يتم التحقق من صحة البيانات عند الإدخال (تطبيق Validation_Rules.md).

    النسخ الاحتياطي: يتم عمل نسخ احتياطية للبيانات المرجعية بشكل دوري.
