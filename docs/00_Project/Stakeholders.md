# أصحاب المصلحة (Stakeholders)

## 1. الجهات الراعية والمنظمة (Sponsors & Regulators)
| المصلحة | الدور | مستوى التأثير |
| :---       | :--- | :---  |

| **وزارة الصحة الاتحادية** | المالك الرسمي للمنصة، جهة إصدار السياسات الصحية. | عالي (راعي) |

| **الإدارة العامة للطوارئ الصحية ومكافحة الأوبئة** | المستخدم الرئيسي لغرفة العمليات (EOC) والاستجابة للطوارئ. | عالي |

| **المركز الوطني للوائح الصحية الدولية (IHR)** | المسؤول عن التقارير الدولية والامتثال لمنظمة الصحة العالمية. | متوسط |

## 2. المستخدمون النهائيون (End Users)
| المصلحة | الدور | مستوى التأثير |
| :---       | :--- | :--- |

| **المسافرون (مواطنون ومقيمون)** | مستخدمي بوابة المسافرين وتطبيق المتابعة الصحية. | عالي (متأثر مباشر) |

| **موظفو الحجر الصحي في المنافذ** | يستخدمون بوابة الفحص الصحي وتقييم المخاطر. | عالي |

| **الأطباء والفنيون في عيادات الحجر** | يستخدمون السجل الطبي الإلكتروني (EMR) وإدارة العلاج. | عالي |
| **فنيو المختبرات** | يستخدمون بوابة المختبرات لتسجيل العينات والنتائج. | متوسط |

## 3. شركاء التكامل (Integration Partners)
| المصلحة | الدور | مستوى التأثير |

| :---       | :--- | :--- |

| **شركات الطيران وهيئات الطيران المدني** | توفير قوائم الركاب (Manifest) والتكامل مع جداول الرحلات. | متوسط |

| **هيئة الجمارك والمنافذ البرية والبحرية** | التكامل لإتمام إجراءات الإفراج (خاصة للحجر الغذائي). | متوسط |

| **المختبرات المرجعية والمستشفيات** | استقبال الحالات المحولة والنتائج المخبرية المعتمدة. | 
متوسط |

| **وزارة الزراعة والثروة الحيوانية** | التكامل في جانب سلامة الأغذية والواردات الحيوانية. | منخفض |

## 4. فريق التسليم (Delivery Team)
| المصلحة | الدور | مستوى التأثير |

| :--- | :--- | :--- |

| **مدير المشروع (PM)** | إدارة الجداول الزمنية والميزانية والموارد. | عالي |

| **مهندسو البرمجيات (Backend/Frontend)** | بناء وتطوير المنصة. | عالي |

| **مهندسو البيانات والذكاء الاصطناعي** | بناء محرك تقييم المخاطر ونماذج التنبؤ. | متوسط |

| **فريق ضمان الجودة (QA)** | اختبار المنصة وضمان خلوها من الثغرات. | متوسط |
