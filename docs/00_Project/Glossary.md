# قاموس المصطلحات (Glossary)

## المصطلحات الخاصة بالمشروع (Project-specific)

| المصطلح (AR) | المصطلح (EN) | الشرح / التعريف |
| :---        |:---          | :---          |

| **منصة الحجر الصحي القومي** | National Quarantine Platform (NQP) | النظام الرقمي المتكامل الذي يشمل جميع البوابات والأنظمة الداعمة لإدارة الحجر الصحي في السودان. |


| **نظام تقييم المخاطر** | Risk Engine | محرك خوارزمي (يعتمد على الذكاء الاصطناعي) يُصنف المسافرين عند وصولهم إلى (أخضر، أصفر، أحمر) بناءً على الأعراض والتاريخ المرضي. |


| **نظام المتابعة الصحية** | Health Follow-up System | نظام يُستخدم لمتابعة حالة المسافرين بعد مغادرتهم الحجر الصحي، عبر تطبيق جوال أو رسائل نصية. |


| **غرفة العمليات** | Emergency Operations Center (EOC) | غرفة الطوارئ المركزية التابعة للإدارة العامة للطوارئ الصحية، والتي تستقبل التنبيهات الحمراء وتدير فرق الاستجابة السريعة. |


| **قائمة الركاب** | Passenger Manifest | قائمة رقمية تحتوي على أسماء وأرقام جوازات جميع المسافرين على متن رحلة معينة، ترسلها شركات الطيران قبل الوصول. |


| **تعريف الحالة الوبائية** | Case Definition | معايير طبية محددة تُستخدم لتحديد ما إذا كان المريض يشتبه بإصابته بمرض معين (تعريف حالة مشتبهة، محتملة، أو مؤكدة). |


| **شهادة التعافي** | Recovery Certificate | وثيقة رقمية مُوقعة إلكترونياً تصدر للمريض بعد تعافيه، تثبت خلوه من العدوى وتسمح له بالسفر أو العودة للعمل. |


| **تتبع المخالطين** | Contact Tracing | عملية تحديد واستدعاء الأشخاص الذين كانوا على اتصال وثيق بحالة إيجابية (مثل الركاب في المقاعد المجاورة) لعزلهم أو فحصهم. |


| **مفتاح القتل** | Kill Switch | آلية طوارئ تسمح لغرفة العمليات بإيقاف جميع عمليات الإفراج أو تعليق الرحلات في منفذ معين فوراً أثناء الأزمات. |


| **سجل التدقيق** | Audit Log | سجل رقمي يسجل كل عملية دخول ونفاذ وإجراء يتم على النظام، لضمان المساءلة والشفافية. |


## المصطلحات التقنية والتخصصية (Technical & Domain)

| المصطلح (AR) | المصطلح (EN) | الشرح / التعريف |
| :--- | :--- | :--- |

| **إدارة الصلاحيات** | Role-Based Access Control (RBAC) | نظام للتحكم في الوصول بناءً على أدوار المستخدمين، بحيث لا يرى الموظف إلا البيانات المسموح له بها. |


| **التصنيف الدولي للأمراض** | International Classification of Diseases (ICD-11) | نظام الترميز الطبي المعتمد من منظمة الصحة العالمية لتوحيد تشخيص الأمراض. |


| **معيار تبادل البيانات الصحية** | Fast Healthcare Interoperability Resources (FHIR) | معيار دولي لتبادل السجلات الصحية الإلكترونية بين الأنظمة المختلفة عبر واجهات برمجة (API). |


| **اللوائح الصحية الدولية** | International Health Regulations (IHR 2005) | اتفاقية دولية تلزم الدول الأعضاء بمنع انتشار الأمراض عبر الحدود والإبلاغ عن الفاشيات. |


| **التشبع بالأكسجين** | Oxygen Saturation (SpO2) | قياس نسبة الأكسجين في الدم؛ يُعتبر انخفاضه (أقل من 93%) مؤشراً خطيراً في أمراض الجهاز التنفسي. |


| **قاعدة البيانات العلائقية** | PostgreSQL | نظام إدارة قواعد البيانات المستخدم في المنصة لتخزين بيانات المسافرين والفحوصات. |

| **طابور الرسائل** | Message Queue (e.g., RabbitMQ) | تقنية تستخدم لمعالجة البيانات غير المتزامنة (مثل استقبال قوائم الركاب الضخمة) دون إبطاء واجهة المستخدم. |


| **الاختبار الأولي** | Pilot Testing | تشغيل النظام في منفذ واحد (مثل مطار الخرطوم) كمرحلة تجريبية قبل التعميم على جميع المنافذ. |
