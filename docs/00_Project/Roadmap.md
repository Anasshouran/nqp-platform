# خارطة الطريق (Roadmap)

## المرحلة الأولى: الأساس والبنية التحتية (الأشهر 1 - 3)
- **الهدف**: بناء الأساس التقني والبوابات الأولية.
- **التسليمات الرئيسية**:
  - إعداد بيئات التطوير والاختبار (Dev/Staging) على السحابة.
  - تصميم قاعدة البيانات (ERD) وهيكلة الجداول الأساسية.
  - تطوير نظام إدارة المستخدمين والصلاحيات (RBAC) والمصادقة (JWT).
  - إطلاق الموقع العام (بوابة 1) وبوابة المسافرين (بوابة 2) بنسخة تجريبية.

## المرحلة الثانية: الحجر الصحي البشري (الأشهر 4 - 8)
- **الهدف**: أتمتة دورة المسافر الكاملة (من الوصول إلى التعافي).
- **التسليمات الرئيسية**:
  - تطوير بوابة موظفي الحجر (4) ونظام تقييم المخاطر (Risk Engine).
  - تطوير بوابة العيادات (5) مع السجل الطبي الإلكتروني.
  - تطوير بوابة المختبرات (6) وتكاملها مع أجهزة PCR.
  - إطلاق نظام المتابعة الصحية (Health Follow-up) وتطبيق الهاتف المحمول الخاص بالمريض.

## المرحلة الثالثة: التوسع في السلامة العامة (الأشهر 9 - 11)
- **الهدف**: تغطية الحجر الغذائي وغرفة الطوارئ.
- **التسليمات الرئيسية**:
  - تطوير بوابة الحجر الغذائي (7) وتكاملها مع الجمارك.
  - تطوير بوابة الطوارئ (9) ولوحة الإنذار الفوري لغرفة العمليات.
  - بناء نظام الترصد الوبائي ولوحات المؤشرات (Dashboard) للإدارة الاتحادية (8).

## المرحلة الرابعة: التكامل والتشغيل الكامل (الشهر 12)
- **الهدف**: الربط الكامل مع الأنظمة الخارجية والانطلاق الرسمي.
- **التسليمات الرئيسية**:
  - تفعيل جميع واجهات التكامل (وزارة الصحة، شركات الطيران، الجمارك).
  - اختبارات الأداء والضغط الشاملة (Load Testing).
  - تدريب المستخدمين (موظفي المنافذ والأطباء) وتشغيل النظام بشكل تدريجي (Pilot في مطار الخرطوم).
  - التشغيل الرسمي (Go-Live) لكافة المنافذ.
