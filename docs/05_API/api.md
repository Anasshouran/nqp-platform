# نظرة عامة على واجهات البرمجة (API Overview) - NQP

## 1. الهدف من هذه الوثيقة
توفر هذه الوثيقة نظرة شاملة على استراتيجية واجهات البرمجة (API) لمنصة الحجر الصحي القومي (NQP). تغطي هذه الوثيقة المبادئ الأساسية، التصنيف، والأمان، لتكون مرجعاً للمطورين الجدد وأصحاب المصلحة.

## 2. المبادئ الأساسية لتصميم الـ API
- **التوجه بالموارد (Resource-Oriented)**: تصميم الـ API حول الموارد (مثل: Travelers, Screenings, LabResults) وليس حول الإجراءات.
- **توافق RESTful**: استخدام طرق HTTP القياسية (GET, POST, PUT, DELETE, PATCH).
- **الإصدار (Versioning)**: جميع الـ APIs مسبوقة بـ `/api/v1/` لضمان عدم كسر التطبيقات القائمة عند التحديثات المستقبلية.
- **البيانات في الطلبات والاستجابات**: استخدام JSON حصرياً (Content-Type: application/json).
- **الترقيم (Pagination)**: جميع نقاط النهاية التي تعيد قوائم تدعم `page` و `limit` و `sort`.

## 3. تصنيف وحدات الـ API (Modules)
تم تنظيم الـ APIs حسب البوابات والأنظمة الداعمة لتسهيل الصيانة.

| التصنيف (Tag) | الوصف | الملف المرجعي |
| :--- | :--- | :--- |
| **Authentication** | تسجيل الدخول، المصادقة، وإدارة الجلسات. | `Authentication_API.md` |
| **Traveler** | تسجيل المسافرين، رفع المستندات، واستلام الـ QR. | `Traveler_API.md` |
| **Screening** | فحص المسافرين عند الوصول، وتقييم المخاطر. | `Screening_API.md` |
| **Clinic** | إدارة السجلات الطبية (EMR)، والوصفات، والإحالات. | `Clinic_API.md` |
| **Laboratory** | إدارة العينات والنتائج المخبرية. | `Laboratory_API.md` |
| **Risk Engine** | (داخلي بشكل أساسي) استدعاء خوارزميات التقييم. | `Risk_API.md` |
| **Reports** | إنشاء وتصدير التقارير ولوحات المعلومات. | `Reports_API.md` |
| **Food Quarantine** | إدارة الشحنات الغذائية والتفتيش. | `Food_API.md` |
| **Emergency (EOC)** | إدارة الإنذارات (جزء من Screening و Reports). | `Screening_API.md` |

## 4. التوثيق التفاعلي
- يتم توفير واجهة **Swagger UI** على المسار: `https://nqp.gov.sd/api/docs/`.
- يتم إنشاء ملف `OpenAPI.yaml` تلقائياً من الكود باستخدام مكتبة `drf-spectacular`.

## 5. التحديثات والإصدارات
- **الإصدار الحالي**: `v1`.
- **سياسة التغيير**: سيتم إضافة مسارات جديدة مع الاحتفاظ بالمسارات القديمة لمدة إصدارين رئيسيين على الأقل.
