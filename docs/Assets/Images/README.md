6. إرشادات الصور

    الجودة: استخدم صوراً عالية الجودة (مضغوطة) لتحسين سرعة التحميل.

    التنسيق: تنسيق (WebP) مفضل للويب، (PNG) للصور الشفافة، (JPG) للخلفيات.

    النصوص البديلة (Alt Text): أضف نصوصاً بديلة (Alt Text) لجميع الصور لتحسين (Accessibility) و (SEO).

    التسمية: استخدم أسماء وصفية للملفات (مثل: hero-bg.jpg بدلاً من image1.jpg).

7. تحسين الصور للويب

    استخدم أدوات مثل (TinyPNG) أو (ImageOptim) لضغط الصور.

    استخدم تنسيق (WebP) للصور على الويب (أفضل ضغط وجودة).

    استخدم (Lazy Loading) للصور غير الظاهرة في الشاشة الأولى.
