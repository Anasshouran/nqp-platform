# شعارات منصة الحجر الصحي القومي (NQP Logos)

## 1. قائمة الشعارات

| اسم الملف | الوصف | التنسيق | الاستخدام |
| :--- | :--- | :--- | :--- |
| `NQP-Logo-Horizontal.png` | الشعار الأفقي (عربي) | PNG | الهيدر، التذييل، المواد الرسمية. |
| `NQP-Logo-Horizontal-EN.png` | الشعار الأفقي (إنجليزي) | PNG | الهيدر، التذييل (النسخة الإنجليزية). |
| `NQP-Logo-Square.png` | الشعار المربع (للأيقونات) | PNG | أيقونة التطبيق (App Icon). |
| `NQP-Logo-White.png` | الشعار باللون الأبيض | PNG | الخلفيات الداكنة (مثل: البانر الرئيسي). |
| `NQP-Logo-Favicon.ico` | أيقونة المتصفح (Favicon) | ICO | شريط عنوان المتصفح. |
| `NQP-Logo-SVG.svg` | الشعار بصيغة SVG | SVG | التكبير، المواد المطبوعة، الطباعة عالية الجودة. |

## 2. الشعار الأفقي (عربي) - `NQP-Logo-Horizontal.png`
- **الوصف**: شعار المنصة باللغة العربية (اتجاه أفقي).
- **الاستخدام**: الهيدر والتذييل في الموقع العام والبواتب (النسخة العربية).
- **الأبعاد الموصى بها**: العرض 200px، الارتفاع 50px (قابل للتكبير).

## 3. الشعار الأفقي (إنجليزي) - `NQP-Logo-Horizontal-EN.png`
- **الوصف**: شعار المنصة باللغة الإنجليزية (اتجاه أفقي).
- **الاستخدام**: الهيدر والتذييل في الموقع العام والبواتب (النسخة الإنجليزية).
- **الأبعاد الموصى بها**: العرض 200px، الارتفاع 50px (قابل للتكبير).

## 4. الشعار المربع - `NQP-Logo-Square.png`
- **الوصف**: شعار مربع (بدون نص) مناسب للأيقونات.
- **الاستخدام**: أيقونة تطبيق الجوال (App Icon)، أيقونة المتصفح (بديل للـ Favicon).
- **الأبعاد الموصى بها**: 512x512px.

## 5. الشعار الأبيض - `NQP-Logo-White.png`
- **الوصف**: شعار باللون الأبيض (بدون خلفية).
- **الاستخدام**: الخلفيات الداكنة (مثل: البانر الرئيسي، الشريط العلوي في الوضع الليلي).
- **الأبعاد الموصى بها**: العرض 200px، الارتفاع 50px.

## 6. أيقونة المتصفح - `NQP-Logo-Favicon.ico`
- **الوصف**: أيقونة صغيرة للمتصفح.
- **الاستخدام**: شريط عنوان المتصفح، علامات التبويب.
- **الأبعاد**: 16x16, 32x32, 48x48.

## 7. الشعار بصيغة SVG - `NQP-Logo-SVG.svg`
- **الوصف**: شعار بصيغة (Scalable Vector Graphics) قابل للتكبير دون فقدان الجودة.
- **الاستخدام**: المواد المطبوعة، الطباعة عالية الجودة، التكبير في التطبيقات.
- **المميزات**: يمكن تغيير الألوان بسهولة عبر CSS.

## 8. تعليمات الاستخدام
- استخدم الشعار المناسب حسب السياق (الخلفية، اللغة، الحجم).
- لا تقم بتعديل أو تشويه الشعار (نسبة الأبعاد ثابتة).
- استخدم الشعار الأبيض فقط على الخلفيات الداكنة.
- استخدم الشعار بصيغة SVG للطباعة عالية الجودة.
