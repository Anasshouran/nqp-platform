# إرشادات استخدام الشعار (Logo Guidelines) - NQP

## 1. مقدمة
يعد شعار منصة الحجر الصحي القومي (NQP) العنصر الأكثر تميزاً في هويتها البصرية. يجب استخدامه بشكل صحيح ومتسق في جميع المواد (الرقمية والمطبوعة) للحفاظ على قوة العلامة التجارية.

## 2. أنواع الشعارات

| النوع | الوصف | الاستخدام |
| :--- | :--- | :--- |
| **الشعار الأفقي (عربي)** | الشعار الرئيسي باللغة العربية | جميع المواد العربية (الموقع، التطبيق، المطبوعات). |
| **الشعار الأفقي (إنجليزي)** | الشعار الرئيسي باللغة الإنجليزية | جميع المواد الإنجليزية (الموقع، التطبيق، المطبوعات). |
| **الشعار المربع** | شعار مربع (بدون نص) | أيقونة التطبيق، Favicon. |
| **الشعار الأبيض** | شعار باللون الأبيض | الخلفيات الداكنة. |

## 3. المسافات الآمنة (Clear Space)
- **مسافة أفقية**: لا تقل عن 20px على جانبي الشعار.
- **مسافة رأسية**: لا تقل عن 20px أعلى وأسفل الشعار.
- **في حالة الشعار المربع**: لا تقل المسافة عن 10px من جميع الجوانب.

## 4. الأحجام الموصى بها (Minimum Sizes)

| النوع | الحد الأدنى للعرض | الحد الأدنى للارتفاع |
| :--- | :--- | :--- |
| **الشعار الأفقي** | 150px | 40px |
| **الشعار المربع** | 64px | 64px |
| **الشعار في الهيدر** | 200px | 50px |
| **الشعار في التذييل** | 150px | 40px |

## 5. الاستخدامات الممنوعة (Don'ts)

| الممنوع | لماذا؟ |
| :--- | :--- |
| **تغيير ألوان الشعار** | يؤدي إلى تشويه الهوية البصرية. |
| **تدوير الشعار** | يفقد الشعار معناه البصري. |
| **تشويه نسبة الأبعاد** | يجعل الشعار غير احترافي. |
| **إضافة ظلال أو تأثيرات** | يشتت الانتباه عن الشعار. |
| **وضع الشعار على خلفية غير مناسبة** | يجعل الشعار غير مقروء. |
| **قص أو تعديل عناصر الشعار** | يخالف هوية العلامة التجارية. |

## 6. أمثلة على الاستخدام الصحيح

### 6.1. الشعار على خلفية بيضاء
استخدم الشعار العادي (بالألوان الأساسية) على الخلفية البيضاء.

### 6.2. الشعار على خلفية داكنة
استخدم الشعار الأبيض على الخلفية الداكنة (مثل: الأزرق الأساسي أو الأسود).

### 6.3. الشعار في الهيدر
ضع الشعار في الزاوية العلوية اليسرى (أو اليمنى في حالة العربية) مع مسافة كافية عن العناصر الأخرى.

### 6.4. الشعار في المواد المطبوعة
استخدم الشعار بصيغة (SVG) عالية الجودة للحصول على أفضل طباعة.

## 7. ألوان الشعار

| العنصر | اللون | الـ Hex |
| :--- | :--- | :--- |
| **النص (عربي)** | أزرق أساسي | `#0D47A1` |
| **النص (إنجليزي)** | أزرق أساسي | `#0D47A1` |
| **الأيقونة** | أزرق أساسي | `#0D47A1` |
| **الخلفية (إذا وجدت)** | أبيض | `#FFFFFF` |
