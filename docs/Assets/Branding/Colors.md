# لوحة الألوان الأساسية (Color Palette) - NQP

## 1. الألوان الأساسية (Primary Colors)

| الاسم | الـ Hex | RGB | الاستخدام |
| :--- | :--- | :--- | :--- |
| **الأزرق الأساسي** | `#0D47A1` | `(13, 71, 161)` | الأزرار الرئيسية، العناوين، الشريط العلوي. |
| **الأزرق الداكن** | `#0A3A82` | `(10, 58, 130)` | حالات التمرير (Hover) للأزرار الرئيسية. |
| **الأزرق الفاتح** | `#42A5F5` | `(66, 165, 245)` | الخلفيات، حدود الحقول، أيقونات التنقل. |

## 2. ألوان الحالات (Status Colors)

| الاسم | الـ Hex | RGB | الاستخدام |
| :--- | :--- | :--- | :--- |
| **الأخضر (نجاح)** | `#2E7D32` | `(46, 125, 50)` | حالات (أخضر/مطمئن)، أزرار الإفراج. |
| **الأخضر الفاتح** | `#E8F5E9` | `(232, 245, 233)` | خلفية الحالة الخضراء. |
| **الأصفر (تحذير)** | `#F9A825` | `(249, 168, 37)` | حالات (أصفر/مراقبة)، أيقونات التنبيه. |
| **الأصفر الفاتح** | `#FFF8E1` | `(255, 248, 225)` | خلفية الحالة الصفراء. |
| **الأحمر (خطر)** | `#C62828` | `(198, 40, 40)` | حالات (أحمر/طارئ)، أزرار Kill Switch. |
| **الأحمر الفاتح** | `#FFEBEE` | `(255, 235, 238)` | خلفية الحالة الحمراء. |

## 3. الألوان المحايدة (Neutral Colors)

| الاسم | الـ Hex | RGB | الاستخدام |
| :--- | :--- | :--- | :--- |
| **الأبيض** | `#FFFFFF` | `(255, 255, 255)` | الخلفيات الأساسية، النصوص على الألوان الداكنة. |
| **الرمادي الفاتح جداً** | `#FAFAFA` | `(250, 250, 250)` | خلفيات الصفحات. |
| **الرمادي الفاتح** | `#F5F5F5` | `(245, 245, 245)` | خلفيات البطاقات، مناطق الفصل. |
| **الرمادي المتوسط** | `#E0E0E0` | `(224, 224, 224)` | الحدود، فواصل الجداول. |
| **الرمادي الداكن** | `#424242` | `(66, 66, 66)` | النصوص الثانوية، التواريخ. |
| **الأسود** | `#1A1A1A` | `(26, 26, 26)` | النصوص الأساسية (العناوين، الفقرات). |

## 4. ألوان واجهات محددة

| الاستخدام | اللون | الـ Hex |
| :--- | :--- | :--- |
| **خلفية البانر الرئيسي** | تراكب أزرق | `rgba(13, 71, 161, 0.8)` |
| **خلفية العناوين** | أزرق أساسي | `#0D47A1` |
| **النص على الأزرار** | أبيض | `#FFFFFF` |
| **الروابط** | أزرق أساسي | `#0D47A1` |
| **الروابط عند التمرير** | أزرق داكن | `#0A3A82` |
| **ألوان الخلفية (الوضع الليلي)** | رمادي غامق | `#1A1A2E` |
| **نصوص الوضع الليلي** | أبيض | `#FFFFFF` |

## 5. مثال على تطبيق الألوان

```css
:root {
  /* الألوان الأساسية */
  --primary: #0D47A1;
  --primary-dark: #0A3A82;
  --primary-light: #42A5F5;

  /* ألوان الحالات */
  --success: #2E7D32;
  --warning: #F9A825;
  --danger: #C62828;

  /* الألوان المحايدة */
  --white: #FFFFFF;
  --gray-light: #F5F5F5;
  --gray-medium: #E0E0E0;
  --gray-dark: #424242;
  --black: #1A1A1A;

  /* خلفيات الحالات */
  --success-bg: #E8F5E9;
  --warning-bg: #FFF8E1;
  --danger-bg: #FFEBEE;
}
