# أيقونات منصة الحجر الصحي القومي (NQP Icons)

## 1. نظرة عامة
يحتوي هذا المجلد على جميع الأيقونات المستخدمة في منصة NQP. تم تصميمها لتكون متسقة، واضحة، وقابلة للتكيف مع جميع واجهات المنصة.
