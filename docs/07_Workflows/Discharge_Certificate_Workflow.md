# WF-11: إصدار شهادة التعافي والإفراج (Discharge Certificate)

## 1. الهدف
توثيق عملية إصدار شهادة التعافي الرقمية (أو الإفراج) للمريض بعد اكتمال فترة المتابعة وتحقق معايير الشفاء، بما في ذلك (التوقيع الرقمي، توليد QR، وإتاحتها للمريض عبر بوابة المسافرين وتطبيق الجوال).

## 2. الممثلون (Actors)
- **الطبيب (Doctor)**: يطلب إصدار الشهادة بعد إغلاق الزيارة.
- **نظام NQP (Django)**: يُنشئ الشهادة، يُوقعها رقمياً، ويُولّد الـ QR.
- **المريض (Patient)**: يُطلع على الشهادة ويُحمّلها.

## 3. تدفق العملية

```mermaid
flowchart TD
    Start([بداية: طلب إصدار شهادة]) --> Step1[1. الطبيب يغلق الزيارة في بوابة (5)<br/>مع اختيار "إفراج" أو "متابعة منزلية"]
    Step1 --> Step2[2. إذا كانت المتابعة منزلية،<br/>ينتظر النظام اكتمال الأيام المحددة]

    Step12 --> End2([النهاية: تم الإصدار])

4. معايير الإصدار (Business Rules)

    شرط المدة: إكمال المدة الموصى بها (مثلاً 14 يوماً من تاريخ التشخيص).

    شرط الأعراض: 3 أيام متتالية بدون أعراض (تصنيف أخضر).

    شرط المختبر: وجود نتيجة سلبية (PCR) خلال آخر 72 ساعة.

    التوقيع الرقمي: يتم التوقيع باستخدام (RSA-SHA256) لضمان عدم التزوير.

5. نقاط النهاية الخلفية (API Endpoints)

GET	/api/v1/mobile/certificate/download/	تحميل PDF.
GET	/api/v1/certificates/verify/{hash}/	(عام) التحقق من صحة الشهادة.
