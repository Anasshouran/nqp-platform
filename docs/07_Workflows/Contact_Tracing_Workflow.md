# WF-13: تتبع المخالطين وعزلهم (Contact Tracing)

## 1. الهدف
توثيق عملية تحديد وتتبع المخالطين لحالة إيجابية (خاصة في وسائل النقل العامة مثل الطائرات)، للوصول إليهم وعزلهم وفحصهم في أسرع وقت ممكن لمنع انتشار العدوى.

## 2. الممثلون (Actors)
- **مسؤول EOC**: يقوم بعملية التتبع.
- **نظام NQP (Django)**: يستدعي بيانات الرحلة والمقاعد المجاورة.
- **المخالط (Contact)**: المستلم للإشعار.
- **فريق RRT**: يتولى متابعة المخالطين ميدانياً.

## 3. تدفق العملية

```mermaid
flowchart TD
    Start([بداية: حالة إيجابية مؤكدة]) --> Step1[1. مسؤول EOC يفتح صفحة تتبع المخالطين]
    Step1 --> Step2[2. البحث عن الحالة الإيجابية<br/>(الاسم، رقم الجواز، رقم الحالة)]
    Step2 --> Step3[3. النظام يعرض رحلة المريض الأخيرة<br/>(رقم الرحلة، التاريخ، رقم المقعد)]
    Step3 --> Step4[4. مسؤول EOC يضغط زر "استدعاء المخالطين"]
    Step4 --> Step5[5. النظام يستعلم عن جدول passenger_manifests<br/>لجلب المسافرين في المقاعد المجاورة (صفين أمام وخلف)]
    Step5 --> Step6[6. عرض قائمة المخالطين مع (الاسم، رقم الجواز، رقم المقعد، رقم الهاتف)]
    Step6 --> Step7[7. مسؤول EOC يختار المخالطين المستهدفين]
    Step7 --> Step8[8. الضغط على زر "إرسال إشعار" (SMS + Email)]
    Step8 --> Step9[9. النظام يُرسل رسالة تحذيرية للمخالطين<br/>(طلب العزل المنزلي والتواصل مع أقرب منفذ صحي)]
    Step9 --> Step10[10. فريق RRT يتواصل مع المخالطين (متابعة ميدانية)]
    Step10 --> Step11[11. تحديث حالة كل مخالط:<br/>(جديد، تم الاتصال، تم العزل، مكتمل)]
    Step11 --> Step12[12. تسجيل سجل التتبع في قاعدة البيانات]
    Step12 --> End([النهاية])

4. معايير المخالطة (Contact Definition)

    المقاعد: صفين أمام وخلف المريض (حسب إرشادات منظمة الصحة العالمية).

    طاقم الطائرة: يُعتبرون مخالطين وثيقين (يتم إشعارهم تلقائياً).

    المسافرون في نفس الحافلة/القطار: يتم تطبيق نفس المعايير للنقل البري.
