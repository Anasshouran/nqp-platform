# WF-14: مزامنة البيانات مع الأنظمة الخارجية (Integration Sync)

## 1. الهدف
توثيق عملية مزامنة البيانات بين منصة NQP والأنظمة الخارجية (وزارة الصحة، الجمارك، منظمة الصحة العالمية) بشكل دوري (ليلي/أسبوعي) أو فوري (عند الطلب) باستخدام Celery Beat Tasks.

## 2. الممثلون (Actors)
- **نظام NQP (Celery Beat)**: يقوم بجدولة المهام.
- **الأنظمة الخارجية**: (وزارة الصحة، الجمارك، WHO).
- **مسؤول النظام (Federal Admin)**: يشرف على عملية المزامنة.

## 3. أنواع المزامنة

| النوع | الوصف | التكرار | الوجهة |
| :--- | :--- | :--- | :--- |
| **المزامنة اليومية** | إرسال إحصائيات الفحوصات والحالات. | يومياً (الساعة 6 صباحاً) | وزارة الصحة |
| **المزامنة الأسبوعية** | إرسال تقرير IHR (الأمراض المدرجة). | أسبوعياً (الأحد 3 صباحاً) | المركز الوطني IHR |
| **المزامنة الفورية** | إرسال شهادة الإفراج الغذائي. | عند الإصدار | الجمارك |
| **المزامنة الواردة** | جلب تحديثات ICD-11 من WHO. | يومياً (الساعة 2 صباحاً) | WHO API |

## 4. تدفق العملية (نموذج: المزامنة اليومية مع وزارة الصحة)

```mermaid
sequenceDiagram
    participant Scheduler as Celery Beat (جدول)
    participant Task as Celery Worker
    participant NQP_DB as PostgreSQL (NQP)
    participant MOH_API as وزارة الصحة (API)

    Scheduler->>Task: 1. تشغيل المهمة (الساعة 6 صباحاً)
    Task->>NQP_DB: 2. استعلام عن بيانات اليوم السابق<br/>(الفحوصات، الحالات، الإشغال)
    NQP_DB-->>Task: 3. إرجاع البيانات المجمعة
    Task->>Task: 4. تحويل البيانات إلى JSON (بصيغة MoH المطلوبة)
    Task->>MOH_API: 5. إرسال الطلب (POST) مع مفتاح API
    alt الاتصال ناجح (200 OK)
        MOH_API-->>Task: 6. تأكيد الاستلام
        Task->>NQP_DB: 7. تسجيل نجاح المزامنة في (external_integration_logs)
    else الاتصال فاشل (5xx / Timeout)
        Task-->>Task: 8. إعادة المحاولة (Retry) بعد 5 دقائق
        alt فشل 3 مرات
            Task->>NQP_DB: 9. تسجيل الفشل وإرسال إشعار للمسؤول (Email)
        end
    end
