# WF-05: إدارة العيادات والسجلات الطبية (Clinic Workflow)

## 1. الهدف
توثيق كيفية استقبال الطبيب للإحالات الواردة من بوابة الفحص، وإجراء الفحص السريري، وطلب الفحوصات، ووصف العلاج، وإما الإفراج عن المريض أو تحويله للمتابعة.

## 2. تدفق العملية

```mermaid
flowchart TD
    Start([بداية: وصول إحالة]) --> Step1[1. الطبيب يسجل الدخول<br/>إلى بوابة العيادات (5) - React]
    Step1 --> Step2[2. عرض قائمة الإحالات الواردة<br/>مرتبة حسب الأولوية والأقدمية - Django API]
    Step2 --> Step3[3. اختيار إحالة وفتحها<br/>عرض بيانات المسافر والتقييم الأولي]
    
    Step3 --> Step4[4. الفحص السريري<br/>تسجيل العلامات الحيوية والأعراض - EMR Form]
    Step4 --> Step5[5. التشخيص المبدئي<br/>اختيار المرض من قائمة ICD-11 - Django Search API]
    
    Step5 --> Decision1{هل يحتاج فحوصات؟}
    Decision1 -- نعم --> Step6[6. طلب فحص مخبري<br/>اختيار نوع العينة والفحص المطلوب - POST to Lab API]
    Step6 --> Step7[7. طباعة باركود العينة<br/>وتسليمه للممرض لأخذ العينة - Django Report]
    Step7 --> Step8[8. انتظار النتيجة<br/>(يُتابع الطبيب عبر لوحة المتابعة) - WebSocket]
    Step8 --> Step9[9. استلام النتيجة من المختبر<br/>تظهر تلقائياً في ملف المريض - Django Signal]
    
    Decision1 -- لا --> Step10[10. وصف العلاج<br/>اختيار الدواء والجرعة والمدة - Django Drug Interaction Checker]
    
    Step9 --> Decision2{النتيجة}
    Decision2 -- سلبية --> Step11[11. إفراج المريض<br/>مع توصيات متابعة منزلية]
    Decision2 -- إيجابية --> Step10
    
    Step10 --> Step12[12. تحديث خطة العلاج<br/>وإغلاق الزيارة - Django ORM]
    Step12 --> Step13[13. تنشيط المتابعة المنزلية<br/>(إن كان المريض بحاجة لمتابعة) - Celery Task]
    Step13 --> End([النهاية])
    
    Step11 --> End

3. نقاط القرار (Decision Points)

    فحوصات إضافية: إذا كان التشخيص غير واضح، يطلب الطبيب فحوصات إضافية.

    إحالة خارجية: إذا كانت الحالة تتجاوز قدرات العيادة، يقوم الطبيب بإرسال إحالة إلى مستشفى تابع لوزارة الصحة (عبر التكامل الخارجي).

    حالة حرجة: إذا كانت العلامات الحيوية غير مستقرة، يتم تنشيط زر (طلب إسعاف) بشكل فوري، مما يرسل WebSocket إلى غرفة الطوارئ (EOC).
