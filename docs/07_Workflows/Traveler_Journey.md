# WF-01: رحلة المسافر الكاملة (Traveler Journey)

## 1. الهدف
توثيق الرحلة الكاملة للمسافر بدءاً من تسجيله المسبق قبل السفر، مروراً بالوصول إلى المنفذ، وانتهاءً بإصدار شهادة التعافي أو الإفراج النهائي. هذا هو السيناريو الأساسي (Happy Path) الذي يربط جميع البوابات معاً.

## 2. الممثلون (Actors)
- **المسافر (Traveler)**: المستخدم النهائي.
- **موظف الحجر الصحي (Port Officer)**: يستخدم بوابة (4).
- **الطبيب (Doctor)**: يستخدم بوابة (5).
- **فني المختبر (Lab Technician)**: يستخدم بوابة (6).
- **نظام تقييم المخاطر (Risk Engine)**: يعمل تلقائياً في الخلفية (Django Service).

## 3. سير العمل الرئيسي (Happy Path)

4. المسارات البديلة (Alternate Paths)

    A1 (مستندات ناقصة): في الخطوة (2)، إذا كانت المستندات غير واضحة، يتلقى المسافر إشعاراً (عبر البريد الإلكتروني) لإعادة الرفع، ويتأخر إصدار الـ QR.

    A2 (حالة حرجة في العيادة): إذا قام الطبيب بتصنيف الحالة كـ (حرجة)، يتم تجاوز خطوة المختبر وإرسال المريض مباشرة إلى المستشفى (إحالة خارجية) عبر بوابة (5).

    A3 (نتيجة غير محسومة): إذا كانت نتيجة المختبر (غير محسومة)، يُطلب إعادة الفحص خلال 24 ساعة، ويبقى المريض في الحجر المؤقت.
