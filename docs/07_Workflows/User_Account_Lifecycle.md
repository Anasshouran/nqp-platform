# WF-15: دورة حياة حساب المستخدم (User Account Lifecycle)

## 1. الهدف
توثيق سير العمل الكامل لحساب المستخدم في المنصة، بدءاً من إنشائه (تسجيل أو دعوة)، مروراً بالتفعيل، والاستخدام، وانتهاءً بالتعطيل أو الحذف.

## 2. الممثلون (Actors)
- **المستخدم (User)**: المسافر أو الموظف.
- **مسؤول النظام (Admin)**: يُنشئ الحسابات للموظفين.
- **النظام (Django)**: يدير صلاحية الحساب وإرسال الإشعارات.

## 3. تدفق العملية (للموظفين)

```mermaid
flowchart TD
    Start([بداية: طلب إنشاء حساب]) --> Step1[1. مسؤول النظام يضيف مستخدمًا<br/>عبر بوابة (8) - Django Admin]
    Step1 --> Step2[2. إدخال (الاسم، البريد، الدور، المنفذ)]
    Step2 --> Step3[3. النظام يُنشئ الحساب بحالة "غير مفعل"]
    Step3 --> Step4[4. النظام يُولّد كلمة مرور مؤقتة ويُشفرها]
    Step4 --> Step5[5. إرسال بريد إلكتروني للمستخدم الجديد<br/>(رابط تفعيل + كلمة مرور مؤقتة)]
    Step5 --> Step6[6. المستخدم يفتح البريد وينقر على رابط التفعيل]
    Step6 --> Step7[7. المستخدم يُدخل كلمة المرور المؤقتة<br/>ويُعيد تعيين كلمة مرور جديدة]
    Step7 --> Step8[8. النظام يُفعّل الحساب<br/>(is_active = True)]
    Step8 --> Step9[9. المستخدم يسجل الدخول ويُستخدم النظام]
    Step9 --> Step10{هل الحساب نشط؟}
    Step10 -- نعم --> Step11[11. استخدام عادي للبوابات]
    Step10 -- لا (انتهاء الصلاحية/مخالفة) --> Step12[12. مسؤول النظام يُعطّل الحساب<br/>(is_active = False)]
    Step12 --> Step13[13. يُمنع المستخدم من تسجيل الدخول]
    Step13 --> End([النهاية])

4. سياسة كلمة المرور
