# المتطلبات الوظيفية (Functional Requirements - FR)

## 1. مقدمة
يقسم هذا القسم المتطلبات الوظيفية حسب البوابات والأنظمة الرئيسية للمنصة. كل متطلب يحمل رمزاً فريداً لتتبعه أثناء التطوير والاختبار.

---

## 2. المتطلبات الوظيفية للبوابات (Portals)

### 2.1. الموقع العام (Public Website) - FR-PW
| المعرف | المتطلب | الأولوية |
| :---  | :---   | :---   |

| FR-PW-01 | عرض الصفحة الرئيسية التي تحتوي على آخر الأخبار والإعلانات الصحية. | عالية |

| FR-PW-02 | عرض صفحة "متطلبات السفر" المحدثة آلياً بناءً على تصنيف الدول في نظام إدارة الأمراض. | عالية |

| FR-PW-03 | توفير صفحة "الأمراض والإرشادات" مع معلومات مفصلة عن كل مرض وأعراضه. | متوسطة |

| FR-PW-04 | توفير نموذج "اتصل بنا" للاستفسارات والشكاوى. | منخفضة |

### 2.2. بوابة المسافرين (Traveler Portal) - FR-TR
| المعرف | المتطلب | الأولوية |
| :--- | :--- | :--- |

| FR-TR-01 | تمكين المسافر من إنشاء حساب جديد باستخدام البريد الإلكتروني أو رقم الجوال. | عالية |

| FR-TR-02 | تمكين المسافر من ملء استمارة الفحص الصحي (الأعراض، تاريخ السفر، التطعيمات). | عالية |

| FR-TR-03 | تمكين المسافر من رفع المستندات (صورة جواز السفر، شهادات التطعيم). | عالية |

| FR-TR-04 | توليد كود QR فريد لكل مسافر بعد إكمال التسجيل. | عالية |

| FR-TR-05 | تمكين المسافر من تتبع حالة طلبه (قيد المراجعة، مكتمل، مرفوض). | متوسطة |

| FR-TR-06 | توفير لوحة تحكم تعرض الملف الصحي للمسافر (التاريخ الطبي السابق). | متوسطة |

### 2.3. بوابة موظفي الحجر (Port Health) - FR-PH
| المعرف | المتطلب | الأولوية |
| :--- | :--- | :--- |

| FR-PH-01 | تمكين الموظف من مسح كود QR الخاص بالمسافر لعرض ملفه الصحي. | عالية |

| FR-PH-02 | تمكين الموظف من تسجيل قراءات الفحص الظاهري (الحرارة، SpO2، الضغط). | عالية |

| FR-PH-03 | عرض تصنيف المخاطر (أخضر/أصفر/أحمر) آلياً بعد إدخال القراءات. | عالية |

| FR-PH-04 | تمكين الموظف من إحالة المسافر إلى العيادة إلكترونياً بنقرة واحدة. | عالية |

| FR-PH-05 | توفير لوحة تحكم تعرض إحصائيات الرحلات القادمة والمنتظرة. | متوسطة |

### 2.4. بوابة العيادات (Clinic Portal) - FR-CL
| المعرف | المتطلب | الأولوية |

| :--- | :--- | :--- |

| FR-CL-01 | عرض قائمة الإحالات الواردة من بوابة موظفي الحجر. | عالية |

| FR-CL-02 | تمكين الطبيب من إنشاء سجل طبي إلكتروني (EMR) لكل مريض. | عالية |

| FR-CL-03 | تمكين الطبيب من إجراء الفحص السريري وتوثيق النتائج. | عالية |

| FR-CL-04 | تمكين الطبيب من إرسال طلب فحص مخبري إلى بوابة المختبرات. | عالية |

| FR-CL-05 | تمكين الطبيب من وصف العلاج وتحديد خطة المتابعة. | عالية |

| FR-CL-06 | تمكين الطبيب من إصدار تقرير طبي نهائي (الإفراج/الإحالة للمستشفى). | عالية |

### 2.5. بوابة المختبرات (Laboratory Portal) - FR-LB
| المعرف | المتطلب | الأولوية |
| :--- | :--- | :--- |
| FR-LB-01 | تمكين فني المختبر من تسجيل العينات الواردة من العيادات (مع باركود). | عالية |
| FR-LB-02 | تمكين فني المختبر من تتبع حالة العينة (قيد التحليل، مكتمل). | متوسطة |
| FR-LB-03 | تمكين فني المختبر من إدخال نتيجة الفحص (إيجابي/سلبي) بعد التحليل. | عالية |
| FR-LB-04 | تمكين المشرف المخبري من اعتماد النتائج. | عالية |
| FR-LB-05 | إرسال النتيجة المعتمدة تلقائياً إلى بوابة العيادات ونظام الترصد. | عالية |

### 2.6. بوابة غرفة الطوارئ (EOC) - FR-EC
| المعرف | المتطلب | الأولوية |
| :--- | :--- | :--- |
| FR-EC-01 | عرض خريطة تفاعلية للمنافذ مع حالة الإنذار لكل منفذ (أخضر/أصفر/أحمر). | عالية |
| FR-EC-02 | عرض التنبيهات الحمراء (الحالات الحرجة) فور ورودها مع إحداثيات الموقع. | عالية |
| FR-EC-03 | تمكين فريق الطوارئ من توجيه فرق الاستجابة السريعة (RRT) عبر النظام. | عالية |
| FR-EC-04 | تمكين الفريق من تفعيل خاصية (Kill Switch) لإيقاف الإفراج في منفذ معين. | عالية |
| FR-EC-05 | توفير أداة لتتبع المخالطين (سحب بيانات المسافرين في المقاعد المجاورة). | متوسطة |
