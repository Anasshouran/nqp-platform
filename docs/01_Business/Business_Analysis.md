## 1. ملخص تنفيذي

منصة الحجر الصحي القومي (NQP) نظام رقمي متكامل لإدارة الحجر الصحي البشري والغذائي،
الفحوصات، المختبر، الطوارئ، والتكاملات في منافذ دخول السودان. التحليل أدناه يعكس
**الحالة الفعلية المبنية حالياً** (وليس الرؤية المثالية فقط)، ويحدد الفجوات وأولويات
التنفيذ. الوثيقة تُكمّل الملفات المنفصلة في `docs/01_Business/` بلا تكرار، وتركّز على
التجميع والتحليل والتوصيات.

## 3. المتطلبات غير الوظيفية (Non-Functional Requirements)

> التفاصيل في `docs/01_Business/Non_Functional_Requirements.md` (NFR-01 إلى NFR-15).
> الجدول أدناه يضيف تقييم الحالة الفعلية والفجوات.

| المعرف | البعد | الهدف | الحالة الفعلية |
| :--- | :--- | :--- | :--- |
| NFR-01 | زمن استجابة API | < 200ms | قابل للتحقيق (REST بسيط + ترقيم) — بلا اختبار أداء موثّق |
| NFR-05 | التوفر | 99.9% | **فجوة**: الخوادم تتوقف عند انقطاع PG/الجلسة؛ لا systemd/Docker موثّق |
| NFR-06 | التعافي من الكوارث | RTO<4h، RPO<15m | **فجوة**: DBAS يعرّف الخطط لكن لا جدولة نسخ فعلية |
| NFR-09 | RBAC + MFA | مصادقة ثنائية للمسؤولين | RBAC مبني؛ **MFA غير مبني** |
| NFR-10 | سجل التدقيق | تسجيل كل العمليات الحساسة | مبني جزئياً (`PermissionAudit`) — يحتاج توسيعاً |
| NFR-13 | سهولة التدريب | إتقان خلال يوم تدريبي | لوحات الأدوار تساعد — يحتاج دليل مستخدم |
| NFR-14 | توثيق OpenAPI | محدّث باستمرار | drf-spectacular متاح — بلا فحص CI |
| NFR-15 | الوحدات النمطية | بوابة مستقلة عن أخرى | مبني (تطبيقات Django منفصلة) ✔ |

### فجوات NFR ذات الأولوية
1. **استقرار الخدمة**: سكربت تشغيل موحّد (`scripts/dev.sh`) + health-check.
2. **الأمان**: `DEBUG=True` افتراضي + `CORS_ALLOW_ALL_ORIGINS` عند غياب البيئة.
3. **CI**: GitHub Actions فارغ + ESLint بلا إعداد.
4. **تغطية الاختبارات**: 6 من 16 تطبيقاً فقط مختبرة؛ Frontend بلا اختبارات.

| الدور | الكود | الصلاحيات الرئيسة | الحالة |

## 6. التحسينات المقترحة (Suggested Improvements)

### 6.1 أولوية عالية (التنفيذ التالي)
1. **بناء وحدة الهيكل الإداري** (`apps/organization`): مناصب قيادية + قطاعات (6) +
   أقسام (11) + تعيينات، مع صفحة شجرة هرمية عربية.
   > ✅ **مبني** — رابط `/app/organization` + أمري بذر + RBAC محدد بالنطاق.
2. **إصلاح RBAC**: إزالة AUTO-ADMIN من البذر؛ توحيد الحقلين؛ تفعيل `PermissionAction`
   على كل الـ Viewsets (حالياً accounts فقط).
3. **ربط النطاق**: تفعيل `ScopeFilter` في الوحدات حسب القطاع/القسم.
4. **لوحات الأدوار المتبقية**: مدير مختبر، غرفة طوارئ، مفتش غذاء، مدير قطاع.
5. **سكربت تشغيل موحّد** + تفعيل CI + ضبط إعدادات الإنتاج.

### 6.2 أولوية متوسطة
6. سجل تدقيق تلقائي لكل تعديل صلاحيات/DDL.
7. إشعارات فورية (WebSocket/SSE) للإنذارات.
8. دمج مكتبة رسم واحدة وتقليل الحزمة (~380KB).

### 6.3 أولوية منخفضة
9. دعم اللغة الإنجليزية (i18n).
10. تقارير قيادية (وزارة) قابلة للتصدير PDF/Excel.
