# قصص المستخدمين (User Stories)

## 1. مقدمة
صيغت قصص المستخدمين وفقاً للصياغة التقليدية:
"كـ [نوع المستخدم]، أريد [الهدف] بحيث يمكنني [الغاية/القيمة المضافة]."
تم ترتيبها حسب الأولوية (Must Have، Should Have، Could Have، Won't Have) لتوجيه سباقات التطوير (Sprints).

---

## 2. قصص المستخدمين - بوابة المسافرين (Traveler Portal)

### الأولوية: Must Have
| المعرف | القصة |
| :--- | :--- |
| US-TR-01 | كـ مسافر، أريد إنشاء حساب شخصي على البوابة، بحيث يمكنني تسجيل بياناتي الصحية ومستنداتي مسبقاً قبل السفر. |
| US-TR-02 | كـ مسافر، أريد ملء استمارة الفحص الصحي (الأعراض والأسئلة الوبائية)، بحيث لا أضطر لتعبئة نماذج ورقية عند الوصول. |
| US-TR-03 | كـ مسافر، أريد رفع صور المستندات (جواز السفر وشهادات التطعيم)، بحيث يتم التحقق منها آلياً دون تدخل بشري. |
| US-TR-04 | كـ مسافر، أريد الحصول على رمز QR فريد بعد إكمال التسجيل، بحيث أستطيع عرضه في المنفذ لتسريع إجراءاتي. |

### الأولوية: Should Have
| المعرف | القصة |
| :--- | :--- |
| US-TR-05 | كـ مسافر، أريد تتبع حالة طلبي (معتمد، قيد المراجعة)، بحيث أعرف ما إذا كنت مؤهلاً للسفر أم لا. |
| US-TR-06 | كـ مسافر، أريد رؤية تاريخي الصحي السابق (الملف الصحي)، بحيث يمكنني متابعة تطعيماتي وفحوصاتي السابقة. |

---

## 3. قصص المستخدمين - بوابة موظفي الحجر (Port Health)

### الأولوية: Must Have
| المعرف | القصة |
| :--- | :--- |
| US-PH-01 | كـ موظف حجر، أريد مسح رمز QR الخاص بالمسافر لعرض بياناته، بحيث أتمكن من التحقق من هويته بسرعة. |
| US-PH-02 | كـ موظف حجر، أريد إدخال قراءات الفحص (الحرارة والأكسجين)، بحيث يقوم النظام بتقييم المخاطر تلقائياً. |
| US-PH-03 | كـ موظف حجر، أريد رؤية تصنيف المخاطر (أخضر/أصفر/أحمر) مباشرة، بحيث أعرف القرار المناسب (دخول/حجر/إحالة). |
| US-PH-04 | كـ موظف حجر، أريد إحالة المسافر للعيادة إلكترونياً، بحيث يصل ملفه للطبيب دون تأخير. |

---

## 4. قصص المستخدمين - بوابة العيادات (Clinic Portal)

### الأولوية: Must Have
| المعرف | القصة |
| :--- | :--- |
| US-CL-01 | كـ طبيب، أريد الاطلاع على قائمة الإحالات الواردة من المطار، بحيث يمكنني استقبال المرضى بشكل منظم. |
| US-CL-02 | كـ طبيب، أريد فتح ملف طبي إلكتروني (EMR) للمريض، بحيث يمكنني تسجيل جميع ملاحظاتي وتشخيصاتي بدقة. |
| US-CL-03 | كـ طبيب، أريد إرسال طلب فحص مخبري بنقرة واحدة، بحيث تصل عينة المريض للمختبر مع البيانات الصحيحة. |
| US-CL-04 | كـ طبيب، أريد وصف الدواء وجدول العلاج، بحيث تظهر المنبهات في تطبيق المتابعة للمريض. |

### الأولوية: Should Have
| المعرف | القصة |
| :--- | :--- |
| US-CL-05 | كـ طبيب، أريد إصدار شهادة إفراج صحي عند تعافي المريض، بحيث يغادر الحجر بشكل رسمي. |

---

## 5. قصص المستخدمين - بوابة غرفة الطوارئ (EOC)

### الأولوية: Must Have
| المعرف | القصة |
| :--- | :--- |
| US-EC-01 | كـ مسؤول غرفة العمليات، أريد رؤية خريطة تفاعلية للمنافذ مع حالة الإنذار الخاصة بها، بحيث يمكنني تتبع جميع المنافذ من مكان واحد. |
| US-EC-02 | كـ مسؤول غرفة العمليات، أريد تلقي إنذار فوري (صوتي ومرئي) عند اكتشاف حالة حمراء (حرجة)، بحيث أستطيع تفعيل خطة الاستجابة دون تأخير. |
| US-EC-03 | كـ مسؤول غرفة العمليات، أريد تفعيل خاصية (Kill Switch)، بحيث يمكنني إيقاف أو تعليق عمليات الإفراج في منفذ مهدد وبائياً بسرعة. |
| US-EC-04 | كـ مسؤول غرفة العمليات، أريد عرض بيانات المخالطين لرحلة معينة، بحيث يمكنني توجيه الفرق لعزلهم وفحصهم. |

---

## 6. قصص المستخدمين - بوابة الحجر الغذائي (Food Quarantine)

### الأولوية: Must Have
| المعرف | القصة |
| :--- | :--- |
| US-FQ-01 | كـ مفتش الحجر الغذائي، أريد تسجيل الشحنات الغذائية الواردة إلكترونياً، بحيث يتم ربطها بطلب التفتيش. |
| US-FQ-02 | كـ مفتش الحجر الغذائي، أريد أخذ عينات من الشحنة وربطها بباركود، بحيث يتم تتبعها حتى ظهور النتيجة. |
| US-FQ-03 | كـ مفتش الحجر الغذائي، أريد إصدار شهادة إفراج صحي إلكترونية، بحيث يتم إرسالها آلياً إلى الجمارك لإنهاء الإجراءات. |

---

## 7. قصص المستخدمين - نظام المتابعة الصحية (Health Follow-up)

### الأولوية: Must Have
| المعرف | القصة |
| :--- | :--- |
| US-HF-01 | كـ مريض، أريد الإبلاغ عن الأعراض والعلامات الحيوية يومياً عبر تطبيق الهاتف، بحيث يتابع الطبيب حالتي عن بُعد. |
| US-HF-02 | كـ مريض، أريد استقبال تذكير بمواعيد تناول الأدوية، بحيث لا أنسى الجرعات. |
| US-HF-03 | كـ مريض، أريد الحصول على شهادة تعافي رقمية بعد تجاوز مرحلة المرض، بحيث أستطيع استخدامها للسفر أو العمل. |
| US-HF-04 | كـ طبيب متابعة، أريد رؤية قائمة المرضى المصنفين حسب درجة الخطورة (أحمر أولاً)، بحيث أستطيع التدخل للحالات الحرجة فوراً. |

---

## 8. قصص المستخدمين - الإدارة الاتحادية (Federal Admin)

### الأولوية: Must Have
| المعرف | القصة |
| :--- | :--- |
| US-FA-01 | كـ مدير النظام، أريد إنشاء وإدارة صلاحيات المستخدمين (RBAC)، بحيث يكون لكل موظف دور محدد لا يتجاوزه. |
| US-FA-02 | كـ مدير النظام، أريد مشاهدة لوحة المؤشرات الرئيسية (KPIs) للحجر الصحي، بحيث يمكنني تقييم أداء جميع المنافذ. |
| US-FA-03 | كـ مدير النظام، أريد تصدير التقارير الوطنية بصيغة (PDF/Excel)، بحيث أرفعها لوزارة الصحة. |
