# سير العمل الحالي (Current Workflow - As-Is)

## 1. نظرة عامة على الوضع الراهن
تعتمد عملية الحجر الصحي في المنافذ السودانية حالياً على **نظام ورقي شبه تقليدي** مع وجود بعض الحلول الإلكترونية المحدودة غير المتصلة ببعضها. يعاني هذا النظام من التجزؤ وضعف التنسيق، مما يؤدي إلى بطء الإجراءات وازدواجية تسجيل البيانات.

## 2. رحلة المسافر الحالية (Current Traveler Journey)
| الخطوة | الوصف | الجهة المسؤولة | نقاط الألم (Pain Points) |
| :--- | :--- | :--- | :--- |
| **1. الوصول** | يصل المسافر إلى المنفذ (مطار/ميناء). | المسافر | تكدس طوابير طويلة. |

| **2. التسجيل اليدوي** | يقوم موظف الحجر بتسجيل بيانات المسافر (جواز السفر، العنوان، جهة القدوم) في سجل ورقي كبير. | موظف الحجر | أخطاء في الكتابة، ضياع الأوراق، عدم وضوح الخط. |

| **3. الفحص الظاهري** | يتم قياس الحرارة باستخدام جهاز (مقياس حرارة) وتسجيل النتيجة يدوياً. | موظف التمريض | لا يتم تسجيل قراءات دقيقة بشكل منهجي. |

| **4. التقييم** | يعتمد الطبيب أو الموظف على خبرته الشخصية لتقييم المخاطر. | الطبيب | قرارات غير موحدة، تباين في التصنيفات. |

| **5. الإحالة أو الإفراج** | إما يتم إفراج المسافر، أو إحالته للعيادة. | الطبيب / الموظف | في حال الإحالة، يتم إرسال المسافر ورقياً للعيادة مما يضيع الوقت. |

| **6. العيادة والمختبر** | يقوم الطبيب بكتابة تقرير طبي يدوي، ويتم أخذ عينة وإرسالها للمختبر مع ورقة مصاحبة. | الطبيب، فني المختبر | فقدان العينات، خلط بين أسماء المرضى، تأخر نتائج المختبر (أيام). |

| **7. المتابعة** | لا يوجد نظام متابعة منزلية. يغادر المسافر ولا تُعرف حالته بعد ذلك. | لا يوجد | عدم تتبع المضاعفات، ضياع فرصة التعلم من مسار المرض. |

## 3. تحديات الحجر الغذائي الحالية (Current Food Challenges)
- الاعتماد على التفتيش البصري فقط دون وجود مختبرات متنقلة.
- يتم إصدار شهادات الإفراج يدوياً بواسطة المفتشين، مما يسهل عملية التزوير.
- عدم الربط مع هيئة المواصفات والمقاييس لفحص المطابقة آلياً.

## 4. تحديات التنسيق الحكومي
- كل جهة (الصحة، الجمارك، الزراعة) تعمل بنظامها المنعزل.
- يتم تبادل المعلومات عبر الفاكس أو البريد الإلكتروني العادي، مما يشكل خطراً على أمن البيانات.
- غياب الرؤية الشاملة (لوحة القيادة) لصناع القرار في وزارة الصحة.
