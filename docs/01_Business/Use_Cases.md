# حالات الاستخدام (Use Cases)

## 1. مقدمة
حالات الاستخدام تصف التفاعلات النموذجية بين المستخدمين (الممثلين - Actors) والنظام لتحقيق هدف معين. تم تصميم هذه الحالات لتوجيه فريق التطوير والاختبار.

## 2. قائمة حالات الاستخدام الرئيسية

| المعرف | حالة الاستخدام (Use Case) | الممثل الأساسي (Primary Actor) | الموجز |
| :--- | :--- | :--- | :--- |
| UC-01 | تسجيل المسافر المسبق | المسافر | يقوم المسافر بإنشاء حساب، وملء الاستمارة، ورفع المستندات، والحصول على QR. |
| UC-02 | فحص المسافر عند الوصول | موظف الحجر | يقوم الموظف بمسح QR، قياس العلامات الحيوية، ويصدر النظام تقييم المخاطر. |
| UC-03 | إحالة الحالة للعيادة | موظف الحجر | يقوم النظام بإرسال بيانات المسافر إلكترونياً إلى العيادة. |
| UC-04 | إجراء فحص سريري | الطبيب | يطلع الطبيب على الإحالة، يسجل التشخيص، ويطلب فحوصات أو يصف علاجاً. |
| UC-05 | إدخال نتيجة المختبر | فني المختبر | يقوم الفني بإدخال النتيجة (إيجابي/سلبي) ويقوم المشرف باعتمادها. |
| UC-06 | متابعة المريض منزلياً | المريض | يقوم المريض بإدخال الأعراض يومياً، ويقوم النظام بتقييم حالته وإصدار الشهادة. |
| UC-07 | إدارة تفشي وبائي | مسؤول الطوارئ (EOC) | يقوم مسؤول الطوارئ بمشاهدة الإنذارات، وتوجيه الفرق، وتفعيل Kill Switch. |

## 3. حالة الاستخدام التفصيلية - نموذج (UC-02: فحص المسافر عند الوصول)

| الحقل | التفاصيل |
| :---   | :--- |

| المعرف | UC-02 |

| الاسم | فحص المسافر عند الوصول |

| الوصف | يقوم موظف الحجر الصحي بإجراء الفحص الظاهري للمسافر وتحديد ما إذا كان يحتاج إلى حجر أم لا. |

| الممثل الأساسي | موظف الحجر الصحي (Port Health Officer) |

| الممثلون الثانويون | المسافر، نظام تقييم المخاطر (Risk Engine) |

| الشروط المسبقة (Pre-conditions) | المسافر مسجل مسبقاً في النظام (لديه QR Code). |

| الشروط اللاحقة (Post-conditions) | تم إصدار قرار للدخول، أو الإحالة للعيادة، أو الحجر. |

| مسار النجاح الرئيسي | 1. يقوم الموظف بتسجيل الدخول إلى بوابة موظفي الحجر. 2. يقوم بمسح QR Code الخاص بالمسافر. 3. يظهر ملف المسافر على الشاشة (البيانات المسجلة مسبقاً). 4. يقوم الموظف بقياس (الحرارة، SpO2). 5. يقوم بإدخال القراءات في النظام. 6. يقوم محرك تقييم المخاطر بحساب التصنيف خلال ثوانٍ. 7. يظهر التصنيف (أخضر/أصفر/أحمر). 8. الموظف يبلغ المسافر بالقرار. |

| المسارات البديلة | A1: إذا كانت البيانات المسجلة مسبقاً غير مكتملة، يطلب الموظف من المسافر إكمالها عبر تطبيق الجوال. A2: إذا كان التصنيف (أحمر)، يتم إرسال إشعار تلقائي لغرفة الطوارئ. |

| متطلبات خاصة | يجب أن تكون عملية مسح QR سريعة، وألا تستغرق أكثر من ثانيتين. |
