# المساعد الذكي للمنصة (AI Assistant - Chatbot)

## 1. الهدف الاستراتيجي
تقديم مساعد ذكي (Chatbot / Virtual Assistant) مدمج في المنصة لمساعدة المستخدمين (المسافرين، الموظفين، الأطباء) في الحصول على إجابات سريعة للأسئلة الشائعة، وتوجيههم إلى الخدمات المناسبة، وتوفير توصيات ذكية بناءً على البيانات المتاحة، مع تقليل الضغط على فريق الدعم الفني.

## 2. الميزات الرئيسية
| الميزة | الوصف | الفئة المستهدفة | التقنية المستخدمة |
| :--- | :--- | :--- | :--- |
| **الرد على الأسئلة الشائعة** | الإجابة على أسئلة المستخدمين حول (التسجيل، الفحص، الحجر، الشهادات). | المسافرون، المواطنون | LLM (GPT-4 / Mistral) + RAG |
| **توجيه المستخدم** | توجيه المستخدم إلى الصفحة أو الخدمة المناسبة (مثل: "كيف أحصل على QR؟"). | جميع الفئات | Classifier + Rules Engine |
| **توصيات طبية مبدئية** | تقديم توصيات طبية مبدئية بناءً على الأعراض المدخلة (مع إخلاء مسؤولية). | المرضى | Symptom Checker (Decision Tree) |
| **تحليل البيانات** | (للمسؤولين) تقديم تحليلات سريعة عن أداء المنافذ والحالات. | الإدارة | LLM + Data Analysis |
| **الدعم متعدد اللغات** | دعم اللغة العربية والإنجليزية. | جميع الفئات | LLM (Multilingual) |

## 3. التقنية المستخدمة

### 3.1. النموذج اللغوي (LLM)
- **الخيار الأول**: استخدام (OpenAI GPT-4) عبر API (للدقة العالية).
- **الخيار الثاني**: استخدام نموذج مفتوح المصدر (Mistral 7B) مع تخصيص (Fine-tuning) على بيانات المنصة (للخصوصية والأمان).
- **الخيار الثالث (مستقبلي)**: استخدام نموذج (Llama 3) المستضاف محلياً.

### 3.2. Retrieval-Augmented Generation (RAG)
- **قاعدة المعرفة**: يتم تغذية النموذج بـ (الأسئلة الشائعة، السياسات، البروتوكولات، الوثائق الرسمية) من قاعدة البيانات (PostgreSQL).
- **آلية العمل**:
  1.  يتم تحويل المستندات إلى (Embeddings) باستخدام نموذج (all-MiniLM-L6-v2).
  2.  تخزين الـ Embeddings في (Vector Database) مثل (Pinecone) أو (ChromaDB).
  3.  عند استلام سؤال المستخدم، يتم البحث عن المستندات الأكثر صلة في (Vector DB).
  4.  يتم إرسال المستندات + السؤال إلى (LLM) لتوليد إجابة دقيقة ومحددة.

### 3.3. التكامل مع Django
```python
# apps/ai/services/chatbot_service.py
import openai
from django.conf import settings
from apps.ai.vector_store import VectorStore

class ChatbotService:
    def __init__(self):
        self.vector_store = VectorStore()
        openai.api_key = settings.OPENAI_API_KEY

    def get_response(self, user_query: str, user_context: dict) -> str:
        # 1. البحث عن المستندات ذات الصلة
        relevant_docs = self.vector_store.similarity_search(user_query, k=5)

        # 2. بناء السياق
        context = "\n".join([doc.page_content for doc in relevant_docs])

        # 3. توليد الإجابة باستخدام LLM
        response = openai.ChatCompletion.create(
            model="gpt-4",
            messages=[
                {"role": "system", "content": "أنت مساعد لمنصة الحجر الصحي القومي. أجب بدقة وباختصار."},
                {"role": "user", "content": f"السياق: {context}\n\nالسؤال: {user_query}"}
            ]
        )
        return response.choices[0].message.content

6. المراقبة والتحسين

    تسجيل المحادثات: يتم تسجيل جميع المحادثات (مجهولة الهوية) لتحسين النموذج.

    تقييم الرضا: طلب تقييم (👍/👎) من المستخدم بعد كل محادثة.

    التدريب المستمر: إعادة تدريب النموذج شهرياً على البيانات الجديدة.
