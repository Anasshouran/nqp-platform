# 05_Emergency_UI_UX - شاشات نظام إدارة الطوارئ

## 1. شاشة الإبلاغ عن حدث (للأطباء والموظفين)

### مكونات الشاشة (نموذج إبلاغ سريع):
1.  **عنوان**: "الإبلاغ عن حدث صحي طارئ"
2.  **نوع الحدث**: قائمة منسدلة (مرض معدي، تسمم غذائي، كارثة، أخرى).
3.  **العنوان**: حقل نصي مختصر (مثال: "اشتباه بحمى نزفية في المطار").
4.  **الوصف التفصيلي**: حقل نصي كبير (يجب ذكر الأعراض، الأماكن، والأشخاص المتأثرين).
5.  **مصدر الحدث**: (فحص، مختبر، عيادة، عامة).
6.  **المنفذ**: اختيار المنفذ المعني.
7.  **درجة الشدة**: اختيار (LOW, MODERATE, HIGH, CRITICAL) مع توصيات توضيحية لكل منها.
8.  **المتأثرون**: إمكانية إضافة معرفات المسافرين المتأثرين (اختياري).
9.  **زر**: (إرسال البلاغ) - باللون البرتقالي (تحذيري).
10. **زر**: (إلغاء) - باللون الرمادي.

---

## 2. لوحة تحكم إدارة الأزمات (لـ EOC)

### مكونات الشاشة (لوحة القيادة الرئيسية):
1.  **شريط الملخص العلوي (KPI Cards)**:
    - الأحداث النشطة (مفتوحة).
    - الأحداث ذات الأولوية (HIGH / CRITICAL).
    - الأحداث التي تم حلها (CLOSED) اليوم.
2.  **قائمة الأحداث النشطة**: جدول يعرض (الرقم، العنوان، المنفذ، الشدة، الحالة، الوقت المنقضي).
    - تمييز الصفوف بالألوان: (أحمر لـ CRITICAL، برتقالي لـ HIGH، أصفر لـ MODERATE).
3.  **زر**: (عرض التفاصيل) لكل حدث.
4.  **زر**: (إنشاء بلاغ جديد) - بارز في الأعلى.

---

## 3. شاشة تفاصيل الحدث وإدارة الأزمة (لـ EOC)

### مكونات الشاشة:
1.  **بطاقة معلومات الحدث**: (الرقم، العنوان، الحالة، الشدة، وقت الإبلاغ).
2.  **شريط تقدم دورة الحياة (Lifecycle Progress)**:
    - IDENTIFIED → VERIFIED → RESPONDING → CONTROLLED → CLOSED.
    - مع إضاءة الخطوة الحالية باللون الأزرق.
3.  **قسم فريق الاستجابة**: عرض أعضاء الفريق المعينين (القائد، الفرق الطبية، الخدمات اللوجستية) مع زر (تعديل الفريق).
4.  **قسم خطة الاستجابة**: عرض الخطة المُفعّلة (الخطوات، الموارد) مع زر (تعديل الخطة) وزر (تسجيل إجراء جديد).
5.  **سجل الإجراءات (Timeline)**: عرض جميع الإجراءات المتخذة (التواريخ، الأوصاف، من قام بها).
6.  **قسم تقرير الإغلاق**: (يظهر عندما تكون الحالة CONTROLLED) - نموذج لإدخال (الدروس المستفادة، التوصيات) وزر (إغلاق الأزمة).

---

## 4. شاشة إدارة خطط الاستجابة (للمسؤولين)

### مكونات الشاشة:
1.  **جدول الخطط**: عرض (الاسم، نوع الحدث، الإصدار، الحالة، تاريخ التحديث).
2.  **زر**: (إضافة خطة جديدة) - نموذج يحتوي على:
    - الاسم، نوع الحدث، الوصف.
    - **معايير التفعيل**: (مثل: عدد الحالات الأدنى للإبلاغ).
    - **الخطوات**: قائمة ديناميكية لإضافة خطوات الاستجابة مع ترتيب زمني.
    - **الموارد المطلوبة**: قائمة بالموارد (أدوية، معدات، فرق).
    - **خطة الاتصال**: جهات الاتصال الأساسية.
3.  **زر**: (تعديل) و (تعطيل) لكل خطة.
