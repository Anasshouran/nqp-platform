# 01_System_Overview - نظام إدارة الطوارئ والأزمات الصحية

## 1. الهدف الاستراتيجي (Strategic Objective)
يهدف نظام إدارة الطوارئ والأزمات الصحية إلى **توفير إطار رقمي متكامل لإدارة دورة حياة الأحداث الصحية الطارئة**، بدءاً من الإبلاغ عنها، مروراً بتفعيل خطط الاستجابة، وانتهاءً بإدارة الأزمة بالكامل وتحليل الدروس المستفادة. يعمل هذا النظام كطبقة **تخطيطية واستراتيجية** تكمل طبقة العمليات اللحظية (غرفة العمليات - EOC).

## 2. النطاق الوظيفي (Functional Scope)
| الوظيفة | الوصف |
| :--- | :--- |
| **الإبلاغ عن الأحداث (Event Reporting)** | تمكين الموظفين (في المنافذ، العيادات، المختبرات) من الإبلاغ عن أحداث صحية مشتبه بها (حالة فردية، تفشي، خطر بيئي) عبر نموذج موحد. |
| **متابعة خطط الاستجابة (Response Plans)** | إدارة مكتبة من خطط الاستجابة الجاهزة (قابلة للتكوين) لكل نوع من الأحداث (جائحة، كارثة طبيعية، تسمم غذائي)، مع ربطها بالموارد والإجراءات المطلوبة. |
| **إدارة الأزمات الصحية (Crisis Management)** | تتبع دورة حياة الأزمة بالكامل (مُحددة، مُحققة، قيد الاستجابة، مُسيطر عليها، مُغلقة) مع تعيين الأدوار، وإدارة اجتماعات الأزمات، وتوليد تقارير ما بعد الأزمة. |

## 3. التكامل مع البوابات الأخرى (Integration Matrix)
| البوابة/النظام | نوع التكامل | الغرض |
| :--- | :--- | :--- |
| **بوابة موظفي الحجر (4)** | إرسال تنبيه | عند اكتشاف حالة مشتبه بها، يمكن للموظف الإبلاغ عنها كحدث طارئ. |
| **بوابة المختبرات (6)** | إرسال تلقائي | اكتشاف مجموعة من النتائج الإيجابية لنفس المرض في منفذ واحد قد يُولّد حدثاً تلقائياً. |
| **بوابة العيادات (5)** | إرسال تقرير | إذا شخّص الطبيب حالة لمرض نادر أو خطير، يقدم تقريراً للطوارئ. |
| **غرفة العمليات (EOC - 9)** | تبادل بيانات ثنائي | تتلقى لوحة EOC بيانات الأحداث والخطط، وترسل تحديثات الحالة إلى نظام إدارة الأزمات. |
| **نظام الترصد الوبائي** | استقبال بيانات | تغذية نظام الترصد ببيانات الأحداث لتحليل الأنماط والإنذار المبكر. |
| **وزارة الصحة / WHO** | إبلاغ خارجي | توليد تقارير للتبليغ الدولي (IHR) عند تفعيل حالة الطوارئ الصحية العامة (PHEIC). |

## 4. المبادئ الأساسية للتصميم
- **المرونة (Flexibility)**: يجب أن تكون خطط الاستجابة قابلة للتعديل بسهولة لتتناسب مع طبيعة كل حدث.
- **التسلسل الزمني الكامل (Full Audit Trail)**: تسجيل كل إجراء (إبلاغ، قرار، تعيين فريق، تغيير حالة) مع التوقيت والمسؤول.
- **التوافق مع IHR**: تم تصميم النظام لدعم متطلبات اللوائح الصحية الدولية (IHR 2005) في الإبلاغ عن الأحداث.
- **التنبيه الذكي (Smart Alerts)**: نظام تنبيهات آلي لرفع علم (Flag) عند استيفاء شروط معينة (مثل: 3 حالات من نفس المرض خلال 24 ساعة).
