# 22_Vector_Control_System - نظام مكافحة النواقل

## 1. الهدف الاستراتيجي
نظام دورة حياة كاملة لمكافحة النواقل في نقاط الدخول (مطارات/موانئ/معابر برية): مسح → تقييم مخاطر → خطة → أمر عمل → تنفيذ → استهلاك موارد → متابعة فعالية → إغلاق.

## 2. التكامل مع الأنظمة الأخرى
- **صحة المطارات/الموانئ/المعابر البرية**: نقطة الدخول كيان مشترك (EntryPoint).
- **محرك المخاطر (risk_engine)**: تعميم التقييم على النواقل.
- **FCLIS**: تحاليل النواقل والعينات.
