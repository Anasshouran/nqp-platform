

# 01_Public_Website - الموقع العام للمنصة

## 1. الهدف الاستراتيجي
يمثل الموقع العام (Public Website) **الواجهة الأمامية التعريفية والخدمية** لمنصة الحجر الصحي القومي (NQP). وهو موجه لجميع فئات المجتمع (المسافرين، المواطنين، الإعلام، وشركات الطيران) لتوفير:
- **المعلومات الرسمية**: آخر الأخبار الصحية، متطلبات السفر، تعريفات الأمراض.
- **الخدمات الذاتية**: التسجيل المسبق للمسافرين، تحميل الوثائق، الاستعلام عن حالة الطلب.
- **التوجيه**: توجيه المستخدمين إلى البوابات المتخصصة (العيادات، الموظفين، الإدارة) عبر بوابة تسجيل الدخول الموحدة.

## 2. المميزات الرئيسية (Key Features)
- **تصميم عصري ومستجيب (Responsive)**: يعمل بكفاءة على جميع الأجهزة (حاسوب، جهاز لوحي، جوال) باستخدام (React + Tailwind CSS).
- **ثنائي اللغة (RTL/LTR)**: دعم كامل للغة العربية والإنجليزية مع تبديل سلس.
- **سهولة الوصول (Accessibility)**: متوافق مع معايير WCAG 2.1 لضمان استخدام الجميع.
- **محرك بحث قوي**: للبحث في الأخبار، الوثائق، والأسئلة الشائعة.
- **ربط آمن**: جميع النماذج والبيانات تُرسل عبر (HTTPS) مع حماية (CSRF) المدمجة في Django.

## 3. الهيكل التنظيمي للموقع (Sitemap)

| القسم | المسار (URL) | الوصف |
| :--- | :--- | :--- |
| **الصفحة الرئيسية** | `/` | واجهة ترحيبية مع آخر الأخبار وروابط سريعة للخدمات. |
| **عن الإدارة** | `/about` | تعريف بالمنصة، رؤيتها، أهدافها، والفريق المشرف. |
| **الخدمات الإلكترونية** | `/services` | عرض شامل لجميع الخدمات (تسجيل المسافرين، الاستعلام، طلب المساعدة). |
| **متطلبات السفر** | `/travel-requirements` | عرض ديناميكي لمتطلبات الدخول حسب الدولة القادم منها (مدمج مع نظام إدارة الأمراض). |
| **الأخبار والإعلانات** | `/news` | أرشيف للأخبار والإعلانات الرسمية (مع إمكانية التصفية حسب الفئة). |
| **الأمراض والإرشادات** | `/diseases` | معلومات طبية موثقة عن الأمراض الوبائية (الأعراض، الوقاية، العلاج). |
| **مركز الوثائق** | `/documents` | مستودع للقوانين، البروتوكولات، والنماذج القابلة للتحميل (PDF). |
| **الأسئلة الشائعة** | `/faq` | قائمة ديناميكية بالأسئلة الأكثر تداولاً. |
| **اتصل بنا** | `/contact` | نموذج تواصل مع الفريق، وخريطة للموقع. |
| **تسجيل الدخول** | `/login` | بوابة الدخول الموحدة للموظفين، شركات الطيران، والإداريين. |

## 4. إدارة المحتوى (CMS)
يتم إدارة محتوى الموقع (الأخبار، الصفحات، الأسئلة الشائعة، الوثائق) عبر **لوحة تحكم المسؤول (Admin Dashboard)** المدمجة في Django، مما يتيح لمسؤولي المحتوى تحديث المعلومات دون الحاجة لتدخل فريق التطوير.

## 5. التكامل مع بقية المنصة
- **بوابة المسافرين (2)**: يوفر الموقع العام روابط مباشرة للتسجيل المسبق والاستعلام عن حالة الطلب.
- **بوابة موظفي الحجر (4)**: (غير مرئية للعامة) ولكن الموقع يوجه الموظفين لصفحة تسجيل الدخول الخاصة بهم.
- **نظام الإشعارات**: يعرض الموقع العام آخر الإشعارات الهامة (مثل: تعليق الرحلات) في شريط علوي عائم.
- **نظام إدارة الوثائق**: يقوم بربط الملفات التي يتم رفعها من المسؤولين مباشرة في مركز الوثائق.

## 6. إرشادات للمطورين
- **الموقع مبني بـ React + Vite**: استخدام `react-router-dom` لإدارة المسارات.
- **جلب البيانات**: يتم جلب بيانات الأخبار والأسئلة الشائعة عبر (React Query) من واجهات API التي يوفرها Django REST Framework.
- **الـ SEO**: يتم استخدام `react-helmet-async` لإدارة العناوين والوصف لكل صفحة لتحسين ظهور الموقع في محركات البحث.

2. صفحة "القطاعات والمنافذ" (Sectors & Ports Page)
2.1. الهدف

تقديم معلومات شاملة عن الهيكل الإداري والجغرافي لمنصة الحجر الصحي القومي، بما في ذلك القطاعات الستة والمنافذ التابعة لها (المطارات، الموانئ، المعابر البرية)، مع توفير معلومات الاتصال والخدمات المقدمة في كل منفذ.
2.2. مكونات الصفحة
أ. خريطة السودان التفاعلية

    خريطة تفاعلية توضح توزيع القطاعات والمنافذ.

    طبقات (Layers):

        حدود القطاعات (مظللة بألوان مختلفة).

        أيقونات المنافذ (✈️ للمطارات، 🚢 للموانئ، 🚛 للمعابر البرية).

    عند النقر على منطقة أو منفذ: تظهر نافذة منبثقة بمعلومات مختصرة وزر "عرض التفاصيل".

ب. قائمة القطاعات (Sectors List)

    عرض شبكي (Grid) أو قائمة بالقطاعات الستة:

        قطاع البحر الأحمر.

        قطاع الخرطوم.

        القطاع الشمالي.

        قطاع كسلا.

        قطاع القضارف.

        قطاع كردفان.

    كل قطاع يحتوي على:

        اسم القطاع.

        وصف مختصر.

        عدد المنافذ التابعة.

        زر "عرض التفاصيل".

ج. صفحة تفاصيل القطاع (Sector Detail)

    معلومات القطاع:

        الاسم، الوصف، المنطقة الجغرافية.

        عدد المنافذ.

        معلومات الاتصال (الهاتف، البريد الإلكتروني).

        ساعات العمل.

    قائمة المنافذ التابعة:

        جدول يحتوي على: (اسم المنفذ، النوع، الموقع، الحالة، الخدمات).

    خريطة مصغرة توضح موقع المنافذ التابعة.

    زر: "العودة إلى القطاعات".

د. صفحة تفاصيل المنفذ (Port Detail)

    معلومات المنفذ:

        الاسم، النوع (مطار/ميناء/بري).

        القطاع التابع.

        الموقع الجغرافي.

        معلومات الاتصال (الهاتف، البريد الإلكتروني، العنوان).

        ساعات العمل.

        الخدمات المقدمة (قائمة).

    إحصائيات المنفذ (إذا كانت متاحة للعامة):

        عدد المسافرين شهرياً.

        عدد الفحوصات.

        الحالات المكتشفة.

    زر: "العودة إلى القطاع".
