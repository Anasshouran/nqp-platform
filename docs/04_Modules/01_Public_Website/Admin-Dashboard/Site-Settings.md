# إعدادات الموقع العامة (Site Settings)

## 1. نظرة عامة
تتيح هذه الواجهة للمسؤولين (بصلاحية `CAN_MANAGE_SETTINGS`) التحكم في الإعدادات العامة للموقع العام، مثل (الشعار، بيانات الاتصال، شريط الإشعارات).

## 2. الإعدادات المتاحة للتعديل
| الإعداد | الوصف | النوع |
| :--- | :--- | :--- |
| **شعار الموقع** | صورة الشعار في أعلى الصفحة (Header). | صورة (Image) |
| **عنوان الموقع** | النص المكتوب بجانب الشعار. | نص (String) |
| **نص البانر الرئيسي** | النص الكبير في الصفحة الرئيسية. | نص طويل (Text) |
| **صورة خلفية البانر** | الصورة الخلفية للقسم الرئيسي. | صورة (Image) |
| **شريط الإشعارات** | النص الذي يظهر في الشريط العلوي العائم (مثل: "تنويه هام..."). | نص (String) |
| **رقم الهاتف** | رقم الاتصال الموحد. | نص (String) |
| **البريد الإلكتروني** | بريد الدعم الفني. | بريد إلكتروني (Email) |
| **العنوان** | العنوان الكامل للمقر الرئيسي. | نص طويل (Text) |
| **روابط التواصل الاجتماعي** | روابط (فيسبوك، تويتر، يوتيوب، إنستغرام). | روابط (URLs) |
| **حالة الصيانة** | خانة اختيار (وضع الصيانة) - تفعيلها يعرض صفحة "قيد الصيانة" لجميع الزوار. | Boolean |

## 3. الآلية التقنية
- يتم تخزين هذه الإعدادات في نموذج Django مخصص (`SiteSetting`) أو باستخدام حزمة `django-constance` لإدارة الإعدادات الديناميكية في قاعدة البيانات.
- يتم جلب هذه الإعدادات في كل صفحة عبر (Context Processor) في Django، أو عبر واجهة API منفصلة في React.
