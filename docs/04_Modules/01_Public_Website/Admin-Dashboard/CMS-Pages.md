# إدارة الصفحات (CMS Pages Management)

## 1. نظرة عامة
هذه الواجهة مخصصة لمسؤولي المحتوى (بصلاحية `CAN_MANAGE_PAGES`) لإدارة محتوى الصفحات الثابتة في الموقع العام (مثل: "عن الإدارة"، "الخدمات"، "مركز الوثائق").

## 2. الوظائف
- **عرض قائمة الصفحات**: جدول يحتوي على (عنوان الصفحة، المسار (URL)، حالة النشر، تاريخ آخر تعديل).
- **إضافة صفحة جديدة**: نموذج يحتوي على (العنوان، المحتوى (محرر WYSIWYG)، المسار، قالب الصفحة، حالة النشر).
- **تعديل صفحة**: نفس نموذج الإضافة مع إمكانية معاينة الصفحة قبل النشر.
- **حذف صفحة**: (مع تأكيد أمني) - لا يمكن حذف الصفحات الأساسية (الرئيسية، اتصل بنا، إلخ).

## 3. التقنية المستخدمة
- **الخلفية**: Django Model `Page` مع حقل `content` من نوع `TextField` يدعم محرر (TinyMCE أو CKEditor) لتنسيق النصوص.
- **الواجهة**: Django Admin المعزز بـ (django-ckeditor) لعرض المحرر.
