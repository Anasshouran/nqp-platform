# إدارة الأسئلة الشائعة (FAQ Management)

## 1. نظرة عامة
تتيح هذه الواجهة لمسؤولي المحتوى إدارة قائمة الأسئلة الشائعة المعروضة في صفحة `/faq`، مع إمكانية تنظيمها حسب الفئات.

## 2. الوظائف
-  عرض قائمة الأسئلة :
     جدول يحتوي على (السؤال، الفئة، ترتيب العرض، نشط/غير نشط).

-  إضافة سؤال وجواب :
  - حقل السؤال (نص).
  - حقل الإجابة (محرر WYSIWYG) - لدعم النصوص الغنية والروابط.
  - اختيار الفئة (تسجيل، فحص، حجر، شهادات).
  - تحديد ترتيب العرض (رقم).
  - خانة نشط (لإخفاء السؤال دون حذفه).

-  إعادة ترتيب الأسئلة :
 عن طريق تغيير رقم الترتيب أو باستخدام سحب وإفلات (في حالة استخدام واجهة React مخصصة).

## 3. التكامل
- التحديثات في هذه الواجهة تنعكس فوراً في صفحة `/faq` على الموقع العام (مع مراعاة التخزين المؤقت لتحديثه كل ساعة).
