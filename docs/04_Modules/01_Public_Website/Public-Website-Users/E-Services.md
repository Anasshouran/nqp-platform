# صفحة الخدمات الإلكترونية (E-Services)

## 1. الهدف
توفير بوابة مركزية تعرض جميع الخدمات الإلكترونية التي تقدمها المنصة للمواطنين والمسافرين وشركات الطيران، مع روابط مباشرة للوصول إلى كل خدمة.

## 2. مكونات الصفحة

### 2.1. بطاقات الخدمات (Services Cards)
عرض الخدمات في شبكة (Grid) من البطاقات، كل بطاقة تحتوي على:
- **أيقونة تمثل الخدمة**.
- **عنوان الخدمة** (مثل: "التسجيل المسبق للمسافرين").
- **وصف مختصر** (حد أقصى 120 حرفاً).
- **الفئة المستهدفة** (تاج صغير: مسافر، مواطن، شركة طيران، موظف).
- **زر "ابدأ الخدمة"** (يؤدي إلى الرابط المناسب).

### 2.2. قائمة الخدمات الأساسية
| الخدمة | الفئة المستهدفة | الرابط |
| :--- | :--- | :--- |
| التسجيل المسبق للمسافرين | مسافر | `/traveler/register` |
| الاستعلام عن حالة الطلب | مسافر | `/traveler/status` |
| تحميل رمز QR | مسافر | `/traveler/qr-code` |
| الاستعلام عن متطلبات السفر | مسافر، مواطن | `/travel-requirements` |
| بوابة شركات الطيران | شركة طيران | `/carrier/login` (يتطلب تسجيل دخول) |
| بوابة موظفي الحجر | موظف | `/port-health/login` (يتطلب تسجيل دخول) |
| طلب الدعم الفني | جميع الفئات | `/contact` |

### 2.3. الخدمات الأكثر استخداماً (Most Used)
- عرض أيقونات أو روابط سريعة لأكثر 3 خدمات استخداماً (يتم حسابها تلقائياً بناءً على عدد الزيارات).

## 3. التكامل
- جميع الروابط تؤدي إلى صفحات داخل التطبيق (React Router) أو بوابات خارجية (إذا كانت منفصلة).
- يتم تتبع استخدام الخدمات عبر (Google Analytics أو Piwik) لتحسين تجربة المستخدم.
