# صفحة متطلبات السفر (Travel Requirements)

## 1. الهدف
تقديم معلومات محدثة ودقيقة عن متطلبات الدخول إلى السودان (أو مغادرته) بناءً على 
**آخر التصنيفات الصحية للدول**
 الصادرة عن وزارة الصحة، مما يساعد المسافرين على الاستعداد قبل السفر وتجنب المفاجآت عند الوصول.

## 2. آلية العمل
- **ديناميكية**: تعتمد البيانات على نظام `Disease_Management` في الخلفية (Django). عندما تقوم وزارة الصحة بتحديث تصنيف دولة ما (أخضر/أصفر/أحمر) في لوحة الإدارة، تنعكس التغييرات فوراً على هذه الصفحة دون أي تدخل برمجي.
- **التخزين المؤقت (Caching)**: يتم تخزين البيانات في Redis لمدة ساعة واحدة لتقليل الضغط على الخادم، مع إمكانية تحديثها يدوياً عبر زر "تحديث البيانات".

## 3. مكونات الصفحة

### 3.1. نموذج الاستعلام السريع (Quick Inquiry Form)
- **قائمة منسدلة**: "اختر دولة المغادرة" (جميع دول العالم مدرجة مع بحث سريع).
- **زر**: "استعلام" (باللون الأزرق).

### 3.2. نتيجة الاستعلام (Result Card) - تظهر بعد الضغط على "استعلام"
- **بطاقة ملونة** حسب تصنيف الدولة:
  - **خلفية خضراء** (🟢): "الدولة مصنفة (منخفضة الخطورة). لا توجد قيود إضافية. يمكنك السفر دون فحص إضافي."
  - **خلفية صفراء** (🟡): "الدولة مصنفة (متوسطة الخطورة). يلزم تقديم شهادة تطعيم (أو فحص PCR) قبل 72 ساعة من المغادرة."
  - **خلفية حمراء** (🔴): "الدولة مصنفة (عالية الخطورة). يلزم حجر صحي إلزامي لمدة 7 أيام عند الوصول، مع فحص PCR إلزامي."
- تحتوي البطاقة أيضاً على:
  - اسم الدولة ورمزها.
  - تاريخ آخر تحديث للتصنيف.
  - رابط (تحميل الإعلان الرسمي) إن وجد.

### 3.3. جدول التصنيفات العالمي (Global Classification Table) - أسفل الصفحة
- عرض جدول بجميع الدول (أو الدول الأكثر طلباً) وتصنيفاتها:
  - الأعمدة: (الدولة، التصنيف، المتطلبات الإضافية، آخر تحديث).
  - **دعم البحث**: حقل بحث لتصفية الجدول بالاسم.
  - **الترقيم**: عرض 20 دولة في كل صفحة.

### 3.4. الأسئلة الشائعة الخاصة بالسفر (Travel FAQ)
- عرض أهم 3 أسئلة شائعة حول متطلبات السفر (مع رابط لعرض الكل في صفحة FAQ).

## 4. واجهة المسؤول (Django Admin)
- يمكن لمسؤول النظام (عبر `admin.py` في تطبيق `countries`) تحديث حقل `risk_level` لكل دولة، بالإضافة إلى حقل `additional_requirements` (نص طويل) لكتابة التفاصيل الإضافية.
- **سجل التغييرات (Audit Log)**: يتم تسجيل كل تغيير في تصنيف دولة مع اسم المسؤول وتاريخ التعديل لضمان الشفافية.

## 5. اعتبارات تقنية
- **دعم اللغتين**: عرض أسماء الدول بالعربية والإنجليزية.
- **تحسين SEO**: استخدام (Schema Markup) من نوع `TravelDestination` لتحسين ظهور الصفحة في محركات البحث.
- **تحميل البيانات**: يتم جلب قائمة الدول وتصنيفاتها عبر API (`/api/v1/countries/`).
