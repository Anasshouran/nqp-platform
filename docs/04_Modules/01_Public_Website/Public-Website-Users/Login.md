# صفحة تسجيل الدخول (Login Page)

## 1. الهدف
بوابة الدخول الموحدة (Single Sign-On) التي تمكن المستخدمين (الموظفين، شركات الطيران، المسؤولين) من الوصول إلى البوابات المخصصة لهم (4، 3، 8، 5، 6، 9) بناءً على صلاحياتهم.

## 2. مكونات الصفحة

### 2.1. نموذج تسجيل الدخول
- **حقل البريد الإلكتروني** (نص مع خاصية الإكمال التلقائي).
- **حقل كلمة المرور** (نوع Password مع إمكانية إظهار/إخفاء النص).
- **خيار "تذكرني"** (Checkbox) لتمديد مدة الجلسة.
- **زر**: "تسجيل الدخول" (باللون الأزرق، كبير).
- **رابط**: "نسيت كلمة المرور؟" (يؤدي إلى صفحة استرداد كلمة المرور).

### 2.2. التنبيهات (Alerts)
- **حالة الخطأ**: ظهور رسالة حمراء ("البريد الإلكتروني أو كلمة المرور غير صحيحة") مع إمكانية إعادة المحاولة.
- **حالة النجاح**: بعد تسجيل الدخول، يتم توجيه المستخدم إلى لوحة التحكم الخاصة بدوره (بناءً على المجموعة التي ينتمي إليها في Django).

## 3. التوجيه بعد تسجيل الدخول
- **موظف الحجر (مجموعة: PORT_OFFICER)**: يُعاد توجيهه إلى `/port-health/dashboard`.
- **الطبيب (مجموعة: DOCTOR)**: يُعاد توجيهه إلى `/clinic/dashboard`.
- **ممثل شركة طيران (مجموعة: CARRIER)**: يُعاد توجيهه إلى `/carrier/dashboard`.
- **مدير النظام (مجموعة: SUPER_ADMIN)**: يُعاد توجيهه إلى `/admin/dashboard`.
