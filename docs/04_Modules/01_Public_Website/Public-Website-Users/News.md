# صفحة الأخبار والإعلانات (News & Announcements)

## 1. الهدف
توفير أرشيف منظم لأخبار وإعلانات المنصة، مع إمكانية البحث والتصفية حسب الفئة والتاريخ، لإبقاء المستخدمين على اطلاع دائم بآخر المستجدات الصحية.

## 2. مكونات الصفحة

### 2.1. شريط التصفية (Filter Bar)
- **قائمة منسدلة للفئة**: (الكل، أخبار، إعلانات، تعميمات عاجلة، بيانات صحية).
- **منتقي التاريخ (Date Picker)**: تصفية الأخبار من تاريخ معين إلى تاريخ معين.
- **حقل بحث**: البحث في عنوان الخبر ومحتواه.

### 2.2. قائمة الأخبار (News List)
- عرض الأخبار في شكل **بطاقات (Cards)** مرتبة تنازلياً حسب التاريخ:
  - **البطاقة تحتوي على**:
    - صورة مميزة (Thumbnail Image).
    - تاريخ النشر.
    - العنوان (كامل).
    - الملخص (أول 150 حرف من المحتوى).
    - **تاج (Tag)**: "خبر عاجل" (باللون الأحمر) إذا تم تفعيله من قبل المسؤول.
    - زر "اقرأ المزيد" (يؤدي إلى صفحة الخبر كاملاً).
- **الترقيم (Pagination)**: عرض 10 أخبار في كل صفحة، مع أزرار (السابق، التالي، وأرقام الصفحات).

### 2.3. صفحة الخبر الكامل (News Detail)
- **العنوان** (كبير).
- **تاريخ النشر** و **فئة الخبر**.
- **صورة الخبر** (كبيرة).
- **المحتوى** (نص كامل مع دعم الصور والروابط والفيديوهات المضمنة).
- **زر "العودة إلى الأخبار"**.
- **(اختياري) أخبار ذات صلة** (Related News) أسفل الصفحة.

### 2.4. الخبر العاجل (Breaking News)
- يتم عرض الخبر العاجل (الأحدث) في **شريط منبثق** في أعلى كل صفحة من صفحات الموقع العام (بالإضافة إلى ظهوره في قائمة الأخبار مع تاج "عاجل").

## 3. إدارة المحتوى (للمسؤولين)
- **Django Admin**: يمكن لمسؤول المحتوى إدارة الأخبار:
  - إضافة خبر جديد (العنوان، الملخص، المحتوى، الصورة، الفئة، تاريخ النشر، خبر عاجل، نشط/غير نشط).
  - جدولة النشر: يمكن تحديد تاريخ مستقبلي لنشر الخبر تلقائياً.
  - تعديل وحذف الأخبار.
- **التخزين**: يتم تخزين الصور على (MinIO/S3) باستخدام `django-storages`.

## 4. التكامل التقني
- **جلب البيانات**: استخدام React Query مع Pagination لجلب الأخبار من API (`/api/v1/cms/news?page=1&category=news`).
- **التخزين المؤقت (Caching)**: تخزين قائمة الأخبار لمدة 5 دقائق في Redis.
- **تحسين SEO**: إضافة (Open Graph) و (Twitter Cards) لتحسين مشاركة الأخبار على وسائل التواصل الاجتماعي.
