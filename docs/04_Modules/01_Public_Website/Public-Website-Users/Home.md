# الصفحة الرئيسية (Homepage)

## 1. الهدف
الصفحة الرئيسية هي **الواجهة الترحيبية** للمنصة. تهدف إلى إعطاء انطباع أولي احترافي، وتوجيه المستخدم بسرعة إلى الخدمات والمعلومات التي يبحث عنها، مع عرض آخر المستجدات الصحية.

## 2. مكونات الصفحة (Layout)

### 2.1. الشريط العلوي (Header)
- **الجهة اليمنى**: شعار المنصة + اسم "منصة الحجر الصحي القومي".
- **الجهة اليسرى**: روابط التنقل (الرئيسية، عن الإدارة، الخدمات، الأخبار، اتصل بنا) + **زر "تسجيل الدخول"** (باللون الأزرق).
- **(مميز) شريط الإشعارات العائم**: يظهر في أعلى الصفحة إذا كانت هناك حالة طوارئ أو تعميم هام (مثل: "تعليق الرحلات من دولة X اعتباراً من الغد"). يتم التحكم به من لوحة الإدارة.

### 2.2. البانر الرئيسي (Hero Section)
- **الخلفية**: صورة عالية الجودة لمطار أو منفذ حدودي (مع طبقة تراكب زرقاء شفافة لتسهيل قراءة النص).
- **النص الرئيسي**: "رحلتك الآمنة تبدأ من هنا" (عنوان كبير).
- **النص الفرعي**: "سجل مسبقاً لتسهيل إجراءات الوصول إلى السودان، واحصل على رمز QR الخاص بك."
- **أزرار الدعوة للعمل (CTA)**:
  - زر "سجل الآن" (أزرق كبير، يؤدي إلى `/services/pre-registration`).
  - زر "استعلام عن متطلبات السفر" (أبيض بحد أزرق، يؤدي إلى `/travel-requirements`).

### 2.3. بطاقات الخدمات السريعة (Quick Services Cards)
- **4 بطاقات مرتبة في شبكة (Grid)**:
  1.  **تسجيل المسافرين** (أيقونة ✈️): "أكمل بياناتك الصحية قبل الوصول." → زر "ابدأ التسجيل".
  2.  **متطلبات السفر** (أيقونة 📋): "تعرف على شروط الدخول حسب بلدك." → زر "استعلم الآن".
  3.  **الأمراض والإرشادات** (أيقونة 🩺): "اطلع على أعراض الأمراض وطرق الوقاية." → زر "اقرأ المزيد".
  4.  **مركز الوثائق** (أيقونة 📄): "تحميل البروتوكولات والنماذج الرسمية." → زر "تصفح الوثائق".

### 2.4. آخر الأخبار والإعلانات (News Feed)
- عرض آخر **3 أخبار** بشكل بطاقات أفقية مع:
  - الصورة المصغرة.
  - العنوان (حد أقصى 60 حرفاً).
  - التاريخ.
  - زر "اقرأ المزيد" (للفتح في صفحة منفصلة).
- زر "عرض جميع الأخبار" في نهاية القسم (يؤدي إلى `/news`).

### 2.5. إحصائيات سريعة (Quick Stats) - اختياري
- عرض أرقام معبرة تعكس حجم العمل:
  - "تم فحص أكثر من 1,500,000 مسافر".
  - "تم إصدار 250,000 شهادة تعافي".
  - "يغطي النظام 25 منفذاً".

### 2.6. التذييل (Footer)
- يحتوي على 4 أعمدة:
  - **العمود الأول**: روابط سريعة (عن الإدارة، الخدمات، اتصل بنا).
  - **العمود الثاني**: معلومات الاتصال (العنوان، الهاتف، البريد الإلكتروني).
  - **العمود الثالث**: ساعات العمل الرسمية.
  - **العمود الرابع**: أيقونات وسائل التواصل الاجتماعي (فيسبوك، تويتر، يوتيوب).
- سطر حقوق النشر: "جميع الحقوق محفوظة © 2025 - منصة الحجر الصحي القومي."

## 3. واجهة المسؤول (Django Admin)
- يمكن لمسؤول المحتوى تعديل **نص البانر الرئيسي**، **صورة الخلفية**، و **بطاقات الخدمات** عبر نموذج (CMS) مخصص.
- يمكن تعديل **شريط الإشعارات العائم** بسهولة من لوحة التحكم (`SiteSettings`).

## 4. التكامل التقني
- **جلب البيانات**: يتم جلب آخر الأخبار عبر React Query من API (`/api/v1/cms/news?limit=3`).
- **التخزين المؤقت**: يتم تخزين بيانات الأخبار في Redis لمدة 5 دقائق لتقليل الضغط على الخادم.
- **تحسين SEO**: يتم استخدام `react-helmet-async` لإدارة العناوين والوصف لتحسين ظهور الموقع في محركات البحث.
