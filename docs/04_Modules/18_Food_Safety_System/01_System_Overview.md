# 18_Food_Safety_System - نظام سلامة الغذاء

> **علاقة هذه الوحدة بـ `07_Food_Quarantine`**: هذا المجلد هو **المظلة المعمارية**
> للنظام (نظرة عامة، مخطط البيانات، الترصّد الغذائي، الإدارة والأمن)؛ مجلد **7** هو
> **الدليل التشغيلي التفصيلي** (الأدوار العشرة، سير العمل الكامل، الرسوم، الشاشات).

## 1. الهدف الاستراتيجي
نظام متخصص لإدارة سلامة الأغذية في الموانئ والمعابر البرية، يشمل فحص الشحنات الغذائية، التفتيش الصحي، وإصدار الشهادات.

## 2. المكونات الرئيسية
| المكون | الوصف | الأولوية |
| :--- | :--- | :--- |
| **إدارة الشحنات** | تسجيل وتتبع الشحنات الغذائية الواردة والصادرة. | عالية |
| **التفتيش الصحي** | فحص الشحنات (العبوات، التواريخ، درجة الحرارة). | عالية |
| **أخذ العينات** | تسجيل العينات وإرسالها للمختبر. | عالية |
| **نتائج المختبر** | استلام نتائج تحليل العينات الغذائية. | عالية |
| **شهادات الإفراج** | إصدار شهادات الإفراج الصحي. | عالية |
| **إدارة الرسوم** | حساب وتحصيل الرسوم. | متوسطة |

## 3. التكامل مع الأنظمة الأخرى
- **نظام المختبرات (06)**: إرسال العينات واستلام النتائج.
- **نظام الجمارك (12)**: إرسال شهادات الإفراج.
- **نظام الترصد الوبائي (10)**: تغذية بيانات سلامة الغذاء.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `POST` | `/api/v1/food/shipments/` | تسجيل شحنة جديدة |
| `GET` | `/api/v1/food/shipments/{id}/` | تفاصيل شحنة |
| `POST` | `/api/v1/food/shipments/{id}/inspection/` | تسجيل التفتيش |
| `POST` | `/api/v1/food/shipments/{id}/release/` | إصدار شهادة إفراج |

## ⚙️ حالة التنفيذ مقابل الكود

> التطبيق الخلفي: `apps/food_quarantine` — الدليل التشغيلي: `04_Modules/07_Food_Quarantine`

| المكوّن (كما في §2) | الحالة | ملاحظة التحقق |
| :--- | :--- | :--- |
| إدارة الشحنات | ✅ مطبَّق | CRUD + مسودة/تسجيل فوري + `clerk-stats` — 240 اختبارًا للمجموعة كلها |
| التفتيش الصحي | ✅ مطبَّق | `inspection` + `reviewed_at` + فصل المفتشين الثلاثة |

| نتائج المختبر | ⚠️ جزئي | استلام النتائج داخليًا؛ بوابة FCLIS موصّفة غير مفعّلة |
| شهادات الإفراج | ✅ مطبَّق | إفراج كلي/مشروط/رفض/إتلاف + أرقام تلقائية |
| إدارة الرسوم | ✅ مطبَّق | `invoice` + `pay` + إعفاء الإغاثة الكلي |
| نقاط النهاية في §4 | ✅ مطابقة | المسارات الفعلية تحت `/api/v1/food/shipments/` |
