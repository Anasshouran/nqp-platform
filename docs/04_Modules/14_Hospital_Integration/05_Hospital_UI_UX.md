# 05_Hospital_UI_UX - شاشات نظام المستشفيات

## 1. شاشة إنشاء إحالة (بوابة العيادات - 5)

### مكونات الشاشة (نافذة منبثقة أو صفحة منفصلة):
1.  **عنوان**: "إحالة المريض إلى المستشفى"
2.  **قسم بيانات المريض**: اسم المريض، رقم الجواز، العمر (للقراءة فقط).
3.  **قسم اختيار المستشفى**: 
    - قائمة منسدلة للمستشفيات المتاحة (مصنفة حسب الموقع والتخصص).
    - حقل اختيار القسم (مثل: العناية المركزة، الجراحة، القلب).
4.  **قسم التفاصيل الطبية**:
    - **درجة الأولوية**: زر اختيار (ROUTINE, URGENT, EMERGENCY, CRITICAL) - مع تمييز باللون (أزرق، أصفر، برتقالي، أحمر).
    - **سبب الإحالة**: حقل نصي كبير (مطلوب).
    - **الملخص السريري**: ملخص للتشخيص والعلامات الحيوية (يُستخرج تلقائياً من EMR مع إمكانية التعديل).
5.  **قسم المرفقات**: زر (رفع ملفات) لإضافة صور الأشعة أو نتائج الفحوصات.
6.  **زر**: (إرسال الإحالة) - باللون الأزرق.
7.  **زر**: (إلغاء) - باللون الرمادي.

---

## 2. شاشة متابعة الإحالات (لوحة الطبيب)

### مكونات الشاشة:
1.  **جدول الإحالات**: يعرض جميع الإحالات التي أنشأها الطبيب أو المرتبطة بعيادته.
    - الأعمدة: (رقم الإحالة، المريض، المستشفى، الحالة، الأولوية، التاريخ).
    - **مؤشر الحالة**: (دائرة ملونة حسب الحالة: صفراء لـ PENDING، خضراء لـ ACCEPTED/COMPLETED، حمراء لـ REJECTED).
2.  **خيارات التصفية**: (حسب الحالة، الأولوية، المستشفى، التاريخ).
3.  **زر**: (إنشاء إحالة جديدة) - زر بارز باللون الأزرق.
4.  **زر**: (عرض التفاصيل) - ينقل المستخدم إلى شاشة تفاصيل الإحالة.

---

## 3. شاشة تفاصيل الإحالة (متابعة الحالة والتقارير)

### مكونات الشاشة:
1.  **بطاقة المعلومات الأساسية**: المريض، المستشفى، درجة الأولوية.
2.  **شريط الحالة الزمني (Timeline)**: 
    - يعرض تطور حالة الإحالة بصرياً (PENDING → ACCEPTED → IN_TREATMENT → DISCHARGED).
    - مع تواريخ وأوقات كل تحديث.
3.  **قسم السبب والملخص الطبي**: عرض سبب الإحالة والملخص السريري المرسل.
4.  **قسم التقارير الطبية المستلمة**:
    - إذا تم استلام تقرير (PDF)، يظهر زر (تنزيل التقرير) وزر (تحديد كمُراجَع).
    - حالة التقرير: (غير مُراجَع / مُراجَع).
5.  **قسم إجراءات الطبيب**:
    - زر (إلغاء الإحالة) - إذا كانت الحالة PENDING أو ACCEPTED.
    - زر (إعادة التوجيه لمستشفى آخر) - إذا كانت REJECTED.

---

## 4. لوحة تحكم غرفة الطوارئ (EOC) - حالة الإحالات الحرجة

### مكونات الشاشة (قسم منفصل في لوحة EOC):
1.  **قائمة الإحالات الحرجة (CRITICAL)**:
    - تظهر في أعلى القائمة مع أيقونة وامضة (🚨).
    - الأعمدة: (المريض، المستشفى، الوقت المنقضي، الحالة).
2.  **زر**: (تسريع الإجراء) - يرسل إشعاراً إضافياً للمستشفى عبر (SMS/بريد إلكتروني).
3.  **زر**: (الاتصال بالمستشفى) - يفتح رقم الهاتف المسجل للمستشفى مباشرة.

## 5. شاشة إدارة المستشفيات (بوابة الإدارة الاتحادية - 8)

### مكونات الشاشة (للإعدادات):

3.  **زر**: (اختبار الاتصال) - للتحقق من صحة نقطة نهاية API للمستشفى.
4.  **زر**: (تعديل) و (تعطيل) لكل مستشفى.
