# 04_Hospital_Workflow - سير عمل الإحالات والتقارير الطبية

## 1. الممثلون (Actors)
- **الطبيب (Doctor)**: ينشئ الإحالة في العيادة، ويراجع التقارير المستلمة.
- **نظام المستشفى (Hospital System)**: يستقبل الإحالة، ويُحدث الحالة، ويرسل التقارير.
- **غرفة الطوارئ (EOC)**: تتابع الحالات الحرجة.
- **مسؤول النظام (Admin)**: يراجع سجلات التدقيق ويُصلح الأخطاء.

## 2. سير العمل الرئيسي (دورة الإحالة الكاملة)

```mermaid
flowchart TD
    Start([بداية: يحتاج المريض لرعاية متقدمة]) --> Step1[1. الطبيب يفتح ملف المريض<br/>في بوابة العيادات (5)]
    Step1 --> Step2[2. الطبيب ينشئ إحالة جديدة<br/>يختار المستشفى، يكتب السبب، يرفق الملفات]
    Step2 --> Step3[3. النظام يرسل الإحالة إلى المستشفى<br/>(عبر API أو نظام مركزي)]
    Step3 --> Step4[4. حالة الإحالة تصبح (PENDING)]
    
    Step4 --> Step5[5. المستشفى يستقبل الإحالة]
    Step5 --> Decision1{يقبل المستشفى الإحالة؟}
    Decision1 -- لا --> Step6[6. المستشفى يُرسل تحديث (REJECTED)<br/>مع سبب الرفض]
    Step6 --> Step7[7. الطبيب يتلقى إشعاراً،<br/>يُعيد التوجيه لمستشفى آخر]
    Step7 --> Step2
    
    Decision1 -- نعم --> Step8[8. المستشفى يُرسل تحديث (ACCEPTED)]
    Step8 --> Step9[9. المريض يُنقل إلى المستشفى]
    Step9 --> Step10[10. المستشفى يُرسل تحديث (IN_TREATMENT)]
    Step10 --> Step11[11. المستشفى يُنهي العلاج]
    
    Step11 --> Decision2{هل يحتاج تقرير خروج؟}
    Decision2 -- نعم --> Step12[12. المستشفى يُرفع تقرير طبي<br/>(DISCHARGE_SUMMARY)]
    Step12 --> Step13[13. النظام يُرسل إشعاراً للعيادة<br/>"تم استلام تقرير طبي جديد"]
    Step13 --> Step14[14. الطبيب يراجع التقرير<br/>ويضغط (مراجعة)]
    Step14 --> Step15[15. يتم تحديث حالة الإحالة إلى (COMPLETED)<br/>وربط التقرير بملف المريض]
    Step15 --> End([النهاية])
    
    Decision2 -- لا --> Step16[16. المستشفى يُرسل تحديث (DISCHARGED)<br/>بدون تقرير مفصل]
    Step16 --> End

3. حالة الإحالة (مرئية لكلا الطرفين)
الحالة	الوصف	الإجراء التلقائي
PENDING	بانتظار مراجعة المستشفى.	إرسال إشعار للمستشفى.
ACCEPTED	تم القبول، المريض في طريقه للمستشفى.	إرسال إشعار للعيادة و(EOC).
REJECTED	تم الرفض (مع سبب).	إشعار للعيادة لإعادة التوجيه.
IN_TREATMENT	المريض يتلقى العلاج في المستشفى.	تحديث دوري (اختياري).
DISCHARGED	خرج المريض من المستشفى.	انتظار التقرير الطبي.
COMPLETED	تم استلام التقرير ومراجعته.	إغلاق الملف.
CANCELLED	ألغى الطبيب الإحالة (قبل القبول).	لا يوجد.
4. الحالات الحرجة (Critical Priority)

    إذا كانت درجة الأولوية CRITICAL، يتم:

        إرسال إشعار فوري (WebSocket) إلى غرفة الطوارئ (EOC).

        محاولة الاتصال بالمستشفى عبر (SMS/بريد إلكتروني) بخلاف الـ API لضمان سرعة الاستجابة.

        تظهر الإحالة في لوحة تحكم EOC مع مؤقت (Timer) يوضح الوقت المنقضي منذ الإنشاء.
