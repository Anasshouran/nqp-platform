# 01_System_Overview - نظام التكامل مع المستشفيات (Hospital Integration System)

## 1. الهدف الاستراتيجي (Strategic Objective)
يهدف نظام المستشفيات إلى **رقمنة وأتمتة عملية إحالة المرضى** من عيادات الحجر الصحي إلى المستشفيات الخارجية، مع توفير آلية لمتابعة حالة المريض بعد الإحالة، واستلام التقارير الطبية النهائية إلكترونياً، لضمان استمرارية الرعاية الصحية وسرعة الاستجابة للحالات الحرجة.

## 2. النطاق الوظيفي (Functional Scope)
| الوظيفة | الوصف |
| :--- | :--- |
| **إحالة المرضى (Referral)** | تمكين الأطباء في عيادات الحجر من إنشاء إحالة إلكترونية للمستشفى المناسب، تتضمن (التشخيص، الفحوصات المطلوبة، درجة الخطورة). |
| **متابعة نتائج الإحالة (Tracking)** | تمكين الفريق الطبي في العيادة من متابعة حالة الإحالة لحظياً (قيد الانتظار، تم القبول، تم الرفض، قيد العلاج، تم الخروج). |
| **استلام التقارير الطبية (Reports)** | استلام التقارير الطبية النهائية من المستشفى (تقرير الخروج، الملخص الطبي) وربطها بالملف الصحي للمريض في نظام EMR. |

## 3. التكامل مع البوابات الأخرى (Integration Matrix)
| البوابة/النظام | نوع التكامل | الغرض |
| :--- | :--- | :--- |
| **بوابة العيادات (5)** | كتابة وقراءة | يقوم الطبيب بإنشاء الإحالة، ويعرض حالة الإحالات السابقة للمريض. |
| **بوابة الطوارئ (9)** | تنبيه فوري | إذا كانت الإحالة **حرجة (Critical)**، يتم إرسال تنبيه فوري لغرفة العمليات (EOC) لتسريع الاستجابة. |
| **نظام الترصد الوبائي** | استقبال بيانات مجمعة | إرسال إحصائيات عن حالات الإحالة (عدد الإحالات، الأسباب الأكثر شيوعاً) لدعم التخطيط الصحي. |
| **التكامل الخارجي (وزارة الصحة/المستشفيات)** | تبادل بيانات | إرسال طلب الإحالة عبر (FHIR أو REST API) إلى نظام المستشفى، واستلام تحديثات الحالة والتقارير النهائية. |
| **نظام المتابعة الصحية** | استقبال بيانات | إذا خرج المريض من المستشفى، يتم تنشيط متابعة منزلية إذا لزم الأمر. |

## 4. المبادئ الأساسية للتصميم
- **الشفافية**: يتم تحديث حالة الإحالة تلقائياً عند أي تغيير من قبل المستشفى، ويتم إشعار الطبيب المعالج.
- **الأمان**: نقل البيانات الحساسة (التشخيص، التقارير) عبر قنوات مشفرة (TLS) مع صلاحيات وصول صارمة (RBAC).
- **التوحيد القياسي**: دعم تنسيق (FHIR) لتبادل البيانات الصحية مع الأنظمة الخارجية، مع الاحتفاظ بنسخة داخلية (NQP Format) لضمان التكامل مع أنظمة المنصة.
- **التسلسل الزمني (Audit Trail)**: تسجيل جميع العمليات (إنشاء، تحديث، استلام) مع الطوابع الزمنية وأسماء المستخدمين.
