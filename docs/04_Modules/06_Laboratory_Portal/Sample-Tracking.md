# تتبع العينات (Sample Tracking)

## 1. الهدف
تمكين فني المختبر والمشرف من متابعة حالة العينة في أي وقت، ومعرفة المرحلة التي وصلت إليها (مسجلة، قيد التحليل، مكتملة، معتمدة)، لضمان عدم ضياع العينات أو تأخر النتائج، وتحسين إدارة سير العمل في المختبر.

## 2. مكونات الصفحة

### 2.1. شريط البحث (Search Bar)
- البحث عن عينة بواسطة: (الباركود، اسم المريض، رقم الإحالة، تاريخ التسجيل).

### 2.2. قائمة العينات (Samples List)
- عرض جدول بجميع العينات مع إمكانية التصفية حسب:
  - **الحالة**: (الكل، مسجلة، قيد التحليل، نتائج مدخلة، معتمدة، مرفوضة).
  - **الأولوية**: (الكل، عادي، عاجل، فوري).
  - **الفترة الزمنية**: (من تاريخ إلى تاريخ).
- **الأعمدة**:
  - الباركود.
  - اسم المريض.
  - نوع العينة.
  - الفحص المطلوب.
  - الأولوية (مع تمييز بالألوان: 🟢 عادي، 🟡 عاجل، 🔴 فوري).
  - الحالة (مع تمييز بالألوان).
  - تاريخ التسجيل.
  - تاريخ آخر تحديث.
  - **زر**: "عرض التفاصيل" (لفتح صفحة تفاصيل العينة).

### 2.3. صفحة تفاصيل العينة (Sample Detail)
- **معلومات العينة الأساسية**:
  - (الباركود، نوع العينة، الفحص المطلوب، الأولوية، الحالة، تاريخ التسجيل، تاريخ آخر تحديث).
- **معلومات المريض المرتبط**:
  - (الاسم، رقم الجواز، الجنسية، العمر، الجنس).
- **معلومات الزيارة العيادية المرتبطة**:
  - (رقم الزيارة، الطبيب المعالج، التشخيص المبدئي).
- **سجل التغييرات (Activity Log)**:
  - عرض جدول زمني (Timeline) للتغييرات التي حدثت على العينة:
    - (مثل: "2024-07-25 10:00 - تم تسجيل العينة (فني: أحمد)").
    - (مثل: "2024-07-25 10:30 - بدء التحليل (فني: سارة)").
    - (مثل: "2024-07-25 11:00 - تم إدخال النتيجة (فني: سارة)").
    - (مثل: "2024-07-25 11:15 - تم اعتماد النتيجة (مشرف: د. خالد)").

### 2.4. إشعارات التتبع (Tracking Notifications)
- يتم إرسال إشعارات (داخل البوابة) عند تغيير حالة العينة إلى:
  - **فوري (STAT)**: إشعار لكل 5 دقائق حتى يتم إدخال النتيجة.
  - **عاجل (Urgent)**: إشعار لكل 30 دقيقة إذا لم يتم إدخال النتيجة.

## 3. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/lab/samples/` | قائمة العينات (مع التصفية والبحث). |
| `GET` | `/api/v1/lab/samples/{id}` | تفاصيل عينة محددة. |
| `GET` | `/api/v1/lab/samples/{id}/timeline` | سجل التغييرات (Activity Log). |
