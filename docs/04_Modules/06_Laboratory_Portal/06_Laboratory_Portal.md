# 06_Laboratory_Portal - بوابة المختبرات

## 1. الهدف الاستراتيجي
تزويد المختبرات (المركزية والميدانية في المنافذ) بأداة رقمية متكاملة لإدارة دورة حياة العينة المخبرية بكفاءة ودقة، بدءاً من تسجيل العينة، مروراً بتتبع حالتها، وإدخال النتائج، وانتهاءً باعتمادها وإرسالها إلى الجهات المعنية (العيادات، نظام الترصد، وغرفة الطوارئ). تهدف البوابة إلى:
- **تقليل الأخطاء البشرية**: من خلال استخدام الباركود لربط العينة بالمريض.
- **تسريع عملية التحليل**: من خلال إدارة أولويات العينات (عادي، عاجل، فوري).
- **ضمان جودة النتائج**: من خلال آلية اعتماد مزدوجة (فني + مشرف).
- **التكامل الفوري**: إرسال النتائج الإيجابية إلى نظام الترصد وغرفة الطوارئ تلقائياً.

## 2. الممثلون (Actors)
- **فني المختبر (Lab Technician)**: يقوم بتسجيل العينات، إدخال النتائج، وتحديث حالة العينة.
- **مشرف المختبر (Lab Supervisor)**: يقوم بمراجعة النتائج واعتمادها (أو رفضها).
- **نظام المنصة (NQP)**: يستقبل البيانات، يدير حالة العينة، ويرسل الإشعارات.
- **نظام الترصد الوبائي (Surveillance)**: يستقبل النتائج المعتمدة (المجمعة) لتغذية لوحات المعلومات.
- **غرفة الطوارئ (EOC)**: تستقبل إشعارات فورية (WebSocket) للنتائج الإيجابية للأمراض الخطيرة.

## 3. الميزات الرئيسية (Key Features)
| الميزة | الوصف | الأولوية |
| :--- | :--- | :--- |
| **تسجيل العينات** | تسجيل العينات الواردة من العيادات (مع باركود فريد). | عالية |
| **تتبع العينات** | متابعة حالة العينة (مسجلة، قيد التحليل، مكتملة). | عالية |
| **إدخال النتائج** | إدخال النتيجة المخبرية (إيجابي، سلبي، غير محدد) مع القيم الرقمية. | عالية |
| **اعتماد النتائج** | مراجعة واعتماد النتائج من قبل المشرف المخبري. | عالية |
| **التقارير** | عرض إحصائيات المختبر (عدد العينات، النتائج، الأوقات). | متوسطة |
| **التكامل التلقائي** | إرسال النتائج المعتمدة إلى العيادات، نظام الترصد، وغرفة الطوارئ. | عالية |

5. المتطلبات التقنية (Technical Requirements)

    الواجهة الأمامية: React + Tailwind CSS (مسار /laboratory).

    الخلفية: Django REST Framework (نقاط النهاية تحت /api/v1/lab/).

    المصادقة: JWT مع صلاحيات محددة (الدور: LAB_TECH أو LAB_SUPERVISOR).

    الباركود: توليد باركود فريد لكل عينة (باستخدام مكتبة python-barcode أو django-barcode).

    التكامل مع أجهزة المختبر: (مستقبلي) استقبال النتائج آلياً من أجهزة (PCR، أجهزة التحليل الكيميائي) عبر واجهات (HL7, ASTM) أو ملفات CSV.

6. التكامل مع الأنظمة الأخرى

    بوابة العيادات (5): استقبال طلبات الفحوصات (العينات المطلوبة، بيانات المريض).

    نظام الترصد الوبائي: إرسال النتائج المعتمدة (المجمعة ومخفية الهوية) لتغذية لوحات المعلومات والتنبؤات.

    غرفة الطوارئ (9): إرسال إشعار فوري (WebSocket) عند اعتماد نتيجة إيجابية لمرض مدرج في قائمة (PHEIC - الطوارئ الصحية العامة).

    نظام إدارة الأمراض: استرجاع تعريفات الأمراض والأعراض المرتبطة بها لتوجيه الفني في حالة الشك.
