# التقارير والإحصائيات (Reports & Statistics)

## 1. الهدف
تزويد فنيي المختبرات والمشرفين ومديري المختبرات بتقارير وإحصائيات عن أداء المختبر، بما في ذلك (عدد العينات، أنواع الفحوصات، النتائج، أوقات الإنجاز، وأداء الفنيين)، لتحسين العمليات وتحديد الاحتياجات التدريبية.

## 2. مكونات الصفحة

### 2.1. مؤشرات الأداء الرئيسية (KPI Cards)
| البطاقة | القيمة | المصدر |
| :--- | :--- | :--- |
| **إجمالي العينات (اليوم)** | عدد العينات المسجلة اليوم. | نظام تسجيل العينات. |
| **النتائج المعتمدة (اليوم)** | عدد النتائج التي تم اعتمادها اليوم. | نظام اعتماد النتائج. |
| **نتائج إيجابية (اليوم)** | عدد النتائج الإيجابية (لكل الأمراض). | نظام اعتماد النتائج. |
| **متوسط وقت الإنجاز (TAT)** | متوسط الوقت من تسجيل العينة إلى اعتماد النتيجة (بالساعات). | نظام تتبع العينات. |

### 2.2. الرسوم البيانية (Charts)
- **توزيع العينات حسب النوع**: رسم بياني دائري (Pie Chart) يوضح نسب أنواع العينات (دم، مسحة، بول، إلخ) خلال الفترة المحددة.
- **توزيع النتائج**: رسم بياني عمودي (Bar Chart) يوضح عدد النتائج (إيجابي، سلبي، غير محدد) لكل مرض.
- **اتجاهات الفحوصات**: رسم بياني خطي يوضح عدد الفحوصات المطلوبة يومياً خلال الأسبوع أو الشهر الحالي.
- **أوقات الإنجاز (TAT)**: رسم بياني (Box Plot) يوضح توزيع أوقات الإنجاز للعينات حسب الأولوية (عادي، عاجل، فوري).

### 2.3. أداء الفنيين (Technician Performance) - للمشرفين
- جدول يوضح أداء كل فني:
  - (اسم الفني، عدد العينات التي قام بتحليلها، متوسط وقت الإنجاز، نسبة الأخطاء/الرفض).
- **استخدام**: لتقييم الأداء وتحديد احتياجات التدريب.

### 2.4. تصدير التقارير (Export)
- **زر**: "تصدير تقرير اليوم بصيغة PDF" (تقرير منظم يحتوي على جميع المؤشرات والرسوم البيانية).
- **زر**: "تصدير تقرير الشهر بصيغة Excel" (للتحليل المتقدم).

## 3. التصفية
- **الفترة الزمنية**: (اليوم، الأسبوع، الشهر، مخصص).
- **نوع الفحص**: (الكل، PCR، مزرعة، CBC، إلخ).
- **حالة العينة**: (الكل، مسجلة، قيد التحليل، معتمدة، مرفوضة).

## 4. الصلاحيات
- **فني المختبر**: يرى تقارير عامة وإحصائيات (لا يرى أداء الفنيين الآخرين).
- **مشرف المختبر / مدير المختبر**: يرى جميع التقارير بما في ذلك أداء الفنيين.

## 5. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/lab/reports/kpi` | الحصول على مؤشرات الأداء الرئيسية. |
| `GET` | `/api/v1/lab/reports/samples` | الحصول على بيانات العينات (مع التصفية). |
| `GET` | `/api/v1/lab/reports/export` | تصدير التقرير بصيغة (PDF/Excel). |
