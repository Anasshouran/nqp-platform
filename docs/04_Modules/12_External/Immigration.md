# الجوازات والهجرة - Immigration & Passport Authority

## 1. الهدف
ربط منصة NQP مع نظام الجوازات والهجرة الوطني للتحقق من صحة بيانات المسافرين (جوازات السفر، التأشيرات) بشكل آلي، وتسريع عملية التحقق من الهوية عند الوصول إلى المنافذ.

## 2. نقاط التكامل (Integration Points)

| الاتجاه | البيانات المرسلة | التوقيت | البروتوكول | التنسيق |
| :--- | :--- | :--- | :--- | :--- |
| **من NQP → Immigration** | طلب التحقق من صحة جواز السفر (رقم الجواز، الاسم، تاريخ الميلاد). | عند مسح QR أو إدخال يدوي (للمسافرين غير المسجلين). | REST API | JSON |
| **من Immigration → NQP** | نتيجة التحقق (صحيح/غير صحيح، بيانات إضافية إن وجدت). | فوري (متزامن) | REST API | JSON |

## 3. نموذج طلب التحقق (Verification Request JSON)
```json
{
  "passport_number": "A1234567",
  "first_name": "محمد",
  "last_name": "أحمد",
  "date_of_birth": "1990-05-15"
}

4. نموذج استجابة التحقق (Verification Response JSON)
json

{
  "status": "success",
  "data": {
    "is_valid": true,
    "full_name_ar": "محمد أحمد علي",
    "national_id": "1234567890123",
    "nationality": "السودان",
    "expiry_date": "2030-01-01",
    "visa_status": "VALID"  // VALID, EXPIRED, NONE
  }
}

5. آلية العمل

    يقوم موظف الحجر الصحي بمسح QR الخاص بالمسافر أو إدخال رقم جواز السفر يدوياً في بوابة الفحص (4).

    يقوم النظام بإرسال طلب التحقق إلى نظام الجوازات (عبر واجهة التكامل).

    يتلقى النظام استجابة (صحيح/غير صحيح) خلال ثانيتين.

    إذا كانت البيانات غير صحيحة (جواز مزور أو منتهي الصلاحية)، يعرض النظام تحذيراً للموظف ويتخذ إجراءات إضافية (مثل: إحالة المريض للتحقيق).

6. الأمان

    المصادقة: مفتاح API مخصص لنظام الجوازات (يتم إدارته من قبل مسؤولي النظام).

    التشفير: TLS 1.3.

    الخصوصية: لا يتم تخزين بيانات الجوازات في NQP بشكل دائم (يتم استعلامها في الوقت الفعلي فقط). يتم تخزين (رقم الجواز) فقط كمرجع، وليس البيانات الإضافية.

7. نقاط النهاية (API Endpoints)
الطريقة	المسار	الوصف
POST	/api/v1/integration/immigration/verify	التحقق من صحة جواز السفر.
