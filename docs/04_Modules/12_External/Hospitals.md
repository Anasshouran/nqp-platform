# المستشفيات - Hospitals

## 1. الهدف
ربط منصة NQP مع المستشفيات التابعة لوزارة الصحة (أو الخاصة) لإرسال الإحالات الطبية للحالات الحرجة التي تتجاوز قدرات عيادات الحجر الصحي، مع ضمان نقل كامل البيانات الطبية (التشخيص، الفحوصات، الخطة العلاجية) لتسهيل استقبال المريض واستمرارية الرعاية.

## 2. نقاط التكامل (Integration Points)

| الاتجاه | البيانات المرسلة | التوقيت | البروتوكول | التنسيق |
| :--- | :--- | :--- | :--- | :--- |
| **من NQP → Hospital** | إحالة طبية (بيانات المريض، التشخيص، الفحوصات، الخطة العلاجية). | عند الحاجة | REST API | JSON (متوافق مع FHIR) |
| **من NQP → Hospital** | تحديث حالة المريض (في حال تغير الحالة قبل وصوله). | اختياري | REST API | JSON |

4. آلية العمل

    يقوم الطبيب في بوابة العيادات (5) بتصنيف الحالة كـ (حرجة) ويضغط على زر "إحالة للمستشفى".

    يختار المستشفى المستهدف من قائمة المستشفيات المسجلة في النظام.

    يقوم النظام بتوليد الإحالة وإرسالها إلى المستشفى عبر واجهة التكامل.

    يستقبل المستشفى الإحالة في نظامه، ويتم إشعار الفريق الطبي (عبر البريد الإلكتروني أو الإشعار الداخلي).

    يقوم المستشفى بتأكيد استقبال الإحالة (اختياري)، وتبدأ إجراءات استقبال المريض.

5. الأمان

    المصادقة: مفتاح API لكل مستشفى.

    التشفير: TLS 1.3.

    الخصوصية: يتم إرسال البيانات الطبية الحساسة بتشفير إضافي (AES-256 على مستوى التطبيق) لحماية المريض.

6. نقاط النهاية (API Endpoints)
الطريقة	المسار	الوصف
POST	/api/v1/integration/hospitals/referral	إرسال إحالة طبية إلى مستشفى.
POST	/api/v1/integration/hospitals/confirm	(يستخدمه المستشفى) تأكيد استقبال الإحالة.
