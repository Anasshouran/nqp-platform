# نظام الترصد الوبائي الوطني - National Surveillance System

## 1. الهدف
ربط منصة NQP مع نظام الترصد الوبائي الوطني (إن وجد) أو لوحة القيادة (Dashboard) المركزية لوزارة الصحة، لتغذيته بالبيانات المجمعة (مخفية الهوية) لتوفير رؤية وطنية شاملة عن الحالة الوبائية في جميع المنافذ.

## 2. نقاط التكامل (Integration Points)

| الاتجاه | البيانات المرسلة | التوقيت | البروتوكول | التنسيق |
| :--- | :--- | :--- | :--- | :--- |
| **من NQP → Surveillance** | البيانات المجمعة للحالات (حسب المرض، المنفذ، الفئة العمرية). | كل 6 ساعات (دفعة) | SFTP / REST API | CSV / JSON |
| **من NQP → Surveillance** | التنبيهات الوبائية (تجاوز العتبات). | فوري | REST API / Webhook | JSON |

## 3. البيانات المرسلة (Data Payload)
- **البيانات التي لا تحتوي على معلومات شخصية (Anonymized)**:
  - المرض (كود ICD-11).
  - المنفذ (رمز المنفذ).
  - الفئة العمرية (0-18، 19-40، 41-60، 60+).
  - الجنس.
  - عدد الحالات المؤكدة.
  - عدد الحالات المشتبه بها.
- **مثال على ملف CSV**:
```csv
ICD11_CODE,PORT_CODE,AGE_GROUP,GENDER,CONFIRMED_CASES,PROBABLE_CASES
RA01,KRT,19-40,M,45,12
1B50,KRT,41-60,F,5,2
RA01,PSD,0-18,M,8,4

4. الأمان

    المصادقة: مفتاح API يوفره نظام الترصد.

    إخفاء الهوية: يتم إرسال البيانات بدون (أسماء، أرقام جوازات، هويات) حفاظاً على الخصوصية.

    التحقق: يتم التحقق من صحة البيانات قبل الإرسال (التأكد من عدم احتوائها على معلومات شخصية).

5. نقاط النهاية (API Endpoints)
الطريقة	المسار	الوصف
POST	/api/v1/integration/surveillance/aggregated	إرسال البيانات المجمعة (دفعة).
POST	/api/v1/integration/surveillance/alert	إرسال تنبيه وبائي فوري.
