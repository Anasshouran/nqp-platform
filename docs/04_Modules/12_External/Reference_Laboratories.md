# المختبرات المرجعية - Reference Laboratories

## 1. الهدف
ربط منصة NQP بالمختبرات المرجعية الوطنية (مثل: المختبر المركزي) لإرسال العينات التي تتطلب فحوصات متقدمة أو تأكيدية، واستلام النتائج المعتمدة لإدراجها في ملف المريض.

## 2. نقاط التكامل (Integration Points)

| الاتجاه | البيانات المرسلة | التوقيت | البروتوكول | التنسيق |
| :--- | :--- | :--- | :--- | :--- |
| **من NQP → Lab** | طلب فحص مرجعي (مع بيانات العينة والمريض). | عند الحاجة | REST API | JSON |
| **من Lab → NQP** | نتيجة الفحص المرجعي (معتمدة). | عند الانتهاء | REST API | JSON |
| **من NQP → Lab** | حالة العينة (تم الاستلام، قيد التحليل). | دوري | REST API | JSON |

## 3. نموذج طلب الفحص المرجعي (Request JSON)
```json
{
  "sample_id": "LAB-2024-0001",
  "patient_id": "123e4567-e89b-12d3-a456-426614174000",
  "test_type": "PCR_CONFIRMATORY",
  "disease_code": "RA01",
  "sample_type": "SWAB",
  "collected_at": "2024-07-25T10:00:00Z",
  "notes": "حالة مشتبه بها، المريض يعاني من أعراض حادة."
}

4. نموذج نتيجة الفحص (Result JSON)
json

{
  "sample_id": "LAB-2024-0001",
  "result": "POSITIVE",
  "value": 32.5,
  "approved_by": "د. خالد محمد",
  "approved_at": "2024-07-25T14:30:00Z",
  "notes": "تم تأكيد الإصابة بكوفيد-19."
}

5. آلية العمل

    يقوم الطبيب في بوابة العيادات (5) بطلب فحص مرجعي (إذا كانت النتيجة غير حاسمة أو تحتاج تأكيد).

    يتم إرسال الطلب إلى المختبر المرجعي عبر واجهة التكامل.

    يقوم المختبر بتحليل العينة وإدخال النتيجة في نظامه.

    يقوم نظام المختبر بإرسال النتيجة إلى NQP عبر Webhook أو REST API.

    تظهر النتيجة في بوابة العيادات (5) وتُدرج في EMR الخاصة بالمريض.

6. الأمان

    المصادقة: مفتاح API مخصص للمختبرات المرجعية.

    التشفير: TLS 1.3.

    سجل التدقيق: تسجيل كل طلب ونتيجة في سجل التكامل.

7. نقاط النهاية (API Endpoints)
الطريقة	المسار	الوصف
POST	/api/v1/integration/labs/request	إرسال طلب فحص مرجعي.
POST	/api/v1/integration/labs/result	استقبال نتيجة الفحص (يستخدمه المختبر).
GET	/api/v1/integration/labs/status/{sample_id}	الاستعلام عن حالة العينة.
