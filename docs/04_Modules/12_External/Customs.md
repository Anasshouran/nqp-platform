# الجمارك - Customs

## 1. الهدف
ربط منصة NQP مع نظام الجمارك الوطني (إلكترونياً) لتبادل شهادات الإفراج الصحي للشحنات الغذائية، وتحديث حالة الشحنات في نظام الجمارك، وتسريع عملية الإفراج الجمركي للشحنات المطابقة للمواصفات.

## 2. نقاط التكامل (Integration Points)

| الاتجاه | البيانات المرسلة | التوقيت | البروتوكول | التنسيق |
| :--- | :--- | :--- | :--- | :--- |
| **من NQP → Customs** | شهادة الإفراج الصحي للشحنة الغذائية (مع QR Code). | عند إصدار الشهادة | REST API / SFTP | JSON / PDF |
| **من Customs → NQP** | تحديث حالة الشحنة في نظام الجمارك (مفرج، محتجز). | عند التغيير | REST API | JSON |
| **من NQP → Customs** | تقرير الحالة (عدد الشحنات المفرج عنها، المرفوضة). | يومي/أسبوعي | SFTP / REST API | CSV / JSON |

5. آلية العمل

    بعد إتمام جميع الفحوصات واعتماد النتائج، يقوم مفتش الحجر الغذائي بإصدار شهادة الإفراج الصحي (بوابة 7).

    يقوم النظام تلقائياً بإرسال الشهادة (بصيغة PDF أو JSON) إلى نظام الجمارك عبر واجهة التكامل.

    يستقبل نظام الجمارك الشهادة ويُحدث حالة الشحنة في نظامه (مفرج).

    يتم إرسال تأكيد الاستلام إلى NQP، ويتم تحديث حالة الشحنة في بوابة الحجر الغذائي (7) إلى RELEASED.

6. الأمان

    المصادقة: مفتاح API لنظام الجمارك (يتم توفيره من قبل مسؤولي النظام).

    التشفير: TLS 1.3 (أو SFTP عبر SSH).

    التوقيع الرقمي: يتم توقيع الشهادات رقمياً (Digital Signature) لمنع التزوير.

7. نقاط النهاية (API Endpoints)
الطريقة	المسار	الوصف
POST	/api/v1/integration/customs/certificate	إرسال شهادة الإفراج الصحي إلى الجمارك.
POST	/api/v1/integration/customs/status	(يستخدمه نظام الجمارك) تحديث حالة الشحنة.
