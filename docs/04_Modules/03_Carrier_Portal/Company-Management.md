# إدارة الشركات (Company Management)

## 1. الهدف
تمكين ممثل الشركة من عرض وتحديث بيانات شركته (معلومات الاتصال، الشعار، الإعدادات الأساسية)، وتمكين مسؤولي الإدارة الاتحادية من إنشاء وإدارة حسابات الشركات الجديدة.

## 2. مكونات الصفحة

### 2.1. ملف الشركة الشخصي (Company Profile) - للممثل
- **الحقول القابلة للعرض والتحديث**:
  - اسم الشركة (نص، للقراءة فقط بالنسبة للممثل، يُعدل من قبل الإدارة).
  - رمز IATA / ICAO (نص، للقراءة فقط).
  - البريد الإلكتروني الرسمي (نص، قابل للتعديل).
  - رقم الهاتف (نص، قابل للتعديل).
  - العنوان (نص، قابل للتعديل).
  - الشعار (صورة، قابل للرفع - يُخزن على S3/MinIO).
- **زر**: "حفظ التغييرات".

### 2.2. إدارة المستخدمين الداخليين للشركة (Company Users) - للمسؤولين فقط
- عرض قائمة الموظفين التابعين للشركة (الذين لديهم صلاحية الدخول إلى بوابة الناقل).
- الأعمدة: (الاسم، البريد الإلكتروني، آخر دخول، الحالة (نشط/غير نشط)).
- **زر**: "إضافة مستخدم جديد" (يفتح نموذج لإضافة موظف بصلاحية `CARRIER`).
- **زر**: "تعطيل" / "تفعيل" للمستخدمين.

### 2.3. إدارة مفاتيح API (API Key Management) - للمسؤولين الفنيين
- عرض مفتاح API الحالي (للشركات التي تستخدم التكامل الآلي).
- **زر**: "إنشاء مفتاح جديد" (يُبطل المفتاح القديم ويُولد مفتاحاً جديداً).
- **زر**: "نسخ المفتاح" (مع تنبيه أمني بعدم مشاركته).
- **سجل استخدام المفتاح**: عرض آخر مرة تم فيها استخدام المفتاح وعنوان IP الخاص بالطلب.

## 3. واجهة المسؤول (Django Admin)
- يمكن لمسؤولي الإدارة الاتحادية (دور `FEDERAL_ADMIN`) إدارة جميع الشركات عبر Django Admin:
  - إضافة شركة جديدة (الاسم، IATA، معلومات الاتصال).
  - تعيين مستخدمين (Carrier Representatives) للشركة.
  - تفعيل / تعطيل حسابات الشركات بأكملها (في حالة المخالفات).

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف | الصلاحية |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/carrier/company/profile` | استرجاع بيانات الشركة. | Carrier Rep |
| `PUT` | `/api/v1/carrier/company/profile` | تحديث بيانات الشركة. | Carrier Rep |
| `POST` | `/api/v1/carrier/company/logo` | رفع شعار الشركة. | Carrier Rep |
| `GET` | `/api/v1/admin/companies` | قائمة جميع الشركات (للمسؤولين). | Federal Admin |
| `POST` | `/api/v1/admin/companies` | إضافة شركة جديدة. | Federal Admin |
| `GET` | `/api/v1/carrier/company/api-key` | استرجاع مفتاح API. | Carrier Rep (Admin) |
| `POST` | `/api/v1/carrier/company/api-key/regenerate` | إعادة توليد مفتاح API. | Carrier Rep (Admin) |
