# السجل الطبي الإلكتروني (Electronic Medical Record - EMR)

## 1. الهدف
توفير سجل طبي شامل ودائم لكل مريض في نظام العيادات، يحتوي على التاريخ الطبي، الحساسية، الأدوية الحالية، سجل الزيارات السابقة، والملاحظات السريرية، لضمان استمرارية الرعاية ودقة التشخيص.

## 2. مكونات ملف المريض (Patient Record)

### 2.1. معلومات المريض الأساسية (Demographics)
- (الاسم الكامل، رقم الجواز، تاريخ الميلاد، الجنس، الجنسية، معلومات الاتصال).
- **مكان الإقامة**: (عنوان مؤقت أثناء الحجر - يُطلب من المريض).

### 2.2. التاريخ الطبي (Medical History)
- **الأمراض المزمنة**: (قائمة: السكري، ارتفاع الضغط، أمراض القلب، الربو، إلخ).
- **العمليات الجراحية السابقة**: (مع التواريخ إن وجدت).
- **الحساسية**: (أدوية، أطعمة، مواد أخرى) - تظهر بتحذير أحمر في أعلى الملف.
- **الأدوية الحالية**: (قائمة الأدوية التي يتناولها المريض بانتظام).

### 2.3. سجل الزيارات (Visit History)
- عرض جدول زمني (Timeline) لجميع زيارات العيادة السابقة (إن وجدت):
  - (التاريخ، التشخيص، الطبيب المعالج، ملخص العلاج، حالة الزيارة).
- **زر**: "عرض التفاصيل" (لفتح الزيارة السابقة لعرض السجل الكامل).

### 2.4. سجل التطعيمات (Vaccination Record)
- عرض التطعيمات التي تلقاها المريض (من بوابة المسافرين أو الملف الصحي).
- (اللقاح، التاريخ، الجهة المانحة).

### 2.5. زر "بدء زيارة جديدة" (New Visit)
- (يظهر إذا لم تكن هناك زيارة نشطة للمريض) - يقوم بإنشاء زيارة جديدة وينتقل إلى صفحة الفحص السريري.

## 3. صلاحيات الوصول (Access Control)
- **الطبيب المعالج**: يمكنه عرض وتحديث الملف (قراءة/كتابة).
- **الممرض**: يمكنه عرض الملف وإضافة العلامات الحيوية (قراءة/كتابة محدودة).
- **المسافر**: يمكنه عرض ملفه (قراءة فقط) عبر بوابة المسافرين (2) (بعض الحقول مقيدة).

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/clinic/patients/{traveler_id}/emr` | استرجاع السجل الطبي الكامل للمريض. |
| `PUT` | `/api/v1/clinic/patients/{traveler_id}/emr` | تحديث التاريخ الطبي (الأمراض، الحساسية). |
| `GET` | `/api/v1/clinic/patients/{traveler_id}/visits` | استرجاع سجل الزيارات السابقة. |
