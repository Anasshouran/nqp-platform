# 05_Clinic_Portal - بوابة عيادات الحجر الصحي

## 1. الهدف الاستراتيجي
تزويد الأطباء والممرضين في عيادات الحجر الصحي بأداة رقمية متكاملة لإدارة الرعاية الصحية للمسافرين المحولين من بوابة الفحص (4). تهدف البوابة إلى:
- **ضمان استمرارية الرعاية**: من خلال استلام الإحالات الإلكترونية مع كامل بيانات الفحص الأولي.
- **توحيد التشخيص والعلاج**: باستخدام نظام إدارة الأمراض (ICD-11) وقواعد الأدوية الموحدة.
- **تقليل الأخطاء الطبية**: من خلال السجل الطبي الإلكتروني (EMR) الموحد وكشف التداخلات الدوائية.
- **تسهيل المتابعة**: من خلال ربط خطة العلاج بنظام المتابعة المنزلية (Health Follow-up).

## 2. الممثلون (Actors)
- **الطبيب (Doctor)**: المستخدم الأساسي (مسجل دخوله، مرتبط بعيادة معينة).
- **الممرض (Nurse)**: (دور مساعد) يمكنه تسجيل العلامات الحيوية والمساعدة في الإجراءات.
- **المسافر (Traveler)**: المريض الخاضع للكشف (تفاعل غير مباشر).
- **نظام المنصة (NQP)**: يستقبل البيانات، يستدعي أنظمة الدعم، ويسجل السجل الطبي.

## 3. الميزات الرئيسية (Key Features)
| الميزة | الوصف | الأولوية |
| :--- | :--- | :--- |
| **استقبال الإحالات** | عرض وإدارة الإحالات الواردة من بوابة الفحص (4). | عالية |
| **السجل الطبي الإلكتروني (EMR)** | إنشاء وعرض السجل الطبي للمريض (التاريخ، التشخيص، العلاج). | عالية |
| **الفحص السريري** | تسجيل نتائج الفحص البدني والعلامات الحيوية. | عالية |
| **طلب الفحوصات المخبرية** | إرسال طلبات عينات إلى بوابة المختبرات (6). | عالية |
| **العلاج والوصفات** | وصف الأدوية مع كشف التداخلات الدوائية. | عالية |
| **المتابعة** | إما إفراج المريض، أو تحويله للمتابعة المنزلية، أو إحالته للمستشفى. | عالية |
| **التقارير الطبية** | إصدار تقارير طبية (شهادات، ملخصات) للمريض أو للجهات المختصة. | متوسطة |

5. المتطلبات التقنية (Technical Requirements)

    الواجهة الأمامية: React + Tailwind CSS (مسار /clinic).

    الخلفية: Django REST Framework (نقاط النهاية تحت /api/v1/clinic/).

    المصادقة: JWT مع صلاحيات محددة (الدور: DOCTOR أو NURSE).

    التكامل مع نظام إدارة الأمراض: للحصول على قائمة الأمراض (ICD-11) والأدوية والتداخلات الدوائية.

    التخزين: يتم تخزين السجلات الطبية (EMR) كـ (JSON) في قاعدة البيانات (مع إمكانية البحث).

6. التكامل مع الأنظمة الأخرى

    بوابة الفحص (4): استقبال الإحالات (البيانات الشخصية، الفحص الظاهري، تقييم المخاطر).

    بوابة المختبرات (6): إرسال طلبات الفحوصات واستلام النتائج.

    نظام إدارة الأمراض: استرجاع تعريفات الأمراض والأدوية والتداخلات الدوائية.

    نظام المتابعة الصحية: تفعيل ملف المتابعة للمرضى الذين يحتاجون متابعة منزلية.

    غرفة الطوارئ (9): إرسال إشعار فوري في الحالات الحرجة (مع إمكانية طلب إسعاف).
