# الملف الصحي للمسافر (Health Profile)

## 1. الهدف
توفير سجل صحي دائم للمسافر يحتوي على تاريخه الطبي، التطعيمات، والإقرارات الصحية السابقة، ليكون مرجعاً للطبيب عند الحاجة، ولتسهيل عمليات التسجيل المستقبلية (لا يحتاج المسافر لإعادة إدخال نفس البيانات في كل رحلة).

## 2. مكونات الملف الصحي

### 2.1. المعلومات الأساسية (Demographics)
- الاسم الكامل، تاريخ الميلاد، الجنس، الجنسية، رقم الجواز.

### 2.2. التاريخ الطبي (Medical History)
- **الأمراض المزمنة**: قائمة بالأمراض (مع تواريخ التشخيص إن وجدت).
- **الحساسية**: قائمة بالمواد المسببة للحساسية (أدوية، أطعمة، مواد أخرى).
- **العمليات الجراحية السابقة**: (اختياري) مع تواريخها.
- **الأدوية الحالية**: قائمة بالأدوية التي يتناولها المسافر بانتظام.

### 2.3. سجل التطعيمات (Vaccination Record)
- قائمة بالتطعيمات التي تلقاها المسافر (اللقاح، التاريخ، الجهة المانحة، وصلاحية الشهادة).
- إمكانية رفع شهادة التطعيم وعرضها في الملف.

### 2.4. سجل الإقرارات الصحية (Health Declaration History)
- عرض جميع الإقرارات الصحية السابقة التي قدمها المسافر مع التواريخ.
- إمكانية عرض تفاصيل كل إقرار.

### 2.5. حالة الحجر الصحي السابقة (Quarantine History)
- عرض تاريخ الحجر الصحي السابق (إن وجد): (التاريخ، المنفذ، النتيجة، شهادة التعافي).

## 3. صلاحيات الوصول
- **المسافر**: يمكنه عرض وتحديث ملفه الصحي (باستثناء بعض الحقول التي تكون للقراءة فقط مثل تاريخ الحجر السابق).
- **الطبيب**: يمكنه عرض الملف الصحي للمسافر (عبر بوابة العيادات) عند الحاجة.
- **موظف الحجر**: يمكنه عرض الملف الصحي للمسافر (عبر بوابة الفحص) للتحقق من البيانات.

## 4. التحديثات والإصدارات (Versioning)
- يتم الاحتفاظ بسجل (Audit Log) لكل تغيير يتم إجراؤه على الملف الصحي (متى، ومن قام به، والقيمة القديمة والجديدة) لضمان الشفافية والمساءلة.

## 5. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/travelers/{id}/profile` | استرجاع الملف الصحي الكامل. |
| `PUT` | `/api/v1/travelers/{id}/profile` | تحديث الملف الصحي. |
| `GET` | `/api/v1/travelers/{id}/vaccinations` | استرجاع سجل التطعيمات. |
| `POST` | `/api/v1/travelers/{id}/vaccinations` | إضافة تطعيم جديد. |
