# المختبر (Laboratory Tests) - استلام النتائج وربطها بالشحنة

## 1. الهدف
تمكين مفتش الحجر الغذائي من استلام نتائج تحليل العينات الغذائية من بوابة المختبرات (6) (نفس آلية العينات الطبية)، وربطها بالشحنة، واتخاذ القرار النهائي (مطابق / غير مطابق) بناءً على النتائج ومقارنتها بالمواصفات القياسية.

## 2. مكونات الصفحة

### 2.1. قائمة العينات التي ظهرت نتائجها (Results Received)
- عرض جدول بجميع العينات التي تم تحليلها وظهرت نتائجها (من بوابة المختبرات):
  - الأعمدة: (الباركود، المنتج، الفحص المطلوب، النتيجة (مطابق/غير مطابق)، القيمة الرقمية، تاريخ النتيجة).
- **زر**: "عرض النتيجة" (لفتح تفاصيل النتيجة ومقارنتها بالمواصفات).

### 2.2. صفحة تفاصيل النتيجة (Result Detail)
- **معلومات العينة**:
  - (الباركود، المنتج، نوع العينة، الفحص المطلوب).
- **النتيجة المخبرية**:
  - (القيمة الرقمية، النتيجة النوعية (مطابق/غير مطابق)، ملاحظات الفني).
- **المواصفات القياسية (Standards)**:
  - عرض الحدود المسموحة حسب هيئة المواصفات والمقاييس (يتم جلبها آلياً عبر التكامل الخارجي).
  - (مثال: "الحد الأقصى المسموح للبكتيريا القولونية: 10 CFU/g"، "القيمة المقاسة: 5 CFU/g" ← مطابق).
- **قرار المفتش (Inspector Decision)**:
  - **زر**: "مطابق (Compliant)" - إذا كانت النتيجة ضمن الحدود المسموحة.
  - **زر**: "غير مطابق (Non-Compliant)" - إذا كانت النتيجة خارج الحدود المسموحة (مع حقل سبب).
- **تحديث حالة الشحنة**:
  - إذا كانت جميع العينات مطابقة، يتم تحديث حالة الشحنة إلى `PENDING_RELEASE` (بانتظار الإفراج).
  - إذا كانت أي عينة غير مطابقة، يتم تحديث حالة الشحنة إلى `REJECTED` (مرفوضة) وإشعار المورد والجمارك.

## 3. منطق الأعمال (Business Logic)
- **المقارنة الآلية**: يتم مقارنة النتائج المخبرية مع المواصفات القياسية تلقائياً، وعرض تقرير (Compliant / Non-Compliant) للمفتش.
- **الاستئناف (Appeal)**: (اختياري) يمكن للمورد طلب إعادة التحليل (عبر بوابة خارجية)، وفي هذه الحالة يتم إعادة أخذ العينات وإرسالها لمختبر آخر (مرجعي).

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/food/shipments/{id}/lab-results` | قائمة نتائج المختبر للشحنة. |
| `POST` | `/api/v1/food/samples/{id}/review-result` | مراجعة النتيجة واتخاذ القرار (مطابق/غير مطابق). |
| `GET` | `/api/v1/standards/{product}/{test}` | استرجاع المواصفات القياسية (تكامل خارجي). |
