# 👤 رئيس قسم الكيمياء — Chemistry Section Head

> الدور: `CHEM_SECTION_HEAD` — نظام معلومات المختبر (FCLIS) (`04_Modules/07_Food_Quarantine`)

يدير **عينات قسم الكيمياء** داخل المختبر: يُوزّع العينات على المحللين، يتابع التحاليل وSLA، يراجع النتائج ويعيدها للتصحيح عند الحاجة، يراجع الجودة (QC)، ويُشرف على جاهزية الأجهزة ومعايرتها.

## 🎯 Dashboard رئيس القسم

يفتح مباشرة على صفحة **قسم الكيمياء** (`/app/chemistry`) والتي تضم:

* 📊 **لوحة الإحصاءات**: عينات الكيمياء، قيد التحليل، الجاهزة للاعتماد، المتأخرة SLA، بانتظار QC، مخالفات QC، الأجهزة، المعايرات المتأخرة.
* 🧪 **عينات الكيمياء**: جدول عينات القسم (قسم الكيمياء) مع الأولوية والحالة والمحلّل — وفتح العينة لإسناد المحلّل وإدارة الاختبارات.
* ✅ **مراجعة الجودة QC**: جدول نتائج فحوصات الكيمياء مع حالة QC لكل نتيجة.
* 🔧 **الأجهزة والمعايرة**: سجل أجهزة القسم وحالاتها ومواعيد المعايرة.

## 🔒 قاعدة أساسية

> **رئيس القسم يُوزّع ويراجع ويقبل القسم — ولا يُدخل النتائج بدل المحلل، ولا يُعدّل المواصفات.**

* **التوزيع**: إسناد المحلل من داخل تفاصيل العينة (`assign-analyst`) — يملك صلاحية `laboratory:edit`.
* **المراجعة**: يظهر زر `مراجعة القسم` للنتائج `SUBMITTED` فقط (دور رئيس القسم/مدير المختبر).
* **الإعادة**: زر `إعادة للتحليل` يعيد النتيجة إلى المحلل كـ `DRAFT` مع تسجيل السبب في الملاحظات.
* **الاعتماد**: زر `اعتماد` يتاح لمدير المختبر ورئيس القسم على النتائج `REVIEWED`.
* **QC**: زر `مراجعة QC` يسجّل حالة النتيجة (مطابق/غير مطابق) مع الملاحظة واسم المراجِع.
* محجوب عنه تقنيًا عبر `_block_non_analyst_role` كل أدوار «الاستلام/التنسيق» لا تُدخل النتائج ولا تراجعها.

## 🖥️ شاشات رئيس القسم

* **لوحة القسم**: إحصاءات فورية (عينات، قيد التحليل، متأخرة، QC، أجهزة).
* **جدول عينات الكيمياء**: بحث وترتيب وفتح العينة — داخل تفاصيل العينة يُسنِد المحلّل ويشاهد الفحوصات (نتيجة/تقييم ميكروبي/مراجعة/إعادة/QC/اعتماد حسب الحالة).
* **مراجعة QC**: جدول نتائج القسم مع حالة QC، وزر `مراجعة QC` لتسجيل المطابقة/المخالفة.
* **الأجهزة والمعايرة**: سجل الأجهزة (تشغيلية/قيد الصيانة/خارج الخدمة)، تسجيل معايرة جديد وتحديث موعدها القادم، تنبيه عند تأخر المعايرة.
* **تقرير CSV**: تصدير جدول عينات القسم الحالي لملف CSV.
