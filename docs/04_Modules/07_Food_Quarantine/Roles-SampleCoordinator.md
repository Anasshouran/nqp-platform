# 👤 منسق عينات المختبر — Sample Coordinator

> الدور: `LAB_COORDINATOR` — نظام معلومات المختبر (FCLIS) (`04_Modules/07_Food_Quarantine`)

حلقة الوصل بين **الاستلام** و**الأقسام الفنية**: يوزّع العينات على الأقسام، يحدد الفحوصات، يرتب الأعباء ويراقب الأولوية وSLA قبل تسليم العينة للمحلل. **لا يدخل نتائج التحليل ولا يعتمدها.**

## 🎯 Dashboard المنسّق

يفتح مباشرة على صفحة **معمل الأغذية** (`/app/food-lab`) ويعمل على:

* 📊 **لوحة التحكم** (إحصائيات العينات، أولويات، استحقاق SLA)
* 🔍 **مشاهدة العينات المقبولة** وتصنيفها حسب القسم/الحالة/الأولوية
* 🏷️ **ضبط الأولوية** (منخفضة / عادية / عالية / عاجلة)
* 📂 **تصنيف العينة** وتعديله
* 🔄 **التوزيع** على الأقسام (كيمياء / ميكروبيولوجي) ورؤساء الأقسام
* 🧪 **تحديد الفحوصات** المطلوبة (analysis orders)
* 📤 **إعادة التوزيع** عند الحاجة
* ⏱️ **متابعة SLA** لكل اختبار (استحقاق، تأخير، TAT)

## 🔒 قاعدة أساسية

> **المنسّق يُوزّع ويُصنّف ويُرتب أولويات العمل، ولا يلمس نتائج التحليل أو قرارات الاعتماد.**

النظام يحقق ذلك على طبقتين:
* **الواجهة**: أزرار إدخال/تقييم النتيجة (`نتيجة` / `تقييم` / `بدء` / `تصحيح`) مخفية عن المنسّق؛ تظهر فقط لمدير المختبر والمحلّل الفني.
* **RBAC**: التوزيع/التنسيق/الفواتير لا تتطلب صلاحيات نتائج.

## 🔄 Workflow المنسّق

```text
┌──────────────────────────┐
│ العينات المقبولة          │
│ من موظف الاستلام          │
└──────┬───────────────────┘
       ↓
┌──────────────────────────┐
│ تصنيف العينة + الأولوية   │
└──────┬───────────────────┘
       ↓
┌──────────────────────────┐
│ توزيع على القسم            │
│ (كيمياء/مايكرو)           │
└──────┬───────────────────┘
       ↓
┌──────────────────────────┐
│ تحديد الفحوصات المطلوبة   │
└──────┬───────────────────┘
       ↓
┌──────────────────────────┐
│ إحالة للمحلل الفني        │
│ + متابعة SLA              │
└──────┬───────────────────┘
       ↓
   عينة قيد التحليل
   (دائرة المحلل ورئيس القسم)
```

## 🖥️ شاشات المنسّق

* **لوحة المنسّق (الديتيل)**: حقل "أولوية التحليل" + حقل "التصنيف" مع حفظ منفصل لكل منهما.
* **إعادة توزيع**: إعادة إسناد العينة لقسم آخر أو رئيس قسم آخر في أي وقت قبل بدء التحليل.
* **تحديد الفحوصات**: اختيار المعايير/الفحوصات المطلوبة قبل إرسالها للمحلل.

## 🏷️ مستويات الأولوية

| الكود      | العربية     | الترخيم |
| ---------- | ----------- | ------- |
| `LOW`      | منخفضة      | `neutral` |
| `NORMAL`   | عادية       | `info`   |
| `HIGH`     | عالية       | `warning`|
| `URGENT`   | عاجلة       | `error`  |

تُعرض كـ Chip في: رأس نافذة العينة، جدول العينات، وجداول لوحة المنسّق. كل تحديث يُسجَّل مع المُحدِّث والوقت (`priority_updated_by` / `priority_updated_at`).
