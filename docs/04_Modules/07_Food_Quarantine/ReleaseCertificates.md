# شهادات الإفراج الصحي (Release Certificates)

## 0. شهادة القرار المطبق (`FoodDecisionCertificate`)
- ينشئها `POST /api/v1/food/shipments/{id}/decide` بأمر **رئيس القسم** بعد سداد الرسوم
  (`fees_paid=true` إلزامي).
- رقم الشهادة: `FCER-<hex 10 رموز>`، ونوعها `certificate_type` = القرار (مطابق/إفراج مشروط/
  جزئي/مؤقت/رفض/حجز/إعادة تصدير/تحويل/إتلاف) — راجع جدول القرارات وفـ «ملاحظة» أن
  `PARTIAL_RELEASE`/`TEMPORARY_RELEASE`/`TRANSFER` تُسقط على حالات `CONDITIONAL_RELEASE`/`HOLD`.
- الحقول: `shipment`, `certificate_number`, `certificate_type`, `decision`, `reason`,
  `certificate_data` (`{manifest}`).

## 1. الهدف
تمكين مفتش الحجر الغذائي من إصدار شهادة إفراج صحي إلكترونية للشحنات التي اجتازت جميع مراحل التفتيش والتحليل المخبري بنجاح، مع إرسالها آلياً إلى نظام الجمارك لإنهاء إجراءات الإفراج الجمركي.

## 2. مكونات الصفحة

### 2.1. قائمة الشحنات الجاهزة للإفراج (Pending Release)
- عرض جدول بالشحنات التي حالتها `PENDING_RELEASE` (بانتظار الإفراج):
  - الأعمدة: (رقم البيان، المورد، تاريخ الوصول، عدد المنتجات، تاريخ الانتهاء من التحليل).
- **زر**: "إصدار شهادة" (لفتح نموذج إصدار الشهادة).

### 2.2. نموذج إصدار الشهادة (Certificate Issuance Form)
- **بيانات الشحنة** (للرجوع السريع):
  - (رقم البيان، المورد، دولة المنشأ، قائمة المنتجات).
- **محتوى الشهادة (Certificate Content)**:
  - يتم توليده تلقائياً بناءً على بيانات الشحنة ونتائج التحليل.
  - **المحتوى النموذجي**:
    - اسم الجهة المصدرة: "منصة الحجر الصحي القومي - إدارة الحجر الغذائي".
    - رقم الشهادة: (يُولّد تلقائياً بصيغة `FQ-YYYY-XXXX`).
    - اسم المورد.
    - قائمة المنتجات (الأسماء، الكميات، التواريخ).
    - تاريخ الإصدار.
    - توقيع المفتش الإلكتروني.
    - **رمز QR**: يحتوي على (رقم الشهادة، رقم البيان، تاريخ الإصدار، توقيع رقمي) للتحقق من صحتها.
- **زر**: "معاينة الشهادة" (لعرض الشهادة بصيغة PDF قبل الإصدار).
- **زر**: "إصدار الشهادة وإرسالها للجمارك" (الزر الرئيسي).

### 2.3. أرشيف الشهادات الصادرة (Issued Certificates Archive)
- عرض جدول بجميع الشهادات الصادرة سابقاً:
  - الأعمدة: (رقم الشهادة، رقم البيان، المورد، تاريخ الإصدار، الحالة (نشط، ملغي)).
- **زر**: "عرض الشهادة" (لفتح الشهادة بصيغة PDF).
- **زر**: "إلغاء الشهادة" (في حال اكتشاف خطأ، مع إشعار الجمارك تلقائياً).

### 2.4. التحقق من صحة الشهادة (Certificate Verification - واجهة عامة)
- **صفحة عامة** (لا تتطلب تسجيل دخول) لمسح QR Code أو إدخال رقم الشهادة للتحقق من صحتها.
- تظهر معلومات الشهادة (رقم البيان، المورد، المنتجات، تاريخ الإصدار، حالة الشهادة (نشط/ملغي)).

## 3. منطق الأعمال (Business Logic)
- **الإصدار التلقائي**: يتم توليد الشهادة تلقائياً بناءً على بيانات الشحنة، ولا يمكن تعديلها يدوياً (لضمان الدقة).
- **التكامل مع الجمارك**: يتم إرسال الشهادة إلكترونياً إلى نظام الجمارك عبر API (أو SFTP) عند الإصدار.
- **إلغاء الشهادة**: لا يمكن إلغاء الشهادة إلا بصلاحية (Food Supervisor) مع إشعار الجمارك فوراً.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `POST` | `/api/v1/food/shipments/{id}/release-certificate` | إصدار شهادة الإفراج. |
| `POST` | `/api/v1/food/shipments/{id}/decide` | إصدار شهادة القرار (`FoodDecisionCertificate`) لكل القرارات. |
| `GET` | `/api/v1/food/certificates/{id}` | استرجاع شهادة (للعرض أو الطباعة). |
| `GET` | `/api/v1/food/certificates/verify?number={number}` | التحقق من صحة الشهادة (عام). |
| `POST` | `/api/v1/food/certificates/{id}/revoke` | إلغاء الشهادة (للمشرفين فقط). |
