# 02_User_Profiles - ملفات المستخدمين والأدوار في التطبيق

## 1. ملف المريض/المسافر (Patient Profile)

### البيانات الأساسية (مأخوذة من بوابة المسافرين)
| الحقل | المصدر | القابلية للتعديل |
| :--- | :--- | :--- |
| الاسم الكامل | التسجيل المسبق | ❌ (للقراءة فقط) |
| رقم الجواز | التسجيل المسبق | ❌ |
| تاريخ الميلاد | التسجيل المسبق | ❌ |
| رقم الجوال | التسجيل المسبق | ✅ (يمكن تحديثه) |
| البريد الإلكتروني | التسجيل المسبق | ✅ |

### البيانات الصحية (ديناميكية)
| الحقل | المصدر | الوصف |
| :--- | :--- | :--- |
| الأمراض المزمنة | الملف الصحي | (مثل: سكري، ضغط) - تُقرأ من النظام. |
| التطعيمات | نظام التطعيم | قائمة بالتطعيمات المسجلة. |
| الأدوية الحالية | نظام الأدوية | الأدوية الموصوفة في المتابعة. |
| حالة المتابعة | نظام المتابعة | (نشط، مكتمل، ملغي). |

### حالة المتابعة (Follow-up Status)
- **نشط (Active)**: المريض تحت المتابعة ويجب عليه الإبلاغ يومياً.
- **مكتمل (Completed)**: انتهت فترة المتابعة بنجاح.
- **منتهي (Expired)**: انتهت المدة دون استكمال الإبلاغ.
- **ملغي (Cancelled)**: ألغى الطبيب المتابعة.

## 2. ملف الفريق الطبي (Staff Profile) - اختياري للتطبيق
| الحقل | الوصف |
| :--- | :--- |
| الاسم الكامل | اسم الطبيب أو الممرض. |
| الدور (Role) | (طبيب، ممرض، مشرف). |
| الحالات النشطة (Active Cases) | عدد المرضى المتابعين حالياً. |
| التنبيهات المعلقة (Pending Alerts) | الحالات التي تحتاج إلى تدخل. |
