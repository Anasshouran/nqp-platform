# 08_Push_Notifications - الإشعارات الفورية (Push Notifications)

## 1. التقنية المستخدمة
- **Firebase Cloud Messaging (FCM)**: لإرسال الإشعارات إلى كل من iOS و Android.
- **التكامل**: يتم تسجيل جهاز المستخدم (Device Token) عند تسجيل الدخول الأول، وإرساله إلى الخادم الخلفي.

## 2. أنواع الإشعارات

| النوع | التوقيت | المحتوى | الإجراء عند الضغط |
| :--- | :--- | :--- | :--- |
| **تذكير بالإبلاغ اليومي** | كل صباح (الساعة 8:00 صباحاً) | "حان وقت الإبلاغ اليومي. كيف تشعر اليوم؟" | فتح شاشة الإبلاغ اليومي. |
| **تذكير بالدواء** | قبل 15 دقيقة من موعد الجرعة | "حان موعد تناول [اسم الدواء] بجرعة [الجرعة]." | فتح شاشة الأدوية. |
| **تحديث الحالة** | عند تغيير حالة المتابعة | "تم تحديث حالتك إلى [الحالة الجديدة]." | فتح الشاشة الرئيسية. |
| **نتيجة فحص جديد** | عند اعتماد النتيجة | "تم استلام نتيجة الفحص: [النتيجة]." | فتح الملف الصحي. |
| **تنبيه خطر (أحمر)** | فوري | "تنبيه: تم تسجيل أعراض خطيرة. يرجى التوجه للمستشفى." | فتح شاشة الطوارئ (SOS). |
| **شهادة التعافي** | عند إصدار الشهادة | "تهانينا! تم إصدار شهادة التعافي الخاصة بك." | فتح شاشة الشهادات. |
| **رسالة من الطبيب** | عند إرسال رسالة | "لديك رسالة جديدة من فريق المتابعة الصحية." | فتح مركز الرسائل. |

## 3. تدفق الإشعارات (Notification Flow)
```mermaid
sequenceDiagram
    participant Backend as الخادم الخلفي
    participant FCM as Firebase FCM
    participant Device as جهاز المستخدم
    participant App as التطبيق

    Backend->>FCM: 1. إرسال إشعار (مع Device Token)
    FCM-->>Device: 2. استقبال الإشعار (حتى لو كان التطبيق مغلقاً)
    Device->>App: 3. فتح التطبيق (إذا تم الضغط على الإشعار)
    App->>App: 4. عرض الشاشة المناسبة (حسب نوع الإشعار)

4. إدارة الإشعارات في التطبيق

    الإعدادات: يمكن للمستخدم تفعيل/تعطيل أنواع معينة من الإشعارات (مثل: تذكير الدواء، الإبلاغ اليومي).
    الخصوصية: لا يتم إرسال أي بيانات حساسة في الإشعار (يتم عرضها فقط بعد فتح التطبيق).
