# 03_Features - الميزات والوظائف الرئيسية للتطبيق

## 1. ميزات ما قبل السفر (Pre-Travel Features)
### 1.1. التسجيل المسبق (Pre-registration)
- إنشاء حساب جديد باستخدام البريد الإلكتروني أو رقم الجوال.
- ملء استمارة الفحص الصحي (الأعراض، تاريخ السفر).
- رفع المستندات (صورة جواز السفر، شهادات التطعيم).
- استلام رمز QR بعد اعتماد الطلب.

### 1.2. متطلبات السفر (Travel Requirements)
- عرض متطلبات الدخول للدولة المستهدفة (تطعيمات، فحوصات).
- تحديثات فورية عند تغيير متطلبات السفر.

## 2. ميزات أثناء المتابعة (Follow-up Features)
### 2.1. الإبلاغ اليومي (Daily Check-in)
- إدخال درجة الحرارة (يدوياً أو عبر جهاز Bluetooth).
- إدخال تشبع الأكسجين (SpO2).
- اختيار الأعراض من قائمة (سعال، ضيق تنفس، صداع، إلخ).
- **مقياس الحالة النفسية (Mood Scale)**: اختيار من 1-10 (لتقييم الصحة النفسية).

### 2.2. إدارة الأدوية (Medication Management)
- عرض جدول الأدوية اليومي (الاسم، الجرعة، الوقت).
- **زر (تأكيد التناول)**: يتحول إلى (تم التناول) باللون الأخضر.
- تذكير قبل موعد الجرعة بـ 15 دقيقة (Push Notification).

### 2.3. عرض التقييم (Risk Assessment)
- عرض درجة المخاطر الحالية (أخضر/أصفر/أحمر) مع شرح.
- عرض تاريخ التقييمات السابقة (Timeline).

### 2.4. استلام الشهادات (Certificates)
- **شهادة التعافي (Recovery Certificate)**: تظهر تلقائياً عند اكتمال المتابعة.
- **رمز QR**: قابل للمسح للتحقق من صحة الشهادة.
- **مشاركة الشهادة**: عبر البريد الإلكتروني، واتساب، أو حفظ الصورة.

## 3. ميزات التواصل (Communication Features)
### 3.1. الإشعارات الفورية (Push Notifications)
- تذكير بالإبلاغ اليومي (كل صباح).
- تنبيه بموعد الجرعة (قبل 15 دقيقة).
- إشعار بتدهور الحالة (إذا كانت الأعراض خطيرة).
- إشعار باستلام شهادة التعافي.

### 3.2. مركز الرسائل (Inbox)
- استلام رسائل توجيهية من الفريق الطبي.
- استلام نتائج الفحوصات الجديدة.
- إشعارات بتحديث حالة الطلب.

### 3.3. زر الطوارئ (Emergency SOS)
- زر ثابت في الشاشة الرئيسية (باللون الأحمر).
- عند الضغط (مع تأكيد): إرسال إحداثيات GPS + آخر قراءات + طلب إسعاف فوري إلى غرفة الطوارئ (EOC).

## 4. ميزات الملف الشخصي (Profile Features)
- عرض الملف الصحي الكامل.
- تحديث معلومات الاتصال.
- تغيير كلمة المرور.
- تسجيل الخروج.
- حذف الحساب (طلب إلغاء).

## 5. ميزات الفريق الطبي (Staff Features - اختياري)
- لوحة تحكم مبسطة للحالات النشطة.
- عرض المرضى حسب الأولوية (أحمر أولاً).
- إرسال رسائل توجيهية للمرضى.
- تعديل خطة العلاج (إذا كان طبيباً).
