# 01_System_Overview - التطبيق الجوال لمنصة NQP

## 1. الهدف الاستراتيجي (Strategic Objective)
يهدف التطبيق الجوال إلى **تمكين المسافرين والمرضى من التفاعل مع منصة الحجر الصحي القومي بسهولة ومرونة** من خلال هواتفهم الذكية، دون الحاجة لجهاز حاسوب. يوفر التطبيق واجهة مبسطة للإبلاغ اليومي عن الأعراض، وتتبع حالة الطلب، واستلام شهادات التعافي، والتواصل مع الفريق الطبي.

## 2. أنواع المستخدمين (User Types)
| النوع | الوصف | الأجهزة المدعومة |
| :--- | :--- | :--- |
| **المسافر / المريض (Patient)** | مستخدم عادي يقوم بالتسجيل المسبق، والإبلاغ اليومي، وعرض سجله الصحي. | iOS & Android |
| **فريق المتابعة (Medical Staff)** | (اختياري) أطباء وممرضون لمتابعة الحالات وإدارة التنبيهات. | iOS & Android (أو عبر الويب) |
| **مسؤول النظام (Admin)** | (نادر) إدارة المستخدمين والإعدادات - يُفضل عبر الويب. | - |

## 3. النطاق الوظيفي (Functional Scope)
| الوظيفة | الوصف |
| :--- | :--- |
| **التسجيل المسبق (Pre-registration)** | (مرحلة أولى) يمكن للمسافر التسجيل عبر التطبيق بدلاً من الويب. |
| **الإبلاغ اليومي (Daily Check-in)** | إدخال الأعراض والعلامات الحيوية (الحرارة، SpO2) يومياً. |
| **تتبع حالة الطلب (Request Tracking)** | عرض حالة الطلب (قيد المراجعة، مكتمل، مرفوض). |
| **عرض الملف الصحي (Health Profile)** | عرض تاريخ الفحوصات، التطعيمات، والأدوية. |
| **إدارة الأدوية (Medication Reminders)** | تذكير بمواعيد الجرعات وتأكيد التناول. |
| **استلام الشهادات (Certificates)** | تنزيل ومشاركة شهادة التعافي الرقمية (QR Code). |
| **التواصل مع الطبيب (Chat/Notifications)** | إرسال استفسارات واستقبال توجيهات من الفريق الطبي. |
| **إشعارات فورية (Push Notifications)** | تنبيهات تذكير بالإبلاغ اليومي، مواعيد الأدوية، تحديثات الحالة. |
| **وضع عدم الاتصال (Offline Mode)** | إدخال البيانات دون اتصال، مع مزامنة تلقائية عند عودة الاتصال. |

## 4. التكامل مع المنصة (Integration)
| النظام/البوابة | نوع التكامل | الغرض |
| :--- | :--- | :--- |
| **بوابة المسافرين (2)** | REST API | تسجيل الدخول، رفع المستندات، استلام QR. |
| **نظام المتابعة الصحية** | REST API + WebSocket | الإبلاغ اليومي، استلام التوجيهات. |
| **نظام الإشعارات** | Firebase FCM | إرسال Push Notifications. |
| **نظام إدارة الأدوية** | REST API | استلام جدول الأدوية وتأكيد التناول. |
| **نظام الشهادات** | REST API | استلام وتنزيل شهادة التعافي. |
