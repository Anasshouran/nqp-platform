# 19_Port_Health_System - نظام صحة الموانئ

## 1. الهدف الاستراتيجي
نظام متخصص لإدارة الصحة العامة والحجر الصحي في الموانئ البحرية، وفقاً للوائح الصحية الدولية (IHR 2005).

## 2. المكونات الرئيسية
| المكون | الوصف | الأولوية |
| :--- | :--- | :--- |
| **إدارة السفن** | تتبع السفن القادمة والمغادرة. | عالية |
| **فحص المسافرين** | فحص الركاب وأطقم السفن. | عالية |
| **صحة الطاقم** | تتبع الشهادات الصحية للطاقم. | عالية |
| **تفتيش السفن** | فحص نظافة السفن ومياه الشرب. | عالية |
| **العزل والحجر** | إدارة حالات العزل على متن السفن. | عالية |

## 3. التكامل مع الأنظمة الأخرى
- **نظام صحة المسافرين (02)**: استرجاع بيانات المسافرين.
- **نظام المختبرات (06)**: إرسال العينات.
- **نظام الترصد الوبائي (10)**: تغذية بيانات الحالات.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/port/vessels/` | قائمة السفن |
| `POST` | `/api/v1/port/screenings/` | تسجيل فحص |
| `GET` | `/api/v1/port/quarantine/` | حالات العزل |
