# الإعدادات العامة (System Settings)

## 1. الهدف
تمكين المسؤولين (Super Admin) من تعديل الإعدادات العامة للمنصة بشكل ديناميكي (بدون الحاجة لتعديل الكود أو إعادة النشر)، مثل: (إعدادات البريد الإلكتروني، عتبات الإنذار، فترات الحجر، قوالب الإشعارات، وإعدادات التكامل الخارجي).

## 2. مكونات الصفحة

### 2.1. الإعدادات الأساسية (General Settings)
| الإعداد | الوصف | النوع |
| :--- | :--- | :--- |
| **اسم المنصة** | الاسم الذي يظهر في شريط العنوان وفي البريد الإلكتروني. | نص (String) |
| **اللغة الافتراضية** | اللغة الافتراضية للموقع (عربي / إنجليزي). | قائمة منسدلة |
| **المنطقة الزمنية** | المنطقة الزمنية الافتراضية (Africa/Khartoum). | قائمة منسدلة |
| **وضع الصيانة (Maintenance Mode)** | تفعيل/تعطيل وضع الصيانة (يعرض صفحة "قيد الصيانة" للزوار). | خانة اختيار (Boolean) |

### 2.2. إعدادات الحجر الصحي (Quarantine Settings)
| الإعداد | الوصف | النوع |
| :--- | :--- | :--- |
| **مدة الحجر الإلزامي (أيام)** | المدة الافتراضية للحجر المؤسسي (قابلة للتعديل حسب المرض). | رقم (Integer) |
| **عتبة الإنذار للحرارة** | درجة الحرارة التي يتم عندها تصنيف المسافر كـ (أصفر) تلقائياً. | رقم (Float) |
| **عتبة الإنذار لـ SpO2** | مستوى الأكسجين الذي يتم عندها تصنيف المسافر كـ (أحمر) تلقائياً. | رقم (Integer) |
| **صلاحية QR Code (ساعات)** | المدة التي يظل فيها QR Code صالحاً للاستخدام. | رقم (Integer) |

### 2.3. إعدادات الإشعارات (Notification Settings)
| الإعداد | الوصف | النوع |
| :--- | :--- | :--- |
| **قوالب الإشعارات (البريد الإلكتروني، SMS)** | تحرير محتوى الإشعارات (مثل: قالب تأكيد التسجيل، قالب تغيير الحالة). | محرر نصوص (TextArea) |
| **مزود الرسائل القصيرة (SMS Provider)** | اختيار مزود خدمة الرسائل القصيرة (Sudani، Zain، Twilio). | قائمة منسدلة |
| **مفتاح API لمزود الرسائل القصيرة** | المفتاح الخاص بمزود الخدمة. | حقل آمن (Password) |

### 2.4. إعدادات التكامل (Integration Settings)
| الإعداد | الوصف | النوع |
| :--- | :--- | :--- |
| **رابط API لوزارة الصحة** | عنوان URL الخاص بـ API وزارة الصحة. | رابط (URL) |
| **مفتاح API لوزارة الصحة** | مفتاح المصادقة الخاص بوزارة الصحة. | حقل آمن (Password) |
| **رابط API لهيئة المواصفات** | عنوان URL الخاص بـ API هيئة المواصفات والمقاييس. | رابط (URL) |
| **إعدادات الجمارك (SFTP/API)** | بيانات الاتصال بنظام الجمارك (المضيف، المنفذ، اسم المستخدم، كلمة المرور). | مجموعة حقول آمنة |

### 2.5. سجل التغييرات (Change Log)
- عرض جدول بآخر التغييرات التي تم إجراؤها على الإعدادات:
  - (من قام بالتغيير، متى، ما هو الإعداد الذي تم تغييره، القيمة القديمة، القيمة الجديدة).

## 3. منطق الأعمال (Business Logic)
- **الصلاحيات**: فقط المستخدمون الذين لديهم دور `SUPER_ADMIN` يمكنهم الوصول إلى هذه الصفحة.
- **التخزين**: يتم تخزين الإعدادات في قاعدة البيانات (جدول `SystemSettings`) أو باستخدام حزمة `django-constance`.
- **التطبيق الفوري**: جميع التغييرات تنعكس فوراً على النظام (بدون الحاجة لإعادة تشغيل الخادم).

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف | الصلاحية |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/admin/settings/` | استرجاع جميع الإعدادات. | Super Admin |
| `PUT` | `/api/v1/admin/settings/` | تحديث الإعدادات. | Super Admin |
| `GET` | `/api/v1/admin/settings/audit` | سجل التغييرات على الإعدادات. | Super Admin |
