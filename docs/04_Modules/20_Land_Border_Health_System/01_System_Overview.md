# 20_Land_Border_Health_System - نظام صحة المعابر البرية

## 1. الهدف الاستراتيجي
نظام متخصص لإدارة الصحة العامة والحجر الصحي في المعابر البرية، مع التركيز على المسافرين والشحنات الغذائية البرية.

## 2. المكونات الرئيسية
| المكون | الوصف | الأولوية |
| :--- | :--- | :--- |
| **إدارة المعابر** | تتبع المعابر البرية وحالتها. | عالية |
| **فحص المسافرين** | فحص المسافرين القادمين والمغادرين. | عالية |
| **فحص الشحنات** | فحص الشحنات الغذائية البرية. | عالية |
| **صحة الطواقم** | تتبع صحة سائقي الشاحنات والطواقم. | عالية |
| **العزل والحجر** | إدارة حالات العزل في المعابر. | عالية |

## 3. التكامل مع الأنظمة الأخرى
- **نظام صحة المسافرين (02)**: استرجاع بيانات المسافرين.
- **نظام سلامة الغذاء (18)**: فحص الشحنات الغذائية.
- **نظام الترصد الوبائي (10)**: تغذية بيانات الحالات.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/border/checkpoints/` | قائمة المعابر |
| `POST` | `/api/v1/border/screenings/` | تسجيل فحص |
| `GET` | `/api/v1/border/shipments/` | قائمة الشحنات البرية |

## 5. الوثائق الفرعية
| الوثيقة | المحتوى |

## ⚙️ حالة التنفيذ مقابل الكود

> **لا يوجد تطبيق `border` منفصل** — المعابر البرية تُدار عبر المنصة الموحدة:

| المكوّن (كما في §2) | الحالة | أين يُنفَّذ فعليًا |
| :--- | :--- | :--- |
| إدارة المعابر | ✅ مطبَّق | `masterdata.EntryPoint` بنوع `LAND_PORT` (لا مسار `/api/v1/border/` كما ورد أعلاه — انظر الملاحظة) |
| فحص المسافرين | ✅ مطبَّق | `apps.screening` + `HealthScreening` على أي منفذ بما فيه البري |
| فحص الشحنات | ✅ مطبَّق | `apps.food_quarantine` مع التصفية `?port_type=LAND_PORT` |
| صحة الطواقم | ✅ مطبَّق | `screening` + `clinic` (الإحالات) |
| العزل والحجر | ✅ مطبَّق | `clinic.ClinicReferral` + حالات الحجر في screening |
| نقاط النهاية §4 | ⚠️ توثيق قديم | المسارات الفعلية: `/api/v1/screening/`، `/api/v1/food/shipments/?port_type=LAND_PORT`، `/api/v1/public/ports/?kind=LAND_PORT` |
