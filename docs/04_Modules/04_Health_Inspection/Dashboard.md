# لوحة تحكم موظف الحجر الصحي (Port Health Dashboard)

## 1. الهدف
تزويد موظف الحجر الصحي بنظرة لحظية شاملة على الرحلات القادمة إلى منفذه، وحالة المسافرين المنتظرين، والتنبيهات الفورية، لتمكينه من التخطيط المسبق وتوزيع الجهود بشكل فعال.

## 2. مكونات الصفحة

### 2.1. الشريط العلوي (Top Bar)
- **اسم المنفذ**: (مثل: "مطار الخرطوم الدولي - بوابة رقم 3").
- **اسم الموظف**: (مسجل الدخول) مع زر "تسجيل الخروج".
- **حالة الاتصال**: أيقونة (🟢 متصل / 🔴 غير متصل) مع عدد الطلبات المعلقة في وضع عدم الاتصال.
- **زر**: "التبديل بين اللغات" (عربي/إنجليزي).

### 2.2. بطاقات الملخص العلوي (KPI Cards)
| البطاقة | القيمة | المصدر |
| :--- | :--- | :--- |
| **الرحلات القادمة اليوم** | عدد الرحلات | نظام إدارة الرحلات (المصفاة حسب المنفذ). |
| **المسافرون المنتظرون** | عدد المسافرين | قوائم الركاب (Manifest) للرحلات القادمة خلال الـ 4 ساعات القادمة. |
| **حالات (أصفر) اليوم** | عدد الحالات المصنفة صفراء | نظام تقييم المخاطر (منذ منتصف الليل). |
| **حالات (أحمر) اليوم** | عدد الحالات المصنفة حمراء | نظام تقييم المخاطر (مع إشعار فوري). |

### 2.3. قائمة الرحلات القادمة (Upcoming Flights)
- عرض جدول بالرحلات المتوقع وصولها خلال الـ 6 ساعات القادمة:
  - الأعمدة: (رقم الرحلة، شركة الطيران، بلد المغادرة، وقت الوصول المتوقع، عدد الركاب، نسبة المسجلين مسبقاً، حالة الرحلة).
- **زر**: "عرض التفاصيل" (ينتقل إلى صفحة إدارة الرحلات مع تركيز على الرحلة المحددة).
- **زر**: "تحديث القائمة" (لجلب البيانات يدوياً).

### 2.4. قائمة انتظار المسافرين (Passenger Queue)
- عرض المسافرين الذين تم مسح QR الخاص بهم ولكن لم يتم إجراء الفحص لهم بعد:
  - الأعمدة: (الاسم، رقم الجواز، وقت المسح، حالة التسجيل المسبق).
- **زر**: "بدء الفحص" (لفتح نموذج الفحص الظاهري مباشرة لهذا المسافر).

### 2.5. التنبيهات الفورية (Real-time Alerts)
- عرض آخر التنبيهات (مثل: وصول رحلة جديدة، اكتشاف حالة حمراء في بوابة أخرى من نفس المنفذ).
- **التنبيه الصوتي**: (اختياري) إصدار صوت عند وصول رحلة جديدة أو حالة حمراء.

### 2.6. اختصار الوضع غير المتصل (Offline Mode Indicator)
- إذا كان الاتصال بالإنترنت ضعيفاً، تظهر رسالة تنبيه: "أنت تعمل في وضع عدم الاتصال. سيتم مزامنة البيانات عند عودة الاتصال." مع عدد الفحوصات المعلقة.

## 3. اعتبارات الأداء
- **التحديث التلقائي**: يتم تحديث قائمة الرحلات والمسافرين تلقائياً كل 30 ثانية عبر (WebSocket) أو (Polling) بسيط.
- **زمن التحميل**: يجب ألا يتجاوز زمن تحميل اللوحة ثانيتين.

# تصميم الواجهة (UI)

لتحقيق سرعة العمل في المنافذ، يُفضل أن تعتمد الواجهة على:

* أزرار كبيرة مناسبة للأجهزة اللوحية (Tablet).
* ألوان واضحة لحالة المخاطر (🟢 منخفض، 🟡 متوسط، 🟠 مرتفع، 🔴 عالي).
* دعم اللغتين العربية والإنجليزية.
* إمكانية العمل باللمس أو باستخدام قارئ الباركود/QR.
* الاستجابة السريعة مع أقل عدد ممكن من الخطوات لإتمام فحص كل مسافر.

بهذا التصميم يستطيع موظف الحجر الصحي إنجاز معظم الحالات خلال وقت قصير، مع الاحتفاظ بجميع البيانات والقرارات داخل النظام بصورة منظمة.
