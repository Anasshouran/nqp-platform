# تقييم المخاطر (Risk Assessment - Display)

## 1. الهدف
عرض نتيجة تقييم المخاطر التي يقوم بها محرك المخاطر (Risk Engine) بناءً على بيانات الفحص المدخلة، مع توضيح عوامل القرار والتوصيات المناسبة، لتمكين الموظف من اتخاذ القرار النهائي بثقة.

## 2. مكونات صفحة النتيجة

### 2.1. بطاقة التصنيف النهائي (Final Classification Card) - تظهر فوراً بعد التقييم
- **بطاقة كبيرة وواضحة** ملونة حسب التصنيف:
  - **🟢 أخضر**: أيقونة (✔) + نص "منخفض الخطورة - إفراج فوري".
  - **🟡 أصفر**: أيقونة (⚠️) + نص "متوسط الخطورة - إحالة للعيادة".
  - **🔴 أحمر**: أيقونة (🚨) + نص "عالي الخطورة - عزل فوري وإشعار الطوارئ" (مع ظهور زر "إرسال إنذار للطوارئ" باللون الأحمر).

### 2.2. تفاصيل التقييم (Assessment Details)
- **درجة المخاطر (Risk Score)**: رقم من 0 إلى 100 (مع شريط تقدم ملون).
- **عوامل القرار (Decision Factors)**: عرض القائمة التي ساهمت في حساب الدرجة:
  - (مثال: بلد القدوم (مرتفع): +20 نقطة، الحرارة (38.5°): +15 نقطة، SpO2 (94%): +5 نقاط، التطعيم (مطعم): -5 نقاط).
- **التوصية (Recommendation)**:
  - (مثال: "يوصى بإجراء فحص سريري إضافي في العيادة للتأكد من عدم وجود التهاب تنفسي حاد.")

### 2.3. أزرار الإجراء (Action Buttons)
| الزر | الحالة التي يظهر فيها | الوصف |
| :--- | :--- | :--- |
| **إفراج** | أخضر | طباعة تصريح دخول صحي (مع تحديث حالة المسافر إلى "مفرج"). |
| **إحالة للعيادة** | أصفر/أحمر | إرسال بيانات المسافر إلكترونياً إلى بوابة العيادات (5) مع تقرير الفحص الأولي. |
| **إشعار الطوارئ** | أحمر | إرسال إنذار فوري (WebSocket) إلى غرفة الطوارئ (9) مع إحداثيات الموقع. |
| **إعادة التقييم** | جميع الحالات | العودة إلى نموذج الفحص لتعديل البيانات وإعادة حساب التقييم (في حال كان هناك شك في القراءات). |

## 3. منطق الأعمال (Business Logic) - استثناءات
- **الحالات الحرجة**: إذا كان التصنيف (أحمر) بسبب SpO2 < 90% أو حرارة > 39.5°، يتم تعطيل زر "إفراج" نهائياً، ويتم تفعيل زر "إشعار الطوارئ" بشكل إجباري.
- **الاستئناف (Appeal)**: (اختياري) يمكن للموظف ذو الصلاحية (مشرف) تغيير التصنيف يدوياً بعد مراجعة إضافية، مع تسجيل سبب التغيير في سجل التدقيق.

## 4. التقارير والإحصائيات (للموظف)
- يتم تسجيل جميع نتائج التقييم في قاعدة البيانات لتغذية نظام الترصد الوبائي ولتقييم أداء الموظفين في المستقبل.
