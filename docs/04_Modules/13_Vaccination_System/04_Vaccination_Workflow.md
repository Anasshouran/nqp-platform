# 04_Vaccination_Workflow - سير عمل التطعيمات

## 1. الممثلون (Actors)
- **المسافر (Traveler)**: يرفع الشهادات ويعرض سجله.
- **موظف الحجر (Port Officer)**: يتحقق من صحة الشهادات عند الوصول.
- **الطبيب (Doctor)**: يضيف تطعيمات جديدة (في العيادة) ويحقق.
- **مسؤول النظام (Admin)**: يدير صلاحيات النظام ويراجع سجلات التدقيق.

## 2. سير العمل الرئيسي (رفع وتحقق شهادة)
