# 01_System_Overview - نظام إدارة التطعيمات (Vaccination Management System)

## 1. الهدف الاستراتيجي (Strategic Objective)
يهدف نظام التطعيم إلى **رقمنة وإدارة دورة حياة شهادات التطعيم** للمسافرين والمواطنين، وربطها بملفاتهم الصحية، لتسهيل التحقق منها في المنافذ، ودعم اتخاذ قرارات الحجر الصحي، وتوفير بيانات دقيقة للترصد الوبائي.

## 2. النطاق الوظيفي (Functional Scope)
| الوظيفة | الوصف |
| :--- | :--- |
| **التحقق من الشهادات** | التحقق من صحة شهادات التطعيم المرفوعة (مقابل قواعد بيانات عالمية، التحقق من التوقيع الرقمي، والتواريخ). |

| **عرض سجل التطعيم** | عرض تاريخ التطعيمات الكامل للمسافر (اللقاحات، الجرعات، التواريخ، جهة الإصدار) في ملفه الصحي. |

| **تحديث بيانات التطعيم** | إضافة أو تعديل أو حذف بيانات التطعيم (للمسؤولين والأطباء المصرح لهم). |

## 3. التكامل مع البوابات الأخرى (Integration Matrix)
| البوابة/النظام | نوع التكامل | الغرض |
| :--- | :--- | :--- |
| **بوابة المسافرين (2)** | رفع واسترجاع | يقوم المسافر برفع شهادات التطعيم أثناء التسجيل المسبق، ويعرض سجله الصحي. |
| **بوابة موظفي الحجر (4)** | قراءة وتحقق سريع | يقوم الموظف بمسح QR أو التحقق من صلاحية التطعيم لتعديل تقييم المخاطر. |
| **بوابة العيادات (5)** | قراءة وكتابة | يقوم الطبيب بالاطلاع على سجل التطعيمات وإضافة جرعات جديدة (في حالة التطعيم داخل العيادة). |
| **نظام تقييم المخاطر** | استدعاء بيانات | عند حساب درجة المخاطر، يتم خفض النقاط إذا كان المسافر مطعماً ضد المرض المشتبه به. |
| **نظام الترصد الوبائي** | استقبال بيانات مجمعة | إرسال إحصائيات عن نسبة المطعمين بين المسافرين (مخفية الهوية) لدعم الدراسات الوبائية. |
| **التكامل الخارجي (WHO)** | استعلام | استدعاء قاعدة بيانات منظمة الصحة العالمية (أو المختبرات المرجعية) للتحقق من صحة أرقام الدفعات (Batch Numbers). |

## 4. المبادئ الأساسية للتصميم
- **مصدر واحد للحقيقة (Single Source of Truth)**: يتم تخزين جميع التطعيمات في ملف مركزي مرتبط بـ `traveler_id`.
- **التحقق الآلي (Automated Verification)**: يتم التحقق من صحة الشهادات عبر خوارزميات ذكاء اصطناعي (OCR + مطابقة البيانات) وتقليل الاعتماد على المراجعة اليدوية.
- **الامتثال للمعايير الدولية**: دعم تنسيق شهادات منظمة الصحة العالمية (Smart Vaccination Certificate) ومعايير (FHIR).
- **الخصوصية**: لا يتم مشاركة تفاصيل التطعيم مع جهات خارجية إلا بموافقة المسافر أو بموجب قانون الصحة العامة.
