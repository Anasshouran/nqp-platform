# 05_Vaccination_UI_UX - شاشات نظام التطعيم

## 1. شاشة رفع الشهادة (بوابة المسافرين - 2)

### مكونات الشاشة:
1.  **عنوان**: "رفع شهادة التطعيم"
2.  **حقل اختيار المرض**: قائمة منسدلة (مثل: كوفيد-19، الحمى الصفراء، التهاب الكبد).
3.  **حقول بيانات التطعيم**:
    - اسم اللقاح (نص).
    - رقم الدفعة (نص - اختياري).
    - رقم الجرعة (اختيار: 1، 2، 3، معززة).
    - تاريخ الجرعة (منتقي تاريخ).
    - الدولة المُصدرة (قائمة منسدلة).
4.  **منطقة رفع الملف (Drag & Drop)**: تدعم صور (PNG/JPG) وملفات (PDF) بحجم لا يتجاوز 5 ميجابايت.
5.  **زر**: (رفع الشهادة) - يظهر شريط تقدم أثناء الرفع.
6.  **رسالة تأكيد**: "تم استلام الشهادة، سيتم التحقق منها قريباً."

---

## 2. شاشة سجل التطعيمات (الملف الصحي للمسافر)

### مكونات الشاشة:
1.  **جدول زمني (Timeline)** يعرض جميع الجرعات المسجلة مع:
    - تاريخ الجرعة.
    - اسم اللقاح.
    - اسم المرض.
    - **حالة التحقق** (أيقونة خضراء لـ "معتمد"، صفراء لـ "قيد المراجعة"، حمراء لـ "مرفوض").
2.  **زر**: (إضافة تطعيم جديد) - للأطباء فقط.
3.  **زر**: (تنزيل سجل التطعيمات) بصيغة PDF.
4.  **زر**: (عرض شهادة التعافي / التطعيم) لعرض QR Code قابلاً للطباعة.

---

## 3. شاشة التحقق السريع (بوابة موظفي الحجر - 4)

### مكونات الشاشة (نافذة منبثقة):
- تظهر تلقائياً عند مسح QR Code للمسافر.
1.  **بطاقة ملخصة**:
    - اسم المسافر، رقم الجواز.
    - **اللقاحات المسجلة** (قائمة مختصرة).
    - **نتيجة التحقق**: 
        - ✅ **صالح** (خلفية خضراء) + تاريخ انتهاء الصلاحية.
        - ⚠️ **منتهي الصلاحية** (خلفية صفراء) + التاريخ المنتهي.
        - ❌ **مزور / غير صالح** (خلفية حمراء) + زر (إبلاغ الأمن).
2.  **زر**: (تحديث حالة التحقق يدوياً) - للموظف المصرح له.

---

## 4. شاشة إدارة التطعيمات (لوحة الأطباء - 5)

### مكونات الشاشة (ضمن السجل الطبي الإلكتروني):
- **قسم خاص بالتطعيمات** في ملف المريض.
- **نموذج إضافة جرعة جديدة** (مشابه لشاشة الرفع ولكن مع صلاحية الكتابة).
- **زر**: (تعديل) بجانب كل جرعة مسجلة (لتغيير التاريخ أو رقم الدفعة في حال وجود خطأ).
- **زر**: (التحقق من الشهادة) لفتح أداة مراجعة الصورة المرفوعة مكبرة.
- **زر**: (ربط مع نظام الترصد) لإرسال بيانات التطعيم المجمعة إلى وزارة الصحة.

## 6. اعتبارات إمكانية الوصول (Accessibility)
- **وضوح النص**: استخدام خط واضح وحجم كبير (16px+) لعرض نتائج التحقق.
- **الألوان**: لا يعتمد فقط على الألوان لنقل المعلومات، بل يُستخدم (أيقونات + نصوص) لحالات (صالح، منتهي، مرفوض).
- **دعم اللغتين**: جميع الشاشات تدعم العربية والإنجليزية مع تبديل فوري (RTL/LTR).
