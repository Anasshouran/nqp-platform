# 01_System_Overview - نظام إدارة الأمراض (Disease Management System)

## 1. الهدف الاستراتيجي (Strategic Objective)
يهدف نظام إدارة الأمراض إلى **توفير قاعدة معرفية مركزية وموحدة** لجميع الأمراض الخاضعة للرقابة الصحية، بما في ذلك تعريفات الحالات (Case Definitions)، والبروتوكولات العلاجية، ومعايير التصنيف، وتصنيفات اللوائح الصحية الدولية (IHR). يعمل هذا النظام كـ **مصدر واحد للحقيقة (Single Source of Truth)** لجميع أنظمة المنصة.

## 2. النطاق الوظيفي (Functional Scope)
| الوظيفة | الوصف |
| :--- | :--- |
| **تحديث قائمة الأمراض** | إضافة، تعديل، أو حذف الأمراض في النظام، مع ربطها بالتصنيف الدولي (ICD-11) وتفاصيلها (الأعراض، فترة الحضانة، طرق الانتقال). |
| **تحديث البروتوكولات العلاجية** | إدارة خطط العلاج الموحدة لكل مرض (الأدوية، الجرعات، مدة العلاج، الأدوية البديلة) مع إمكانية الإصدارات (Versioning). |
| **تحديث تعريفات الحالات** | تعريف معايير دقيقة لتصنيف الحالات إلى (مشتبهة، محتملة، مؤكدة، غير مصابة) بناءً على الأعراض والنتائج المخبرية. |
| **إدارة الأمراض الخاضعة للوائح الصحية** | تصنيف الأمراض حسب متطلبات IHR 2005 (PHEIC، الأمراض المستهدفة للاستئصال، الأمراض الخاضعة للمراقبة الدولية). |

## 3. التكامل مع الأنظمة الأخرى (Integration Matrix)
| النظام/البوابة | نوع التكامل | الغرض |
| :--- | :--- | :--- |
| **نظام تقييم المخاطر** | استدعاء بيانات | استخدام تعريفات الأمراض لتحديد عوامل الخطر وتعديل خوارزميات التصنيف. |
| **بوابة العيادات (5)** | قراءة وكتابة | عرض قائمة الأمراض للأطباء لتحديد التشخيص، والبروتوكولات العلاجية للوصف. |
| **بوابة المختبرات (6)** | قراءة | ربط الفحوصات المخبرية بالأمراض المشتبه بها (اختبارات التأكيد). |
| **نظام الترصد الوبائي** | قراءة | تصنيف الحالات المبلّغة حسب تعريفات الحالة. |
| **نظام المتابعة الصحية** | قراءة | تحديد معايير التعافي ومدة المتابعة لكل مرض. |
| **نظام إدارة الطوارئ** | قراءة | تحديد الأمراض التي تستدعي تفعيل خطط الاستجابة (PHEIC). |
| **نظام التكامل الخارجي (WHO)** | تبادل بيانات | استيراد تحديثات ICD-11 وتصدير تقارير الأمراض الخاضعة للوائح الصحية. |

## 4. المبادئ الأساسية للتصميم
- **التوحيد القياسي (Standardization)**: الاعتماد على التصنيف الدولي للأمراض (ICD-11) كمرجع أساسي.
- **التحكم في الإصدارات (Versioning)**: الحفاظ على تاريخ كامل للتغييرات على تعريفات الأمراض والبروتوكولات (لضمان التتبع والتراجع إن لزم).
- **المرونة (Flexibility)**: إمكانية إضافة أمراض جديدة أو تعديل البروتوكولات دون الحاجة لتحديث الكود البرمجي (Configuration-driven).
- **الأمان**: صلاحيات صارمة (فقط المسؤولون الصحيون يمكنهم تعديل البيانات).
- **التكامل الدولي**: دعم تنسيق (FHIR) و (ICD-11) لتبادل البيانات مع منظمة الصحة العالمية والأنظمة الوطنية.
