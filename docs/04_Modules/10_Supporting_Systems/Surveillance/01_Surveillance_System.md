# 01_Surveillance_System - نظام الترصد الوبائي والتكامل الوطني

## 1. المبدأ الأساسي
هذا النظام هو **عين وزارة الصحة** على المنصة. يقوم بتحويل البيانات الخام (الفردية) إلى **معلومات مجمعة وقابلة للتنفيذ** لصناع القرار، مع الحفاظ الكامل على خصوصية المرضى (بيانات مجهولة المصدر). يتم تشغيل مهام التجميع عبر **Celery Beat** (مجدول المهام) في منتصف الليل.

## 2. الوظائف الأساسية
| الوظيفة | الوصف | الفئة المستفيدة | التنفيذ في Django |
| :---     | :---        | :---  | :---         |

| **التحليل الوصفي** | عرض إحصائيات يومية (عدد الحالات الإيجابية، نسبة الفحوصات، توزيع المنافذ). | مديري المنافذ | `SurveillanceReport` model مع `aggregated_data` (JSONField) |

| **التحليل الجيولوجي** | رسم خرائط حرارية (Heatmaps) توضح كثافة الحالات على خريطة الدولة (تُغذي واجهة React عبر API). | وزارة الصحة | `GET /api/v1/surveillance/heatmap` |

| **التحليل الزمني** | إنشاء منحنيات وبائية (Epidemic Curves) لتتبع اتجاه التفشي (تصاعدي/تنازلي). | فريق الطوارئ | `GET /api/v1/surveillance/timeline` |

| **الإنذار المبكر (EWS)** | نظام تنبيهات يقوم بإرسال إشارة تحذير (WebSocket) إذا تجاوز عدد الحالات في منفذ معين العتبة الإحصائية المحددة. | غرفة العمليات (EOC) | `AlertService` مع إشارات Django (Signals) |

## 3. مصادر البيانات (Data Sources)
- **بوابة المختبرات (6)**: النتائج الإيجابية المؤكدة (المصدر الرئيسي) - يتم استقبالها عبر Webhook داخلي.
- **بوابة موظفي الحجر (4)**: بيانات الفحوصات السريعة والإحالات.
- **بوابة العيادات (5)**: التشخيصات السريرية النهائية.
- **نظام المتابعة الصحية**: مضاعفات ما بعد التعافي (Long COVID).

## 4. الإنذار المبكر (Early Warning System - EWS)
- **العتبات (Thresholds)**: يتم تحديدها في جدول `SurveillanceThresholds`.
  - مثال: إذا تجاوزت الحالات الإيجابية في منفذ معين 5 حالات في يوم واحد، يتم إرسال إنذار (أصفر).
  - إذا تجاوزت 10 حالات، يتم إرسال إنذار (أحمر) إلى EOC فوراً.
- **الإجراء التلقائي**: عند تفعيل الإنذار، يتم إنشاء سجل في جدول `emergency_alerts` وإرسال إشعار WebSocket.

## 5. التقارير الإجبارية (Mandatory Reporting)
يقوم النظام تلقائياً بإنشاء صيغة التقرير الوطني الموحدة والمطلوبة من قبل (المركز الوطني للوائح الصحية - IHR)، بصيغة (JSON) جاهزة للرفع إلى المنصة العالمية لمنظمة الصحة العالمية بنقرة واحدة عبر بوابة الإدارة الاتحادية (8).

## 6. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف | الصلاحية |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/surveillance/daily-stats` | إحصائيات اليوم. | Federal Admin+ |
| `GET` | `/api/v1/surveillance/timeline?days=30` | البيانات الزمنية (للرسوم البيانية). | Federal Admin+ |
| `GET` | `/api/v1/surveillance/heatmap` | بيانات الخريطة الحرارية (JSON). | Federal Admin+ |
| `GET` | `/api/v1/surveillance/alerts/thresholds` | عتبات الإنذار. | EOC Operator+ |
| `PUT` | `/api/v1/surveillance/alerts/thresholds` | تحديث العتبات. | Federal Admin+ |
