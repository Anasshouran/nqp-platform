# About

> **حالة التنفيذ:** ✅ مطبّق (2026-08-01) — `pages/public/AboutPage.tsx` على المسار `/about`. محتوى النبذة يُجلب من `Page` بصفحة `about-us` (`GET /api/v1/cms/pages/about-us/`) مع نص احتياطي ثابت؛ والرؤية/الرسالة/الأهداف/الاختصاصات/الهيكل التنظيمي/الإدارات التابعة ثابتة في الواجهة.

### 2.2. صفحة "من نحن" (About Us)

 المسار:  `/about`  
 الهدف:  تعريف الزائر بالإدارة العامة للحجر الصحي، رؤيتها، رسالتها، وهيكلها التنظيمي.

 التخطيط: 

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  📋 من نحن                                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │  🏛️ الإدارة العامة للحجر الصحي                                    │   │
│  │  (محتوى ديناميكي يتم جلبه من CMS - صفحة `about-us`)               │   │
│  │  [نص طويل يعرض الرؤية، الرسالة، الأهداف، الاختصاصات]             │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │  📊 الهيكل التنظيمي (شجرة بسيطة)                                  │   │
│  │  المدير العام                                                     │   │
│  │  ├── إدارة الحجر الصحي الجوي                                      │   │
│  │  ├── إدارة الحجر الصحي البحري                                     │   │
│  │  └── إدارة الحجر الصحي البري                                      │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────────────┘
```

 المكونات: 

- `PageContent`: يعرض محتوى `content_ar/content_en` من `website_pages` حيث `page_slug='about-us'`.
- `OrgChart`: شجرة تنظيمية مبسطة (قد تكون ثابتة أو مسترجعة من `GET /api/org/structure`).

 التفاعل: 

- عند تحميل الصفحة: `GET /api/cms/pages/by_slug/?slug=about-us`.
