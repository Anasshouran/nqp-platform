# صفحة تفاصيل الخبر (News Detail)

## 1. الهدف
عرض الخبر بشكل كامل ومتكامل بعد النقر على "اقرأ المزيد" من صفحة الأخبار الرئيسية، مع إظهار جميع التفاصيل (المحتوى، الصور، الفيديوهات المضمنة، وتاريخ النشر)، وتوفير خيارات التفاعل (المشاركة، طباعة).

## 2. مكونات الصفحة

### 2.1. رأس الخبر (Header)
- **العنوان**: (بخط كبير وواضح).
- **تاريخ النشر**: (بالتنسيق: "25 يوليو 2024").
- **الفئة**: (تاج ملون: أخبار، إعلانات، تعميمات عاجلة).
- **اسم الكاتب**: (إن وجد).

### 2.2. الصورة الرئيسية (Featured Image)
- عرض الصورة المرفوعة مع الخبر بحجم كبير (مع إمكانية تكبيرها عند النقر عليها).

### 2.3. محتوى الخبر (Body)
- عرض النص الكامل للخبر مع التنسيق (الخطوط، العناوين الفرعية، القوائم، الجداول).
- الصور والفيديوهات المضمنة في المحتوى (تدعم التحميل البطيء Lazy Loading).

### 2.4. أزرار التفاعل (Interaction)
- **زر**: "مشاركة" (عبر فيسبوك، تويتر، واتساب، نسخ الرابط).
- **زر**: "طباعة" (لطباعة الخبر).
- **زر**: "الإبلاغ عن خطأ" (إن وجد خطأ في الخبر - اختياري).

### 2.5. أخبار ذات صلة (Related News)
- عرض آخر 3 أخبار من نفس الفئة أسفل الخبر (مع صور مصغرة وعناوين).

### 2.6. زر العودة (Back Button)
- زر: "العودة إلى قائمة الأخبار".

## 3. منطق الأعمال (Business Logic)
- **عدد المشاهدات**: يتم زيادة عداد المشاهدات تلقائياً في كل مرة يتم فيها فتح صفحة الخبر (لتغذية قسم "الأخبار الأكثر قراءة" في لوحة التحكم).
- **التخزين المؤقت (Caching)**: يتم تخزين الخبر مؤقتاً في Redis لمدة 10 دقائق لتقليل الضغط على الخادم.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/cms/news/{slug}/` | استرجاع تفاصيل خبر معين (باستخدام slug). |
| `PATCH` | `/api/v1/cms/news/{id}/increment-view/` | زيادة عدد المشاهدات (اختياري). |
