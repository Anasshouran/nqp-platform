### 2.10. صفحة "تسجيل الدخول" (Login)

 المسار:  `/login`  
 الهدف:  بوابة موحدة لجميع المستخدمين (مواطن، مسافر، مستورد، مصدر، شركة، جهة حكومية، موظف وزارة).

 التخطيط:  (موضح بالكامل في القسم 3.1 من الدليل السابق، ولكن نعيده للسياق).

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  [شعار منصة الحجر الصحي القومي]                                              │
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │  🔑 تسجيل الدخول                                                   │   │
│  │  طريقة الدخول: [بريد إلكتروني ▼]  [____name@example.com____]        │   │
│  │  🔒 كلمة المرور                                                    │   │
│  │  [________________________________]                                │   │
│  │  [💾 تسجيل الدخول]                                                │   │
│  │  ليس لديك حساب؟ [أنشئ حساباً جديداً] → /register                  │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────────────┘
```

 طريقة الدخول:  يمكن للمستخدم اختيار التعريف بالبريد الإلكتروني أو رقم الجوال أو الرقم القومي، ويُرسل في حقل `identifier`.

 التفاعل:  بعد نجاح تسجيل الدخول، يتم تخزين الـ JWT في `localStorage`، ويتم توجيه المستخدم بناءً على `user_type` / `role`:
- `SUPER_ADMIN` أو `FEDERAL_MANAGER` → `/dashboard/federal`.
- `PORT_MANAGER` → `/dashboard/port`.
- `OFFICER` → `/officer/scanner`.
- `DOCTOR` → `/clinic/queue`.
- المسافر العادي (إن كان له حساب) → `/profile`.

### 2.10.1. صفحة "إنشاء حساب جديد" (Register)

 المسار:  `/register`  
 الهدف:  تسجيل ذاتي لمختلف فئات المستخدمين.

 التخطيط:

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  [شعار منصة الحجر الصحي القومي]                                              │
│  إنشاء حساب جديد                                                            │
│  اختر نوع الحساب:                                                           │
│  [👤 مواطن][✈️ مسافر][📦 مستورد][↗️ مصدر][🏢 شركة][🏛️ جهة حكومية][🪪 موظف]  │
│  الاسم الكامل: [____]    البريد الإلكتروني: [____]                          │
│  رقم الجوال: [____] (اختياري)   الرقم القومي: [____] (اختياري)             │
│  (اسم المنشأة/الجهة: [____] — يظهر للشركة والجهة الحكومية فقط)               │
│  كلمة المرور: [____]   تأكيد كلمة المرور: [____]                            │
│  [💾 إنشاء الحساب]                                                          │
│  لديك حساب بالفعل؟ [تسجيل الدخول] → /login                                 │
└──────────────────────────────────────────────────────────────────────────────┘
```

 التفاعل:  عند النجاح يتم حفظ الرموز فوراً (تسجيل دخول تلقائي) وتوجيه المستخدم إلى الصفحة الرئيسية مع رسالة ترحيب.
