# News

### 2.5. صفحة "الأخبار والإعلانات" (News & Announcements)

 المسار:  `/news` (القائمة) و `/news/{id}` (التفاصيل)  
 الهدف:  عرض آخر المستجدات والتحذيرات الصحية.

 القائمة (List View): 

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  📰 الأخبار والإعلانات                                                      │
│  [🔍 بحث في الأخبار...]  [التصنيف: كل الأخبار ▾]                         │
├──────────────────────────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │  📰 عنوان الخبر الأول (عاجل) 🚨                                    │   │
│  │  ملخص الخبر...  التاريخ: 2026-07-18                               │   │
│  │  [اقرأ المزيد]                                                     │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │  📰 عنوان الخبر الثاني                                              │   │
│  │  ملخص الخبر...  التاريخ: 2026-07-17                               │   │
│  │  [اقرأ المزيد]                                                     │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│  [1] [2] [3] ...  [عرض 10] ▾                                            │
└──────────────────────────────────────────────────────────────────────────────┘
```

 التفاصيل (Detail View): 

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  📰 عنوان الخبر (عاجل)                                                     │
│  التاريخ: 2026-07-18  │  الناشر: الإدارة العامة                          │
├──────────────────────────────────────────────────────────────────────────────┤
│  [صورة الخبر]                                                              │
│  (نص الخبر الكامل هنا...)                                                  │
│  (يتضمن تفاصيل، إرشادات، روابط)                                           │
├──────────────────────────────────────────────────────────────────────────────┤
│  🔗 شارك الخبر: [فيسبوك] [تويتر] [واتساب]                                │
└──────────────────────────────────────────────────────────────────────────────┘
```

 نقاط API: 

- القائمة: `GET /api/cms/news/?page=1&search=...`
- التفاصيل: `GET /api/cms/news/{id}/`
