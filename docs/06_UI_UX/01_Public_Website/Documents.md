### 2.7. صفحة "مركز الوثائق" (Documents Center)

 المسار:  `/documents`  
 الهدف:  مستودع للقوانين، اللوائح، والأدلة الإجرائية.

 التخطيط: 

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  📂 مركز الوثائق                                                           │
│  [التصنيف: كل الوثائق ▾]  [🔍 بحث...]                                     │
├──────────────────────────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │  📄 اللوائح الصحية الدولية (PDF)   2026-01-01  [📥 تحميل]        │   │
│  ├──────────────────────────────────────────────────────────────────────┤   │
│  │  📄 دليل إجراءات الحجر الصحي (PDF) 2026-07-01  [📥 تحميل]        │   │
│  ├──────────────────────────────────────────────────────────────────────┤   │
│  │  📄 استمارة الفحص الصحي (DOCX)     2026-07-10  [📥 تحميل]        │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────────────┘
```

 التفاعل:  الضغط على [تحميل] يبدأ تنزيل الملف عبر الرابط المباشر.
