# Home

## 2. تفاصيل كل شاشة (Screen-by-Screen)

### 2.1. الصفحة الرئيسية (Home)

 المسار:  `/`  
 الهدف:  أول انطباع للمستخدم، يعرض ملخص الخدمات، آخر الأخبار، والإحصائيات السريعة.

 المكونات (Components): 

- `HeroBanner`: نص ترحيبي، أزرار CTA (دعوة للتفاعل).
- `NewsTicker`: شريط متحرك يعرض آخر الإعلانات العاجلة (`is_urgent=True`).
- `ServiceCards`: 4 بطاقات رئيسية (تسجيل مسبق، فحص، QR، متابعة).
- `StatsCounter`: أرقام إحصائية (يتم جلبها من API `GET /api/public/stats`).
- `LatestNews`: بطاقتان أو ثلاث من أحدث الأخبار المنشورة (`GET /api/cms/news/?limit=3`).

 التفاعل (Interactions): 

- الضغط على "تسجيل مسبق" → التوجيه إلى `/register`.
- الضغط على بطاقة خبر → التوجيه إلى `/news/{id}`.
- تحميل الصفحة: جلب الإحصائيات والأخبار عبر `useEffect`.

 نقاط API: 

- `GET /api/public/stats/` → `{ travelers: 12450, suspected: 45, referrals: 28, ports: 12 }`
- `GET /api/cms/news/?is_published=true&limit=3` → قائمة الأخبار.
