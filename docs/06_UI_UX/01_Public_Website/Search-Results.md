# صفحة نتائج البحث (Search Results)

## 1. الهدف
تمكين زوار الموقع من البحث في محتوى الموقع العام (الأخبار، الصفحات، الأسئلة الشائعة، الوثائق، والأمراض) وعرض النتائج في صفحة منظمة ومرتبة حسب الصلة، لتسهيل الوصول إلى المعلومات المطلوبة بسرعة.

## 2. مكونات الصفحة

### 2.1. شريط البحث (Search Bar)
- يظهر في أعلى الصفحة مع خانة البحث التي تحتوي على الكلمة المبحوث عنها.
- **زر**: "بحث" (باللون الأزرق).

### 2.2. خيارات التصفية (Filter Tabs)
- **تبويبات** لتصفية النتائج حسب النوع:
  - (الكل، الأخبار، الصفحات، الأسئلة الشائعة، الوثائق، الأمراض).
- **ترتيب النتائج**: (حسب الصلة، حسب التاريخ الأحدث).

### 2.3. قائمة النتائج (Results List)
- عرض النتائج في قائمة عمودية (أو بطاقات).
- كل نتيجة تحتوي على:
  - **العنوان**: (رابط قابل للنقر).
  - **الملخص**: (نص قصير يظهر فيه الكلمة المبحوث عنها باللون الأصفر).
  - **النوع**: (تاج صغير يوضح نوع المحتوى: خبر، صفحة، سؤال شائع، وثيقة، مرض).
  - **التاريخ**: (تاريخ النشر أو التعديل).
- **الترقيم (Pagination)**: عرض 10 نتائج في كل صفحة.

### 2.4. حالة "لا توجد نتائج" (No Results)
- عرض رسالة: "لم نعثر على نتائج مطابقة لبحثك. يرجى التأكد من الكلمة أو استخدام كلمات أخرى."
- عرض روابط سريعة للخدمات الأكثر استخداماً (مثل: "سجل الآن"، "متطلبات السفر").

## 3. منطق الأعمال (Business Logic)
- **البحث المتقدم**: يدعم البحث باللغة العربية والإنجليزية، ويتجاهل علامات الترقيم.
- **تسليط الضوء (Highlight)**: يتم تمييز الكلمة المبحوث عنها في النتائج باللون الأصفر.
- **الأولوية**: يتم ترتيب النتائج حسب (الصلة أولاً، ثم التاريخ).
- **التخزين المؤقت**: يتم تخزين نتائج البحث الشائعة في Redis لمدة ساعة لتسريع الاستعلامات المتكررة.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/search?q={term}&type={all|news|pages|...}` | البحث في المحتوى وإرجاع النتائج. |
