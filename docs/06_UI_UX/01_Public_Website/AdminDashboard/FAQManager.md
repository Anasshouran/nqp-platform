# إدارة الأسئلة الشائعة (FAQ Manager)

## 1. الهدف
تمكين مسؤولي المحتوى من إدارة قائمة الأسئلة الشائعة (FAQ) على الموقع العام، مع إمكانية تنظيمها حسب الفئات، وإعادة ترتيب ظهورها باستخدام خاصية السحب والإفلات (Drag & Drop)، وتفعيل أو تعطيل أي سؤال بسهولة.

## 2. مكونات الشاشة

### 2.1. قائمة الأسئلة (FAQ List)
- **قائمة قابلة للترتيب (Sortable List)**:
  - عرض جميع الأسئلة في قائمة عمودية.
  - كل عنصر يحتوي على: (رقم الترتيب، السؤال، الفئة، الحالة (نشط/غير نشط)، وأزرار الإجراءات).
  - **مقبض السحب (Drag Handle)**: (☰) على يسار كل عنصر لسحبه وإفلاته في المكان المطلوب لتغيير ترتيب ظهوره في الموقع العام.
- **أدوات التصفية**:
  - قائمة منسدلة لتصفية (الفئة: التسجيل، الفحص، الحجر، الشهادات، عام).
  - زر: "عرض النشط فقط".
- **زر**: "إضافة سؤال جديد".

### 2.2. نموذج إضافة / تعديل السؤال (FAQ Form)
- **الحقول الإلزامية**:
  - **السؤال**: (نص، 200 حرف كحد أقصى).
  - **الإجابة**: (محرر WYSIWYG) لدعم النصوص الغنية والروابط.
  - **الفئة**: (قائمة منسدلة: التسجيل المسبق، الفحص الصحي، الحجر الصحي، شهادة التعافي، عام).
- **خيارات إضافية**:
  - **نشط؟**: (خانة اختيار) - إذا تم إلغاؤها، يختفي السؤال من الموقع العام (مع الاحتفاظ به في قاعدة البيانات).
  - **ترتيب العرض**: (حقل رقمي) - يمكن تحديد رقم محدد، أو ترك النظام لإدارة الترتيب تلقائياً.

### 2.3. معاينة التغييرات
- يتم تحديث ترتيب الأسئلة فوراً بعد السحب والإفلات (عبر إرسال طلب API لتحديث حقل `order`).

## 3. منطق الأعمال (Business Logic)
- **الترتيب التلقائي**: إذا لم يتم تحديد ترتيب، يقوم النظام بوضع السؤال الجديد في نهاية القائمة.
- **التخزين المؤقت (Caching)**: يتم تخزين قائمة الأسئلة الشائعة في Redis لمدة ساعة واحدة. عند إجراء أي تغيير، يتم إفراغ الـ Cache لتحديث الموقع العام فوراً.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/admin/cms/faq/` | قائمة الأسئلة (مع التصفية). |
| `POST` | `/api/v1/admin/cms/faq/` | إنشاء سؤال جديد. |
| `PUT` | `/api/v1/admin/cms/faq/{id}/` | تحديث سؤال. |
| `PATCH` | `/api/v1/admin/cms/faq/reorder/` | تحديث ترتيب الأسئلة (يُرسل قائمة المعرفات بالترتيب الجديد). |
| `DELETE` | `/api/v1/admin/cms/faq/{id}/` | حذف سؤال. |
