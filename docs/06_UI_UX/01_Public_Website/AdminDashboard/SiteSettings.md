# إعدادات الموقع العامة (Site Settings)

## 1. الهدف
توفير واجهة واحدة لمسؤولي النظام (Super Admin) للتحكم في جميع الإعدادات العامة للموقع العام، مثل (الشعار، بيانات الاتصال، الإشعارات، وضع الصيانة، وإعدادات التواصل الاجتماعي)، مما يسمح بتحديث هذه المعلومات دون الحاجة لتعديل أي ملفات برمجية أو قوالب.

## 2. مكونات الشاشة (مقسمة إلى تبويبات Tabs)

### 2.1. التبويب الأول: الهوية البصرية (Branding)
- **شعار الموقع (Logo)**: رفع صورة الشعار (يفضل PNG مع خلفية شفافة).
- **أيقونة الموقع (Favicon)**: رفع أيقونة الموقع (16x16 أو 32x32 بكسل).
- **عنوان الموقع (Site Title)**: النص الذي يظهر في شريط عنوان المتصفح.
- **الشعار النصي (Tagline)**: النص التعريفي القصير الذي يظهر تحت الاسم (أو في الهيدر).
- **معاينة حية**: عرض معاينة فورية للشعار والعنوان عند التعديل.

### 2.2. التبويب الثاني: الإشعارات (Notifications)
- **تفعيل شريط الإشعارات**: (خانة اختيار) إظهار أو إخفاء الشريط العلوي.
- **نص الإشعار**: (حقل نصي) لإدخال النص الذي سيظهر في الشريط (مثل: "تنويه هام: تم تحديث متطلبات السفر...").
- **لون الخلفية**: (منتقي ألوان) لتغيير لون خلفية شريط الإشعارات (افتراضي: أحمر للعاجل، أزرق للمعلومات).
- **تاريخ الانتهاء**: (منتقي تاريخ) تحديد تاريخ انتهاء صلاحية الإشعار (بعدها يختفي تلقائياً).

### 2.3. التبويب الثالث: معلومات الاتصال (Contact Information)
- **العنوان**: (حقل نصي طويل) العنوان الكامل للمقر الرئيسي.
- **رقم الهاتف**: (حقل نصي).
- **البريد الإلكتروني**: (حقل بريد إلكتروني) بريد الدعم الفني.
- **روابط التواصل الاجتماعي**:
  - فيسبوك (رابط).
  - تويتر (رابط).
  - يوتيوب (رابط).
  - إنستغرام (رابط).
- **خريطة الموقع**: (رابط تضمين iframe من Google Maps أو OpenStreetMap) لتظهر في صفحة "اتصل بنا".

### 2.4. التبويب الرابع: الصيانة (Maintenance)
- **وضع الصيانة (Maintenance Mode)**: (خانة اختيار) عند التفعيل، يعرض الموقع صفحة "قيد الصيانة" لجميع الزوار (ما عدا المسؤولين الذين يسجلون دخولهم).
- **رسالة الصيانة**: (حقل نصي) لتخصيص الرسالة التي تظهر للمستخدمين (مثل: "الموقع قيد التطوير، يعود قريباً...").
- **وقت العودة المتوقع**: (منتقي تاريخ ووقت) اختياري لعرض العد التنازلي.

## 3. منطق الأعمال (Business Logic)
- **حفظ الإعدادات**: يتم حفظ الإعدادات في قاعدة البيانات (جدول `SiteSettings`). يتم تحميلها في كل طلب عبر (Context Processor) في Django، أو تخزينها مؤقتاً في Redis لتسريع التحميل.
- **تطبيق فوري**: جميع التغييرات تنعكس فوراً على الموقع العام (بدون الحاجة لإعادة تشغيل الخادم).
- **الصلاحيات**: فقط المستخدمون الذين لديهم صلاحية `CAN_MANAGE_SETTINGS` (Super Admin أو Federal Admin) يمكنهم الوصول إلى هذه الصفحة.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/admin/settings/` | استرجاع جميع الإعدادات الحالية. |
| `PUT` | `/api/v1/admin/settings/` | تحديث الإعدادات (إرسال كائن JSON كامل أو جزئي). |
| `POST` | `/api/v1/admin/settings/logo` | رفع شعار جديد (نقطة نهاية منفصلة للتعامل مع الملفات). |
