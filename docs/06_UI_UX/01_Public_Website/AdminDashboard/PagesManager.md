# إدارة الصفحات (Pages Manager)

## 1. الهدف
تمكين مسؤولي المحتوى من إدارة الصفحات الثابتة للموقع العام (مثل: "عن الإدارة"، "الخدمات الإلكترونية"، "مركز الوثائق")، بما في ذلك إنشاء صفحات جديدة، تعديل المحتوى، ونشرها أو إخفاؤها بسهولة.

## 2. مكونات الشاشة

### 2.1. قائمة الصفحات (Pages List)
- **عرض جدولي (Table)** يحتوي على الأعمدة التالية:
  - **العنوان**: اسم الصفحة (عربي/إنجليزي).
  - **المسار (URL)**: الرابط النسبي للصفحة (مثل: `/about`, `/services`).
  - **الحالة**: (منشور `Published` / مسودة `Draft` / مخفي `Hidden`) مع تاج ملون.
  - **تاريخ آخر تعديل**: (مثل: "2024-07-25").
  - **الإجراءات**: أزرار (✏️ تعديل، 👁️ معاينة، 🗑️ حذف).
- **شريط البحث**: للبحث عن الصفحات بالعنوان أو المسار.
- **زر**: "إضافة صفحة جديدة" (في أعلى الجدول).

### 2.2. نموذج إضافة / تعديل الصفحة (Page Form) - يظهر في نافذة منبثقة أو صفحة منفصلة
- **الحقول الإلزامية**:
  - **العنوان (عربي)**: حقل نصي.
  - **العنوان (إنجليزي)**: حقل نصي.
  - **المسار (Slug)**: حقل نصي (يُملأ تلقائياً من العنوان، ولكن يمكن تعديله يدوياً). *مثال: `about-us`*.
  - **المحتوى**: محرر نصوص متقدم (WYSIWYG) يدعم (الخطوط، الصور، الفيديوهات المضمنة، الجداول). *يتم استخدام مكتبة React مثل `react-quill` أو `tiptap`*.
- **الحقول الاختيارية**:
  - **صورة الغلاف (Cover Image)**: رفع صورة (اختياري) لتظهر في أعلى الصفحة.
  - **الوصف المختصر (Meta Description)**: لتحسين ظهور الصفحة في محركات البحث (SEO).
- **حالة النشر**: (زر اختيار): منشور / مسودة / مخفي.
- **أزرار الإجراء**: (💾 حفظ المسودة) و (📤 نشر) و (👁️ معاينة).

### 2.3. حالة المعاينة (Preview)
- عند الضغط على زر "معاينة"، يتم فتح الصفحة في علامة تبويب جديدة بالشكل الذي ستبدو عليه للمستخدم النهائي، مع إظهار شريط علوي رمادي (للتذكير بأنها في وضع المعاينة).

## 3. منطق الأعمال (Business Logic)
- **المسار الفريد (Unique Slug)**: لا يمكن أن يتكرر مسار صفحتين (يتم التحقق منه في الخلفية).
- **الصفحات الأساسية**: لا يمكن حذف الصفحات الأساسية للنظام (مثل: الصفحة الرئيسية، اتصل بنا)؛ يمكن فقط تعطيلها أو إخفاؤها مؤقتاً.
- **التخزين المؤقت (Caching)**: عند نشر أو تعديل صفحة، يتم إفراغ (Cache) الصفحة تلقائياً في Redis لتظهر التغييرات فوراً للمستخدمين.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/admin/cms/pages/` | قائمة الصفحات. |
| `POST` | `/api/v1/admin/cms/pages/` | إنشاء صفحة جديدة. |
| `GET` | `/api/v1/admin/cms/pages/{id}/` | تفاصيل صفحة. |
| `PUT` | `/api/v1/admin/cms/pages/{id}/` | تحديث صفحة. |
| `DELETE` | `/api/v1/admin/cms/pages/{id}/` | حذف صفحة (باستثناء الأساسية). |
