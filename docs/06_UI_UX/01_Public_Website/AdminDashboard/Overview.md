# نظرة عامة على لوحة تحكم المسؤول (Admin Dashboard Overview)

## 1. الهدف
توفير واجهة مركزية وآمنة لمسؤولي المحتوى (Content Managers) والإدارة الاتحادية لإدارة جميع جوانب الموقع العام (البوابة 1) بشكل ديناميكي. تتيح هذه اللوحة التحكم الكامل في (الأخبار، الصفحات الثابتة، الأسئلة الشائعة، الوثائق، والإعدادات العامة) دون الحاجة لأي تدخل برمجي.

## 2. الممثلون (Actors)
- **مسؤول المحتوى (Content Manager)**: يمكنه إدارة (الأخبار، الصفحات، الأسئلة الشائعة، الوثائق).
- **مدير النظام (Super Admin / Federal Admin)**: يمكنه إدارة جميع ما سبق بالإضافة إلى (إعدادات الموقع) و (صلاحيات المستخدمين) إن لزم الأمر.

## 3. هيكل التنقل (Sidebar Navigation)
عند الدخول إلى لوحة التحكم، تظهر القائمة الجانبية (Sidebar) التالية:

| الأيقونة | القسم | الوصف |
| :--- | :--- | :--- |
| 📄 | **إدارة الصفحات** | إدارة الصفحات الثابتة (عن الإدارة، الخدمات، إلخ). |
| 📰 | **إدارة الأخبار** | إضافة وتعديل وحذف الأخبار والإعلانات. |
| ❓ | **الأسئلة الشائعة** | إدارة الأسئلة والأجوبة (FAQ). |
| 📁 | **إدارة الوثائق** | رفع وتنظيم الملفات (PDF، صور). |
| ⚙️ | **إعدادات الموقع** | تعديل الشعار، الإشعارات، معلومات الاتصال. |
| 🔒 | **تسجيل الخروج** | إنهاء الجلسة والعودة إلى واجهة تسجيل الدخول. |

## 4. الشكل العام (Layout)
- **الشريط العلوي (Header)**: يحتوي على (شعار المنصة، اسم المستخدم المسجل الدخول، وأيقونة الإشعارات).
- **القائمة الجانبية (Sidebar)**: قابلة للطي (Collapsible) لتوفير مساحة أكبر على الشاشات الصغيرة.
- **منطقة المحتوى (Main Area)**: تعرض الجداول، النماذج، والإحصائيات حسب القسم المختار.
