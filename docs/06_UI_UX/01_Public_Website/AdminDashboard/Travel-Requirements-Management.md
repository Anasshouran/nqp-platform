# إدارة متطلبات السفر (Travel Requirements Management)

## 1. الهدف
تمكين مسؤولي المحتوى (بالتنسيق مع الفريق الصحي) من تحديث متطلبات السفر لكل دولة بشكل ديناميكي، بما في ذلك (تصنيف المخاطر، متطلبات الفحص، مدة الحجر، وإرشادات إضافية)، بحيث تنعكس هذه التحديثات فوراً على صفحة "متطلبات السفر" في الموقع العام.

## 2. مكونات الشاشة

### 2.1. قائمة الدول (Countries List)
- **عرض جدولي (Table)** يحتوي على الأعمدة التالية:
  - **الدولة**: (الاسم العربي والإنجليزي).
  - **التصنيف**: (أخضر، أصفر، أحمر) مع تاج ملون.
  - **متطلبات الفحص**: (مثل: "PCR قبل 72 ساعة").
  - **مدة الحجر**: (عدد الأيام).
  - **آخر تحديث**: (تاريخ آخر تعديل).
  - **الإجراءات**: (✏️ تعديل).
- **شريط بحث**: للبحث عن دولة بالاسم.
- **زر**: "تحديث بيانات الدول من WHO" (للمزامنة التلقائية مع منظمة الصحة العالمية).

### 2.2. نموذج تعديل متطلبات الدولة (Country Requirements Form)
- **الحقول القابلة للتعديل**:
  - **تصنيف المخاطر**: (قائمة منسدلة: أخضر، أصفر، أحمر).
  - **متطلبات الفحص**: (نص، مثل: "شهادة تطعيم أو فحص PCR خلال 72 ساعة").
  - **مدة الحجر الإلزامي**: (رقم، عدد الأيام).
  - **إرشادات إضافية**: (محرر نصوص) لعرض معلومات إضافية للمسافرين (مثل: "يُفضل تجنب السفر في حالة الأعراض").
  - **تاريخ سريان التحديث**: (منتقي تاريخ) - لتحديد موعد بدء تطبيق المتطلبات الجديدة.
- **زر**: "حفظ التغييرات".

### 2.3. سجل التغييرات (Change Log)
- عرض جدول زمني (Timeline) بجميع التغييرات التي تم إجراؤها على متطلبات الدول:
  - (التاريخ، الدولة، من قام بالتغيير، التغيير الذي تم إجراؤه).

## 3. منطق الأعمال (Business Logic)
- **التحديث التلقائي للموقع**: عند تغيير متطلبات دولة ما، يتم إفراغ (Cache) صفحة "متطلبات السفر" لتظهر التغييرات فوراً.
- **التكامل مع نظام إدارة الأمراض**: يتم ربط التصنيفات مع نظام `Disease_Management` لضمان اتساق البيانات مع تقييم المخاطر الطبي.
- **التنبيه**: إذا تم رفع تصنيف دولة من (أصفر) إلى (أحمر)، يتم إرسال إشعار لمسؤولي الطوارئ وشركات الطيران تلقائياً.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/admin/travel-requirements/countries/` | قائمة الدول مع متطلباتها. |
| `PUT` | `/api/v1/admin/travel-requirements/countries/{id}/` | تحديث متطلبات دولة معينة. |
| `GET` | `/api/v1/admin/travel-requirements/history/` | سجل تغييرات متطلبات السفر. |
| `POST` | `/api/v1/admin/travel-requirements/sync-who` | مزامنة التصنيفات من منظمة الصحة العالمية. |
