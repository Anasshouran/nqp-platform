# إدارة البانرات والشرائح الدوارة (Sliders Management)

## 1. الهدف
تمكين مسؤولي المحتوى من إدارة الشرائح الدوارة (Carousel / Sliders) التي تظهر في الصفحة الرئيسية للموقع العام، بما في ذلك (إضافة شرائح جديدة، ترتيبها، تفعيلها، أو تعطيلها)، لعرض أهم الإعلانات والخدمات بشكل جذاب للزوار.

## 2. مكونات الشاشة

### 2.1. قائمة الشرائح (Sliders List)
- **عرض بطاقات (Cards)** يمثل كل شريحة بطاقة تحتوي على:
  - **معاينة الصورة**: صورة مصغرة للشريحة.
  - **العنوان**: نص عنوان الشريحة.
  - **ترتيب العرض**: (رقم يحدد ترتيب ظهورها في الكاروسيل).
  - **الحالة**: (نشط / غير نشط) مع تاج ملون.
  - **الإجراءات**: (✏️ تعديل، 👁️ معاينة، 🗑️ حذف).
- **زر**: "إضافة شريحة جديدة".

### 2.2. نموذج إضافة / تعديل شريحة (Slide Form)
- **الحقول الإلزامية**:
  - **العنوان**: (نص، حد أقصى 100 حرف).
  - **النص الفرعي**: (نص، 200 حرف كحد أقصى).
  - **الصورة**: (رفع صورة، يفضل أن تكون بمقاس (1920x800) مع إمكانية قصها (Crop) أثناء الرفع).
- **الحقول الاختيارية**:
  - **رابط الزر (Button Link)**: (رابط URL) لتوجيه المستخدم عند النقر على الشريحة أو الزر الموجود عليها.
  - **نص الزر (Button Text)**: (نص) - (مثل: "سجل الآن"، "اقرأ المزيد").
  - **ترتيب العرض**: (رقم) لتحديد مكان الشريحة في الكاروسيل.
- **حالة النشر**: (زر اختيار): نشط / غير نشط.
- **زر**: "حفظ".

### 2.3. معاينة الشريحة (Preview)
- عند الضغط على زر "معاينة"، يتم عرض الشريحة في نافذة منبثقة (Modal) بالشكل الذي ستبدو عليه في الصفحة الرئيسية، لتقييم المظهر قبل النشر.

## 3. منطق الأعمال (Business Logic)
- **الحد الأقصى للشرائح**: يمكن عرض 5 شرائح كحد أقصى في الكاروسيل (يتم تحديد ذلك في الإعدادات).
- **الصور المحسنة**: يتم تحويل الصور المرفوعة إلى تنسيق (WebP) تلقائياً لتحسين سرعة التحميل.
- **التخزين المؤقت**: عند إضافة أو تعديل شريحة، يتم إفراغ (Cache) الصفحة الرئيسية لتحديث الكاروسيل فوراً للمستخدمين.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/admin/cms/sliders/` | قائمة الشرائح. |
| `POST` | `/api/v1/admin/cms/sliders/` | إضافة شريحة جديدة. |
| `GET` | `/api/v1/admin/cms/sliders/{id}/` | تفاصيل شريحة. |
| `PUT` | `/api/v1/admin/cms/sliders/{id}/` | تحديث شريحة. |
| `DELETE` | `/api/v1/admin/cms/sliders/{id}/` | حذف شريحة. |
| `PATCH` | `/api/v1/admin/cms/sliders/reorder/` | إعادة ترتيب الشرائح. |
