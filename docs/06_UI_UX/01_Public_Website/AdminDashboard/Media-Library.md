# مكتبة الوسائط (Media Library)

## 1. الهدف
توفير مستودع مركزي لإدارة جميع الصور والملفات المرفوعة في لوحة التحكم (صور الأخبار، البانرات، الوثائق، صور الصفحات)، مع إمكانية البحث، المعاينة، الحذف الجماعي، ومعرفة مكان استخدام كل ملف.

## 2. مكونات الشاشة

### 2.1. عرض المكتبة (Gallery View)
- **عرض شبكي (Grid View)** للصور والملفات مع:
  - **معاينة الصورة**: (مصغرة).
  - **اسم الملف**.
  - **الحجم**.
  - **تاريخ الرفع**.
  - **أيقونة الملف**: (PDF، DOCX، JPG، إلخ).
- **زر**: "رفع ملف جديد" (يفتح نافذة لرفع الملفات بشكل منفرد أو متعدد).

### 2.2. شريط البحث والتصفية
- **حقل بحث**: للبحث باسم الملف.
- **تصفية حسب النوع**: (صور، مستندات PDF، مستندات Word، إلخ).
- **تصفية حسب تاريخ الرفع**: (من - إلى).

### 2.3. تفاصيل الملف (File Detail)
- عند النقر على ملف، تظهر نافذة جانبية (Side Panel) تحتوي على:
  - **معاينة الملف** (للملفات المدعومة).
  - **اسم الملف**: (قابل للتعديل).
  - **المسار**: (حقل للنسخ).
  - **حجم الملف**.
  - **مكان الاستخدام**: (يعرض أسماء الصفحات أو الأخبار التي تستخدم هذا الملف، لمعرفة التأثير قبل الحذف).
  - **زر**: "تنزيل" و "حذف".

## 3. منطق الأعمال (Business Logic)
- **التحقق من الاستخدام**: لا يمكن حذف ملف مستخدم في صفحة أو خبر منشور (يظهر تحذير).
- **الضغط التلقائي (Auto-Compression)**: يتم ضغط الصور المرفوعة (أكبر من 1 ميجابايت) تلقائياً لتوفير مساحة التخزين وتسريع تحميل الموقع.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/admin/cms/media/` | قائمة الملفات. |
| `POST` | `/api/v1/admin/cms/media/upload/` | رفع ملف جديد (يدعم الرفع المتعدد). |
| `GET` | `/api/v1/admin/cms/media/{id}/` | تفاصيل ملف. |
| `DELETE` | `/api/v1/admin/cms/media/{id}/` | حذف ملف (مع التحقق من الاستخدام). |
