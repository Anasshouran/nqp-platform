# إدارة الأخبار والإعلانات (News Manager)

## 1. الهدف
تمكين مسؤولي المحتوى من إدارة جميع الأخبار والإعلانات المنشورة على الموقع العام، مع إمكانية جدولة النشر، وترتيب ظهورها، وتحديد الأخبار العاجلة التي تظهر في شريط الإشعارات العلوي.

## 2. مكونات الشاشة

### 2.1. قائمة الأخبار (News List)
- **عرض جدولي (Table)** يحتوي على الأعمدة التالية:
  - **الصورة المصغرة**: صورة مصغرة للخبر.
  - **العنوان**: عنوان الخبر.
  - **الفئة**: (أخبار، إعلانات، تعميمات).
  - **تاريخ النشر**: (التاريخ المحدد للنشر).
  - **عاجل؟**: أيقونة (⭐) إذا كان الخبر عاجلاً.
  - **الحالة**: (منشور، مسودة، مجدول).
  - **الإجراءات**: (✏️ تعديل، 👁️ عرض، 🗑️ حذف).
- **أدوات التصفية**:
  - قائمة منسدلة لتصفية (الفئة، الحالة).
  - منتقي تاريخ (من - إلى).
- **زر**: "إضافة خبر جديد".

### 2.2. نموذج إضافة / تعديل الخبر (News Form)
- **الحقول الإلزامية**:
  - **العنوان**: (نص، حد أقصى 200 حرف).
  - **الملخص**: (نص، 300 حرف كحد أقصى، يظهر في بطاقات الأخبار).
  - **المحتوى**: (محرر WYSIWYG للنص الكامل).
  - **الفئة**: (قائمة منسدلة: أخبار، إعلانات، تعميمات عاجلة).
  - **صورة مميزة**: (رفع صورة، يفضل أن تكون بمقاس (16:9) مع إمكانية قصها (Crop) أثناء الرفع).
- **خيارات متقدمة**:
  - **خانة اختيار "خبر عاجل"**: عند تفعيلها، يظهر الخبر في شريط الإشعارات العلوي (مع أولوية العرض).
  - **تاريخ النشر**: منتقي تاريخ ووقت (لجدولة النشر). إذا ترك فارغاً، يُنشر فوراً.
  - **حالة النشر**: (منشور / مسودة / مجدول).
- **أزرار الإجراء**: (💾 حفظ كمسودة) و (📤 نشر الآن) و (⏰ جدولة).

### 2.3. عرض الخبر (News Detail) - في نافذة منبثقة
- عرض الخبر كاملاً بالشكل الذي سيظهر به في الموقع العام (مع الصورة والمحتوى المنسق).
- **إحصائيات**: (عدد المشاهدات، عدد المشاركات - إن وجدت).

## 3. منطق الأعمال (Business Logic)
- **الأخبار العاجلة**: يتم عرض آخر 3 أخبار عاجلة في شريط الإشعارات العلوي مع خاصية التمرير التلقائي (Marquee).
- **جدولة النشر**: في الوقت المحدد، يقوم Celery Beat بنشر الخبر تلقائياً (تغيير الحالة من `SCHEDULED` إلى `PUBLISHED`).
- **تنظيف Cache**: عند نشر خبر جديد، يتم تحديث Cache الصفحة الرئيسية وقائمة الأخبار.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/admin/cms/news/` | قائمة الأخبار (مع التصفية). |
| `POST` | `/api/v1/admin/cms/news/` | إنشاء خبر جديد. |
| `GET` | `/api/v1/admin/cms/news/{id}/` | تفاصيل خبر. |
| `PUT` | `/api/v1/admin/cms/news/{id}/` | تحديث خبر. |
| `DELETE` | `/api/v1/admin/cms/news/{id}/` | حذف خبر. |
