# إدارة مستخدمي CMS والصلاحيات (CMS Users & Roles)

## 1. الهدف
تمكين مدير النظام (Super Admin) من إدارة حسابات مسؤولي المحتوى (CMS Users) الذين لديهم صلاحية الدخول إلى لوحة تحكم الموقع العام (AdminDashboard)، وتعيين الأدوار والصلاحيات المناسبة لكل مستخدم بناءً على مبدأ "أقل امتياز (Least Privilege)".

## 2. الأدوار المحددة مسبقاً (Predefined Roles for CMS)

| الدور (Role) | الصلاحيات (Permissions) | الوصف |
| :--- | :--- | :--- |
| **CMS Admin** | الوصول الكامل إلى جميع أقسام لوحة التحكم (إدارة الصفحات، الأخبار، الأسئلة الشائعة، الوثائق، الإعدادات، ومستخدمي CMS). | مدير المحتوى الأعلى صلاحية. |
| **Content Editor** | إضافة، تعديل، وحذف (الأخبار، الصفحات، الأسئلة الشائعة). لا يستطيع إدارة المستخدمين أو إعدادات الموقع. | المحرر الأساسي للمحتوى. |
| **Content Publisher** | مثل (Content Editor) بالإضافة إلى صلاحية تغيير حالة النشر (نشر/إخفاء المحتوى). | المسؤول عن الموافقة النهائية ونشر المحتوى. |
| **Document Manager** | إدارة الوثائق فقط (رفع، تعديل، حذف). | مسؤول مركز الوثائق. |
| **Support Agent** | قراءة وإدارة رسائل "اتصل بنا" فقط. | مسؤول الرد على الاستفسارات. |
| **Viewer (قراءة فقط)** | يمكنه عرض جميع المحتويات ولكن لا يستطيع تعديلها. | للمراجعين والمدققين. |

## 3. مكونات الشاشة

### 3.1. قائمة المستخدمين (Users List)
- **عرض جدولي (Table)** يحتوي على الأعمدة التالية:
  - **الاسم الكامل**.
  - **البريد الإلكتروني**.
  - **الدور (Role)** (مع تاج ملون).
  - **آخر دخول**.
  - **الحالة**: (نشط، غير نشط) مع أيقونة.
  - **الإجراءات**: (✏️ تعديل، 🔒 إعادة تعيين كلمة المرور، 🚫 تعطيل / تفعيل).
- **زر**: "إضافة مستخدم جديد".

### 3.2. نموذج إضافة / تعديل مستخدم CMS (User Form)
- **الحقول الإلزامية**:
  - **الاسم الكامل**: (نص).
  - **البريد الإلكتروني**: (بريد إلكتروني، فريد).
  - **الدور**: (قائمة منسدلة من الأدوار المحددة مسبقاً).
  - **كلمة المرور المؤقتة**: (حقلين: كلمة المرور وتأكيدها) - تُرسل للمستخدم عبر البريد الإلكتروني.
- **خيارات إضافية**:
  - **الحالة**: (نشط / غير نشط).
  - **صلاحيات إضافية (دقيقة)**: (تظهر للمشرفين المتقدمين) قائمة بجميع الصلاحيات المتاحة في النظام (مثل: `can_edit_pages`, `can_publish_news`, `can_manage_settings`).

## 4. منطق الأعمال (Business Logic)
- **أقل امتياز**: يتم تعيين الصلاحيات الأساسية لكل دور تلقائياً. يمكن تعديلها يدوياً فقط بواسطة (Super Admin).
- **تدقيق الدخول**: يتم تسجيل جميع محاولات الدخول إلى لوحة التحكم في (Audit Log) لأغراض المراجعة الأمنية.
- **مدة الجلسة**: تنتهي جلسة مستخدم CMS بعد 30 دقيقة من الخمول (لأسباب أمنية).

## 5. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف | الصلاحية |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/admin/cms/users/` | قائمة مستخدمي CMS. | Super Admin / CMS Admin |
| `POST` | `/api/v1/admin/cms/users/` | إضافة مستخدم جديد. | Super Admin / CMS Admin |
| `GET` | `/api/v1/admin/cms/users/{id}/` | تفاصيل مستخدم. | Super Admin / CMS Admin |
| `PUT` | `/api/v1/admin/cms/users/{id}/` | تحديث بيانات المستخدم. | Super Admin / CMS Admin |
| `PATCH` | `/api/v1/admin/cms/users/{id}/toggle-status` | تفعيل/تعطيل مستخدم. | Super Admin / CMS Admin |
| `POST` | `/api/v1/admin/cms/users/{id}/reset-password` | إعادة تعيين كلمة المرور. | Super Admin / CMS Admin |
