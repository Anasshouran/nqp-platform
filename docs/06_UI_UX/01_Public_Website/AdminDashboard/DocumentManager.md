# إدارة الوثائق والملفات (Document Manager)

## 1. الهدف
تمكين مسؤولي المحتوى من إدارة جميع الملفات والوثائق الرسمية المتاحة للتحميل في "مركز الوثائق" بالموقع العام (مثل: القوانين، البروتوكولات الصحية، النماذج، والمنشورات التوعوية)، بالإضافة إلى الملفات المرفوعة من قبل المسافرين (التي تظهر في لوحة المسؤول للرجوع إليها في حالات الضرورة).

## 2. مكونات الشاشة

### 2.1. قائمة الوثائق العامة (Public Documents List)
- **عرض جدولي (Table)** يحتوي على الأعمدة التالية:
  - **اسم الملف**: (مع أيقونة تعكس نوع الملف: PDF، DOCX، JPG).
  - **الفئة**: (قوانين، بروتوكولات، نماذج، منشورات).
  - **الحجم**: (بالـ KB أو MB).
  - **تاريخ الرفع**.
  - **عدد مرات التحميل**: (إحصائية).
  - **الإجراءات**: (⬇️ تحميل، ✏️ تعديل الوصف، 🗑️ حذف).
- **زر**: "رفع وثيقة جديدة".

### 2.2. نموذج رفع وثيقة جديدة (Upload Form)
- **الحقول الإلزامية**:
  - **اسم الملف** (العنوان الذي سيظهر للمستخدم): (نص).
  - **الفئة**: (قائمة منسدلة: قوانين، بروتوكولات، نماذج، منشورات توعوية، تقارير).
  - **رفع الملف**: (منطقة سحب وإفلات (Drag & Drop) تدعم الملفات: PDF، DOCX، XLSX، JPG، PNG. الحد الأقصى للحجم: 10 ميجابايت).
- **الحقول الاختيارية**:
  - **الوصف**: (نص قصير يوضح محتوى الملف).
  - **تاريخ النشر**: (لجدولة ظهور الوثيقة).
- **زر**: "رفع الملف".

### 2.3. قسم المستندات الخاصة (Private / Traveler Documents) - للمشرفين فقط
- **عرض جدولي** بجميع الملفات التي رفعها المسافرون (صور جوازات، شهادات التطعيم) مع إمكانية:
  - **البحث**: حسب (اسم المسافر، رقم الجواز، نوع المستند).
  - **تنزيل الملف**: (للرجوع إليه في حالات التحقق).
  - **حذف الملف**: (في حال انتهاك سياسة الخصوصية).
- **ملاحظة**: صلاحية الوصول إلى هذا القسم محدودة جداً (Super Admin أو Federal Admin).

## 3. منطق الأعمال (Business Logic)
- **التحقق من سلامة الملف**: يتم فحص الملف للتأكد من خلوه من الفيروسات (باستخدام ClamAV أو خدمة مشابهة في الخلفية) قبل قبوله.
- **التخزين**: يتم تخزين الملفات على (MinIO/S3) مع أسماء فريدة (UUID) لمنع التعارض.
- **رابط التحميل المؤقت**: عند الضغط على "تحميل"، يتم إنشاء رابط (Signed URL) صالح لمدة ساعة واحدة فقط (لأسباب أمنية).

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/admin/cms/documents/` | قائمة الوثائق العامة. |
| `POST` | `/api/v1/admin/cms/documents/` | رفع وثيقة جديدة. |
| `GET` | `/api/v1/admin/cms/documents/{id}/download` | تحميل وثيقة (مع Signed URL). |
| `DELETE` | `/api/v1/admin/cms/documents/{id}/` | حذف وثيقة. |
| `GET` | `/api/v1/admin/travelers/documents/` | (للمشرفين) قائمة مستندات المسافرين. |
