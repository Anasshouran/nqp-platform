# TravelRequirements

---

### 2.4. صفحة "متطلبات السفر" (Travel Requirements)

 المسار:  `/travel-requirements`  
 الهدف:  عرض شروط الدخول إلى السودان بناءً على دولة القدوم، التطعيمات المطلوبة، والإرشادات الصحية.

 التخطيط: 

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  🛂 متطلبات السفر                                                          │
├──────────────────────────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │  حدد دولة القدوم: [قائمة منسدلة ──────────── ▾]                    │   │
│  │  [عرض المتطلبات]                                                    │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │  📋 المتطلبات لدولة: إثيوبيا                                       │   │
│  │  ✅ التطعيمات المطلوبة: كوفيد-19، الحمى الصفراء                    │   │
│  │  ✅ اشتراطات صحية: فحص PCR خلال 72 ساعة                            │   │
│  │  ⚠️ الدول عالية الخطورة: نعم (مطلوب حجر صحي)                      │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │  📚 إرشادات المسافرين العامة                                       │   │
│  │  (نص طويل يتم جلبه من CMS)                                         │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────────────┘
```

 المكونات: 

- `CountrySelector`: قائمة منسدلة (بياناتها من `GET /api/countries/`).
- `RequirementsDisplay`: تعرض معلومات من `GET /api/travel-requirements/?country=ETH`.
