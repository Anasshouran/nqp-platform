# صفحة تفاصيل الوثيقة (Document Detail)

## 1. الهدف
عرض معلومات مفصلة عن وثيقة معينة من مركز الوثائق قبل تحميلها، بما في ذلك (الوصف، الفئة، الحجم، تاريخ الإضافة)، وتوفير معاينة سريعة (إن أمكن) وزر التحميل.

## 2. مكونات الصفحة

### 2.1. رأس الوثيقة (Header)
- **اسم الوثيقة**: (عنوان الملف).
- **الفئة**: (تاج ملون: قوانين، بروتوكولات، نماذج، منشورات).

### 2.2. معلومات الوثيقة (Document Info)
- **الوصف**: (نص يوضح محتوى الوثيقة).
- **الحجم**: (مثل: 2.5 ميجابايت).
- **التنسيق**: (مثل: PDF).
- **تاريخ الإضافة**: (مثل: 25 يوليو 2024).
- **عدد مرات التحميل**: (إحصائية).

### 2.3. معاينة الوثيقة (Preview) - للملفات PDF
- عرض معاينة للملف (أول 3 صفحات أو عرض مصغر) باستخدام مكتبة (مثل: `react-pdf`).
- **زر**: "تحميل الملف" (الزر الرئيسي باللون الأزرق).

### 2.4. وثائق ذات صلة (Related Documents)
- عرض آخر 3 وثائق من نفس الفئة.

### 2.5. زر العودة (Back Button)
- زر: "العودة إلى مركز الوثائق".

## 3. منطق الأعمال (Business Logic)
- **رابط التحميل المؤقت**: عند الضغط على "تحميل"، يتم إنشاء رابط (Signed URL) صالح لمدة ساعة واحدة فقط (لأسباب أمنية).
- **زيادة عداد التحميلات**: يتم زيادة عداد التحميلات عند الضغط على زر التحميل.
- **تسجيل التدقيق**: يتم تسجيل كل عملية تحميل في (Audit Log) لأغراض التحليل والإحصاء.

## 4. نقاط النهاية الخلفية (API Endpoints)
| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `GET` | `/api/v1/cms/documents/{slug}/` | استرجاع تفاصيل وثيقة معينة. |
| `GET` | `/api/v1/cms/documents/{id}/download/` | تحميل الوثيقة (مع Signed URL). |
