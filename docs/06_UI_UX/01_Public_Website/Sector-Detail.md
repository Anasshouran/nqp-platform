# شاشة تفاصيل القطاع (Sector Detail)

## 1. الهدف
عرض معلومات مفصلة عن قطاع معين، بما في ذلك المنافذ التابعة له، ومعلومات الاتصال، والإحصائيات.

## 2. مكونات الصفحة

### 2.1. رأس الصفحة (Header)
- **العنوان**: اسم القطاع (مثل: "قطاع البحر الأحمر").
- **النص الفرعي**: وصف القطاع (مثل: "يضم 7 منافذ في ولاية البحر الأحمر").
- **زر**: "العودة إلى القطاعات".

### 2.2. معلومات القطاع (Sector Info)
| الحقل | القيمة |
| :--- | :--- |
| **الاسم** | قطاع البحر الأحمر |
| **المنطقة** | البحر الأحمر |
| **عدد المنافذ** | 7 منافذ |
| **الهاتف** | +249-123-456-789 |
| **البريد الإلكتروني** | redsea.sector@nqp.gov.sd |
| **ساعات العمل** | 8:00 صباحاً - 4:00 عصراً (سبت - خميس) |

### 2.3. خريطة مصغرة (Mini Map)
- عرض موقع القطاع والمنافذ التابعة على خريطة مصغرة.

### 2.4. قائمة المنافذ التابعة (Ports List)
- **جدول** يحتوي على:
  - الأعمدة: (اسم المنفذ، النوع، الموقع، الحالة، الخدمات، الإجراءات).
- **أزرار الإجراءات**:
  - زر "عرض التفاصيل" (👁️) - يفتح صفحة تفاصيل المنفذ.
  - زر "الاتجاهات" (📍) - يفتح الموقع على خرائط Google (اختياري).

### 2.5. إحصائيات القطاع (Sector Stats) - اختياري
- عدد المسافرين شهرياً.
- عدد الفحوصات.
- عدد الحالات المكتشفة.

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader).
- **حالة عدم وجود منافذ**: "لا توجد منافذ تابعة لهذا القطاع".
- **حالة الخطأ**: رسالة خطأ مع زر "إعادة المحاولة".

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية | الغرض |
| :--- | :--- |
| `GET /api/v1/public/sectors/{id}/` | جلب تفاصيل القطاع |
| `GET /api/v1/public/sectors/{id}/ports/` | جلب قائمة منافذ القطاع |
