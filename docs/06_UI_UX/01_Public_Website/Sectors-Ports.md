# شاشة القطاعات والمنافذ (Sectors & Ports)

## 1. الهدف
تقديم معلومات شاملة عن الهيكل الإداري والجغرافي لمنصة الحجر الصحي القومي، بما في ذلك القطاعات الستة والمنافذ التابعة لها.

## 2. مكونات الصفحة

### 2.1. العنوان العلوي (Header)
- **العنوان**: "القطاعات والمنافذ - الإدارة الاتحادية للحجر الصحي".
- **النص الفرعي**: "تعرف على قطاعات ومنافذ الحجر الصحي في جميع أنحاء السودان."
- **زر**: "تحميل دليل المنافذ (PDF)".

### 2.2. خريطة السودان التفاعلية (Interactive Map)
- **خريطة السودان** مع:
  - حدود القطاعات (مظللة بألوان مختلفة).
  - أيقونات المنافذ (✈️ مطار، 🚢 ميناء، 🚛 معبر بري).
  - عند النقر على منطقة: ظهور نافذة منبثقة باسم القطاع وعدد المنافذ.
  - عند النقر على أيقونة منفذ: ظهور نافذة منبثقة باسم المنفذ ونوعه وزر "عرض التفاصيل".

### 2.3. قائمة القطاعات (Sectors List)
- **عرض شبكي (Grid) من 3 أعمدة** (يتحول إلى عمودين أو عمود واحد على الجوال):
  - **بطاقة كل قطاع** تحتوي على:
    - أيقونة القطاع (حسب المنطقة).
    - اسم القطاع.
    - وصف مختصر (أقل من 100 حرف).
    - عدد المنافذ التابعة.
    - زر "عرض التفاصيل" (باللون الأزرق).

### 2.4. الإحصائيات السريعة (Quick Stats)
- **بطاقات إحصائيات** أعلى الصفحة:
  - عدد القطاعات: 6 قطاعات.
  - عدد المنافذ: 25+ منفذاً.
  - المطارات الدولية: 5 مطارات.
  - الموانئ البحرية: 4 موانئ.
  - المعابر البرية: 10+ معبراً.

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للبطاقات والخريطة.
- **حالة عدم وجود بيانات**: رسالة "لا توجد قطاعات مسجلة حالياً".
- **حالة خطأ الخريطة**: عرض رسالة "تعذر تحميل الخريطة، يرجى تحديث الصفحة".

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية | الغرض |
| :--- | :--- |
| `GET /api/v1/public/sectors/` | جلب قائمة القطاعات |
| `GET /api/v1/public/ports/map/` | جلب بيانات الخريطة (GeoJSON) |
| `GET /api/v1/public/sectors/{id}/` | جلب تفاصيل قطاع |
