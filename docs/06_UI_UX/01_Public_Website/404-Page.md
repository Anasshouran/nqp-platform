# صفحة 404 - غير موجود (404 Not Found)

## 1. الهدف
توفير تجربة مستخدم لطيفة ومفيدة عند محاولة الوصول إلى صفحة غير موجودة (رابط مكسور أو تم نقله)، بدلاً من عرض صفحة الخطأ الافتراضية القياسية للمتصفح. تساعد هذه الصفحة في إبقاء الزائر على الموقع وتوجيهه إلى المحتوى الصحيح.

## 2. مكونات الصفحة

### 2.1. المحتوى الأساسي
- **صورة/أيقونة معبرة**: (مثل: 🧭 أو صورة لخريطة).
- **عنوان رئيسي**: "عذراً! الصفحة غير موجودة." (بخط كبير).
- **نص توضيحي**: "قد يكون الرابط الذي تبحث عنه مكسوراً، أو تم نقله، أو أن الصفحة قد أُزيلت."
- **زر**: "العودة إلى الصفحة الرئيسية" (باللون الأزرق، كبير).

### 2.2. روابط مفيدة (Quick Links)
- عرض روابط سريعة لأهم الأقسام:
  - (الرئيسية، الخدمات، متطلبات السفر، اتصل بنا، الأخبار).
- **شريط البحث**: حقل بحث للسماح للمستخدم بالبحث عن المحتوى المطلوب.

### 2.3. الإبلاغ عن الرابط المكسور (اختياري)
- رابط: "هل وجدت رابطاً مكسوراً؟ أخبرنا." (يؤدي إلى صفحة "اتصل بنا" مع ملء الحقول تلقائياً بالرابط المطلوب).

## 3. منطق الأعمال (Business Logic)
- **التسجيل في السجلات**: يتم تسجيل جميع محاولات الوصول إلى صفحات 404 في سجلات الخادم لتحليلها وإصلاح الروابط المكسورة.
- **إعادة التوجيه الذكي**: (اختياري) إذا كان الرابط المطلوب مشابهاً لرابط موجود (مثل: `/abot` بدلاً من `/about`)، يمكن للنظام إعادة التوجيه تلقائياً مع رسالة تنبيه.
