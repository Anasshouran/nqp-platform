## خارطة الطريق

### P0 — فورية (قبل الإطلاق)
1. **إلغاء/إخفاء مبدّل اللغة** في الصفحات غير المترجمة (يمنع `lang=en` على محتوى عربي).
2. **توحيد تسميات `/verify`** في تسمية واحدة (تنقّل + تذييل + بلاطات).
3. ~~إصلاح CLS على الجوال~~ — **أُقصي**: القياس النظيف CLS = 0 في desktop والجوال (كان 0.362 أثراً لوسائط قياس خاطئة).
4. ~~تقليص TBT~~ — **لا يُحل بتقسيم الرزم**: التجربة فعلية (نفس البصمات ⇒ نفس TBT ~1.5s)؛ التخفيض الجذري يتطلب SSR/ISR للصفحات العامة (P2). التقسيم الحالي يشمل استقرار، تخزين مؤقتاً (vendor موازية).
5. **قياس في CI**: Lighthouse gates (LCP ≤ 2.5s، CLS ≤ 0.1، TBT ≤ 200ms) بعد كل build — مع معايير ثابتة وفحص VR (اختباري لتفاوت التشغيل).

### P1 — المدى القريب
5. نقل ألوان hex العشوائية إلى tokens (palette دلالية) وتوحيد سكب البطاقات.
6. خط عربي مخصص (Cairo/Tajawal) + ضبط لوغاريتمي للعناوين.
7. جلسات اختبار قابلية الاستخدام (مسافر دولي + مسؤول حكومي) → توثيق.
8. بوابة تفاعلية (بحث + اختصارات) في `/gateways`.

### P2 — المدى المتوسط
9. Design System رسمي: /ui-kit كامل + توحيد لوحات الأدوار (إزالة SectionTitle المكررة).
10. i18n كامل لأهم 10 صفحات عامة (هياكل + CMS ثنائي اللغة).
11. أتمتة جودة: axe + Lighthouse في pipeline.
