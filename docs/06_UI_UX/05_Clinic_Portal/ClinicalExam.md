# شاشة الفحص السريري (Clinical Examination)

## 1. الهدف
تمكين الطبيب من تسجيل نتائج الفحص السريري الكامل للمريض (العلامات الحيوية، الفحص البدني، التشخيص المبدئي) بطريقة منظمة وسريعة، مع ربط التشخيص بنظام إدارة الأمراض (ICD-11) للحصول على توصيات علاجية مبدئية.

## 2. مكونات النموذج

### 2.1. رأس النموذج (Form Header)
- **اسم المريض** و **رقم الجواز** و **عمر المريض**.
- **تاريخ الفحص** (يُملأ تلقائياً).

### 2.2. قسم العلامات الحيوية (Vital Signs)
- **شبكة (Grid) مكونة من 4 أعمدة**:
  - **درجة الحرارة** (°C): (حقل رقمي مع زر "استقبال من جهاز" إن أمكن).
  - **تشبع الأكسجين (SpO2)**: (حقل رقمي).
  - **الضغط الانقباضي/الانبساطي**: (حقلين رقميين).
  - **معدل ضربات القلب**: (حقل رقمي اختياري).
- **التحقق اللحظي**: إذا كانت الحرارة > 39° أو SpO2 < 93%، يظهر تحذير أحمر فوري: "⚠️ قراءة حرجة! يرجى التحقق مرة أخرى."

### 2.3. قسم الفحص البدني (Physical Examination) - منظم حسب الأجهزة
- **بطاقات قابلة للطي (Accordion)** لكل جهاز:
  - **الجهاز التنفسي**: (حقل نصي + خيارات (طبيعي/غير طبيعي)).
  - **الجهاز القلبي الوعائي**: (حقل نصي + خيارات).
  - **الجهاز الهضمي**: (حقل نصي + خيارات).
  - **الجهاز العصبي**: (حقل نصي + خيارات).
  - **الجلد والأغشية المخاطية**: (حقل نصي + خيارات).

### 2.4. قسم التشخيص (Diagnosis)
- **حقل بحث**: (متصل بـ `Disease_Management`، يعرض قائمة مقترحات من ICD-11 أثناء الكتابة).
- **شدة الحالة**: (قائمة منسدلة: خفيفة، متوسطة، شديدة، حرجة).
- **التشخيص النهائي**: (نص، يتم تحديده بعد استلام نتائج المختبر).

### 2.5. أزرار الإجراء (Action Buttons)
- **زر**: "حفظ المسودة" (لحفظ التغييرات دون إغلاق الزيارة).
- **زر**: "طلب فحوصات مخبرية" (ينتقل إلى نموذج `LabRequests`).
- **زر**: "إغلاق الزيارة" (ينتقل إلى صفحة `Treatment.md` لتحديد خطة المتابعة النهائية).

## 3. حالات واجهة المستخدم (UI States)
- **حالة الحقل غير المكتمل**: تمييز الحقل بإطار أحمر عند محاولة الحفظ دون ملء الحقول الإلزامية.
- **حالة اقتراح التشخيص**: عرض قائمة منسدلة (Dropdown) بالأمراض المقترحة أثناء الكتابة في حقل التشخيص.
- **حالة تحميل الاقتراحات**: عرض (Spinner) صغير بجانب حقل البحث أثناء جلب البيانات من الخادم.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `POST /api/v1/clinic/visits/{id}/exam/` | تسجيل الفحص السريري. |
| `GET /api/v1/clinic/visits/{id}/exam/` | استرجاع بيانات الفحص (للتعديل). |
| `GET /api/v1/diseases/search/?q={term}` | البحث عن الأمراض (ICD-11) لملء التشخيص. |
