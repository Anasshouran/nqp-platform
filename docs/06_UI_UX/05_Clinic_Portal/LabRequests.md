# شاشة طلبات المختبر (Laboratory Requests)

## 1. الهدف
تمكين الطبيب من إرسال طلبات فحوصات مخبرية (مسحات، دم، بول) إلى بوابة المختبرات (6)، وتتبع حالة العينة، واستلام النتائج عند اعتمادها.

## 2. مكونات الشاشة

### 2.1. تبويبات التنقل (Tabs)
- **طلبات جديدة** (📝): لإنشاء طلب جديد.
- **قيد التنفيذ** (⏳): لعرض الطلبات التي لم تظهر نتيجتها بعد.
- **النتائج المستلمة** (✅): لعرض النتائج المعتمدة.

### 2.2. نموذج طلب فحص جديد (New Request Form) - في التبويب الأول
- **نوع العينة**: (قائمة منسدلة: مسحة أنفية، عينة دم، عينة بول، إلخ).
- **الفحص المطلوب**: (قائمة منسدلة: PCR، مزرعة بكتيرية، CBC، إلخ).
- **الأولوية**: (عادي، عاجل، فوري) - مع تمييز باللون (أخضر، أصفر، أحمر).
- **ملاحظات إضافية**: (حقل نصي للطبيب).
- **زر**: "إرسال الطلب" (باللون الأزرق).

### 2.3. قائمة الطلبات قيد التنفيذ (Pending Requests) - التبويب الثاني
- **جدول** يحتوي على:
  - (نوع العينة، الفحص المطلوب، تاريخ الطلب، الأولوية، حالة العينة (مسجلة، قيد التحليل)).
- **زر**: "تحديث" (لتحديث الحالة يدوياً).

### 2.4. استلام النتائج (Results) - التبويب الثالث
- **عند ظهور نتيجة جديدة، تظهر كبطاقة (Card)** مع:
  - **اسم المريض** و **نوع العينة**.
  - **النتيجة**: (🟢 سلبية / 🔴 إيجابية / 🟡 غير محدد).
  - **القيمة الرقمية**: (مثل: Ct Value = 32.5).
  - **تاريخ الاعتماد**.
  - **زر**: "ربط النتيجة بالتشخيص" (لإضافة النتيجة إلى السجل الطبي وتحديث التشخيص النهائي).

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح الإرسال**: ظهور رسالة خضراء "تم إرسال طلب المختبر بنجاح. رقم العينة: LAB-2024-001".
- **حالة استلام النتيجة الجديدة**: ظهور إشعار (Toast) في أعلى الصفحة: "📨 نتيجة جديدة للمريض محمد أحمد".
- **حالة عدم وجود طلبات**: عرض رسالة "لا توجد طلبات مختبر" مع أيقونة 🔬.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `POST /api/v1/clinic/visits/{id}/lab-requests/` | إرسال طلب فحص مخبري جديد. |
| `GET /api/v1/clinic/visits/{id}/lab-requests/` | قائمة طلبات المختبر لهذه الزيارة. |
| `GET /api/v1/clinic/visits/{id}/lab-results/` | استرجاع نتائج المختبر المعتمدة. |
| `PATCH /api/v1/clinic/visits/{id}/apply-result/` | ربط النتيجة بالتشخيص النهائي. |
