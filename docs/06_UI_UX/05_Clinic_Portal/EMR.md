# شاشة السجل الطبي الإلكتروني (Electronic Medical Record - EMR)

## 1. الهدف
توفير واجهة متكاملة للطبيب لعرض التاريخ الطبي للمريض، وتسجيل الفحص السريري الحالي، ووصف العلاج، ومتابعة تطور الحالة عبر جدول زمني. تم تصميم هذه الشاشة لتكون **ثلاثية الأعمدة** لتوفير أقصى قدر من المعلومات في لمحة واحدة.

## 2. تخطيط الصفحة (Three-Column Layout)

### 2.1. العمود الأيسر: معلومات المريض الأساسية (Patient Summary)
- **الصورة الشخصية** (أو أيقونة افتراضية).
- **الاسم الكامل** و **العمر** و **الجنس** و **رقم الجواز**.
- **الحالة الحالية**: (مثل: 🟡 قيد الفحص / 🟢 مستقر / 🔴 حرج).
- **الأمراض المزمنة**: (تُعرض كعلامات (Tags) ملونة، مع تحذير أحمر للحساسية).
- **الحساسية**: (تُعرض بتحذير أحمر كبير: "تحذير: حساسية من البنسلين!").
- **تاريخ الزيارات السابقة**: (قائمة مختصرة بالتواريخ والتشخيصات السابقة، مع زر "عرض الكل").

### 2.2. العمود الأوسط: الفحص السريري والتدخلات (Clinical Exam & Notes) - **المنطقة النشطة**
- **العلامات الحيوية الحالية** (قابلة للتحديث):
  - الحرارة، SpO2، الضغط، النبض، معدل التنفس.
- **الفحص البدني**: (حقول منظمة حسب الجهاز: التنفسي، القلبي، الهضمي، العصبي، الجلد) مع خيارات (طبيعي / غير طبيعي) لتقليل الكتابة.
- **التشخيص**: (حقل بحث متصل بـ ICD-11 لاختيار المرض بدقة).
- **الوصفات الطبية**: (زر "إضافة دواء" لفتح نافذة منبثقة لاختيار الدواء والجرعة).
- **طلبات المختبر**: (زر "طلب فحص مخبري").
- **أزرار الإجراء**: (💾 حفظ المسودة، 🧪 طلب مختبر، 📤 إغلاق الزيارة).

### 2.3. العمود الأيمن: الجدول الزمني (Timeline & Labs)
- **الجدول الزمني (Timeline)**: (عرض آخر 7 أيام من العلامات الحيوية والأعراض على شكل رسم بياني خطي (Line Chart) بسيط).
- **نتائج المختبر**: (عرض آخر النتائج المعتمدة مع حالة كل نتيجة (سلبية/إيجابية) وتاريخها).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للأعمدة الثلاثة.
- **حالة التحذير من الحساسية**: ظهور نافذة منبثقة (Pop-up) عند فتح الملف لأول مرة: "تنبيه: المريض يعاني من حساسية تجاه...".
- **حالة نجاح الحفظ**: ظهور رسالة (Toast) خضراء "تم حفظ السجل الطبي بنجاح".
- **حالة التفاعل الدوائي**: عند إضافة دواء، إذا كان هناك تعارض مع دواء آخر، يظهر تحذير أحمر ويمنع إضافة الدواء حتى يتم إلغاؤه.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/clinic/patients/{id}/emr/` | جلب السجل الطبي الكامل. |
| `PUT /api/v1/clinic/patients/{id}/emr/` | تحديث التاريخ الطبي (الأمراض، الحساسية). |
| `GET /api/v1/clinic/visits/{id}/exam/` | جلب بيانات الفحص الحالي. |
| `POST /api/v1/clinic/visits/{id}/exam/` | حفظ الفحص السريري. |
