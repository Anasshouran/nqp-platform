# شاشة التقارير الطبية (Medical Reports)

## 1. الهدف
تمكين الأطباء من إصدار تقارير طبية رسمية للمرضى (شهادات الإفراج، تقارير الإحالة، ملخصات الحالة)، وعرض إحصائيات أداء العيادة (للمشرفين).

## 2. مكونات الشاشة

### 2.1. تبويبات التنقل (Tabs)
- **شهادات الإفراج** (📄): لإصدار وعرض شهادات الإفراج.
- **تقارير الإحالة** (📤): لعرض تقارير الإحالة إلى المستشفيات.
- **إحصائيات العيادة** (📊): لعرض مؤشرات الأداء (للمشرفين).

### 2.2. التبويب الأول: شهادات الإفراج (Clearance Certificates)
- **زر**: "إصدار شهادة جديدة" (يفتح نموذجاً لاختيار مريض من الزيارات المغلقة).
- **جدول الشهادات الصادرة**:
  - الأعمدة: (اسم المريض، رقم الجواز، تاريخ الإصدار، حالة الشهادة (نشط/ملغي)).
  - **زر**: "عرض" (لفتح الشهادة بصيغة PDF).
  - **زر**: "طباعة" (لطباعة الشهادة مباشرة).

### 2.3. التبويب الثاني: تقارير الإحالة (Referral Reports)
- **جدول تقارير الإحالة الصادرة**:
  - الأعمدة: (اسم المريض، المستشفى المحال إليه، تاريخ الإحالة، حالة الإحالة (مرسل، قيد المعالجة، مكتمل)).
  - **زر**: "عرض التقرير" (لفتح التقرير بصيغة PDF).

### 2.4. التبويب الثالث: إحصائيات العيادة (Clinic Statistics) - للمشرفين
- **بطاقات الملخص العلوي**:
  - عدد الإحالات الواردة (الشهر).
  - عدد المرضى المفرج عنهم.
  - عدد المرضى المحولين للمتابعة المنزلية.
  - عدد المرضى المحولين للمستشفى.
- **رسوم بيانية**:
  - توزيع الأمراض الأكثر شيوعاً (Pie Chart).
  - اتجاه الزيارات اليومية (Line Chart).
- **زر**: "تصدير تقرير العيادة (PDF/Excel)".

## 3. حالات واجهة المستخدم (UI States)
- **حالة توليد الشهادة**: ظهور رسالة "جاري توليد الشهادة..." مع (Spinner).
- **حالة نجاح التوليد**: فتح الشهادة في علامة تبويب جديدة (PDF) مع رسالة نجاح.
- **حالة عدم وجود تقارير**: عرض رسالة "لا توجد تقارير صادرة" مع أيقونة 📭.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/clinic/reports/clearance/{visit_id}/` | استرجاع شهادة الإفراج (PDF). |
| `GET /api/v1/clinic/reports/referral/{visit_id}/` | استرجاع تقرير الإحالة (PDF). |
| `GET /api/v1/clinic/stats/` | إحصائيات أداء العيادة. |
| `GET /api/v1/clinic/reports/export/` | تصدير تقرير العيادة (PDF/Excel). |
