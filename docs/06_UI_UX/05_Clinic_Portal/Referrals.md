# شاشة استقبال الإحالات (Referrals Reception)

## 1. الهدف
تمكين الطبيب من استعراض وإدارة جميع الإحالات الواردة من بوابة موظفي الحجر (4)، مع إمكانية قبولها أو رفضها، وعرض التفاصيل الكاملة لكل إحالة لاتخاذ القرار المناسب.

## 2. مكونات الشاشة

### 2.1. شريط الأدوات (Toolbar)
- **تبويبات (Tabs)**: (📥 جديدة، ✅ مقبولة، ❌ مرفوضة، 📋 الكل).
- **قائمة منسدلة للتصفية**: (الأولوية: الكل، عاجل، عادي).
- **زر**: "تحديث" (لجلب الإحالات الجديدة يدوياً).

### 2.2. قائمة الإحالات (Referrals List) - بطاقات أو جدول
- **كل إحالة تعرض كبطاقة** (في حالة الجوال) أو صف في جدول (في حالة الحاسوب):
  - **معلومات المريض**: (الاسم، العمر، الجنس).
  - **معلومات الإحالة**: (سبب الإحالة، التصنيف (أصفر/أحمر)، تاريخ الإحالة).
  - **حالة الإحالة**: (جديد، قيد المراجعة، مقبول، مرفوض).
  - **أزرار الإجراءات**: (👁️ عرض التفاصيل، ✅ قبول، ❌ رفض).

### 2.3. نافذة تفاصيل الإحالة (Referral Detail) - نافذة منبثقة (Modal)
- **بيانات المريض الأساسية**: (الاسم، رقم الجواز، الجنسية، العمر، معلومات الاتصال).
- **بيانات الفحص الأولي**: (درجة الحرارة، SpO2، الأعراض الظاهرة، الملاحظات من موظف الحجر).
- **تقييم المخاطر الأولي**: (التصنيف (أصفر/أحمر)، درجة المخاطر، عوامل القرار).
- **منطق القرار للطبيب**:
  - **زر**: "قبول الإحالة" (ينشئ زيارة عيادية وينتقل إلى `EMR.md`).
  - **زر**: "رفض الإحالة" (يفتح نموذجاً لسبب الرفض مع حقل نصي إلزامي).
  - **زر**: "طلب استشارة" (لرفع الإحالة إلى طبيب أخصائي - اختياري).

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح القبول**: رسالة خضراء "تم قبول الإحالة بنجاح" مع إعادة توجيه تلقائي بعد 2 ثانية.
- **حالة رفض الإحالة**: رسالة حمراء مع طلب تأكيد "هل أنت متأكد من رفض الإحالة؟" ونموذج السبب.
- **حالة الإحالة العاجلة**: تمييز البطاقة بحدود حمراء وعلامة (🔥) مع خلفية حمراء فاتحة جداً.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/clinic/referrals/` | قائمة الإحالات (مع التصفية والترقيم). |
| `GET /api/v1/clinic/referrals/{id}/` | تفاصيل إحالة محددة. |
| `POST /api/v1/clinic/referrals/{id}/accept/` | قبول الإحالة. |
| `POST /api/v1/clinic/referrals/{id}/reject/` | رفض الإحالة (مع سبب). |
