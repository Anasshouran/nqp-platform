# شاشة العلاج والمتابعة (Treatment & Follow-up)

## 1. الهدف
تمكين الطبيب من وصف العلاج المناسب للمريض (الأدوية، الجرعات، التعليمات)، وتحديد خطة المتابعة النهائية (الإفراج، المتابعة المنزلية، أو الإحالة إلى المستشفى) قبل إغلاق الزيارة.

## 2. مكونات الشاشة

### 2.1. نموذج وصف الأدوية (Prescription Form)
- **حقل البحث عن الدواء**: (متصل بقاعدة الأدوية في `Disease_Management`).
- **تفاصيل الجرعة**:
  - الجرعة (مثل: 500mg).
  - التكرار (قائمة منسدلة: كل 8 ساعات، مرتين يومياً، إلخ).
  - المدة (عدد الأيام).
  - تعليمات إضافية (نص).
- **زر**: "إضافة إلى الوصفة" (يضيف الدواء إلى قائمة الأدوية الموصوفة).

### 2.2. قائمة الأدوية الموصوفة (Prescribed Medications List) - تظهر ديناميكياً
- **جدول**: (اسم الدواء، الجرعة، التكرار، المدة، الإجراءات (🗑️ حذف)).
- **كشف التداخلات الدوائية**: (إذا تم اكتشاف تعارض، يظهر تحذير أحمر أسفل الجدول مع تعطيل زر "حفظ الوصفة" حتى يتم حل التعارض).

### 2.3. خطة المتابعة (Follow-up Plan) - أسفل الصفحة
- **خيارات الإفراج**:
  - **زر**: "إفراج مباشر" (مع إمكانية طباعة تقرير الإفراج).
  - **زر**: "متابعة منزلية" (يفتح نموذجاً لتحديد مدة المتابعة بالأيام، ويتم تفعيل نظام المتابعة الصحية تلقائياً).
  - **زر**: "إحالة إلى المستشفى" (يفتح نموذجاً لاختيار المستشفى وسبب الإحالة).
- **حقل تعليمات للمريض**: (نص، مثل: "الراحة التامة، شرب سوائل كثيرة").

### 2.4. إغلاق الزيارة (Close Visit)
- **زر**: "إغلاق الزيارة" (باللون الأخضر الداكن). يظهر نافذة تأكيدية بملخص الحالة والعلاج، وبعد التأكيد يتم إغلاق الزيارة ولا يمكن تعديل البيانات بعدها.

## 3. حالات واجهة المستخدم (UI States)
- **حالة التداخل الدوائي**: ظهور تحذير أحمر مع تفاصيل التداخل (مثل: "يتعارض دواء X مع دواء Y (زيادة خطر النزيف)").
- **حالة نجاح الإغلاق**: رسالة خضراء "تم إغلاق الزيارة بنجاح" وإعادة توجيه إلى لوحة التحكم.
- **حالة إلزامية المتابعة**: لا يمكن إفراج مريض مصاب بمرض معدي دون تفعيل المتابعة المنزلية (يظهر تحذير إلزامي).

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `POST /api/v1/clinic/visits/{id}/prescriptions/` | وصف دواء جديد. |
| `POST /api/v1/clinic/visits/{id}/check-interactions/` | التحقق من التداخلات الدوائية. |
| `POST /api/v1/clinic/visits/{id}/close/` | إغلاق الزيارة (مع خطة المتابعة). |
| `POST /api/v1/clinic/visits/{id}/followup/` | تفعيل المتابعة المنزلية (إنشاء ملف في نظام المتابعة). |
| `POST /api/v1/clinic/visits/{id}/refer-hospital/` | إرسال إحالة إلى المستشفى. |
