# لوحة التحكم الرئيسية للعيادة (Clinic Dashboard)

## 1. الهدف
تزويد الطبيب أو الممرض بنظرة شاملة وسريعة عن حالة العيادة (الإحالات الواردة، المرضى المنتظرين، النتائج المخبرية المعلقة، والتنبيهات العاجلة) في صفحة واحدة، لتمكينه من تحديد الأولويات وإدارة الوقت بكفاءة.

## 2. تخطيط الصفحة (Layout)

### 2.1. الشريط العلوي (Header)
- **شعار المنصة** (جهة اليمين).
- **اسم الطبيب / الممرض** مع الصورة الشخصية (جهة اليسار).
- **قائمة منسدلة**: (الملف الشخصي، الإعدادات، تسجيل الخروج).
- **حالة العيادة**: (🟢 متاحة / 🔴 مشغول / ⚠️ طوارئ) - يمكن للطبيب تحديثها يدوياً.

### 2.2. بطاقات الملخص العلوي (KPI Cards) - 4 أعمدة
| البطاقة | القيمة | الأيقونة | لون الخلفية |
| :--- | :--- | :--- | :--- |
| **إحالات جديدة** | عدد (مثل: 5) | 📨 | أحمر فاتح (إذا كانت >0) |
| **مرضى في الانتظار** | عدد (مثل: 3) | 🕒 | برتقالي فاتح |
| **نتائج مختبر معلقة** | عدد (مثل: 2) | 🔬 | بنفسجي فاتح |
| **مرضى تحت المتابعة** | عدد (مثل: 8) | 📋 | أخضر فاتح |

### 2.3. قائمة الإحالات العاجلة (Urgent Referrals) - الأولوية القصوى
- **عرض قائمة مصغرة** بالإحالات الحمراء (ذات الأولوية العالية) التي لم يتم قبولها بعد:
  - الأعمدة: (اسم المريض، العمر، سبب الإحالة، الوقت المنقضي).
  - **زر**: "قبول" (سريع) و "عرض التفاصيل".

### 2.4. قائمة الانتظار (Waiting Queue) - جدول
- **عرض المرضى المقبولين الذين ينتظرون دورهم للكشف**:
  - الأعمدة: (الاسم، رقم الجواز، وقت القدوم، حالة الانتظار).
  - **زر**: "بدء الكشف" (ينتقل إلى صفحة `EMR.md`).

### 2.5. الإشعارات والتنبيهات (Notifications)
- **شريط جانبي أو أسفل الصفحة** يعرض آخر الأحداث:
  - (مثل: "نتيجة مختبر جديدة واردة للمريض محمد أحمد").
  - (مثل: "إحالة جديدة عاجلة من مطار الخرطوم").

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للبطاقات والجداول.
- **حالة عدم وجود إحالات**: عرض رسالة "لا توجد إحالات جديدة" مع أيقونة 📭.
- **حالة الطوارئ**: تغيير لون الخلفية العلوي إلى أحمر فاتح مع رسالة تحذيرية.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/clinic/dashboard/stats/` | جلب إحصائيات البطاقات العلوية. |
| `GET /api/v1/clinic/referrals/urgent/` | جلب الإحالات العاجلة. |
| `GET /api/v1/clinic/patients/waiting/` | جلب قائمة الانتظار. |
