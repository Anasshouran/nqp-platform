# شاشة التقارير والإحصائيات (Reports & Statistics)

## 1. الهدف
تزويد موظف الحجر الصحي ومدير المنفذ بتقارير وإحصائيات عن أداء عملية الفحص في المنفذ، بما في ذلك (عدد الفحوصات، حالات (أصفر/أحمر)، أوقات الفحص، ونسب الإحالات)، لتحسين العمليات وتحديد احتياجات التدريب.

## 2. مكونات الشاشة

### 2.1. بطاقات الملخص العلوي (KPI Cards) - 4 أعمدة
| البطاقة | القيمة | الأيقونة | لون الخلفية |
| :--- | :--- | :--- | :--- |
| **إجمالي الفحوصات (اليوم)** | عدد (مثل: 150) | 📋 | أزرق فاتح |
| **متوسط زمن الفحص (اليوم)** | عدد (مثل: 4.2 دقائق) | ⏱️ | بنفسجي فاتح |
| **نسبة الإحالات إلى العيادات** | نسبة (مثل: 12%) | 📊 | أصفر فاتح |
| **عدد حالات (أحمر) اليوم** | عدد (مثل: 3) | 🚨 | أحمر فاتح |

### 2.2. أدوات التصفية (Filters)
- **الفترة الزمنية**: (اليوم، الأسبوع، الشهر، مخصص).
- **نوع الإجراء**: (الكل، إفراج، إحالة، طوارئ).
- **زر**: "تطبيق التصفية".

### 2.3. الرسوم البيانية (Charts)
- **الفحوصات اليومية خلال الـ 7 أيام الماضية**: رسم بياني (Bar Chart) يوضح عدد الفحوصات اليومية.
- **توزيع التصنيفات (أخضر/أصفر/أحمر)**: رسم بياني دائري (Pie Chart) يوضح نسب التصنيفات خلال الفترة المحددة.
- **أوقات الذروة**: رسم بياني خطي يوضح عدد الفحوصات حسب الساعة خلال اليوم الحالي (لتحديد أوقات الذروة وتوزيع الكوادر).

### 2.4. قائمة الحالات الأخيرة (Recent Cases)
- **جدول بأحدث 20 حالة تم فحصها** (مع إمكانية التحميل للعرض).
- **الأعمدة**: (الاسم، رقم الجواز، التصنيف، تاريخ الفحص، الموظف المسؤول، الإجراء المتخذ).

### 2.5. أزرار التصدير (Export Buttons)
- **زر**: "تصدير تقرير اليوم بصيغة PDF" (تقرير منظم يحتوي على جميع المؤشرات والرسوم البيانية).
- **زر**: "تصدير تقرير الشهر بصيغة Excel" (للتحليل المتقدم).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للرسوم البيانية والجداول.
- **حالة عدم وجود بيانات**: عرض رسالة "لا توجد بيانات للفترة المحددة".
- **حالة تصدير التقرير**: ظهور رسالة "جاري تجهيز الملف..." مع شريط تقدم، ثم رسالة نجاح مع رابط التحميل.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/port-health/reports/kpi/` | الحصول على مؤشرات الأداء الرئيسية. |
| `GET /api/v1/port-health/reports/daily/` | الحصول على بيانات التقارير اليومية. |
| `GET /api/v1/port-health/reports/export/` | تصدير التقرير بصيغة (PDF/Excel). |
