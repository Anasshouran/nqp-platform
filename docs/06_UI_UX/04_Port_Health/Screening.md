# شاشة الفحص الظاهري (Health Screening)

## 1. الهدف
تمكين موظف الحجر الصحي من إدخال قراءات الفحص الظاهري (العلامات الحيوية والأعراض الظاهرة) للمسافر، وإطلاق عملية تقييم المخاطر تلقائياً.

## 2. مكونات الشاشة

### 2.1. معلومات المسافر (Traveler Info) - للرجوع السريع
- **بطاقة مصغرة** تعرض (الاسم، رقم الجواز، العمر) مع زر "تغيير المسافر" للعودة إلى شاشة المسح.

### 2.2. نموذج الفحص (Screening Form) - حقول إدخال كبيرة مناسبة للشاشات اللمسية
- **حقل درجة الحرارة (Body Temperature)**:
  - حقل رقمي (يسمح بعلامة عشرية واحدة).
  - **زر**: "قياس عبر البلوتوث" (🔵) - (للمستقبل).
  - **التحقق**: يجب أن تكون القيمة بين (30 و 45) درجة مئوية.
- **حقل تشبع الأكسجين (SpO2)**:
  - حقل رقمي (عدد صحيح بين 50 و 100).
  - **التحقق**: القيم أقل من 90% تعتبر حرجة وتعرض تحذيراً فورياً.
- **حقل الضغط الانقباضي (Systolic BP)**:
  - حقل رقمي.
- **حقل الضغط الانبساطي (Diastolic BP)**:
  - حقل رقمي.
- **حقل معدل ضربات القلب (Heart Rate)** - اختياري:
  - حقل رقمي.

### 2.3. الأعراض الظاهرة (Observed Symptoms)
- **قائمة اختيارات متعددة (Checkbox)**:
  - (سعال، ضيق تنفس، احتقان، صداع، طفح جلدي، إسهال، غثيان، قيء، آلام عضلية، احمرار العينين).
- **حقل نصي**: "أعراض أخرى" (لإدخال أي أعراض غير مدرجة).

### 2.4. ملاحظات إضافية (Officer Notes)
- حقل نصي لكتابة أي ملاحظات إضافية من قبل الموظف.

### 2.5. أزرار الإجراء (Action Buttons) - في أسفل النموذج
- **زر**: "تقييم المخاطر" (الزر الرئيسي) - يقوم بإرسال البيانات إلى محرك المخاطر وعرض النتيجة (ينتقل إلى صفحة `RiskAssessment.md`).
- **زر**: "حفظ المسودة" (للحفظ والإكمال لاحقاً، خاصة في وضع عدم الاتصال).
- **زر**: "إلغاء" (للعودة إلى لوحة التحكم).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحقق من الحقول**: إذا كانت الحقول الرقمية خارج النطاق، يظهر تحذير أحمر أسفل الحقل.
- **حالة التحذير الفوري**: إذا كانت الحرارة >= 39° أو SpO2 < 90%، يظهر تحذير منبثق (Modal) يطلب تأكيد القراءات.
- **حالة التحميل**: تعطيل جميع الأزرار وإظهار (Spinner) أثناء إرسال البيانات.
- **وضع عدم الاتصال**: حفظ البيانات محلياً وعرض رسالة "تم حفظ البيانات محلياً. سيتم رفعها عند عودة الاتصال."

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `POST /api/v1/port-health/screening/` | إرسال بيانات الفحص وتقييم المخاطر. |
| `GET /api/v1/port-health/screening/{id}/` | استرجاع بيانات فحص سابق (للتعديل). |
