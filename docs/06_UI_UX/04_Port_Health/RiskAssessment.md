# شاشة تقييم المخاطر (Risk Assessment - Display)

## 1. الهدف
عرض نتيجة تقييم المخاطر التي يقوم بها محرك المخاطر (Risk Engine) بناءً على بيانات الفحص المدخلة، مع توضيح عوامل القرار والتوصيات المناسبة، وتمكين الموظف من اتخاذ القرار النهائي.

## 2. مكونات الشاشة

### 2.1. بطاقة التصنيف النهائي (Final Classification Card)
- **بطاقة كبيرة وواضحة** ملونة حسب التصنيف:
  - **🟢 أخضر**: أيقونة (✔) + نص "منخفض الخطورة - إفراج فوري".
  - **🟡 أصفر**: أيقونة (⚠️) + نص "متوسط الخطورة - إحالة للعيادة".
  - **🔴 أحمر**: أيقونة (🚨) + نص "عالي الخطورة - عزل فوري وإشعار الطوارئ".
- **مع تأثيرات بصرية**: (خلفية ملونة، ظل، تغيير حجم الأيقونة).

### 2.2. تفاصيل التقييم (Assessment Details)
- **درجة المخاطر (Risk Score)**: رقم من 0 إلى 100 مع شريط تقدم (Progress Bar) ملون.
- **عوامل القرار (Decision Factors)**: عرض القائمة التي ساهمت في حساب الدرجة (مثل: بلد القدوم، الحرارة، SpO2، الأعراض، التطعيم، الأمراض المزمنة).
- **التوصية (Recommendation)**: نص يشرح الخطوة التالية الموصى بها (مثل: "يوصى بإجراء فحص سريري إضافي في العيادة للتأكد من عدم وجود التهاب تنفسي حاد.").

### 2.3. أزرار الإجراء (Action Buttons)
| الزر | الحالة التي يظهر فيها | الوصف |
| :--- | :--- | :--- |
| **إفراج** | أخضر | طباعة تصريح دخول صحي (مع تحديث حالة المسافر إلى "مفرج"). |
| **إحالة إلى العيادة** | أصفر/أحمر | إرسال بيانات المسافر إلكترونياً إلى بوابة العيادات (5) مع تقرير الفحص الأولي. |
| **إشعار الطوارئ** | أحمر | إرسال إنذار فوري (WebSocket) إلى غرفة الطوارئ (9) مع إحداثيات الموقع. |
| **إعادة التقييم** | جميع الحالات | العودة إلى نموذج الفحص لتعديل البيانات وإعادة حساب التقييم. |

### 2.4. زر "طباعة التقرير" (Print Report)
- زر لطباعة تقرير الفحص النهائي (PDF) يحتوي على: (بيانات المسافر، القراءات، التقييم، التوصية، القرار المتخذ).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التقييم التلقائي**: عرض (Spinner) أثناء انتظار نتيجة محرك المخاطر.
- **حالة الخطأ في التقييم**: ظهور رسالة "حدث خطأ في تقييم المخاطر. يرجى المحاولة مرة أخرى." مع زر "إعادة التقييم".
- **حالة القرار**: بعد الضغط على أي زر إجراء، ظهور رسالة نجاح أو خطأ.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `POST /api/v1/port-health/screening/` | (نفس النقطة لإرسال البيانات واستلام التقييم). |
| `POST /api/v1/port-health/screening/{id}/refer/` | إحالة إلى العيادة. |
| `POST /api/v1/port-health/screening/{id}/release/` | إفراج المسافر. |
| `POST /api/v1/port-health/screening/{id}/emergency/` | إشعار الطوارئ (غرفة العمليات). |
