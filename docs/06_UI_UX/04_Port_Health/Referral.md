# شاشة الإحالة إلى العيادة (Referral to Clinic)

## 1. الهدف
تمكين موظف الحجر الصحي من تأكيد إحالة الحالات (المصنفة أصفر أو أحمر) إلى عيادة الحجر الصحي (البوابة 5) بشكل إلكتروني وفوري.

## 2. مكونات الشاشة

### 2.1. نافذة تأكيد الإحالة (Confirmation Dialog)
- **بطاقة ملخص الحالة**:
  - اسم المسافر، رقم الجواز، التصنيف (أصفر/أحمر).
  - ملخص الفحص (العلامات الحيوية، الأعراض).
- **حقل إلزامي**: "سبب الإحالة" (نص، مثل: "اشتباه بالتهاب رئوي فيروسي").
- **زر**: "تأكيد الإحالة" (باللون الأصفر أو الأحمر حسب التصنيف).
- **زر**: "إلغاء" (للعودة إلى صفحة التقييم).

### 2.2. حالة الإحالة (Referral Status) - بعد التأكيد
- **رسالة نجاح**: "تم إحالة المسافر إلى العيادة بنجاح. رقم الإحالة: #REF-12345".
- **زر**: "طباعة ورقة الإحالة" (تحتوي على: اسم المسافر، رقم الجواز، التصنيف، سبب الإحالة) لتسليمها للمسافر.
- **زر**: "العودة إلى لوحة التحكم".

### 2.3. تتبع الإحالة (Referral Tracking) - اختياري
- يمكن للموظف العودة إلى هذه الصفحة لاحقاً لمعرفة حالة الإحالة (في انتظار الكشف، تحت الفحص، تم الإفراج).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: تعطيل الأزرار وإظهار (Spinner) أثناء إرسال الإحالة.
- **حالة الخطأ**: ظهور رسالة خطأ إذا فشلت عملية الإحالة (مثل: "فشل الإرسال، يرجى المحاولة مرة أخرى").
- **حالة نجاح الإرسال**: كما هو موضح أعلاه.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `POST /api/v1/port-health/screening/{id}/refer/` | إنشاء إحالة جديدة وإرسالها إلى العيادة. |
| `GET /api/v1/port-health/referrals/{id}/status/` | الاستعلام عن حالة الإحالة. |
