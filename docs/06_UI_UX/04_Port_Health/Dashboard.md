# لوحة التحكم الرئيسية لموظفي الحجر الصحي (Port Health Dashboard)

## 1. الهدف
تزويد موظف الحجر الصحي بنظرة لحظية شاملة على الرحلات القادمة إلى منفذه، والمسافرين المنتظرين، والتنبيهات الفورية، بالإضافة إلى توفير وصول سريع إلى أهم المهام (مسح QR، بدء الفحص، إدارة الإحالات).

## 2. تخطيط الصفحة (Layout)

### 2.1. الشريط العلوي (Header)
- **شعار المنصة** (جهة اليمين).
- **اسم المنفذ** و **اسم الموظف** مع قائمة منسدلة لتسجيل الخروج.
- **حالة الاتصال**: أيقونة (🟢 متصل / 🔴 غير متصل) مع عدد الطلبات المعلقة في وضع عدم الاتصال.
- **زر**: "التبديل بين اللغات" (عربي/إنجليزي) - مع أيقونة علم.

### 2.2. بطاقات الملخص العلوي (KPI Cards) - 4 أعمدة
| البطاقة | القيمة | الأيقونة | لون الخلفية |
| :--- | :--- | :--- | :--- |
| **الرحلات القادمة اليوم** | عدد (مثل: 8) | ✈️ | أزرق فاتح |
| **المسافرون المنتظرون** | عدد (مثل: 320) | 🧑‍🤝‍🧑 | بنفسجي فاتح |
| **حالات (أصفر) اليوم** | عدد (مثل: 12) | ⚠️ | أصفر فاتح |
| **حالات (أحمر) اليوم** | عدد (مثل: 3) | 🚨 | أحمر فاتح (يومض إذا كان >0) |

### 2.3. قائمة الرحلات القادمة (Upcoming Flights) - أولوية عالية
- **العنوان**: "الرحلات القادمة خلال الـ 6 ساعات القادمة".
- **الأعمدة**: (رقم الرحلة، شركة الطيران، بلد المغادرة، وقت الوصول، عدد الركاب، نسبة التسجيل المسبق، حالة الرحلة).
- **زر**: "عرض جميع الرحلات" (ينتقل إلى صفحة `FlightManagement.md`).
- **زر**: "تحديث القائمة" (لجلب آخر البيانات).

### 2.4. قائمة انتظار المسافرين (Passenger Queue)
- **العنوان**: "المسافرون بانتظار الفحص".
- **عرض المسافرين الذين تم مسح QR الخاص بهم أو تسجيل وصولهم، ولم يتم إجراء الفحص لهم بعد**.
- **الأعمدة**: (الاسم، رقم الجواز، وقت المسح، حالة التسجيل المسبق).
- **زر**: "بدء الفحص" (📋) - ينتقل مباشرة إلى نموذج الفحص مع تحميل بيانات المسافر.

### 2.5. التنبيهات الفورية (Real-time Alerts) - شريط جانبي أو أسفل الشاشة
- **عرض آخر 5 تنبيهات** (مثل: وصول رحلة جديدة، اكتشاف حالة حمراء في بوابة أخرى).
- **التنبيهات الحرجة**: تظهر بلون أحمر مع أيقونة 🚨.
- **زر**: "عرض الكل" (ينتقل إلى سجل التنبيهات).

### 2.6. اختصار وضع عدم الاتصال (Offline Mode Indicator)
- **بطاقة صغيرة** في أسفل الصفحة (أو أعلى) تعرض:
  - "أنت تعمل في وضع عدم الاتصال. سيتم مزامنة البيانات عند عودة الاتصال."
  - عدد الفحوصات المعلقة (غير المرسلة).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للبطاقات والجداول.
- **حالة عدم وجود رحلات**: عرض رسالة "لا توجد رحلات قادمة حالياً" مع زر "تحديث".
- **حالة عدم وجود مسافرين في قائمة الانتظار**: عرض رسالة "لا يوجد مسافرون بانتظار الفحص".
- **حالة التنبيه العاجل**: ظهور نافذة منبثقة (Modal) مع تفاصيل التنبيه وزر "اتخاذ إجراء".

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/port-health/dashboard/stats/` | جلب إحصائيات البطاقات العلوية. |
| `GET /api/v1/port-health/flights/upcoming/` | جلب قائمة الرحلات القادمة. |
| `GET /api/v1/port-health/queue/` | جلب قائمة انتظار المسافرين. |
| `GET /api/v1/port-health/alerts/` | جلب التنبيهات الفورية (WebSocket للتحديث اللحظي). |
