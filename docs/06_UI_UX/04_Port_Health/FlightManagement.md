# شاشة إدارة الرحلات (Flight Management - عرض فقط)

## 1. الهدف
تمكين موظف الحجر الصحي من عرض جميع الرحلات القادمة إلى منفذه، والاطلاع على تفاصيلها وقوائم ركابها، وتحديث حالة الرحلة يدوياً إذا لزم الأمر.

## 2. مكونات الشاشة

### 2.1. شريط الأدوات (Toolbar)
- **حقل البحث**: للبحث عن رحلة برقم الرحلة أو المسار.
- **قوائم التصفية**:
  - (الحالة: الكل، قادمة، وصلت، ملغاة).
  - (الفترة الزمنية: اليوم، هذا الأسبوع، هذا الشهر).
- **زر**: "تحديث البيانات" (لجلب آخر التحديثات).

### 2.2. جدول الرحلات (Flights Table)
- **الأعمدة**:
  - رقم الرحلة.
  - شركة الطيران.
  - المسار (من - إلى).
  - وقت الوصول المتوقع.
  - عدد الركاب.
  - نسبة التسجيل المسبق.
  - حالة الرحلة (🔵 مجدولة / 🟢 وصلت / ⚫ ملغاة).
  - حالة قائمة الركاب (🟢 مرفوعة / 🔴 غير مرفوعة / 🟡 قيد المعالجة).
- **الإجراءات**:
  - **زر**: "عرض التفاصيل" (👁️) - يفتح نافذة جانبية بتفاصيل الرحلة وقائمة الركاب.
  - **زر**: "تحديث الحالة" (📝) - لتغيير حالة الرحلة إلى (وصلت / ملغاة) يدوياً (إذا لزم الأمر).

### 2.3. نافذة تفاصيل الرحلة (Side Panel)
- **عرض معلومات الرحلة كاملة** (المسار، التواريخ، إلخ).
- **قائمة الركاب**: جدول يحتوي على (الاسم، رقم الجواز، الجنسية، رقم المقعد، حالة التسجيل المسبق، حالة الفحص).
- **إحصائيات الرحلة**: (إجمالي الركاب، عدد المسجلين مسبقاً، عدد غير المسجلين، عدد المفحوصين).
- **زر**: "تنزيل قائمة الركاب (CSV)".

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Spinner) في الجدول أثناء جلب البيانات.
- **حالة نجاح تحديث الحالة**: ظهور رسالة (Toast) خضراء "تم تحديث حالة الرحلة بنجاح".

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/port-health/flights/` | قائمة الرحلات (مع التصفية والبحث). |
| `GET /api/v1/port-health/flights/{id}/` | تفاصيل رحلة محددة. |
| `PATCH /api/v1/port-health/flights/{id}/status/` | تحديث حالة الرحلة (يدوياً). |
