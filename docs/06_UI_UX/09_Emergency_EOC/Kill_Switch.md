# شاشة مفتاح الإيقاف الطارئ (Kill Switch)

## 1. الهدف
توفير آلية أمنية وقائية لـ **تعليق جميع عمليات الإفراج الصحي في منفذ معين فوراً**، في حالات الطوارئ القصوى (مثل: اكتشاف تفشي سريع لمرض خطير). هذه الآلية تُمكّن غرفة العمليات من "تجميد" المنفذ حتى يتم السيطرة على الموقف.

## 2. مكونات الشاشة

### 2.1. زر التفعيل (Activation Button) - العنصر الأبرز
- **زر دائري كبير جداً باللون الأحمر** (يظهر فقط للمستخدمين الذين لديهم صلاحية `CAN_ACTIVATE_KILL_SWITCH`).
- **النص**: "🔴 KILL SWITCH - إيقاف المنفذ".
- **التحذير**: عند تحريك المؤشر فوق الزر، يظهر نص تحذيري: "⚠️ هذا الإجراء لا رجعة فيه! سيتم تعليق جميع عمليات الإفراج في المنفذ المحدد."

### 2.2. نافذة التأكيد (Confirmation Dialog) - تظهر عند الضغط على الزر
- **اختيار المنفذ**: (قائمة منسدلة بجميع المنافذ النشطة).
- **سبب التفعيل (Reason)**: (حقل نصي إلزامي، مثل: "تفشي فيروس إيبولا في مطار الخرطوم").
- **تأكيد الهوية**:
  - **كلمة مرور مدير الطوارئ**: (حقل آمن).
  - **كلمة مرور مسؤول الأمن**: (حقل آمن) - للتحقق المزدوج (Dual Authorization).
- **زر**: "⚠️ تأكيد التفعيل" (أحمر غامق).
- **زر**: "إلغاء" (للعودة).

### 2.3. حالة Kill Switch (After Activation)
- **تغيير حالة المنفذ**: يتغير لون المنفذ على الخريطة إلى (⚫ أسود) وتظهر علامة (🔒) بجانب اسمه.
- **شريط تحذيري في أعلى الصفحة**: "🚨 تم تفعيل Kill Switch في [اسم المنفذ]. جميع العمليات معلقة حتى إشعار آخر."
- **زر**: "إلغاء Kill Switch" (يظهر بدلاً من زر التفعيل).

### 2.4. نافذة إلغاء التفعيل (Deactivation Dialog)
- **سبب الإلغاء**: (حقل نصي إلزامي).
- **تأكيد الهوية**: (كلمتا مرور).
- **زر**: "✅ تأكيد الإلغاء" (أخضر).
- **زر**: "إلغاء".

## 3. حالات واجهة المستخدم (UI States)
- **حالة Kill Switch مفعل**: تغيير لون الخلفية العلوي إلى أحمر غامق مع رسالة تحذيرية.
- **حالة فشل المصادقة**: رسالة خطأ حمراء "كلمة المرور غير صحيحة، يرجى المحاولة مرة أخرى".
- **حالة نجاح التفعيل**: رسالة حمراء "تم تفعيل Kill Switch بنجاح. تم إشعار جميع الموظفين والجهات المعنية."

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `POST /api/v1/eoc/kill-switch/activate/` | تفعيل Kill Switch لمنفذ معين. |
| `POST /api/v1/eoc/kill-switch/deactivate/` | إلغاء Kill Switch. |
| `GET /api/v1/eoc/kill-switch/status/` | استرجاع حالة Kill Switch لجميع المنافذ. |
