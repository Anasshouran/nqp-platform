# شاشة الإشعار الجماعي (Mass Alert System)

## 1. الهدف
تمكين غرفة العمليات من إرسال **رسائل تحذيرية أو إرشادية جماعية (SMS و Push Notifications)** لجميع المسافرين أو الموظفين في منفذ معين، أو لجميع المسافرين الذين دخلوا السودان خلال فترة زمنية محددة، في حالات الطوارئ.

## 2. مكونات الشاشة

### 2.1. نموذج الإشعار الجماعي (Mass Alert Form)
- **الجمهور المستهدف (Audience)**:
  - **منفذ معين**: (قائمة منسدلة من المنافذ).
  - **جميع المسافرين خلال الفترة**: (منتقي تاريخ: من - إلى).
  - **رحلة معينة**: (قائمة منسدلة من الرحلات - اختياري).
- **نوع الإشعار (Alert Type)**:
  - (🔴 تحذير عاجل - خلفية حمراء).
  - (🟡 تنبيه مهم - خلفية صفراء).
  - (🔵 إشعار معلوماتي - خلفية زرقاء).
- **عنوان الإشعار (Subject)**: (نص، مثل: "تنبيه عاجل: تم اكتشاف حالة إيجابية على رحلة KRT123").
- **محتوى الإشعار (Message)**: (حقل نصي طويل، يدعم الروابط).
- **قنوات الإرسال**:
  - (📱 رسائل جوال (SMS)) - (خانة اختيار).
  - (📲 Push Notifications) - (خانة اختيار).
  - (📧 البريد الإلكتروني) - (خانة اختيار، للإشعارات الأقل إلحاحاً).
- **زر**: "🚨 إرسال الإشعار" (باللون الأحمر، مع نافذة تأكيدية).

### 2.2. جدول الإشعارات المرسلة (Sent Alerts)
- **عرض جميع الإشعارات الجماعية التي تم إرسالها سابقاً**:
  - الأعمدة: (التاريخ، الموضوع، الجمهور المستهدف، عدد المستلمين، حالة الإرسال (مرسل، قيد الإرسال، فشل)).
- **الإجراءات**:
  - **زر**: "عرض التفاصيل" (لعرض محتوى الإشعار وإحصائيات الإرسال).

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح الإرسال**: رسالة خضراء "تم إرسال الإشعار بنجاح إلى [عدد] مستلم".
- **حالة فشل الإرسال**: رسالة حمراء مع سبب الفشل (مثل: "فشل الاتصال بمزود SMS").
- **حالة التحميل**: تعطيل زر "إرسال" وإظهار (Spinner).

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `POST /api/v1/eoc/mass-alert/send/` | إرسال إشعار جماعي. |
| `GET /api/v1/eoc/mass-alert/history/` | قائمة الإشعارات المرسلة. |
