# شاشة تتبع المخالطين (Contact Tracing)

## 1. الهدف
تمكين غرفة العمليات من **تحديد وتتبع المخالطين** لحالة إيجابية (خاصة في وسائل النقل العامة مثل الطائرات)، للوصول إليهم وعزلهم وفحصهم في أسرع وقت ممكن لمنع انتشار العدوى.

## 2. مكونات الشاشة

### 2.1. شريط البحث (Search Bar)
- **حقل بحث**: للبحث عن حالة إيجابية (اسم المريض، رقم الجواز، رقم الحالة).
- **زر**: "🔍 بحث".

### 2.2. معلومات المريض (Patient Info) - تظهر بعد البحث
- **بطاقة المريض** تحتوي على:
  - الاسم الكامل، رقم الجواز، تاريخ التشخيص، المرض.
  - **زر**: "🔄 استدعاء المخالطين".

### 2.3. رحلة المريض (Patient's Flight/Vehicle)
- **عرض رحلة المريض الأخيرة**:
  - رقم الرحلة، شركة الطيران، التاريخ، رقم المقعد.
- **زر**: "📋 عرض قائمة الركاب" (عرض جميع ركاب الرحلة).

### 2.4. قائمة المخالطين (Contacts List)
- **عرض جدول بالمسافرين الذين كانوا على نفس الرحلة وفي المقاعد القريبة** (صفين أمام وخلف المريض):
  - الأعمدة: (الاسم، رقم الجواز، رقم المقعد، رقم الهاتف (إن وجد)، حالة الاتصال (جديد، تم الاتصال، تم العزل، مكتمل)).
- **الإجراءات**:
  - **زر**: "📱 إرسال إشعار" (إرسال رسالة SMS فورية للمخالط).
  - **زر**: "📝 تحديث حالة الاتصال" (لتسجيل ما إذا تم الاتصال بالمخالط بنجاح).

### 2.5. سجل التتبع (Tracing History)
- **عرض سجل لجميع عمليات تتبع المخالطين السابقة** (للمراجعة والتدقيق).

## 3. حالات واجهة المستخدم (UI States)
- **حالة البحث**: عرض (Spinner) أثناء جلب البيانات.
- **حالة عدم وجود مخالطين**: عرض رسالة "لم يتم العثور على مخالطين لهذه الحالة" مع أيقونة ✅.
- **حالة نجاح الإشعار**: رسالة خضراء "تم إرسال الإشعار إلى المخالط بنجاح".

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/eoc/tracing/search/?q={term}` | البحث عن حالة إيجابية. |
| `GET /api/v1/eoc/tracing/{case_id}/contacts/` | استرجاع قائمة المخالطين. |
| `POST /api/v1/eoc/tracing/{contact_id}/notify/` | إرسال إشعار للمخالط. |
| `PATCH /api/v1/eoc/tracing/{contact_id}/status/` | تحديث حالة الاتصال. |
