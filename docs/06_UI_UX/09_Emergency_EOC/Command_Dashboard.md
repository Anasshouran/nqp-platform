# شاشة الإنذار الفوري (Command Dashboard - إنذارات حمراء)

## 1. الهدف
توفير واجهة مخصصة لعرض وإدارة جميع **الإنذارات الحمراء** (Red Alerts) الصادرة عن النظام. تتيح هذه الشاشة لفريق الطوارئ متابعة كل إنذار بالتفصيل، وتحديث حالته، واتخاذ الإجراءات المناسبة (توجيه فريق، تفعيل Kill Switch).

## 2. مكونات الشاشة

### 2.1. شريط الأدوات (Toolbar)
- **قوائم التصفية**:
  - (الحالة: الكل، جديد، قيد المعالجة، مغلق).
  - (المنفذ: الكل، مطار الخرطوم، ميناء بورتسودان، إلخ).
  - (المرض: الكل - يتم جلب القائمة من `Disease_Management`).
- **زر**: "تحديث" (لجلب الإنذارات الجديدة يدوياً).
- **زر**: "تصدير التقرير" (لتصدير قائمة الإنذارات بصيغة PDF).

### 2.2. جدول الإنذارات (Alerts Table)
- **الأعمدة**:
  - **الأولوية**: (🔴 عاجل، 🟡 مهم، 🔵 عادي).
  - **المنفذ**: (اسم المنفذ).
  - **المريض**: (الاسم، مع رابط لفتح ملفه).
  - **المرض المشتبه به**: (اسم المرض).
  - **التاريخ والوقت**: (وقت الإبلاغ).
  - **الحالة**: (🟥 جديد، 🟧 قيد المعالجة، 🟩 مغلق).
  - **الوقت المنقضي**: (مثل: "منذ 5 دقائق").
- **الإجراءات**:
  - **زر**: "📋 عرض التفاصيل" (يفتح نافذة جانبية).
  - **زر**: "🚑 توجيه فريق" (ينتقل إلى نموذج توجيه الفريق).
  - **زر**: "🔴 Kill Switch" (يظهر فقط للمديرين).

### 2.3. نافذة تفاصيل الإنذار (Alert Detail Side Panel)
- **معلومات المريض**: (الاسم الكامل، رقم الجواز، العمر، الجنس، معلومات الاتصال).
- **معلومات الإنذار**: (المنفذ، المرض المشتبه به، تاريخ ووقت الإبلاغ، المصدر (بوابة الفحص، العيادة، المختبر)).
- **سجل الإجراءات**: (عرض جميع الإجراءات المتخذة لهذا الإنذار):
  - (مثل: "14:30 - تم استلام الإنذار").
  - (مثل: "14:35 - تم توجيه فريق RRT-01").
  - (مثل: "14:50 - تم تحديث الحالة إلى 'قيد المعالجة'").
- **أزرار الإجراءات**:
  - **زر**: "🚑 توجيه فريق RRT".
  - **زر**: "📝 تحديث الحالة" (لتغيير الحالة إلى قيد المعالجة/مغلق).
  - **زر**: "🔴 Kill Switch" (للمديرين فقط).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للجدول.
- **حالة الإنذار الجديد**: تمييز الصف بخلفية حمراء فاتحة وعلامة (🆕).
- **حالة عدم وجود إنذارات**: عرض رسالة "🎉 لا توجد إنذارات حمراء حالياً. كل المنافذ آمنة."

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/eoc/alerts/` | قائمة الإنذارات (مع التصفية والترقيم). |
| `GET /api/v1/eoc/alerts/{id}/` | تفاصيل إنذار محدد. |
| `PATCH /api/v1/eoc/alerts/{id}/status/` | تحديث حالة الإنذار. |
