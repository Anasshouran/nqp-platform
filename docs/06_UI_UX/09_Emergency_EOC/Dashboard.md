# لوحة التحكم الرئيسية لغرفة الطوارئ (EOC Dashboard)

## 1. الهدف
تزويد فريق غرفة العمليات (EOC) بلوحة تحكم مركزية تعرض **جميع الإنذارات النشطة**، **حالة المنافذ**، **الفرق الميدانية**، و **المؤشرات الحيوية** في الوقت الفعلي، لتكون نقطة الانطلاق لأي تدخل طارئ. تم تصميم هذه اللوحة لتكون **عالية السرعة**، **بديهية**، و **قابلة للتخصيص** حسب دور المستخدم.

## 2. تخطيط الصفحة (Layout) - Full-Screen Dashboard

### 2.1. الشريط العلوي (Top Bar) - ثابت
- **شعار المنصة** (جهة اليمين) مع اسم "غرفة العمليات - الطوارئ".
- **الساعة والتاريخ** (في المنتصف) - بتنسيق واضح (مثل: 14:30 - 25 يوليو 2024).
- **إحصائيات سريعة (Quick Stats)**:
  - 🔴 **الإنذارات الحمراء المعلقة**: عدد (مثل: 3) - يظهر باللون الأحمر الغامق.
  - 🟡 **المنافذ تحت المراقبة**: عدد (مثل: 2).
  - 👥 **فرق RRT النشطة**: عدد (مثل: 4).
- **زر**: "تقرير الطوارئ الفوري" (📄) - لتصدير تقرير سريع بصيغة PDF.
- **زر**: "تحديث البيانات" (🔄) - لجلب آخر البيانات يدوياً.

### 2.2. المنطقة الرئيسية (Main Area) - شبكة مرنة (Grid)

#### الصف الأول: الإنذارات الحمراء النشطة (Active Red Alerts) - الأولوية القصوى
- **عرض قائمة أفقية (Carousel/Horizontal Scroll)** بجميع الإنذارات الحمراء النشطة:
  - **كل إنذار يعرض كبطاقة (Card)** حمراء اللون تحتوي على:
    - (⏰ الوقت المنقضي منذ الإبلاغ) - (مثل: "منذ 5 دقائق").
    - (📍 المنفذ) - (مثل: "مطار الخرطوم").
    - (🧑 اسم المريض) - (مثل: "محمد أحمد").
    - (🦠 المرض المشتبه به) - (مثل: "كوفيد-19").
    - **أزرار الإجراءات السريعة**:
      - **زر**: "📋 عرض التفاصيل" (يفتح نافذة جانبية بتفاصيل الحالة).
      - **زر**: "🚑 توجيه فريق RRT" (ينتقل إلى نموذج توجيه الفريق).
      - **زر**: "🔴 Kill Switch" (للإيقاف الفوري للمنفذ - يظهر فقط للمديرين).

#### الصف الثاني: خريطة المخاطر التفاعلية (Interactive Map) + إحصائيات جانبية
- **الجهة اليمنى (70%)**: خريطة السودان (أو خريطة المنافذ) مع نقاط ملونة:
  - 🟢 **أخضر**: منفذ آمن.
  - 🟡 **أصفر**: منفذ تحت المراقبة.
  - 🔴 **أحمر**: منفذ في حالة طوارئ (يومض).
  - ⚫ **أسود**: منفذ متوقف (Kill Switch مفعل).
- **الجهة اليسرى (30%) - لوحة جانبية**:
  - **عدد المنافذ حسب الحالة**: (🟢 12، 🟡 3، 🔴 2، ⚫ 1).
  - **أكثر 3 أمراض انتشاراً اليوم**.
  - **آخر تحديث للخريطة**: (مثل: "منذ 10 ثوانٍ").

#### الصف الثالث: الفرق الميدانية النشطة (Active Field Teams)
- **عرض قائمة بالفرق التي تم توجيهها ولم تنته مهامها بعد**:
  - (اسم الفريق، الوجهة، وقت التوجيه، الحالة (في الطريق / في الموقع / منتهية)).
  - **زر**: "عرض تتبع الفريق" (🗺️) - لفتح موقع الفريق على الخريطة (مستقبلي).

### 2.3. شريط الأحداث الجانبي (Event Feed) - ثابت على الجهة اليمنى (اختياري)
- **شريط عمودي** يعرض آخر الأحداث (الإنذارات، التحديثات، القرارات) بشكل متسلسل زمنياً:
  - (مثل: "14:30 - إنذار أحمر من مطار الخرطوم").
  - (مثل: "14:35 - تم توجيه فريق RRT-01 إلى مطار الخرطوم").

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للبطاقات والخريطة.
- **حالة الإنذار الجديد**: ظهور (Toast) أحمر كبير مع صوت تنبيه (Siren) وتوميض الخريطة.
- **حالة Kill Switch**: تغيير لون المنفذ على الخريطة إلى (أسود) مع عرض شريط تحذيري في الأعلى.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/eoc/dashboard/stats/` | جلب الإحصائيات السريعة. |
| `GET /api/v1/eoc/alerts/active/` | قائمة الإنذارات النشطة. |
| `GET /api/v1/eoc/ports/status/` | حالة جميع المنافذ (للخريطة). |
| `GET /api/v1/eoc/teams/active/` | قائمة الفرق الميدانية النشطة. |
| `WS /ws/eoc/` | اتصال WebSocket لتلقي التحديثات اللحظية. |
