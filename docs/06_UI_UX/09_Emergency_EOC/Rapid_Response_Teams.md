# شاشة فرق الاستجابة السريعة (Rapid Response Teams - RRT)

## 1. الهدف
تمكين مسؤول غرفة العمليات من **توجيه فرق الاستجابة السريعة (RRT)** إلى مواقع الطوارئ فوراً، وتتبع حالة المهام الميدانية، وضمان الاستجابة السريعة والفعالة للحالات الحرجة.

## 2. مكونات الشاشة

### 2.1. تبويبات التنقل (Tabs)
- **الفرق المتاحة** (✅): لعرض الفرق الجاهزة للتوجيه.
- **المهام النشطة** (⏳): لعرض المهام التي لم تنته بعد.
- **سجل المهام** (📋): لعرض المهام المكتملة (للتدقيق).

### 2.2. التبويب الأول: الفرق المتاحة (Available Teams)
- **عرض بطاقات (Cards)** لكل فريق:
  - **اسم الفريق** و **التخصص** (طوارئ، أمراض معدية، دعم نفسي).
  - **عدد الأعضاء** و **الموقع الحالي**.
  - **الحالة**: (🟢 جاهز / 🟡 في استراحة / 🔴 في مهمة).
- **زر**: "🚑 توجيه الفريق" (يفتح نموذج التوجيه).

### 2.3. نموذج توجيه فريق (Dispatch Form) - نافذة منبثقة (Modal)
- **اختيار الفريق**: (قائمة منسدلة - تم ملؤها مسبقاً من البطاقة المختارة).
- **الوجهة**:
  - **اختيار منفذ**: (قائمة منسدلة من المنافذ).
  - **أو إدخال عنوان/إحداثيات يدوياً**: (حقل نصي مع خريطة صغيرة - اختياري).
- **وصف المهمة**: (حقل نصي، مثل: "حالة اشتباه بحمى نزفية في مطار الخرطوم").
- **الأولوية**: (عادي، عاجل، فوري).
- **المعدات المطلوبة**: (قائمة متعددة الاختيارات: معدات عزل، أدوية، أجهزة فحص).
- **زر**: "🚑 إرسال الفريق" (يرسل إشعار فوري لأعضاء الفريق).

### 2.4. التبويب الثاني: المهام النشطة (Active Missions)
- **جدول المهام التي لم تنته بعد**:
  - الأعمدة: (الفريق، الوجهة، وقت الإرسال، الحالة (في الطريق، في الموقع، منتهية)، آخر تحديث).
- **الإجراءات**:
  - **زر**: "🗺️ عرض التتبع" (لفتح موقع الفريق على الخريطة - مستقبلي).
  - **زر**: "📝 تحديث الحالة" (لتغيير الحالة يدوياً).

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح التوجيه**: رسالة خضراء "تم توجيه الفريق بنجاح، تم إرسال الإشعارات لأعضاء الفريق".
- **حالة عدم وجود فرق متاحة**: عرض رسالة "لا توجد فرق متاحة حالياً" مع زر "تحديث".
- **حالة تحديث المهمة**: نافذة منبثقة لتغيير الحالة مع حقل ملاحظات.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/eoc/teams/available/` | قائمة الفرق المتاحة. |
| `POST /api/v1/eoc/teams/{id}/dispatch/` | توجيه فريق لمهمة جديدة. |
| `GET /api/v1/eoc/missions/active/` | قائمة المهام النشطة. |
| `PATCH /api/v1/eoc/missions/{id}/status/` | تحديث حالة المهمة. |
