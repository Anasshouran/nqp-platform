# شاشة المخزون الاستراتيجي (Strategic Stockpile Management)

## 1. الهدف
تمكين غرفة العمليات من **إدارة وتوزيع المخزون الاستراتيجي** من الأدوية والمستلزمات الطبية (معدات الوقاية الشخصية، أجهزة التنفس، الكواشف) على المنافذ المتضررة أو المهددة، لضمان استمرارية العمليات الصحية في حالات الطوارئ.

## 2. مكونات الشاشة

### 2.1. بطاقات الملخص العلوي (Stock Overview Cards)
| البطاقة | القيمة | الأيقونة | لون الخلفية |
| :--- | :--- | :--- | :--- |
| **إجمالي المواد** | عدد (مثل: 45) | 📦 | أزرق فاتح |
| **مواد منخفضة (تحتاج توريد)** | عدد (مثل: 8) | ⚠️ | برتقالي فاتح |
| **مواد حرجة (نفدت)** | عدد (مثل: 3) | 🚨 | أحمر فاتح |
| **طلبات التوريد النشطة** | عدد (مثل: 5) | 📤 | بنفسجي فاتح |

### 2.2. شريط الأدوات (Toolbar)
- **قائمة منسدلة للتصفية**: (المنفذ: الكل، مطار الخرطوم، ميناء بورتسودان، إلخ).
- **زر**: "تحديث المخزون" (لجلب آخر البيانات يدوياً).
- **زر**: "طلب توريد جديد" (📦) - لفتح نموذج طلب توريد.

### 2.3. جدول المخزون (Stock Table)
- **الأعمدة**:
  - المادة (اسم المادة).
  - الكمية المتاحة.
  - الحد الأدنى للإنذار.
  - المنفذ/المستودع.
  - حالة المخزون (🟢 جيد، 🟡 منخفض، 🔴 حرج).
- **الإجراءات**:
  - **زر**: "طلب توريد" (📤) - لطلب توريد لهذه المادة فقط.

### 2.4. نموذج طلب توريد (Supply Request Form) - نافذة منبثقة (Modal)
- **اختيار المنفذ المستهدف**: (قائمة منسدلة).
- **اختيار المواد المطلوبة**: (قائمة متعددة الاختيارات مع الكميات).
- **سبب الطلب**: (حقل نصي، مثل: "ارتفاع عدد الحالات الإيجابية في المنفذ").
- **الأولوية**: (عادي، عاجل، فوري).
- **زر**: "🚚 إرسال الطلب".

### 2.5. جدول طلبات التوريد (Supply Requests Table)
- **عرض جميع طلبات التوريد السابقة والحالية**:
  - الأعمدة: (رقم الطلب، المنفذ، المواد المطلوبة، التاريخ، الحالة (معلق، قيد التجهيز، تم التوصيل)).
- **الإجراءات**:
  - **زر**: "عرض التفاصيل" (لفتح تفاصيل الطلب).

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح الطلب**: رسالة خضراء "تم إرسال طلب التوريد بنجاح".
- **حالة المخزون الحرجة**: تمييز الصف بخلفية حمراء فاتحة مع أيقونة (🚨).

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/eoc/stockpile/` | عرض مستويات المخزون الحالية. |
| `POST /api/v1/eoc/stockpile/requests/` | إنشاء طلب توريد جديد. |
| `GET /api/v1/eoc/stockpile/requests/` | قائمة طلبات التوريد. |
| `PUT /api/v1/eoc/stockpile/thresholds/` | تحديث الحدود الدنيا للمخزون (للمشرفين). |
