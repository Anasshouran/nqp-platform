# Inspection — التفتيش الميداني (رقابة الأغذية)

> **الإصدار:** v2 — موثّق مطابقًا للتنفيذ الفعلي (لوحة المفتش الحقيقية)
> **آخر تحديث:** 2026-08-23

---

## 1. نظرة عامة

وحدة التفتيش الميداني مسؤولة عن الفحص الفعلي للشحنات الغذائية بعد سداد الرسوم، وتوثيق نتائج الفحص في استمارة تفتيش رسمية، وسحب العينات وإرسالها للمختبر عند الحاجة.

| البند | القيمة |
|---|---|
| **المسار** | `/inspector-dashboard` |
| **الدور** | `FOOD_INSPECTOR` |
| **التخطيط** | `GenericRoleLayout` (لون الهوية: برتقالي `#fd7e14`) |
| **الملف** | `frontend/src/pages/inspector/InspectorDashboardPage.tsx` |
| **الـ API** | `/api/v1/food/shipments/`, `/inspections/`, `/samples/` |

---

## 2. دورة حياة المعاملة من منظور المفتش

```
AWAITING_INSPECTION ──(استمارة التفتيش)──┬─→ COMPLIANT      → RELEASED (إفراج تلقائي)
                                          ├─→ NON_COMPLIANT → AWAITING_DECISION
                                          └─→ NEEDS_ANALYSIS → AWAITING_LAB_RESULTS
                                                                │
                                                    (تسجيل عينة FS-…)
```

- **COMPLIANT:** يُفرج عن الشحنة مباشرة (`decide` داخليًا).
- **NON_COMPLIANT:** تتطلب وصف المخالفة في الملاحظات → تُحال لقرار المشرف.
- **NEEDS_ANALYSIS:** تتحول الشحنة إلى «بانتظار نتائج المختبر» ويُسجَّل إلزاميًا تسلسل عينات.

## 3. بنية لوحة المفتش

### التبويبات

| التبويب | المحتوى |
|---|---|
| **الرئيسية** | 4 بطاقات إحصائية + آخر 5 مهام مع زر «عرض الكل» |
| **مهام التفتيش** | جميع الشحنات `AWAITING_INSPECTION` المسندة للمفتش |
| **العينات** | متابعة كل العينات المسحوبة باسم المفتش |

### البطاقات الإحصائية (بيانات حقيقية)

| البطاقة | المصدر |
|---|---|
| مهام بانتظار التفتيش | `GET /shipments/?assigned_inspector={me}&status=AWAITING_INSPECTION` |
| عينات قيد المختبر | `GET /samples/?received_by={me}` ثم تصفية الحالات النشطة |
| نتائج عينات جاهزة | نفس المصدر — حالات APPROVED/DISPATCHED/COMPLETED |
| تفتيشي المنجز | `GET /inspections/?inspector={me}` |

### جدول المهام

الأعمدة: رقم المعاملة (+ تاريخ الوصول)، المستورد/المصدر، المنفذ، العينات المقترحة (من `fee_preview.samples`)، زر **«بدء التفتيش»**.

## 4. استمارة التفتيش (نافذة حوارية)

### قسم القراءة فقط (من بيانات الشحنة)
المستورد/المصدر، المنفذ، الوزن الإجمالي، عدد العينات المقترح، قائمة المنتجات.

### حقول الاستمارة (كتابة)

| الحقل | الحقل في الـ API |
|---|---|
| درجة الحرارة (°م) | `temperature` |
| رقم التشغيلة | `batch_number` |
| تاريخ الإنتاج | `production_date` |
| تاريخ الانتهاء | `expiry_date` |
| وسيلة النقل/الماعون | `container_condition` |
| حالة العبوات | `package_condition` |
| عبوات سليمة / تالفة | `sound_count` / `damaged_count` |
| الوزن السليم / التالف | `sound_weight` / `damaged_weight` |

### نتيجة التفتيش (إلزامية)

| الخيار | التحقق |
|---|---|
| ✅ مطابق `COMPLIANT` | — |
| ❌ غير مطابق `NON_COMPLIANT` | **وصف المخالفة في الملاحظات إلزامي** |
| 🔬 يحتاج عينة `NEEDS_ANALYSIS` | يفتح نافذة تسجيل العينة بعد الحفظ تلقائيًا |

---

## 5. تسجيل العينة

عند اختيار «يحتاج تحليل مخبري» تظهر نافذة:

| الحقل | القيم |
|---|---|
| نوع العينة * | غذائية / مياه / سطح / أخرى |
| الكمية | نص حر |
| الوحدة | كجم / عبوة / لتر |

عند الحفظ:
- `POST /food/shipments/{id}/samples/`
- توليد باركود فريد `FS-XXXXXXXX` تلقائيًا
- حالة العينة الأولية `RECEIVED`
- الشحنة → `AWAITING_LAB_RESULTS`

> **ملاحظة تنفيذية:** حقول مثل المحطة والجهة الطالبة والمصدر لها قيم افتراضية في الـ backend ولا تُطلب من المفتش الميداني في هذه النافذة.

## 6. جدول العينات

| العمود | ملاحظات |
|---|---|
| باركود العينة | `FS-…` بخط عريض |
| المعاملة | `shipment_manifest` (أضيف للـ Serializer) |
| نوع العينة | نص |
| الحالة | Chip ملون حسب خريطة الحالات أدناه |
| تاريخ الأخذ | `received_at` بصيغة عربية |

خريطة الحالات:
`RECEIVED تم الاستلام` · `COORDINATED تم التنسيق` · `ASSIGNED أُسندت للقسم` · `UNDER_TESTING قيد التحليل` · `READY_FOR_APPROVAL جاهزة للاعتماد` · `APPROVED معتمدة` · `DISPATCHED أُرسلت النتائج` · `COMPLETED مكتملة` · `REJECTED مرفوضة`

## 7. مراجع الـ API

| Endpoint | Method | الاستخدام |
|---|---|---|
| `/food/shipments/` | GET | مهامي (`assigned_inspector`, `status`) |
| `/food/shipments/{id}/inspection/` | POST | حفظ استمارة التفتيش |
| `/food/shipments/{id}/samples/` | POST | تسجيل عينة |
| `/food/samples/?received_by=` | GET | عيناتي |
| `/food/inspections/?inspector=` | GET | سجل تفتيشي |

> فلاتر `assigned_inspector` (شحنات)، `inspector` (تفتيش)، `received_by` (عينات) أُضيفت إلى `filter_fields` ضمن هذا العمل.

### سجل التدقيق
كل عملية تُسجَّل في `AuditLog`: `complete_inspection` (نتيجة التفتيش)، `register_sample` (تسجيل العينة).
