## ⚙️ حالة التنفيذ (مطبَّق فعليًا)

**الدور:** `SECTOR_HEAD` — «مدير إدارة رقابة الأغذية بالقطاع»، نطاق `ScopeType.SECTOR`.
**الحساب التجريبي:** `sector@nqp.gov.sd / testpass123` — مرتبط بـ«قطاع البحر الأحمر» (ميناء بورتسودان).
**النطاق:** حقل `User.sector` → كل الاستعلامات تُفلتر على منافذ القطاع فقط (`Port.sector`). المدير القومي/superuser يستطيع تحديد قطاع عبر `?sector=<id>`.

### نقطة النهاية الموحدة

```
GET /api/v1/food/shipments/sector-head-dashboard/?period=DAY|WEEK|MONTH|QUARTER|YEAR
```

تحديث تلقائي كل 60 ثانية. الأقسام المُرجَعة:

| # | القسم | المفتاح |
|---|---|---|
| 0 | مؤشرات رئيسية (شحنات/تفتيش/عينات/مخالفات مفتوحة) | `kpis` |
| 0 | نتائج المعاملات (إفراج/رفض/احتجاز/SLA%) | `outcomes` |
| 1 | نظرة القطاع — جدول أداء كل منفذ (نقر → لوحة رئيس القسم) | `ports_overview` |
| 2 | توزيع حالات الشحنات (رسم بياني) | `status_breakdown` |
| 3 | إدارة التفتيش — إجماليات + أداء لكل منفذ | `inspection_board` |
| 4 | العينات والمختبر + دلو SLA (ضمن/قريب/متجاوز 48 ساعة) | `samples_board` |
| 5 | تنبيهات قطاعية مشتقة 🔴/⚠️/ℹ️ | `alerts` |
| 6 | شهادات القطاع (اليوم/الفترة/بانتظار قرار) | `certificates` |
| 7 | الموارد البشرية — عبء العمل والحالة | `staff.workload` |
| 8 | الإيرادات الشهرية SDG (قراءة فقط، محصّلة) | `finance` |

### مؤجَّل حتى بناء النماذج الخلفية

- ⚠️ Risk Engine (أعلى المنتجات/الدول خطورة)
- 🚫 المخالفات والإنفاذ (نموذج Violation)
- 🔄 Food Recall
- 📊 التقارير المجدولة PDF/Excel

### الاختبارات

`test_sector_head_flow.py` — 6 اختبارات: المصادقة 401، بلا قطاع 400، حصر النطاق بمنافذ القطاع، لوحة التفتيش والموارد، مفاتيح SLA والتمويل، superuser مع `?sector=`. ✓
