## ⚙️ حالة التنفيذ (مطبَّق فعليًا)

**الدور:** `FOOD_DIRECTOR` — «مدير إدارة رقابة الأغذية» (نطاق `GLOBAL` — أعلى مستوى داخل Food Safety).
**الحساب التجريبي:** `food.director@nqp.gov.sd / testpass123`.
**الصفحة:** `/app/food-director` — صفحة واحدة قابلة للتمرير، تحديث تلقائي كل 60 ثانية.

### نقطة النهاية الموحدة

```
GET /api/v1/food/shipments/food-director-dashboard/?period=DAY|WEEK|MONTH|QUARTER|YEAR
```

| # | القسم | المفتاح |
|---|---|---|
| 0 | الحجم التشغيلي القومي (شحنات/تفتيش/عينات/شهادات) | `kpis` |
| 0 | النسب الوطنية (إفراج% / رفض% / عالية الخطورة% / SLA%) | `outcomes` |
| 2 | أداء القطاعات + نقطة أداء 🟢🟡🔴 (نقر → لوحة القطاع) | `sectors_overview` |
| 4 | التنبيهات الغذائية القومية المشتقة 🔴/⚠️/ℹ️ | `alerts` |
| 6 | أداء المختبرات القومي + دلو SLA | `lab_performance` |
| 7 | مؤشرات الأداء مقابل الأهداف (زمن الإفراج <24س، إنجاز >90%، SLA >90%) | `kpi_table` |
| 8 | الوارد والصادر (نسب إفراج/رفض/احتجاز لكل نوع) | `trade` |
| 12 | الموارد القومية (مفتشون: مشغول/متاح/بلا مهام) | `staff` |
| 13 | الإيرادات الشهرية SDG (قراءة فقط) | `finance` |
