# شاشة الإشعارات (Notifications)

## 1. الهدف
عرض جميع الإشعارات التي تلقاها المسافر (تغييرات الحالة، تذكيرات، تنبيهات) في قائمة منظمة، مع إمكانية تصفيتها حسب النوع وقراءتها أو حذفها.

## 2. مكونات الشاشة

### 2.1. شريط الإجراءات (Action Bar)
- **زر**: "تحديد الكل كمقروء".
- **زر**: "حذف الكل" (مع تأكيد أمني).
- **قائمة منسدلة للتصفية**: (الكل، الإشعارات غير المقروءة، الإشعارات المقروءة).

### 2.2. قائمة الإشعارات (Notifications List)
- **كل إشعار يعرض كبطاقة** تحتوي على:
  - **الأيقونة**: (حسب النوع: 📨 جديد، ✅ مكتمل، ⚠️ تنبيه، 🎉 تهنئة).
  - **العنوان**: (مثل: "تم اعتماد طلبك!").
  - **النص**: (مثل: "يمكنك الآن تنزيل رمز QR الخاص بك من لوحة التحكم.").
  - **التاريخ والوقت**: (مثل: "منذ ساعتين" - عرض نسبي).
  - **حالة القراءة**: (نشط/غير نشط) مع تمييز بصري (خلفية زرقاء فاتحة للجديد).
  - **زر**: "حذف" (🗑️) لكل إشعار.

### 2.3. حالة عدم وجود إشعارات (Empty State)
- عرض أيقونة (🔔) كبيرة مع نص "لا توجد إشعارات جديدة".
- زر: "العودة إلى لوحة التحكم".

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) لقائمة الإشعارات.
- **حالة نجاح التحديث**: ظهور رسالة (Toast) خضراء: "تم تحديد جميع الإشعارات كمقروءة".
- **تفاعل النقر**: عند النقر على إشعار، يتم نقلك إلى الصفحة المرتبطة به (مثل: طلب، QR، خبر).

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/travelers/{id}/notifications/` | قائمة الإشعارات (مع التصفية). |
| `PATCH /api/v1/travelers/{id}/notifications/mark-all-read/` | تحديد الكل كمقروء. |
| `PATCH /api/v1/travelers/{id}/notifications/{id}/read/` | تحديد إشعار واحد كمقروء. |
| `DELETE /api/v1/travelers/{id}/notifications/{id}/` | حذف إشعار. |
