# شاشة الملف الصحي (Health Profile)

## 1. الهدف
عرض وتحديث الملف الصحي الدائم للمسافر، بما في ذلك (التاريخ الطبي، الحساسية، التطعيمات، وسجل الإقرارات الصحية السابقة)، ليكون مرجعاً للطبيب عند الحاجة.

## 2. مكونات الشاشة

### 2.1. تبويبات التنقل (Tabs)
- **الملف الشخصي** (👤): المعلومات الأساسية.
- **التاريخ الطبي** (🩺): الأمراض المزمنة والحساسية.
- **التطعيمات** (💉): سجل التطعيمات.
- **سجل الإقرارات** (📋): الإقرارات الصحية السابقة.

### 2.2. التبويب الأول: الملف الشخصي (Personal Info)
- **عرض معلومات للقراءة فقط**:
  - الاسم الكامل.
  - رقم الجواز.
  - تاريخ الميلاد.
  - الجنسية.
  - رقم الجوال.
  - البريد الإلكتروني.
- **زر**: "تعديل معلومات الاتصال" (يفتح نافذة منبثقة لتحديث الجوال والبريد الإلكتروني).

### 2.3. التبويب الثاني: التاريخ الطبي (Medical History) - قابل للتعديل
- **الأمراض المزمنة**: قائمة اختيارات متعددة (Checkbox) مع إمكانية إضافة "أخرى".
- **الحساسية**: حقل نصي (مع إمكانية إضافة أكثر من حساسية).
- **العمليات الجراحية السابقة**: حقل نصي (اختياري).
- **الأدوية الحالية**: حقل نصي (اختياري).
- **زر**: "حفظ التغييرات".

### 2.4. التبويب الثالث: التطعيمات (Vaccination Record)
- **قائمة جدولية** تحتوي على:
  - (اسم اللقاح، التاريخ، الجهة المانحة، تاريخ انتهاء الصلاحية).
- **زر**: "إضافة تطعيم جديد" (يفتح نموذج لإضافة لقاح جديد مع رفع شهادة التطعيم).

### 2.5. التبويب الرابع: سجل الإقرارات (Declaration History)
- **عرض جدول زمني** (Timeline) لجميع الإقرارات الصحية السابقة:
  - (التاريخ، الأعراض المسجلة، حالة الإقرار).

## 3. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/travelers/{id}/profile/` | استرجاع الملف الصحي الكامل. |
| `PUT /api/v1/travelers/{id}/profile/` | تحديث الملف الصحي. |
| `GET /api/v1/travelers/{id}/vaccinations/` | استرجاع سجل التطعيمات. |
| `POST /api/v1/travelers/{id}/vaccinations/` | إضافة تطعيم جديد. |
