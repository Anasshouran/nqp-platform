# شاشات مصادقة المسافر (Traveler Auth Screens)

## 1. نظرة عامة
تشمل شاشات المصادقة 4 شاشات أساسية لإدارة حساب المسافر:
- **تسجيل الدخول** (`/traveler/login`) — تسجيل الدخول بالبريد وكلمة المرور
- **إنشاء حساب** (`/traveler/signup`) — تسجيل حساب جديد كمسافر
- **نسيت كلمة المرور** (`/traveler/forgot-password`) — إرسال رابط إعادة التعيين
- **إعادة تعيين كلمة المرور** (`/traveler/reset-password`) — تعيين كلمة مرور جديدة من الرابط

## 6. الحماية (Route Guards)

### `TravelerProtectedRoute`

| الصفحة | محمية؟ | إعادة التوجيه عند عدم الدخول |
|:---|:---|:---|
| `/traveler/login` | لا | — |
| `/traveler/signup` | لا | — |
| `/traveler/register` | لا | — |
| `/traveler/forgot-password` | لا | — |
| `/traveler/reset-password` | لا | — |
| `/traveler/dashboard` | نعم | `/traveler/login` |
| `/traveler/tracking` | نعم | `/traveler/login` |
| `/traveler/documents` | نعم | `/traveler/login` |
| `/traveler/profile` | نعم | `/traveler/login` |

**آلية الحماية:** التحقق من وجود `access_token` في `localStorage`.

## 7. الأمان

| الميزة | التفاصيل |
|:---|:---|
| **قفل الحساب** | 5 محاولات خاطئة → قفل 15 دقيقة |
| **تنبيه المحاولات** | يظهر "تبقى N محاولة" عند المحاولات 3، 4 |
| **رفض الموظفين** | حسابات `user_type=STAFF` مرفوضة من بوابة المسافرين |
| **كلمة المرور** | ≥ 8 أحرف، تحقق من التطابق |
| **إعادة التعيين** | رمز one-time use عبر بريد إلكتروني |
| **JWT** | Access token صالح لمدة 30 دقيقة + Refresh token |

## 8. نقاط النهاية الخلفية

| الطريقة | المسار | الوصف |
|:---|:---|:---|
| `POST` | `/api/v1/travelers/auth/register/` | إنشاء حساب مسافر جديد |
| `POST` | `/api/v1/travelers/auth/login/` | تسجيل الدخول (يُرفض للموظفين) |
| `POST` | `/api/v1/travelers/auth/forgot-password/` | إرسال رابط إعادة التعيين |
| `POST` | `/api/v1/travelers/auth/reset-password/` | إعادة تعيين كلمة المرور |
| `GET` | `/api/v1/travelers/auth/me/` | جلب بيانات المستخدم + المسافرين |
| `PATCH` | `/api/v1/travelers/auth/me/` | تحديث البيانات الشخصية |
