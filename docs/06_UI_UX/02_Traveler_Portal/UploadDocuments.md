# شاشة رفع المستندات (Upload Documents)

## 1. الهدف
تمكين المسافر من رفع المستندات الداعمة لطلبه (صورة جواز السفر، شهادة التطعيم، صورة شخصية) بسهولة، مع توفير معاينة فورية للملفات والتحقق من صحتها قبل الإرسال.

## 2. مكونات الشاشة

### 2.1. منطقة رفع الملفات (Upload Zone)
- **منطقة السحب والإفلات (Drag & Drop)**: مستطيل كبير بحدود متقطعة.
- **نص تعليمي**: "اسحب ملفاتك هنا أو انقر للاختيار".
- **أنواع الملفات المدعومة**: (PDF, JPEG, PNG) - تظهر كأيقونات.
- **الحد الأقصى للحجم**: (5 ميجابايت لكل ملف) - يظهر كرسالة توضيحية.

### 2.2. أنواع المستندات المطلوبة (Required Documents)
- **بطاقة رفع لكل نوع**:
  - **صورة جواز السفر**: (إلزامي) - مع أيقونة 📄.
  - **شهادة التطعيم**: (اختياري) - مع أيقونة 💉.
  - **صورة شخصية**: (اختياري) - مع أيقونة 🧑.

### 2.3. قائمة الملفات المرفوعة (Uploaded Files List)
- **عرض جدولي** يحتوي على:
  - **اسم الملف**.
  - **الحجم**.
  - **حالة الرفع**: (مكتمل ✅، قيد الرفع 🔄، فشل ❌).
  - **زر "حذف"**: (🗑️) لإزالة الملف.
- **معاينة الملف**: عند النقر على اسم الملف، تظهر نافذة منبثقة لعرض الصورة أو مستند PDF.

### 2.4. تذييل النموذج (Form Footer)
- **زر "التالي"**: يظهر فقط بعد رفع جميع المستندات الإلزامية.
- **زر "تخطي"**: (إذا كانت المستندات اختيارية) - مع رسالة توضيحية "يمكنك رفع المستندات لاحقاً".

## 3. حالات واجهة المستخدم (UI States)
- **حالة الرفع (Uploading)**: شريط تقدم (Progress Bar) لكل ملف مع نسبة مئوية.
- **حالة نجاح الرفع**: أيقونة خضراء (✔) وتغيير لون الخلفية إلى أخضر فاتح.
- **حالة فشل الرفع**: أيقونة حمراء (✖) ورسالة خطأ (مثل: "حجم الملف كبير جداً" أو "نوع الملف غير مدعوم").
- **حالة التحميل الزائد**: تعطيل زر "رفع" وإظهار رسالة "يُرجى الانتظار حتى اكتمال الرفع الحالي".

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `POST /api/v1/travelers/{id}/documents/` | رفع ملف (يدعم الرفع المتعدد). |
| `DELETE /api/v1/travelers/{id}/documents/{doc_id}/` | حذف ملف مرفوع. |
| `GET /api/v1/travelers/{id}/documents/` | استرجاع قائمة الملفات المرفوعة. |
