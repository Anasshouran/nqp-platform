# شاشة اعتماد النتائج (Result Approval)

## 1. الهدف
تمكين مشرف المختبر من مراجعة النتائج المدخلة من قبل الفنيين، والتأكد من دقتها وسلامتها قبل اعتمادها وإرسالها إلى الجهات المعنية (العيادات، نظام الترصد، وغرفة الطوارئ).

## 2. مكونات الشاشة

### 2.1. شريط الأدوات (Toolbar)
- **قوائم التصفية**:
  - (الأولوية: الكل، عادي، عاجل، فوري).
  - (تاريخ الإدخال: اليوم، الأسبوع، الشهر).

### 2.2. قائمة النتائج بانتظار الاعتماد (Pending Approval List)
- **جدول** يحتوي على:
  - الأعمدة: (الباركود، اسم المريض، الفحص، النتيجة المدخلة، القيمة الرقمية، تاريخ الإدخال، اسم الفني، الأولوية).
- **الإجراءات**:
  - **زر**: "مراجعة" (يفتح نافذة مراجعة النتيجة).
  - **زر**: "اعتماد الكل" (للمشرفين المتقدمين) - مع تحذير أمني.

### 2.3. نافذة مراجعة النتيجة (Result Review Modal)
- **عرض النتيجة المدخلة** (للقراءة فقط):
  - (الباركود، اسم المريض، نوع العينة، الفحص، النتيجة المدخلة، القيمة الرقمية، ملاحظات الفني).
- **قرار المشرف (Supervisor Decision)**:
  - **أزرار اختيار (Radio Buttons)**: (✅ اعتماد `Approve` / ❌ رفض `Reject`).
  - **حقل نصي (سبب الرفض)** - إلزامي إذا تم اختيار `Reject`.
  - **ملاحظات المشرف**: (حقل نصي اختياري).
- **زر**: "تأكيد القرار" (حفظ القرار وتحديث حالة العينة).

### 2.4. حالة العينة بعد القرار
- **معتمدة (Approved)**:
  - (🟢 معتمدة) - يتم إرسال النتيجة تلقائياً إلى (العيادة، نظام الترصد، غرفة الطوارئ إن لزم الأمر).
- **مرفوضة (Rejected)**:
  - (🔴 مرفوضة) - يتم إشعار الفني المسؤول (عبر البريد الإلكتروني والإشعار داخل البوابة) بضرورة إعادة التحليل، مع عرض سبب الرفض.

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح الاعتماد**: رسالة خضراء "تم اعتماد النتيجة بنجاح، وإرسالها إلى الجهات المعنية".
- **حالة رفض النتيجة**: رسالة حمراء "تم رفض النتيجة، سيتم إشعار الفني لإعادة التحليل".
- **حالة التحميل**: تعطيل أزرار القرار أثناء إرسال الطلب.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/lab/samples/pending-approval/` | قائمة النتائج بانتظار الاعتماد. |
| `POST /api/v1/lab/samples/{id}/approve/` | اعتماد النتيجة. |
| `POST /api/v1/lab/samples/{id}/reject/` | رفض النتيجة (مع سبب). |
