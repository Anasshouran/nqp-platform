# شاشة تتبع العينات (Sample Tracking)

## 1. الهدف
تمكين فني المختبر والمشرف من متابعة حالة العينة في أي وقت، ومعرفة المرحلة التي وصلت إليها (مسجلة، قيد التحليل، مكتملة، معتمدة)، لضمان عدم ضياع العينات أو تأخر النتائج.

## 2. مكونات الشاشة

### 2.1. شريط الأدوات (Toolbar)
- **شريط البحث**: (بحث بالباركود، اسم المريض، أو رقم الإحالة).
- **قوائم التصفية**:
  - (الحالة: الكل، مسجلة، قيد التحليل، نتائج مدخلة، معتمدة، مرفوضة).
  - (الأولوية: الكل، عادي، عاجل، فوري).
  - (الفترة الزمنية: اليوم، الأسبوع، الشهر، مخصص).

### 2.2. جدول العينات (Samples Table)
- **الأعمدة**:
  - الباركود.
  - اسم المريض.
  - نوع العينة.
  - الفحص المطلوب.
  - الأولوية (مع تمييز بالألوان: 🟢 عادي، 🟡 عاجل، 🔴 فوري).
  - الحالة (مع تمييز بالألوان: 🟦 مسجلة، 🟧 قيد التحليل، 🟪 نتائج مدخلة، 🟩 معتمدة، 🟥 مرفوضة).
  - تاريخ التسجيل.
- **الإجراءات**:
  - **زر**: "عرض التفاصيل" (يفتح نافذة جانبية (Side Panel) بتفاصيل العينة وسجل التغييرات).

### 2.3. نافذة تفاصيل العينة (Sample Detail Side Panel)
- **معلومات العينة الأساسية**: (الباركود، نوع العينة، الفحص، الأولوية، الحالة).
- **معلومات المريض**: (الاسم، رقم الجواز، الجنسية، العمر).
- **سجل التغييرات (Activity Timeline)**:
  - عرض عمودي (Timeline) بجميع التغييرات التي حدثت على العينة:
    - (مثل: "2024-07-25 10:00 - تم تسجيل العينة (فني: أحمد)").
    - (مثل: "2024-07-25 10:30 - بدء التحليل (فني: سارة)").

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للجدول.
- **حالة عدم وجود نتائج**: عرض رسالة "لا توجد عينات مطابقة للبحث" مع أيقونة 🔍.
- **حالة التحديث التلقائي**: (اختياري) تحديث الجدول تلقائياً كل 30 ثانية (Polling) لعرض أحدث الحالات.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/lab/samples/` | قائمة العينات (مع التصفية والبحث والترقيم). |
| `GET /api/v1/lab/samples/{id}/` | تفاصيل عينة محددة. |
| `GET /api/v1/lab/samples/{id}/timeline/` | سجل التغييرات (Activity Log). |
