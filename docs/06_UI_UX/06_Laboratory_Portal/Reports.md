# شاشة التقارير والإحصائيات (Reports & Statistics)

## 1. الهدف
تزويد فنيي المختبرات والمشرفين ومديري المختبرات بتقارير وإحصائيات عن أداء المختبر، بما في ذلك (عدد العينات، أنواع الفحوصات، النتائج، أوقات الإنجاز، وأداء الفنيين)، لتحسين العمليات وتحديد الاحتياجات التدريبية.

## 2. مكونات الشاشة

### 2.1. بطاقات الملخص العلوي (KPI Cards)
| البطاقة | القيمة | المصدر |
| :--- | :--- | :--- |
| **إجمالي العينات (الشهر)** | عدد العينات المسجلة. | نظام تسجيل العينات. |
| **النتائج المعتمدة (الشهر)** | عدد النتائج التي تم اعتمادها. | نظام اعتماد النتائج. |
| **متوسط وقت الإنجاز (TAT)** | (بالساعات) متوسط الوقت من تسجيل العينة إلى الاعتماد. | نظام تتبع العينات. |
| **نسبة النتائج الإيجابية** | (%) | نظام اعتماد النتائج. |

### 2.2. أدوات التصفية (Filters)
- **الفترة الزمنية**: (اليوم، الأسبوع، الشهر، مخصص).
- **نوع الفحص**: (الكل، PCR، مزرعة، CBC، إلخ).
- **حالة العينة**: (الكل، مسجلة، قيد التحليل، معتمدة، مرفوضة).

### 2.3. الرسوم البيانية (Charts)
- **توزيع العينات حسب النوع**: (Pie Chart) يوضح نسب أنواع العينات (دم، مسحة، بول، إلخ).
- **توزيع النتائج**: (Bar Chart) يوضح عدد النتائج (إيجابي، سلبي، غير محدد) لكل مرض.
- **اتجاهات الفحوصات**: (Line Chart) يوضح عدد الفحوصات المطلوبة يومياً خلال الفترة المحددة.
- **أوقات الإنجاز (TAT)**: (Box Plot) يوضح توزيع أوقات الإنجاز حسب الأولوية.

### 2.4. أداء الفنيين (Technician Performance) - للمشرفين
- **جدول** يوضح أداء كل فني:
  - (اسم الفني، عدد العينات التي قام بتحليلها، متوسط وقت الإنجاز، نسبة الأخطاء/الرفض).

### 2.5. أزرار التصدير (Export Buttons)
- **زر**: "تصدير PDF" (تقرير منظم للطباعة).
- **زر**: "تصدير Excel" (بيانات خام للتحليل).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للرسوم البيانية والجداول.
- **حالة عدم وجود بيانات**: عرض رسالة "لا توجد بيانات للفترة المحددة".
- **حالة تصدير التقرير**: ظهور رسالة "جاري تجهيز الملف..." مع شريط تقدم.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/lab/reports/kpi/` | الحصول على مؤشرات الأداء الرئيسية. |
| `GET /api/v1/lab/reports/samples/` | الحصول على بيانات العينات (مع التصفية). |
| `GET /api/v1/lab/reports/export/` | تصدير التقرير بصيغة (PDF/Excel). |
