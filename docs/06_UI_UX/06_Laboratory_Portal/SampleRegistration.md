# شاشة تسجيل العينات (Sample Registration)

## 1. الهدف
تمكين فني المختبر من تسجيل العينات الواردة من العيادات (أو من الفحص المباشر) في النظام، مع توليد باركود فريد لكل عينة لضمان تتبعها بدقة طوال دورة حياتها، ومنع الخلط بين العينات.

## 2. مكونات الشاشة

### 2.1. نموذج تسجيل عينة جديدة (New Sample Form)
- **حقل البحث عن المريض/الزيارة**:
  - (حقل بحث متصل بـ `/api/v1/clinic/visits/search` يعرض قائمة بالمرضى أثناء الكتابة).
  - بعد اختيار المريض، يتم جلب بيانات (اسم المريض، رقم الجواز، الفحص المطلوب) تلقائياً.
- **نوع العينة**: (قائمة منسدلة: مسحة أنفية بلعومية، عينة دم وريدي، عينة بول، إلخ).
- **الفحص المطلوب**: (قائمة منسدلة - يتم جلبها من طلب العيادة أو يمكن تعديلها).
- **الأولوية**: (قائمة منسدلة: عادي 🟢، عاجل 🟡، فوري 🔴).
- **ملاحظات إضافية**: (حقل نصي اختياري).

### 2.2. توليد الباركود (Barcode Generation)
- بعد حفظ العينة، تظهر **بطاقة الباركود**:
  - **صورة الباركود**: (قابلة للطباعة بصيغة PNG).
  - **رقم الباركود**: (نص قابل للنسخ).
  - **زر**: "طباعة ملصق العينة" (يفتح نافذة الطباعة).

### 2.3. قائمة العينات المسجلة حديثاً (Recently Registered)
- **جدول** يعرض آخر 5 عينات تم تسجيلها في هذه الجلسة:
  - الأعمدة: (الباركود، اسم المريض، نوع العينة، الفحص، الأولوية، الحالة (مسجلة)).
  - **زر**: "بدء التحليل" (ينتقل إلى صفحة `ResultsEntry.md`).

## 3. حالات واجهة المستخدم (UI States)
- **حالة البحث عن المريض**: عرض قائمة منسدلة (Dropdown) بالمرضى المقترحين أثناء الكتابة في حقل البحث.
- **حالة نجاح التسجيل**: ظهور رسالة خضراء "تم تسجيل العينة بنجاح، باركود: LAB-2024-001" مع عرض الباركود.
- **حالة فشل التسجيل**: ظهور رسالة حمراء مع سبب الفشل (مثل: "رقم الزيارة غير موجود").
- **حالة الباركود المكرر**: (نادر) يظهر تحذير بأن الباركود موجود مسبقاً، ويتم إنشاء باركود جديد تلقائياً.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/clinic/visits/search/?q={term}` | البحث عن زيارة عيادية (لربط العينة). |
| `POST /api/v1/lab/samples/` | تسجيل عينة جديدة (إنشاء سجل). |
| `GET /api/v1/lab/samples/{id}/barcode/` | استرجاع صورة الباركود (قابلة للطباعة). |
