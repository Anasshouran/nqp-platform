# لوحة التحكم الرئيسية للمختبر (Laboratory Dashboard)

## 1. الهدف
تزويد فنيي المختبرات والمشرفين بنظرة شاملة وسريعة عن حالة المختبر (العينات الواردة، العينات قيد التحليل، النتائج المعلقة للاعتماد، والمؤشرات الحيوية) في صفحة واحدة، لتمكينهم من إدارة سير العمل بكفاءة وتحديد الأولويات.

## 2. تخطيط الصفحة (Layout)

### 2.1. الشريط العلوي (Header)
- **شعار المنصة** (جهة اليمين).
- **اسم المستخدم** مع الصورة الشخصية (جهة اليسار).
- **القائمة المنسدلة**: (الملف الشخصي، الإعدادات، تسجيل الخروج).
- **حالة المختبر**: (🟢 يعمل بكفاءة / 🟡 ازدحام / 🔴 طوارئ).

### 2.2. بطاقات الملخص العلوي (KPI Cards) - 4 أعمدة
| البطاقة | القيمة | الأيقونة | لون الخلفية |
| :--- | :--- | :--- | :--- |
| **عينات مسجلة (اليوم)** | عدد (مثل: 45) | 📝 | أزرق فاتح |
| **عينات قيد التحليل** | عدد (مثل: 12) | ⏳ | برتقالي فاتح |
| **نتائج بانتظار الاعتماد** | عدد (مثل: 8) | ⏳ | بنفسجي فاتح |
| **نتائج معتمدة (اليوم)** | عدد (مثل: 25) | ✅ | أخضر فاتح |

### 2.3. قائمة الأولويات العاجلة (STAT / Urgent Samples)
- **عرض قائمة مصغرة** بالعينات ذات الأولوية (فوري أو عاجل) التي لم يتم إدخال نتيجتها بعد:
  - الأعمدة: (الباركود، اسم المريض، نوع الفحص، الوقت المنقضي منذ التسجيل).
  - **زر**: "بدء التحليل" (ينتقل إلى صفحة `ResultsEntry.md`).

### 2.4. قائمة العينات الواردة حديثاً (Recent Samples)
- **جدول** يعرض آخر 5 عينات تم تسجيلها:
  - الأعمدة: (الباركود، اسم المريض، نوع العينة، الفحص المطلوب، الحالة).
  - **زر**: "عرض الكل" (ينتقل إلى صفحة `SampleTracking.md`).

### 2.5. التنبيهات والإشعارات (Notifications)
- **شريط جانبي أو أسفل الصفحة** يعرض آخر الأحداث:
  - (مثل: "نتيجة جديدة بانتظار الاعتماد للمريض محمد أحمد").
  - (مثل: "تم رفض نتيجة العينة LAB-2024-001، يرجى إعادة التحليل").

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للبطاقات والجداول.
- **حالة عدم وجود عينات عاجلة**: عرض رسالة "لا توجد عينات عاجلة حالياً" مع أيقونة ✅.
- **حالة انقطاع الاتصال بأجهزة المختبر**: عرض تحذير (Banner) أحمر مع رسالة "تعذر الاتصال بأجهزة التحليل، يرجى التحقق من الاتصال".

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/lab/dashboard/stats/` | جلب إحصائيات البطاقات العلوية. |
| `GET /api/v1/lab/samples/urgent/` | جلب العينات العاجلة. |
| `GET /api/v1/lab/samples/recent/` | جلب آخر العينات المسجلة. |
