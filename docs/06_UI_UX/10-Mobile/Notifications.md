# شاشة الإشعارات (Notifications)

## 1. الهدف
عرض جميع الإشعارات التي تلقاها المريض (تذكيرات الأدوية، تغييرات الحالة، تنبيهات الطوارئ) في قائمة منظمة، مع إمكانية تصفيتها حسب النوع وقراءتها أو حذفها.

## 2. مكونات الشاشة

### 2.1. رأس الشاشة (Header)
- **عنوان**: "🔔 الإشعارات".
- **زر**: "تحديد الكل كمقروء" (✅).
- **زر**: "حذف الكل" (🗑️) - مع تأكيد أمني.

### 2.2. قائمة الإشعارات (Notifications List) - بطاقات عمودية
- **كل إشعار يعرض كبطاقة (Card)** تحتوي على:
  - **الأيقونة**: (حسب النوع: 📨 جديد، ✅ مكتمل، ⚠️ تنبيه، 🎉 تهنئة).
  - **العنوان**: (مثل: "تم اعتماد طلبك!").
  - **النص**: (مثل: "يمكنك الآن تنزيل رمز QR الخاص بك من لوحة التحكم.").
  - **التاريخ والوقت**: (مثل: "منذ ساعتين" - عرض نسبي).
  - **حالة القراءة**: (نشط/غير نشط) مع تمييز بصري (خلفية زرقاء فاتحة للجديد).
  - **زر**: "حذف" (🗑️) لكل إشعار.

### 2.3. حالة عدم وجود إشعارات (Empty State)
- عرض أيقونة (🔔) كبيرة مع نص "لا توجد إشعارات جديدة".
- زر: "العودة إلى الرئيسية".

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Shimmer Effect) لقائمة الإشعارات.
- **حالة نجاح التحديث**: ظهور رسالة (Toast) خضراء: "تم تحديد جميع الإشعارات كمقروءة".
- **تفاعل النقر**: عند النقر على إشعار، يتم نقلك إلى الصفحة المرتبطة به (مثل: طلب، QR، خبر).

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/mobile/notifications/` | قائمة الإشعارات (مع التصفية). |
| `PATCH /api/v1/mobile/notifications/mark-all-read/` | تحديد الكل كمقروء. |
| `PATCH /api/v1/mobile/notifications/{id}/read/` | تحديد إشعار واحد كمقروء. |
| `DELETE /api/v1/mobile/notifications/{id}/` | حذف إشعار. |
