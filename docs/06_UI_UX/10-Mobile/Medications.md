# شاشة إدارة الأدوية (Medications)

## 1. الهدف
تمكين المريض من **عرض جميع الأدوية الموصوفة له**، مع جدول زمني واضح للجرعات، وإمكانية **تأكيد تناول كل جرعة**، واستقبال تذكيرات قبل موعد الجرعة. تم تصميم هذه الشاشة لتعزيز **الالتزام العلاجي (Adherence)** وتقليل فرص النسيان.

## 2. مكونات الشاشة

### 2.1. رأس الشاشة (Header)
- **عنوان**: "💊 أدويتي".
- **زر**: "تحديث" (🔄) - لجلب آخر التحديثات من الطبيب.

### 2.2. بطاقة الملخص العلوي (Summary Card)
- **عدد الأدوية النشطة**: (مثل: "3 أدوية موصوفة").
- **الجرعات المتوقعة اليوم**: (مثل: "4 جرعات متوقعة اليوم").
- **الجرعات التي تم تناولها**: (مثل: "تم تناول 2 من 4").

### 2.3. قائمة الأدوية (Medications List) - بطاقات عمودية
- **كل دواء يعرض كبطاقة (Card)** تحتوي على:
  - **اسم الدواء** و **الجرعة** (مثل: "باراسيتامول 500mg").
  - **التكرار**: (مثل: "كل 8 ساعات").
  - **المدة**: (مثل: "لمدة 7 أيام").
  - **تعليمات**: (مثل: "يؤخذ بعد الأكل").
- **جدول الجرعات اليومية (Daily Schedule)**:
  - عرض قائمة بالجرعات لهذا اليوم مع الوقت المحدد:
    - (🟢 08:00 - تم التناول ✅).
    - (🟡 16:00 - بانتظار التناول ⏳).
    - (🔴 00:00 - فاتت الجرعة ❌) - مع زر "تأكيد متأخر".
  - **زر**: "✅ تأكيد التناول" - يظهر بجانب الجرعة الحالية (قبل الوقت المحدد بـ 15 دقيقة وحتى ساعة بعد الوقت).
  - **زر**: "⏰ تذكير" - لإرسال تذكير يدوي (اختياري).

### 2.4. أرشيف الأدوية المنتهية (Completed Medications) - قابل للطي (Accordion)
- **عرض قائمة بالأدوية التي انتهت مدتها** (للرجوع إليها عند الحاجة).

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح التأكيد**: رسالة خضراء "تم تأكيد تناول الدواء بنجاح" مع تحديث البطاقة فوراً.
- **حالة فشل التأكيد**: رسالة حمراء "حدث خطأ، يرجى المحاولة مرة أخرى".
- **حالة عدم وجود أدوية**: عرض رسالة "لا توجد أدوية موصوفة حالياً" مع أيقونة 💊.
- **حالة تذكير الجرعة**: ظهور (Push Notification) قبل موعد الجرعة بـ 15 دقيقة.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/mobile/medications/` | قائمة الأدوية الموصوفة. |
| `POST /api/v1/mobile/medications/{id}/take/` | تأكيد تناول جرعة معينة. |
| `GET /api/v1/mobile/medications/today/` | جدول جرعات اليوم. |
