# شاشة الملف الشخصي (Profile)

## 1. الهدف
تمكين المريض من **عرض وتحديث معلوماته الشخصية** (الاسم، رقم الجوال، البريد الإلكتروني)، و**عرض تاريخه الصحي** (الأمراض المزمنة، الحساسية، التطعيمات)، و**إدارة إعدادات التطبيق** (اللغة، الإشعارات، الخصوصية).

## 2. مكونات الشاشة

### 2.1. رأس الشاشة (Header)
- **عنوان**: "👤 الملف الشخصي".
- **صورة الملف الشخصي**: (دائرة، مع إمكانية تغيير الصورة - اختياري).
- **اسم المريض**: (الاسم الكامل).
- **حالة المتابعة**: (🟢 قيد المتابعة / ✅ مكتمل).

### 2.2. تبويبات التنقل (Tabs) - أفقية
- **المعلومات الشخصية** (📋).
- **التاريخ الصحي** (🩺).
- **الإعدادات** (⚙️).

### 2.3. التبويب الأول: المعلومات الشخصية (Personal Info)
- **حقول عرض قابلة للتعديل**:
  - الاسم الكامل (للقراءة فقط).
  - رقم الجواز (للقراءة فقط).
  - رقم الجوال (قابل للتعديل مع زر "تحديث").
  - البريد الإلكتروني (قابل للتعديل مع زر "تحديث").
  - تاريخ الميلاد (للقراءة فقط).
  - الجنسية (للقراءة فقط).
- **زر**: "حفظ التغييرات" (يظهر عند تعديل أي حقل).

### 2.4. التبويب الثاني: التاريخ الصحي (Medical History)
- **الأمراض المزمنة**: (قائمة تعرض كـ (Tags) مع زر "تعديل" لتحديث القائمة).
- **الحساسية**: (قائمة مع زر "تعديل").
- **التطعيمات**: (جدول زمني - Timeline - يوضح التطعيمات السابقة مع التواريخ).
- **سجل الإقرارات**: (قائمة بالإقرارات الصحية السابقة مع التواريخ).

### 2.5. التبويب الثالث: الإعدادات (Settings)
- **اللغة**: (قائمة منسدلة: عربي / إنجليزي).
- **الإشعارات**:
  - تفعيل/تعطيل الإشعارات (Toggle Switch).
  - تفعيل/تعطيل تذكير الأدوية (Toggle Switch).
- **الخصوصية والأمان**:
  - زر "تغيير كلمة المرور" (يفتح نافذة لتغيير كلمة المرور).
  - زر "تسجيل الخروج" (مع تأكيد).
- **حول التطبيق**:
  - رقم الإصدار: (مثل: "الإصدار 2.1.0").
  - زر "سياسة الخصوصية" (يفتح صفحة السياسة).
  - زر "شروط الاستخدام" (يفتح صفحة الشروط).

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح التحديث**: رسالة خضراء "تم تحديث البيانات بنجاح".
- **حالة فشل التحديث**: رسالة حمراء مع سبب الفشل.
- **حالة تغيير كلمة المرور**: نافذة منبثقة (Modal) تحتوي على (كلمة المرور القديمة، كلمة المرور الجديدة، تأكيد كلمة المرور).

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/mobile/profile/` | جلب بيانات الملف الشخصي. |
| `PUT /api/v1/mobile/profile/` | تحديث بيانات الملف الشخصي. |
| `POST /api/v1/mobile/profile/change-password/` | تغيير كلمة المرور. |
| `POST /api/v1/mobile/profile/logout/` | تسجيل الخروج. |
