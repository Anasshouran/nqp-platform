# الشاشة الرئيسية لتطبيق الجوال (Mobile Dashboard)

## 1. الهدف
توفير واجهة رئيسية بسيطة وشاملة للمريض، تعرض له **حالته الصحية الحالية**، **عدد الأيام المتبقية من المتابعة**، **مواعيد الأدوية القادمة**، وتوفر وصولاً سريعاً إلى أهم الوظائف (الإبلاغ اليومي، الأدوية، الشهادة). تم تصميم هذه الشاشة لتكون **نقطة الانطلاق** لكل تفاعل للمريض مع التطبيق.

## 2. تخطيط الشاشة (Layout) - Mobile-First

### 2.1. الشريط العلوي (App Bar)
- **شعار التطبيق** (جهة اليمين) - مصغر.
- **اسم المريض** (في المنتصف) مع أيقونة الترحيب 👋.
- **أيقونة الإشعارات** (🔔) مع عداد (Badge) يظهر عدد الإشعارات غير المقروءة.
- **أيقونة القائمة** (☰) - لفتح القائمة الجانبية (Profile, Settings, Logout).

### 2.2. بطاقة الحالة الصحية (Health Status Card) - العنصر الأبرز
- **خلفية متدرجة** (حسب الحالة):
  - 🟢 **خضراء**: "حالتك مستقرة. تابع الإجراءات اليومية."
  - 🟡 **صفراء**: "حالتك تحت المراقبة. يرجى الالتزام بالإرشادات."
  - 🔴 **حمراء**: "حالتك تتطلب تدخلاً عاجلاً. يرجى التوجه لأقرب مستشفى."
- **أيقونة الحالة**: (✅، ⚠️، 🚨) في منتصف البطاقة.
- **عدد الأيام المتبقية**: (مثل: "7 أيام متبقية من المتابعة").
- **آخر قراءات**: (مثل: "آخر حرارة: 37.2°C").
- **زر**: "📋 الإبلاغ اليومي" - زر كبير وبارز في أسفل البطاقة (يظهر فقط عندما يحين وقت الإبلاغ).

### 2.3. شبكة الخدمات السريعة (Quick Actions Grid) - 4 أعمدة
- **شبكة (Grid) مكونة من 4 أعمدة** مع أيقونات كبيرة:
  1.  **الإبلاغ اليومي** (📝): "تسجيل الأعراض" (إذا تم الإبلاغ اليوم، يتحول إلى "تم الإبلاغ ✅").
  2.  **الأدوية** (💊): "عرض الأدوية" (يظهر عدد الأدوية التي لم تؤخذ بعد).
  3.  **الشهادة** (📄): "عرض شهادة التعافي" (يظهر فقط عند اكتمال المتابعة).
  4.  **الملف الشخصي** (👤): "عرض الملف الشخصي".

### 2.4. الأدوية القادمة (Upcoming Medications) - قائمة أفقية
- **عرض شريط أفقي (Horizontal Scroll)** بآخر الأدوية الموصوفة:
  - **كل دواء يعرض كبطاقة صغيرة**: (اسم الدواء، وقت الجرعة القادم).
  - **زر**: "تأكيد التناول" (يظهر إذا كانت الجرعة حالية).
  - **زر**: "عرض الكل" (ينتقل إلى صفحة `Medications.md`).

### 2.5. شريط التنقل السفلي (Bottom Navigation Bar) - ثابت
- **5 أيقونات**:
  - 🏠 **الرئيسية** (نشطة).
  - 📋 **الإبلاغ** (ينتقل إلى `DailyCheckIn.md`).
  - 💊 **الأدوية** (ينتقل إلى `Medications.md`).
  - 📄 **الشهادة** (ينتقل إلى `RecoveryCertificate.md` - يظهر فقط عند توفرها).
  - 👤 **الملف الشخصي** (ينتقل إلى `Profile.md`).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Shimmer Effect) للبطاقات.
- **حالة عدم وجود أدوية**: عرض رسالة "لا توجد أدوية موصوفة حالياً".
- **حالة انتهاء المتابعة**: تغيير لون البطاقة إلى الأخضر مع رسالة "🎉 تم إكمال المتابعة بنجاح!".
- **حالة الطوارئ (الحالة الحمراء)**: تغيير لون الخلفية العلوي إلى أحمر مع رسالة تحذيرية وزر "طلب إسعاف" (🚑) بارز.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/mobile/dashboard/` | جلب بيانات الشاشة الرئيسية (الحالة، الأيام المتبقية، الأدوية). |
| `GET /api/v1/mobile/notifications/unread-count/` | جلب عدد الإشعارات غير المقروءة. |
