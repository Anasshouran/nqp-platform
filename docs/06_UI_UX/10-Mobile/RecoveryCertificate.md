# شاشة شهادة التعافي (Recovery Certificate)

## 1. الهدف
توفير واجهة واضحة للمريض **لعرض وتنزيل ومشاركة شهادة التعافي الرقمية** بعد اكتمال فترة المتابعة وتحقق معايير التعافي. تحتوي الشهادة على رمز QR للتحقق من صحتها من قبل أي جهة رسمية (مثل: شركات الطيران، الجوازات).

## 2. مكونات الشاشة

### 2.1. رأس الشاشة (Header)
- **عنوان**: "📄 شهادة التعافي".
- **زر**: "تحديث" (🔄) - لجلب أحدث نسخة من الشهادة (إذا تم تعديلها).

### 2.2. بطاقة الشهادة (Certificate Card) - العنصر الأبرز
- **خلفية بيضاء مع ظل خفيف**، تشبه الشهادة الورقية.
- **شعار المنصة** (في الأعلى).
- **عنوان**: "شهادة تعافي من الحجر الصحي".
- **اسم المريض**: (الاسم الكامل).
- **رقم الجواز**: (مخف جزئياً، مثل: `A12****67`).
- **تاريخ الإصدار**: (مثل: "25 يوليو 2024").
- **تاريخ الانتهاء**: (مثل: "25 أغسطس 2024").
- **رمز QR**: (في الزاوية السفلية اليمنى أو اليسرى) - بحجم مناسب للمسح.
- **حالة الشهادة**: (🟢 نشطة / 🔴 ملغاة / 🟡 منتهية الصلاحية) - تظهر كشريط في الأعلى.

### 2.3. أزرار الإجراءات (Action Buttons)
- **زر**: "📥 تنزيل PDF" - لتحميل الشهادة بصيغة PDF.
- **زر**: "📤 مشاركة" - لمشاركة الشهادة عبر (واتساب، البريد الإلكتروني، تطبيقات أخرى).
- **زر**: "🖨️ طباعة" - لطباعة الشهادة (عبر AirPrint أو خدمة مشابهة).

### 2.4. تعليمات الاستخدام (Instructions)
- **نص توضيحي**: "يمكنك استخدام هذه الشهادة لإثبات تعافيك من الحجر الصحي عند السفر أو العودة إلى العمل."
- **تحذير**: "هذه الشهادة صالحة لمدة 30 يوماً من تاريخ الإصدار. يرجى طباعتها أو حفظها على هاتفك."

## 3. حالات واجهة المستخدم (UI States)
- **حالة عدم توفر الشهادة**: عرض رسالة "لم يتم إصدار شهادة تعافي لك بعد. يرجى إكمال فترة المتابعة المطلوبة." مع شريط تقدم يوضح النسبة المئوية المتبقية.
- **حالة انتهاء الصلاحية**: عرض تحذير أصفر "انتهت صلاحية الشهادة. يرجى التواصل مع العيادة لتجديدها."
- **حالة إلغاء الشهادة**: عرض تحذير أحمر "تم إلغاء الشهادة. يرجى التواصل مع الدعم الفني."
- **حالة تنزيل PDF**: ظهور رسالة "جاري تنزيل الشهادة..." مع شريط تقدم.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/mobile/certificate/` | استرجاع بيانات الشهادة. |
| `GET /api/v1/mobile/certificate/download/` | تنزيل الشهادة بصيغة PDF. |
| `GET /api/v1/mobile/certificate/verify/` | (عام) التحقق من صحة الشهادة عبر QR. |
