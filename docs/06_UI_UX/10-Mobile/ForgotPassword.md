# شاشة نسيت كلمة المرور (Forgot Password) - تطبيق الجوال

## 1. الهدف
تمكين المستخدم (المسافر/المريض) من إعادة تعيين كلمة المرور في حال نسيانها، من خلال عملية بسيطة وآمنة مكونة من 3 خطوات (إدخال البريد الإلكتروني، التحقق عبر OTP، تعيين كلمة مرور جديدة). تم تصميم هذه الشاشة لتكون سريعة وسهلة لتقليل الاحتكاك وإعادة المستخدم إلى التطبيق في أسرع وقت.

## 2. تصميم الشاشة (Layout) - Mobile-First

### 2.1. الهيكل العام (Single Column - ملء الشاشة)
- **خلفية**: لون موحد (أبيض أو أزرق فاتح جداً) مع شعار المنصة في الأعلى.
- **المحتوى**: يتمركز في منتصف الشاشة عمودياً (Centered Vertically).
- **عدد الخطوات**: 3 خطوات (مع شريط تقدم صغير في الأعلى).

### 2.2. مكونات النموذج (Form Components)

#### الخطوة 1: إدخال البريد الإلكتروني (Email Entry)
- **شعار المنصة** (مصغر) في أعلى النموذج.
- **عنوان الصفحة**: "نسيت كلمة المرور؟" (بخط كبير).
- **نص فرعي**: "أدخل بريدك الإلكتروني المسجل، وسنرسل لك رمز التحقق."
- **حقل البريد الإلكتروني**:
  - أيقونة (📧) في بداية الحقل.
  - Placeholder: "البريد الإلكتروني".
  - نوع الإدخال: `email` مع لوحة مفاتيح مناسبة.
- **زر**: "إرسال رمز التحقق" (باللون الأزرق، يملأ عرض الشاشة).
- **رابط**: "تذكرت كلمة المرور؟ تسجيل الدخول" (في الأسفل).

#### الخطوة 2: التحقق عبر OTP (Verification Code)
- **عنوان الصفحة**: "تحقق من هويتك" (بخط كبير).
- **نص فرعي**: "أدخل الرمز المكون من 6 أرقام الذي أرسلناه إلى بريدك الإلكتروني."
- **حقول إدخال OTP**: (6 حقول منفصلة، كل حقل يستقبل رقم واحد، مع انتقال تلقائي إلى الحقل التالي).
- **مؤقت العد التنازلي**: (مثل: "إعادة إرسال الرمز خلال 59 ثانية").
- **زر**: "إعادة إرسال الرمز" (يظهر بعد انتهاء المؤقت).
- **زر**: "تحقق" (باللون الأزرق، يُفعّل عند اكتمال إدخال الـ OTP).
- **رابط**: "العودة إلى تسجيل الدخول".

#### الخطوة 3: تعيين كلمة مرور جديدة (New Password)
- **عنوان الصفحة**: "كلمة مرور جديدة" (بخط كبير).
- **نص فرعي**: "أدخل كلمة مرور قوية جديدة لحسابك."
- **حقل كلمة المرور الجديدة**:
  - أيقونة (🔒) في بداية الحقل.
  - Placeholder: "كلمة المرور الجديدة".
  - زر إظهار/إخفاء (👁️) في نهاية الحقل.
  - متطلبات كلمة المرور: (8 أحرف على الأقل، حروف كبيرة وصغيرة، أرقام، رموز).
- **حقل تأكيد كلمة المرور**:
  - أيقونة (🔒) في بداية الحقل.
  - Placeholder: "تأكيد كلمة المرور".
  - زر إظهار/إخفاء (👁️) في نهاية الحقل.
- **زر**: "تغيير كلمة المرور" (باللون الأزرق، يُفعّل عند تطابق الحقلين واستيفاء المتطلبات).
- **رابط**: "العودة إلى تسجيل الدخول".

### 2.3. شريط التقدم (Progress Stepper) - في أعلى كل خطوة
- **3 نقاط**: (1-2-3) مع تظليل النقطة النشطة باللون الأزرق، والنقاط المكتملة باللون الأخضر.

## 3. تدفق التفاعل (Interaction Flow)

```mermaid
flowchart TD
    A[فتح شاشة نسيت كلمة المرور] --> B[الخطوة 1: إدخال البريد الإلكتروني]

    C --> D[التحقق من صحة البريد الإلكتروني]

    E --> B
    D -- صحيح --> F[إرسال OTP إلى البريد الإلكتروني]
    F --> G[الانتقال إلى الخطوة 2]
    G --> H[إدخال رمز OTP]
    H --> I[الضغط على زر "تحقق"]
    I --> J{التحقق من صحة OTP}
    J -- غير صحيح --> K[عرض رسالة خطأ "الرمز غير صحيح، حاول مرة أخرى"]
    K --> H
    J -- صحيح --> L[الانتقال إلى الخطوة 3]
    L --> M[إدخال كلمة المرور الجديدة وتأكيدها]
    M --> N[الضغط على زر "تغيير كلمة المرور"]
    N --> O[التحقق من تطابق كلمتي المرور]
    O -- غير متطابقة --> P[عرض رسالة خطأ "كلمتا المرور غير متطابقتين"]
    P --> M
    O -- متطابقة --> Q[إرسال طلب تغيير كلمة المرور إلى API]
    Q -- نجاح --> R[عرض رسالة نجاح "تم تغيير كلمة المرور بنجاح"]
    R --> S[إعادة التوجيه إلى شاشة تسجيل الدخول]
```

### 3.1. حالات الخطأ (Error States)

| حالة الخطأ | الرسالة المعروضة | الإجراء التلقائي |
| :--- | :--- | :--- |
| **البريد الإلكتروني غير مسجل** | "هذا البريد الإلكتروني غير مسجل في النظام." | تمييز الحقل باللون الأحمر. |
| **رمز OTP غير صحيح** | "الرمز غير صحيح. يرجى المحاولة مرة أخرى." | إعادة تعيين حقول OTP والسماح بإعادة المحاولة. |
| **انتهاء صلاحية OTP** | "انتهت صلاحية الرمز. يرجى طلب رمز جديد." | إعادة توجيه تلقائي إلى الخطوة 1. |
| **كلمة المرور ضعيفة** | "كلمة المرور ضعيفة. يرجى استخدام 8 أحرف على الأقل، حروف كبيرة وصغيرة، أرقام، ورموز." | تمييز الحقل باللون الأحمر. |
| **كلمتا المرور غير متطابقتين** | "كلمتا المرور غير متطابقتين." | تمييز الحقلين باللون الأحمر. |

### 3.2. حالات النجاح (Success States)
- ظهور (Toast) أخضر "✅ تم تغيير كلمة المرور بنجاح. يمكنك الآن تسجيل الدخول."
- إعادة التوجيه التلقائي إلى شاشة تسجيل الدخول بعد 3 ثوانٍ.

## 4. اعتبارات أمنية (Security Considerations)

1.  **مدة صلاحية OTP**: 5 دقائق فقط (لأسباب أمنية).
2.  **عدد محاولات OTP**: 3 محاولات فاشلة كحد أقصى، ثم يتم إعادة توجيه المستخدم إلى الخطوة 1 (إعادة إرسال الرمز).
3.  **إعادة إرسال OTP**: يمكن للمستخدم طلب إعادة إرسال الرمز بعد 60 ثانية من الطلب الأول (لمنع الإرسال المتكرر).
4.  **تشفير الاتصال**: جميع الطلبات عبر HTTPS.
5.  **تسجيل محاولات إعادة التعيين**: يتم تسجيل كل محاولة في (Audit Log) لأغراض أمنية.

## 5. واجهة المستخدم (UI) - التفاصيل البصرية للجوال

### 5.1. الألوان
- **الخلفية**: لون أبيض أو أزرق فاتح جداً (`#F5F9FF`).
- **الأزرار**: اللون الأساسي للمنصة (أزرق غامق `#0D47A1`).
- **رسائل الخطأ**: أحمر (`#C62828`).
- **رسائل النجاح**: أخضر (`#2E7D32`).

### 5.2. الخطوط
- **الخط العربي**: Tajawal أو Dubai Font.
- **الخط الإنجليزي**: Inter.
- **أحجام الخطوط** (للجوال):
  - العنوان الرئيسي: 22px (وزن 700).
  - النص الفرعي: 14px (وزن 400).
  - التسميات (Labels): 14px (وزن 500).
  - رسائل الخطأ: 13px (وزن 400).

### 5.3. حقول OTP (6 حقول منفصلة)
- **التصميم**: 6 مربعات صغيرة متجاورة، كل مربع يستقبل رقم واحد.
- **الحجم**: 45x45 بكسل.
- **الحدود**: حدود رمادية فاتحة، تتحول إلى زرقاء عند التركيز، وحمراء عند الخطأ.
- **التنقل التلقائي**: بعد إدخال رقم، ينتقل التركيز تلقائياً إلى المربع التالي. عند الضغط على (Backspace)، يعود إلى المربع السابق.

## 6. نقاط النهاية الخلفية (API Endpoints)

| الطريقة | المسار | الوصف |
| :--- | :--- | :--- |
| `POST` | `/api/v1/auth/forgot-password/` | إرسال طلب إعادة تعيين كلمة المرور (إرسال OTP إلى البريد الإلكتروني). |
| `POST` | `/api/v1/auth/verify-otp/` | التحقق من صحة OTP. |
| `POST` | `/api/v1/auth/reset-password/` | تغيير كلمة المرور بعد التحقق من OTP. |

**نموذج طلب (Forgot Password - الخطوة 1):**
```json
{
  "email": "user@example.com"
}
```

**نموذج استجابة (Forgot Password - الخطوة 1):**
```json
{
  "status": "success",
  "message": "تم إرسال رمز التحقق إلى بريدك الإلكتروني.",
  "data": {
    "otp_expiry": "2024-07-26T15:30:00Z"
  }
}
```

**نموذج طلب (Verify OTP - الخطوة 2):**
```json
{
  "email": "user@example.com",
  "otp": "123456"
}
```

**نموذج طلب (Reset Password - الخطوة 3):**
```json
{
  "email": "user@example.com",
  "otp": "123456",
  "new_password": "NewSecurePass123!"
}
```
