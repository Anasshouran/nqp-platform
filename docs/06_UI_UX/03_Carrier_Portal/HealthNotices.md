# شاشة الإشعارات الصحية (Health Notices)

## 1. الهدف
تزويد ممثل شركة الطيران بمنصة لعرض جميع الإشعارات الصحية الواردة من وزارة الصحة (عبر المنصة)، مع إمكانية تصنيفها حسب النوع والأولوية، وتأكيد الاطلاع عليها.

## 2. مكونات الشاشة

### 2.1. شريط الأدوات (Toolbar)
- **قوائم التصفية**:
  - (النوع: الكل، تعليق رحلات، متطلبات دخول، تنبيه وبائي، تحديثات عامة).
  - (الحالة: الكل، نشط، منتهي).
  - (الأولوية: الكل، عاجل، مهم، عادي).
- **زر**: "تحديث الإشعارات" (لجلب آخر التحديثات يدوياً).

### 2.2. قائمة الإشعارات (Notices List) - بطاقات
- **كل إشعار يعرض كبطاقة** تحتوي على:
  - **الأيقونة**: (🔴 عاجل، 🟡 مهم، 🔵 معلوماتي).
  - **العنوان**: (مثل: "تعليق الرحلات القادمة من دولة X").
  - **تاريخ النشر** و **تاريخ الانتهاء**.
  - **ملخص مختصر** (أول 100 حرف).
  - **حالة الاطلاع**: (👁️ غير مقروء / ✅ تم الاطلاع).
  - **زر**: "عرض التفاصيل" (يفتح صفحة تفاصيل الإشعار).
  - **زر**: "تأكيد الاطلاع" (يظهر فقط إذا لم يتم تأكيده بعد).

### 2.3. صفحة تفاصيل الإشعار (Notice Detail) - نافذة منبثقة أو صفحة منفصلة
- **العنوان الكامل**.
- **المحتوى**: (نص كامل مع دعم الروابط والمستندات المرفقة).
- **المستندات المرفقة**: (إن وجدت) - زر "تحميل" (PDF).
- **حالة الإشعار**: (نشط / منتهي).
- **زر**: "تأكيد الاطلاع" (يسجل في السجل أن ممثل الشركة قد اطلع على الإشعار).

## 3. حالات واجهة المستخدم (UI States)
- **حالة عدم وجود إشعارات**: عرض رسالة "لا توجد إشعارات حالياً" مع زر "تحديث".
- **حالة الإشعار العاجل**: تمييز البطاقة بحدود حمراء وعلامة (❗).

## 4. نقاط النهاية الخلفية (API Calls)
| الطريقة | نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- | :--- |
| `GET` | `/api/v1/carriers/notices/` | قائمة الإشعارات (مع التصفية حسب category وpriority وis_active). |
| `GET` | `/api/v1/carriers/notices/{id}/` | تفاصيل إشعار محدد. |
| `POST` | `/api/v1/carriers/notices/{id}/acknowledge/` | تأكيد الاطلاع على الإشعار (يتطلب صلاحية ممثل شركة نقل). |
| `GET` | `/api/v1/carriers/notices/recent/` | آخر 5 إشعارات نشطة (لا تتطلب مصادقة). |
| `GET` | `/api/v1/carriers/notices/archived/` | الإشعارات المنتهية (expired). |
