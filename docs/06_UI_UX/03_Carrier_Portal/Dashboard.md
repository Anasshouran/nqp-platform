# لوحة التحكم الرئيسية لشركات الطيران (Carrier Dashboard)

## 1. الهدف
تزويد ممثل شركة الطيران بنظرة شاملة وسريعة عن حالة عملياته (الرحلات، الركاب، الإشعارات) في صفحة واحدة، مع توفير وصول سريع إلى أهم المهام (رفع قائمة الركاب، إضافة رحلة جديدة).

## 2. تخطيط الصفحة (Layout)

### 2.1. الشريط العلوي (Header)
- **شعار المنصة** (جهة اليمين).
- **اسم الشركة** و **اسم المستخدم** (جهة اليسار) مع قائمة منسدلة لتسجيل الخروج.
- **أيقونة الإشعارات** (🔔) مع عداد للإشعارات غير المقروءة (خاصة الإشعارات الصحية العاجلة).

### 2.2. بطاقات الملخص العلوي (KPI Cards) - 4 أعمدة
| البطاقة | القيمة | الأيقونة | لون الخلفية |
| :--- | :--- | :--- | :--- |
| **الرحلات القادمة اليوم** | عدد (مثل: 12) | ✈️ | أزرق فاتح |
| **المسافرون المتوقعون** | عدد (مثل: 1,450) | 🧑‍🤝‍🧑 | بنفسجي فاتح |
| **إشعارات صحية جديدة** | عدد (مثل: 3) | 📢 | أحمر فاتح (إذا كانت >0) |
| **نسبة التسجيل المسبق** | نسبة (مثل: 78%) | 📊 | أخضر فاتح |

### 2.3. جدول الرحلات القادمة (Upcoming Flights)
- **العنوان**: "الرحلات القادمة خلال الـ 24 ساعة القادمة".
- **الأعمدة**: (رقم الرحلة، المسار، وقت الوصول، عدد الركاب، حالة قائمة الركاب (مرفوعة/غير مرفوعة)، الإجراءات).
- **الإجراءات**: زر "رفع قائمة الركاب" (📤) للرحلة التي لم ترفع قائمتها بعد.
- **زر**: "عرض جميع الرحلات" (ينتقل إلى صفحة `FlightManagement.md`).

### 2.4. آخر الإشعارات الصحية (Recent Health Notices)
- عرض آخر 3 إشعارات صحية نشطة (مع أيقونة الحالة: 🔴 عاجل، 🟡 مهم، 🔵 معلوماتي).
- **زر**: "عرض جميع الإشعارات" (ينتقل إلى صفحة `HealthNotices.md`).

### 2.5. حالة التكامل (API Status)
- **بطاقة صغيرة** تعرض حالة اتصال الـ API مع المنصة:
  - (🟢 متصل) أو (🔴 غير متصل - تحقق من الإعدادات).
- **زر**: "الانتقال إلى إعدادات API" (ينتقل إلى صفحة `APIIntegration.md`).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للبطاقات والجداول.
- **حالة عدم وجود رحلات**: عرض رسالة "لا توجد رحلات قادمة اليوم" مع زر "إضافة رحلة جديدة".
- **حالة انقطاع API**: عرض تحذير في أعلى الصفحة (Banner) مع رابط لإعادة المحاولة.

## 4. نقاط النهاية الخلفية (API Calls)
| الطريقة | نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- | :--- |
| `GET` | `/api/v1/carriers/dashboard/stats/` | جلب إحصائيات البطاقات العلوية. |
| `GET` | `/api/v1/carriers/dashboard/upcoming/` | جلب قائمة الرحلات القادمة خلال الـ 24 ساعة. |
| `GET` | `/api/v1/carriers/notices/recent/` | جلب آخر 5 إشعارات صحية نشطة. |
