# شاشة التكامل عبر API (API Integration)

## 1. الهدف
تزويد المطورين أو المسؤولين التقنيين في شركة الطيران بالمعلومات اللازمة لربط أنظمتهم تلقائياً مع منصة NQP، بما في ذلك (عرض المفتاح وتوثيق نقاط النهاية).

## 2. مكونات الشاشة

### 2.1. بطاقة المفتاح (API Key Card)
- **المفتاح الحالي**: (مخفى جزئياً مع زر "إظهار").
- **زر**: "إنشاء مفتاح جديد" (مع تحذير أمني بإبطال المفتاح القديم).
- **زر**: "نسخ المفتاح" (📋).
- **آخر استخدام**: التاريخ والوقت + عنوان IP.

### 2.2. التوثيق السريع (Quick Documentation)
- **نقاط النهاية الأساسية (Endpoints)** — تتطلب رأس `X-API-Key`:
  - `POST /api/v1/carriers/integration/flights/`: إرسال بيانات رحلة جديدة.
  - `POST /api/v1/carriers/integration/flights/manifest`: إرسال قائمة الركاب.
  - `GET /api/v1/carriers/integration/flights/{id}/status/`: الاستعلام عن حالة الرحلة.
  - `GET /api/v1/carriers/integration/health-notices/`: استلام الإشعارات الصحية النشطة.
- **مثال لطلب (Curl/JSON)**: (عرض نموذج طلب واستجابة في نافذة قابلة للطي).

## 3. حالات واجهة المستخدم (UI States)
- **حالة إنشاء مفتاح جديد**: نافذة تأكيدية (Modal) مع تحذير: "سيتم إبطال المفتاح القديم. هل أنت متأكد؟".
- **حالة نجاح**: رسالة خضراء "تم التحديث بنجاح".
- **حالة خطأ**: رسالة حمراء مع تفاصيل الخطأ (مثل: "مفتاح API غير صالح").

## 4. نقاط النهاية الخلفية (API Calls)

### إدارة المفتاح (Company ViewSet — يتطلب مصادقة JWT)
| الطريقة | نقطة النهاية | الغرض |
| :--- | :--- | :--- |
| `GET` | `/api/v1/carriers/company/api-key/` | استرجاع المفتاح الحالي (مخفى) مع معلومات آخر استخدام. |
| `POST` | `/api/v1/carriers/company/api-key/regenerate/` | إعادة توليد المفتاح (يبطل المفتاح القديم). |

### التكامل الآلي (Integration — يتطلب رأس `X-API-Key`)
| الطريقة | نقطة النهاية | الغرض |
| :--- | :--- | :--- |
| `POST` | `/api/v1/carriers/integration/flights/` | إنشاء أو تحديث رحلة جديدة مع بيانات المسافرين. |
| `POST` | `/api/v1/carriers/integration/flights/manifest` | إرسال قائمة الركاب لرحلة موجودة. |
| `GET` | `/api/v1/carriers/integration/flights/{id}/status/` | الاستعلام عن حالة الرحلة وكشف المسافرين. |
| `GET` | `/api/v1/carriers/integration/health-notices/` | استلام الإشعارات الصحية النشطة.
