# شاشة التقارير (Reports)

## 1. الهدف
تزويد ممثل شركة الطيران بتقارير تحليلية عن أداء شركته (الرحلات، الركاب، الامتثال) لمساعدتهم في تحسين العمليات واتخاذ القرارات الاستراتيجية.

## 2. مكونات الشاشة

### 2.1. بطاقات الملخص العلوي (KPI Cards)
| البطاقة | القيمة | المصدر |
| :--- | :--- | :--- |
| **إجمالي الرحلات (الشهر)** | عدد الرحلات | نظام الرحلات |
| **إجمالي المسافرين (الشهر)** | عدد المسافرين | قوائم الركاب |
| **نسبة الامتثال للتسجيل المسبق** | (%) | قوائم الركاب + بوابة المسافرين |
| **الرحلات المتأخرة** | عدد الرحلات | نظام الرحلات |

### 2.2. أدوات التصفية (Filters)
- **الفترة الزمنية**: (اليوم، الأسبوع، الشهر، مخصص).
- **نوع التقرير**: (الرحلات، المسافرين، الامتثال).
- **زر**: "تطبيق التصفية".

### 2.3. الرسوم البيانية (Charts)
- **اتجاه الرحلات**: رسم بياني خطي يوضح عدد الرحلات خلال الفترة المحددة.
- **توزيع المسافرين حسب الجنسية**: رسم بياني دائري (Pie Chart).
- **حالة قوائم الركاب**: رسم بياني عمودي (Bar Chart) يوضح (مرفوعة، قيد المعالجة، غير مرفوعة).

### 2.4. الجداول التفصيلية (Detailed Tables)
- **جدول الرحلات**: (رقم الرحلة، المسار، عدد الركاب، نسبة التسجيل المسبق، حالة الرحلة).
- **جدول الامتثال**: (نسبة الالتزام بالإشعارات الصحية، عدد الرحلات الملغاة بسبب عدم الامتثال).

### 2.5. أزرار التصدير (Export Buttons)
- **زر**: "تصدير PDF" (تقرير منظم للطباعة).
- **زر**: "تصدير Excel" (بيانات خام للتحليل).
- **زر**: "جدولة التقرير" (لإرسال التقرير بشكل دوري على البريد الإلكتروني - اختياري).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للرسوم البيانية والجداول.
- **حالة تصدير التقرير**: ظهور رسالة "جاري تجهيز الملف..." مع شريط تقدم، ثم رسالة نجاح مع رابط التحميل.
- **حالة عدم وجود بيانات**: عرض رسالة "لا توجد بيانات للفترة المحددة".

## 4. نقاط النهاية الخلفية (API Calls)
| الطريقة | نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- | :--- |
| `GET` | `/api/v1/carriers/reports/kpi/` | مؤشرات الأداء الرئيسية (رحلات الشهر، مسافرون، نسبة التسجيل المسبق، رحلات متأخرة، امتثال). |
| `GET` | `/api/v1/carriers/reports/flights/` | بيانات تقارير الرحلات (مع إمكانية تصفية by/from/to). |
| `GET` | `/api/v1/carriers/reports/compliance/` | تقرير الامتثال (نسبة تأكيد الإشعارات النشطة). |
