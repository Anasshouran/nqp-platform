# شاشة قائمة الركاب (Passenger Manifest)

## 1. الهدف
تمكين ممثل الشركة من رفع قائمة الركاب (Passenger Manifest) للرحلة المحددة، مع توفير واجهة سهلة لمراقبة حالة المعالجة، وعرض تقرير التحقق (الأخطاء والنجاحات).

## 2. مكونات الشاشة

### 2.1. معلومات الرحلة (Flight Info) - شريط علوي
- **رقم الرحلة**: (مثل: KRT123).
- **المسار**: (مثل: الخرطوم ← دبي).
- **تاريخ الوصول**: (مثل: 2024-07-26).
- **حالة الملف**: (🟡 غير مرفوع / 🟢 قيد المعالجة / ✅ تمت المعالجة / ❌ فشل).

### 2.2. منطقة رفع الملف (Upload Zone)
- **منطقة السحب والإفلات (Drag & Drop)**:
  - الحد الأقصى للحجم: 50 ميجابايت.
  - الصيغ المدعومة: (CSV, XLSX, JSON).
  - **زر**: "اختيار ملف من الجهاز".
- **حالة الرفع**: (شريط تقدم مع نسبة مئوية).

### 2.3. تقرير التحقق (Validation Report) - يظهر بعد المعالجة
- **بطاقة ملخص**: (إجمالي الركاب، الناجحين، الذين بهم أخطاء، المسجلين مسبقاً).
- **جدول الأخطاء (إن وجدت)**:
  - الأعمدة: (رقم الصف، الحقل، الخطأ، القيمة المدخلة).
  - **زر**: "تنزيل تقرير الأخطاء (CSV)".
- **قائمة الركاب الناجحين**: (جدول مصغر مع إمكانية التوسيع لعرض الكل).

### 2.4. أزرار الإجراءات (Action Buttons)
- **زر**: "إعادة معالجة" (إذا فشلت المعالجة أو تم تعديل الملف).
- **زر**: "تأكيد وإرسال" (لتأكيد القائمة وإرسالها إلى المنفذ) - يظهر فقط بعد نجاح المعالجة.
- **زر**: "تنزيل القالب" (لتحميل ملف CSV/Excel فارغ بالهيكل المطلوب).

## 3. حالات واجهة المستخدم (UI States)
- **حالة السحب والإفلات**: تغيير لون المنطقة عند سحب الملف فوقها (تحول إلى اللون الأزرق الفاتح).
- **حالة المعالجة غير المتزامنة**: ظهور رسالة "جاري معالجة الملف... قد يستغرق هذا بضع دقائق" مع (Spinner) وتعطيل الأزرار.
- **حالة نجاح المعالجة**: ظهور رسالة خضراء مع عرض التقرير.
- **حالة فشل المعالجة**: ظهور رسالة حمراء مع عرض الأخطاء.

## 4. نقاط النهاية الخلفية (API Calls)
| الطريقة | نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- | :--- |
| `POST` | `/api/v1/carriers/flights/{id}/manifest/upload/` | رفع ملف القائمة (CSV). يبدأ المعالجة فوراً. |
| `GET` | `/api/v1/carriers/flights/{id}/manifest/status/` | الاستعلام عن حالة المعالجة (UPLOADED / PROCESSING / COMPLETED / FAILED). |
| `GET` | `/api/v1/carriers/flights/{id}/manifest/report/` | استرجاع تقرير التحقق (إجمالي، مطابقة مع المسافرين المسجلين مسبقاً). |
| `GET` | `/api/v1/carriers/flights/{id}/manifest/errors/` | تنزيل تقرير الأخطاء (CSV). |
| `POST` | `/api/v1/carriers/flights/{id}/manifest/reprocess/` | إعادة معالجة الكشف (إذا فشلت المعالجة أو تم تعديل الملف). |
| `GET` | `/api/v1/carriers/flights/{id}/manifest/passengers/` | استرجاع قائمة المسافرين المُعالَجين مع تفاصيلهم.
