# شاشة إدارة الرحلات (Flight Management)

## 1. الهدف
تمكين ممثل الشركة من إدارة جميع الرحلات التابعة لشركته (إضافة، تعديل، حذف، وعرض التفاصيل)، مع ربط كل رحلة بقائمة الركاب الخاصة بها.

## 2. مكونات الشاشة

### 2.1. شريط الأدوات (Toolbar)
- **زر**: "إضافة رحلة جديدة" (باللون الأزرق).
- **حقل البحث**: للبحث عن رحلة برقم الرحلة أو المسار.
- **قوائم التصفية**:
  - (الحالة: الكل، قادمة، وصلت، ملغاة).
  - (الفترة الزمنية: اليوم، هذا الأسبوع، هذا الشهر).

### 2.2. جدول الرحلات (Flights Table)
- **الأعمدة**:
  - رقم الرحلة.
  - المسار (من - إلى).
  - وقت المغادرة.
  - وقت الوصول المتوقع.
  - عدد الركاب.
  - حالة قائمة الركاب (🟢 مرفوعة / 🔴 غير مرفوعة / 🟡 قيد المعالجة).
  - حالة الرحلة (🔵 مجدولة / 🟢 وصلت / ⚫ ملغاة).
- **الإجراءات**:
  - **زر**: "رفع قائمة الركاب" (📤) - يظهر فقط للرحلات القادمة التي لم ترفع قائمتها بعد.
  - **زر**: "عرض التفاصيل" (👁️) - يفتح نافذة جانبية (Side Panel) بتفاصيل الرحلة وقائمة الركاب.
  - **زر**: "تعديل" (✏️).
  - **زر**: "حذف" (🗑️) - مع تأكيد (لا يمكن حذف الرحلات التي وصلت بالفعل).

### 2.3. نموذج إضافة / تعديل رحلة (Flight Form) - نافذة منبثقة (Modal)
- **الحقول الإلزامية**:
  - رقم الرحلة (نص).
  - نوع الرحلة (قائمة منسدلة: جوي، بحري، بري).
  - بلد المغادرة (قائمة منسدلة مع بحث).
  - بلد الوصول (قائمة منسدلة مع بحث).
  - وقت المغادرة المتوقع (منتقي تاريخ ووقت).
  - وقت الوصول المتوقع (منتقي تاريخ ووقت).
  - بوابة الوصول (قائمة منسدلة - تتغير بناءً على بلد الوصول).
- **حقل اختياري**: ملاحظات إضافية.
- **أزرار**: "حفظ" و "إلغاء".

### 2.4. نافذة تفاصيل الرحلة (Side Panel)
- **عرض معلومات الرحلة كاملة**.
- **قائمة الركاب**: جدول مصغر (الاسم، رقم الجواز، المقعد، حالة التسجيل المسبق).
- **زر**: "تنزيل قائمة الركاب (CSV)".

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Spinner) في الجدول أثناء جلب البيانات.
- **حالة نجاح الإضافة**: ظهور رسالة (Toast) خضراء "تمت إضافة الرحلة بنجاح".
- **حالة عدم وجود رحلات**: عرض رسالة "لا توجد رحلات" مع زر "إضافة رحلة جديدة".

## 4. نقاط النهاية الخلفية (API Calls)
| الطريقة | نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- | :--- |
| `GET` | `/api/v1/carriers/flights/` | قائمة الرحلات (مع التصفية والبحث). |
| `POST` | `/api/v1/carriers/flights/` | إضافة رحلة جديدة. |
| `GET` | `/api/v1/carriers/flights/{id}/` | تفاصيل رحلة محددة. |
| `PUT` | `/api/v1/carriers/flights/{id}/` | تحديث الرحلة. |
| `DELETE` | `/api/v1/carriers/flights/{id}/` | حذف رحلة (لا يمكن حذف رحلة وصلت أو أُلغيت أو ارتبطت بكشف مُعالَج). |
| `PATCH` | `/api/v1/carriers/flights/{id}/status/` | تحديث حالة الرحلة يدوياً. |
| `GET` | `/api/v1/carriers/flights/upcoming/` | جلب الرحلات القادمة (المجدولة أو التي رُفع كشفها أو في الطريق). |
