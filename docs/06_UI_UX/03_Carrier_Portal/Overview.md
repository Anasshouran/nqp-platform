# نظرة عامة على شاشات بوابة شركات الطيران (Carrier Portal Screens)

| اسم الشاشة | الملف | الوصف |
| :--- | :--- | :--- |
| لوحة التحكم | `Dashboard.md` | عرض ملخص لجميع الرحلات القادمة وحالة الإشعارات الصحية. |
| إدارة الشركات | `CompanyManagement.md` | تحديث بيانات الشركة، التواصل، والمفتاح الخاص بالـ API. |
| إدارة الرحلات | `FlightManagement.md` | إضافة وتعديل جداول الرحلات. |
| قائمة الركاب | `PassengerManifest.md` | رفع ملف (Excel/CSV) بقائمة الركاب، مع التحقق من الصحة وتصحيح الأخطاء. |
| تكامل API | `APIIntegration.md` | عرض وثائق الـ API والمفتاح الخاص، مع إمكانية اختبار الاتصال. |
| الإشعارات الصحية | `HealthNotices.md` | استلام إشعارات من وزارة الصحة بشأن تعليق أو استئناف الرحلات. |
| التقارير | `Reports.md` | تصدير تقارير عن عدد المسافرين الذين تم فحصهم وحالتهم. |
