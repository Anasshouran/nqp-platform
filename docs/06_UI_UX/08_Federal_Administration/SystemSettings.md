# شاشة الإعدادات العامة (System Settings)

## 1. الهدف
تمكين المسؤولين (Super Admin) من تعديل الإعدادات العامة للمنصة بشكل ديناميكي (بدون الحاجة لتعديل الكود أو إعادة النشر)، مثل: (إعدادات البريد الإلكتروني، عتبات الإنذار، فترات الحجر، قوالب الإشعارات، وإعدادات التكامل الخارجي).

- **المنطقة الزمنية**: (قائمة منسدلة: Africa/Khartoum).
- **وضع الصيانة (Maintenance Mode)**: (خانة اختيار) - عند التفعيل، يعرض الموقع صفحة "قيد الصيانة" للزوار.

- **زر**: "حفظ جميع التغييرات" (باللون الأزرق، يظهر في أسفل الصفحة).

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح الحفظ**: رسالة خضراء "تم حفظ الإعدادات بنجاح، سيتم تطبيق التغييرات فوراً".
- **حالة فشل الحفظ**: رسالة حمراء مع سبب الفشل (مثل: "رابط API غير صالح").
- **حالة الإعدادات المحملة**: عرض (Skeleton Loader) أثناء جلب الإعدادات الحالية.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/admin/settings/` | استرجاع جميع الإعدادات الحالية. |
| `PUT /api/v1/admin/settings/` | تحديث الإعدادات (إرسال كائن JSON كامل أو جزئي). |
| `GET /api/v1/admin/settings/audit/` | سجل التغييرات على الإعدادات (من قام، متى، ماذا). |
