# شاشة إدارة القطاعات (Sectors Management)

## 1. الهدف
تمكين الإدارة الاتحادية من إنشاء وتنظيم القطاعات الجغرافية أو التشغيلية التي تجمع مجموعة من المنافذ تحت إدارة واحدة (مثل: "قطاع الخرطوم"، "قطاع البحر الأحمر"، "قطاع دارفور")، لتسهيل عملية الإشراف، وتوزيع المسؤوليات، وتوليد التقارير على مستوى القطاع.

## 2. مكونات الشاشة

### 2.1. شريط الأدوات (Toolbar)
- **زر**: "إضافة قطاع جديد" (باللون الأزرق).
- **حقل بحث**: للبحث عن قطاع بالاسم.

### 2.2. جدول القطاعات (Sectors Table)
- **الأعمدة**:
  - اسم القطاع.
  - الوصف.
  - عدد المنافذ التابعة.
  - عدد المستخدمين.
  - مدير القطاع (اسم المستخدم).
  - الحالة (🟢 نشط / 🔴 غير نشط).
- **الإجراءات**:
  - **زر**: "تعديل" (✏️).
  - **زر**: "تعطيل/تفعيل" (🚫/✅).
  - **زر**: "عرض التفاصيل" (👁️) - يفتح نافذة جانبية تعرض المنافذ التابعة والإحصائيات.

### 2.3. نموذج إضافة / تعديل قطاع (Sector Form) - نافذة منبثقة (Modal)
- **الحقول الإلزامية**:
  - اسم القطاع (نص، فريد).
  - الوصف (نص، اختياري).
  - مدير القطاع (قائمة منسدلة من المستخدمين الذين لديهم دور `SECTOR_MANAGER`).
- **الحقول الاختيارية**:
  - المنافذ التابعة (قائمة متعددة الاختيارات من المنافذ المسجلة).
  - الحالة (نشط/غير نشط).

### 2.4. نافذة تفاصيل القطاع (Sector Detail Side Panel)
- **معلومات القطاع الأساسية**.
- **قائمة المنافذ التابعة**: جدول بالمنافذ مع حالتها وإحصائياتها السريعة.
- **قائمة مديري القطاع**: عرض المستخدمين المرتبطين بهذا القطاع.
- **إحصائيات القطاع**: ملخص لأداء جميع المنافذ التابعة (عدد الفحوصات، الحالات الإيجابية، الإشغال).

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح الإضافة**: رسالة خضراء "تم إضافة القطاع بنجاح".
- **حالة حذف القطاع**: نافذة تأكيدية "لا يمكن حذف القطاع إذا كان يحتوي على منافذ نشطة. يرجى نقل المنافذ إلى قطاع آخر أولاً." (إذا كانت هناك منافذ).

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/admin/sectors/` | قائمة القطاعات. |
| `POST /api/v1/admin/sectors/` | إضافة قطاع جديد. |
| `GET /api/v1/admin/sectors/{id}/` | تفاصيل قطاع. |
| `PUT /api/v1/admin/sectors/{id}/` | تحديث بيانات القطاع. |
| `DELETE /api/v1/admin/sectors/{id}/` | حذف قطاع (بشروط). |
| `GET /api/v1/admin/sectors/{id}/stats/` | إحصائيات القطاع. |
