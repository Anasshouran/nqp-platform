# لوحة التحكم الرئيسية للإدارة الاتحادية (Federal Admin Dashboard)

## 1. الهدف
تزويد الإدارة العليا بنظرة شاملة وفورية على أداء منصة الحجر الصحي القومي بأكملها. تعرض هذه اللوحة مؤشرات الأداء الرئيسية (KPIs) الوطنية، وحالة المنافذ، وأحدث التنبيهات، لتكون نقطة الانطلاق لاتخاذ القرارات الاستراتيجية.

## 2. تخطيط الصفحة (Layout)

### 2.1. الشريط العلوي (Header)
- **شعار المنصة** (جهة اليمين).
- **اسم المستخدم** مع الصورة الشخصية (جهة اليسار).
- **القائمة المنسدلة**: (الملف الشخصي، الإعدادات، تسجيل الخروج).
- **حالة النظام**: (🟢 جميع الأنظمة تعمل / 🟡 تحذير / 🔴 عطل).

### 2.2. بطاقات الملخص العلوي (National KPI Cards) - 4 أعمدة
| البطاقة | القيمة | الأيقونة | لون الخلفية |
| :--- | :--- | :--- | :--- |
| **إجمالي الفحوصات (اليوم)** | عدد (مثل: 1,540) | 🩺 | أزرق فاتح |
| **الحالات الإيجابية (اليوم)** | عدد (مثل: 12) | 🔴 | أحمر فاتح |
| **نسبة الإشغال في الحجر** | % (مثل: 68%) | 🏥 | برتقالي فاتح |
| **المنافذ النشطة** | عدد (مثل: 18) | 🛃 | أخضر فاتح |

### 2.3. خريطة المنافذ التفاعلية (Ports Map)
- **خريطة السودان** مع نقاط تمثل المنافذ:
  - 🟢 **أخضر**: أداء جيد.
  - 🟡 **أصفر**: أداء متوسط (بحاجة متابعة).
  - 🔴 **أحمر**: أداء منخفض (طوارئ).
- **عند النقر على نقطة**: تظهر نافذة منبثقة بإحصائيات المنفذ (الفحوصات، الحالات، الإشغال).

### 2.4. آخر التنبيهات (Recent Alerts)
- **عرض آخر 5 تنبيهات** صادرة عن النظام:
  - (مثل: "🚨 منفذ بورتسودان تجاوز حد الإشغال 90%").
  - (مثل: "⚠️ ارتفاع غير طبيعي في حالات الملاريا في قطاع دارفور").
- **زر**: "عرض الكل" (ينتقل إلى صفحة `KPIs.md`).

### 2.5. الإجراءات السريعة (Quick Actions)
- **شبكة (Grid) من 4 أزرار**:
  1.  **إدارة المستخدمين** (👥): الانتقال إلى `UsersRBAC.md`.
  2.  **التقارير الوطنية** (📊): الانتقال إلى `NationalReports.md`.
  3.  **إدارة المنافذ** (📍): الانتقال إلى `Ports.md`.
  4.  **الإعدادات العامة** (⚙️): الانتقال إلى `SystemSettings.md`.

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) للبطاقات والخريطة.
- **حالة انقطاع البيانات**: عرض رسالة "تعذر جلب البيانات، يرجى تحديث الصفحة" مع زر "إعادة المحاولة".
- **حالة وجود تنبيهات حرجة**: تغيير لون شريط الحالة العلوي إلى أحمر.

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/admin/dashboard/stats/` | جلب إحصائيات البطاقات العلوية. |
| `GET /api/v1/admin/ports/map-data/` | جلب بيانات المنافذ للخريطة (الحالة، الإحداثيات). |
| `GET /api/v1/admin/alerts/recent/` | جلب آخر التنبيهات. |
