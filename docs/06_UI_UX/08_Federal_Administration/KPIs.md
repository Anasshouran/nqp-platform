# شاشة مؤشرات الأداء الرئيسية (KPIs - National Dashboard)

## 1. الهدف
تزويد الإدارة العليا بلوحة تحكم تحليلية متقدمة تعرض جميع مؤشرات الأداء الرئيسية (KPIs) على المستوى الوطني، مع إمكانية التصفية حسب (القطاع، المنفذ، الفترة الزمنية) لعرض البيانات من زوايا مختلفة ودعم اتخاذ القرار الاستراتيجي.

## 2. مكونات الشاشة

### 2.1. شريط الأدوات (Toolbar)
- **قوائم التصفية**:
  - (القطاع: الكل، قطاع الخرطوم، قطاع البحر الأحمر، إلخ).
  - (المنفذ: الكل، مطار الخرطوم، ميناء بورتسودان، إلخ).
  - (الفترة الزمنية: اليوم، الأسبوع، الشهر، السنة، مخصص).
- **زر**: "تطبيق التصفية".
- **زر**: "إعادة تعيين".

### 2.2. بطاقات KPIs التفصيلية (Detailed KPI Cards) - شبكة 4x2
| البطاقة | القيمة | الاتجاه (مقارنة بالأمس) |
| :--- | :--- | :--- |
| **إجمالي الفحوصات** | 1,540 | 📈 +5% |
| **الحالات الإيجابية** | 12 | 📈 +2 |
| **متوسط زمن الفحص** | 4.2 دقائق | 📉 -0.3 دقيقة |
| **نسبة الإحالات للعيادات** | 12% | ➡️ 0% |
| **معدل الإشغال** | 68% | 📈 +3% |
| **متوسط وقت المختبر** | 6 ساعات | 📈 +1 ساعة |
| **عدد الحالات الحرجة** | 2 | ➡️ 0 |
| **المنافذ المتوقفة** | 0 | ✅ مستقر |

### 2.3. الرسوم البيانية (Charts) - ترتيب شبكي
- **اتجاه الحالات خلال الـ 30 يوماً الماضية**: (رسم بياني خطي - Line Chart) يوضح عدد الفحوصات والحالات الإيجابية اليومية.
- **توزيع الحالات حسب المرض**: (رسم بياني دائري - Pie Chart) يوضح أكثر الأمراض انتشاراً.
- **أداء المنافذ**: (رسم بياني عمودي - Bar Chart) يقارن أداء المنافذ (متوسط زمن الفحص، عدد الفحوصات).
- **معدل الإشغال في الحجر الصحي**: (رسم بياني خطي - Line Chart) يوضح تطور معدل الإشغال خلال الأسبوع.

### 2.4. جدول التنبيهات (Alerts Table)
- **عرض أحدث التنبيهات الصادرة عن النظام مع تفاصيلها**:
  - الأعمدة: (التاريخ، المنفذ، نوع التنبيه، الوصف، الحالة (جديد/قيد المعالجة/مغلق)).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: عرض (Skeleton Loader) لجميع البطاقات والرسوم البيانية.
- **حالة عدم وجود بيانات**: عرض رسالة "لا توجد بيانات للفترة المحددة" مع أيقونة 📊.
- **حالة تصدير البيانات**: (إذا تم إضافة زر تصدير) ظهور رسالة "جاري تجهيز الملف...".

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/admin/kpis/` | الحصول على جميع مؤشرات الأداء (مع معاملات التصفية). |
| `GET /api/v1/admin/kpis/{sector_id}/` | الحصول على مؤشرات قطاع معين. |
| `GET /api/v1/admin/alerts/` | قائمة التنبيهات (مع التصفية). |
