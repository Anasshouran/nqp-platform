# شاشة التقارير الوطنية (National Reports)

## 1. الهدف
تمكين الإدارة الاتحادية من إنشاء وتصدير تقارير وطنية شاملة تغطي جميع جوانب المنصة (الفحوصات، الحالات، أداء المنافذ، الحجر الغذائي، والمختبرات)، بصيغ متعددة (PDF، Excel، CSV) لدعم عملية اتخاذ القرار الاستراتيجي، وتوفير البيانات المطلوبة لوزارة الصحة والمنظمات الدولية (مثل: WHO).

## 2. مكونات الشاشة

### 2.1. نموذج إنشاء التقرير (Report Builder)
- **نوع التقرير (Report Type)**: (قائمة منسدلة):
  - تقرير الفحوصات اليومي/الأسبوعي/الشهري.
  - تقرير الحالات الوبائية (حسب المرض).
  - تقرير أداء المنافذ.
  - تقرير الحجر الغذائي (عدد الشحنات، النتائج).
  - تقرير أداء المختبرات (عدد العينات، أوقات الإنجاز).
  - تقرير شامل (يجمع كل ما سبق).
- **الفترة الزمنية (Date Range)**: (منتقي تاريخ: من - إلى).
- **التصفية حسب (Filters)**:
  - (القطاع: الكل أو قطاع محدد).
  - (المنفذ: الكل أو منفذ محدد).
  - (نوع المرض: الكل أو مرض محدد - يتم جلب القائمة من `Disease_Management`).
- **صيغة التصدير (Export Format)**:
  - (PDF: تقرير منظم وجاهز للطباعة).
  - (Excel: بيانات خام للتحليل المتقدم).
  - (CSV: للاستيراد إلى أنظمة أخرى).
- **زر**: "إنشاء التقرير" (يُرسل الطلب للمعالجة غير المتزامنة).

### 2.2. حالة المعالجة (Processing Status)
- **تظهر رسالة**: "جاري إنشاء التقرير... قد يستغرق هذا بضع دقائق. سيتم إشعارك عند الانتهاء."
- **شريط تقدم (Progress Bar)** تقريبي.

### 2.3. جدول التقارير السابقة (Previous Reports)
- **عرض قائمة بالتقارير التي تم إنشاؤها سابقاً**:
  - الأعمدة: (اسم التقرير، النوع، الفترة الزمنية، تاريخ الإنشاء، الحالة (جاهز/قيد المعالجة)، حجم الملف).
- **الإجراءات**:
  - **زر**: "تنزيل" (لتحميل التقرير).
  - **زر**: "حذف" (لحذف التقرير من النظام لتوفير المساحة).

## 3. حالات واجهة المستخدم (UI States)
- **حالة التحميل**: تعطيل زر "إنشاء التقرير" وإظهار (Spinner).
- **حالة نجاح الإنشاء**: ظهور رسالة خضراء "تم إنشاء التقرير بنجاح" مع إضافة الصف الجديد إلى جدول التقارير السابقة.
- **حالة فشل الإنشاء**: ظهور رسالة حمراء مع سبب الفشل (مثل: "الفترة الزمنية المحددة طويلة جداً، يرجى تقليصها").

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `POST /api/v1/admin/reports/generate/` | طلب إنشاء تقرير جديد (غير متزامن). |
| `GET /api/v1/admin/reports/` | قائمة التقارير السابقة. |
| `GET /api/v1/admin/reports/{id}/download/` | تنزيل تقرير جاهز. |
| `DELETE /api/v1/admin/reports/{id}/` | حذف تقرير. |
