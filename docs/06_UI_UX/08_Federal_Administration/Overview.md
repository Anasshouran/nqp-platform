# نظرة عامة على شاشات بوابة الإدارة الاتحادية (Federal Admin Screens)

| اسم الشاشة | الملف | الوصف |
| :--- | :--- | :--- |
| إدارة القطاعات | `Sectors.md` | إضافة وتعديل القطاعات الصحية (مثل: قطاع الخرطوم، قطاع البحر الأحمر). |
| إدارة المنافذ | `Ports.md` | إضافة وتعديل بيانات المنافذ (الاسم، الموقع، النوع، حالة التشغيل). |
| إدارة المستخدمين | `UsersRBAC.md` | إنشاء وتعديل وحذف المستخدمين، وتعيين الأدوار والصلاحيات. |
| الصلاحيات | `Permissions.md` | عرض وتعديل قائمة الصلاحيات المتاحة في النظام. |
| التقارير الوطنية | `NationalReports.md` | عرض تقارير شاملة على مستوى الدولة (مع إمكانية التصفية حسب القطاع والمنفذ). |
| مؤشرات الأداء | `KPIs.md` | لوحة تحكم متقدمة تعرض (معدل الإشغال، متوسط زمن الفحص، نسب الإحالات). |
| الإعدادات العامة | `SystemSettings.md` | إعدادات النظام (مدة الحجر الافتراضية، عتبات الإنذار، قوالب الإشعارات). |
