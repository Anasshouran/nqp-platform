# شاشة إدارة المنافذ (Ports Management)

## 1. الهدف
تمكين الإدارة الاتحادية من إدارة جميع المنافذ (الجوية، البحرية، البرية) التي تعمل عليها المنصة، بما في ذلك إضافة منافذ جديدة، تعديل بياناتها، أو تعطيلها مؤقتاً، مع ربط كل منفذ بقطاع معين لتنظيم التقارير والإشراف.

## 2. مكونات الشاشة

### 2.1. شريط الأدوات (Toolbar)
- **زر**: "إضافة منفذ جديد" (باللون الأزرق).
- **حقل بحث**: للبحث عن منفذ بالاسم أو الكود.
- **قوائم التصفية**:
  - (نوع المنفذ: الكل، مطار، ميناء بحري، منفذ بري).
  - (القطاع: الكل، قطاع الخرطوم، قطاع البحر الأحمر، إلخ).
  - (الحالة: الكل، نشط، غير نشط).

### 2.2. جدول المنافذ (Ports Table)
- **الأعمدة**:
  - كود المنفذ (رمز مختصر).
  - اسم المنفذ (عربي/إنجليزي).
  - النوع (مع أيقونة: ✈️، 🚢، 🚛).
  - القطاع التابع.
  - الموقع الجغرافي (خط الطول والعرض - اختياري).
  - الحالة (🟢 نشط / 🔴 غير نشط / 🟡 قيد الصيانة).
- **الإجراءات**:
  - **زر**: "تعديل" (✏️).
  - **زر**: "تعطيل/تفعيل" (🚫/✅).
  - **زر**: "عرض الإحصائيات" (📊) - يفتح نافذة جانبية بإحصائيات المنفذ.

### 2.3. نموذج إضافة / تعديل منفذ (Port Form) - نافذة منبثقة (Modal)
- **الحقول الإلزامية**:
  - كود المنفذ (نص، فريد، مثل: KRT، PSD).
  - اسم المنفذ (عربي، إنجليزي).
  - نوع المنفذ (قائمة منسدلة: مطار، ميناء بحري، منفذ بري).
  - القطاع التابع (قائمة منسدلة من القطاعات المسجلة).
  - الدولة (قائمة منسدلة من `countries`).
- **الحقول الاختيارية**:
  - الموقع الجغرافي (خط الطول `Longitude` وخط العرض `Latitude` - لاستخدامه في خريطة الطوارئ).
  - العنوان التفصيلي.
  - معلومات الاتصال (هاتف، بريد إلكتروني).
  - الحالة (نشط / غير نشط - الافتراضي: نشط).

### 2.4. نافذة إحصائيات المنفذ (Port Statistics Side Panel)
- **ملخص أداء المنفذ**:
  - عدد الفحوصات اليومية/الشهرية.
  - عدد الحالات الإيجابية.
  - عدد الإحالات إلى العيادات.
  - متوسط زمن الفحص.
  - عدد الموظفين النشطين في المنفذ.

## 3. حالات واجهة المستخدم (UI States)
- **حالة نجاح الإضافة**: رسالة خضراء "تم إضافة المنفذ بنجاح".
- **حالة تعطيل المنفذ**: نافذة تأكيدية "سيتم تعطيل هذا المنفذ، مما سيؤثر على جميع العمليات المرتبطة به. هل أنت متأكد؟".

## 4. نقاط النهاية الخلفية (API Calls)
| نقطة النهاية (Endpoint) | الغرض |
| :--- | :--- |
| `GET /api/v1/admin/ports/` | قائمة المنافذ (مع التصفية والبحث). |
| `POST /api/v1/admin/ports/` | إضافة منفذ جديد. |
| `GET /api/v1/admin/ports/{id}/` | تفاصيل منفذ. |
| `PUT /api/v1/admin/ports/{id}/` | تحديث بيانات المنفذ. |
| `PATCH /api/v1/admin/ports/{id}/toggle-status/` | تغيير حالة المنفذ (تفعيل/تعطيل). |
| `GET /api/v1/admin/ports/{id}/stats/` | إحصائيات المنفذ. |
