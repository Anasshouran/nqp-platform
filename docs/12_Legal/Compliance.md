# الامتثال القانوني والتنظيمي (Compliance Framework) - NQP

## 1. الهدف
تحديد الإطار القانوني والتنظيمي الذي يجب أن تلتزم به منصة NQP، بما في ذلك (القوانين السودانية، المعايير الدولية، وحماية البيانات الشخصية). يضمن هذا الإطار تشغيل المنصة بشكل قانوني وآمن، وحماية حقوق المستخدمين والجهات المعنية.

## 2. القوانين واللوائح المطبقة

| القانون/اللائحة | الرقم/السنة | الوصف | نطاق التطبيق |
| :--- | :--- | :--- | :--- |
| **قانون الصحة العامة السوداني** | 2017 | ينظم الخدمات الصحية والإجراءات الوقائية في السودان. | جميع عمليات المنصة الصحية. |
| **قانون حماية البيانات الشخصية (السودان)** | (قيد الإصدار) | ينظم جمع ومعالجة البيانات الشخصية. | جمع، تخزين، ومعالجة بيانات المسافرين. |
| **قانون مكافحة الجرائم الإلكترونية** | 2007 | ينظم الجرائم الإلكترونية ويحمي الأنظمة الرقمية. | أمن المنصة، حماية البيانات، الإبلاغ عن الاختراقات. |
| **قانون تنظيم الطيران المدني** | 2020 | ينظم عمليات الطيران والنقل الجوي. | التكامل مع شركات الطيران، بيانات الرحلات. |
| **قانون الجمارك** | 2020 | ينظم عمليات الاستيراد والتصدير والإفراج الجمركي. | الحجر الغذائي، شهادات الإفراج. |
| **اللوائح الصحية الدولية (IHR 2005)** | 2005 | يلزم الدول بالإبلاغ عن الفاشيات والأحداث الصحية. | التقارير الدولية، نظام الترصد. |
| **GDPR (الاتحاد الأوروبي)** | 2016/679 | ينطبق على بيانات المواطنين الأوروبيين (إن وجدوا). | حماية بيانات المسافرين الأوروبيين. |
| **HIPAA (الولايات المتحدة)** | 1996 | ينطبق على البيانات الصحية (إن وجدت). | حماية البيانات الصحية للمواطنين الأمريكيين. |

## 3. متطلبات الامتثال الأساسية

| المتطلب | الوصف | التنفيذ في NQP |
| :--- | :--- | :--- |
| **الموافقة المسبقة (Consent)** | الحصول على موافقة المستخدم قبل جمع بياناته. | نموذج الموافقة في التسجيل المسبق (بوابة 2). |
| **الحد الأدنى من البيانات (Data Minimization)** | جمع البيانات الضرورية فقط. | تصميم النماذج لجمع البيانات الأساسية فقط. |
| **حق الوصول والتصحيح** | تمكين المستخدم من عرض وتصحيح بياناته. | الملف الشخصي في بوابة المسافرين (2) وتطبيق الجوال. |
| **حق النسيان (Right to Erasure)** | تمكين المستخدم من طلب حذف بياناته. | طلب حذف عبر الدعم الفني (مع استثناءات قانونية). |
| **الإبلاغ عن الاختراق (Breach Notification)** | إبلاغ الجهات المعنية في حال اختراق البيانات. | خطة الاستجابة للاختراق (ضمن `Security_Architecture.md`). |
| **نقل البيانات عبر الحدود** | الامتثال لقوانين نقل البيانات عبر الحدود. | تشفير البيانات، استخدام خوادم محلية (إن أمكن). |
| **الاحتفاظ بالبيانات** | تحديد مدة الاحتفاظ بالبيانات. | سياسة الاحتفاظ بالبيانات (5 سنوات للبيانات الصحية). |

## 4. مسؤوليات الامتثال

| الدور | المسؤولية |
| :--- | :--- |
| **مسؤول حماية البيانات (DPO)** | الإشراف على حماية البيانات الشخصية والامتثال للقوانين. |
| **مدير النظام (Federal Admin)** | تنفيذ سياسات الامتثال وإدارة الصلاحيات. |
| **فريق الأمن السيبراني** | تنفيذ الإجراءات الأمنية ومراقبة الاختراقات. |
| **فريق الدعم القانوني** | تقديم المشورة القانونية ومراجعة السياسات. |

## 5. المراجعة الدورية
- **التكرار**: مراجعة الامتثال بشكل سنوي (أو عند تغيير القوانين).
- **المسؤول**: فريق قانوني متخصص + إدارة المنصة.
- **التوثيق**: توثيق جميع إجراءات الامتثال في تقرير سنوي.
