# القوانين واللوائح السودانية (Sudan Regulations) - NQP

## 1. الإطار القانوني السوداني
تخضع منصة NQP للقوانين واللوائح السودانية التالية:

| القانون/اللائحة | الرقم/السنة | الوصف | نطاق التطبيق |
| :--- | :--- | :--- | :--- |
| **قانون الصحة العامة** | 2017 | ينظم الخدمات الصحية والوقائية في السودان. | جميع العمليات الصحية للمنصة. |
| **قانون حماية البيانات الشخصية** | (قيد الإصدار) | ينظم جمع ومعالجة البيانات الشخصية. | جمع، تخزين، ومعالجة بيانات المسافرين. |
| **قانون مكافحة الجرائم الإلكترونية** | 2007 | ينظم الجرائم الإلكترونية ويحمي الأنظمة الرقمية. | أمن المنصة، حماية البيانات. |
| **قانون تنظيم الطيران المدني** | 2020 | ينظم عمليات الطيران والنقل الجوي. | التكامل مع شركات الطيران. |
| **قانون الجمارك** | 2020 | ينظم عمليات الاستيراد والتصدير والإفراج الجمركي. | الحجر الغذائي، شهادات الإفراج. |
| **قانون الزراعة والثروة الحيوانية** | - | ينظم استيراد وتصدير المنتجات الزراعية والحيوانية. | الحجر الغذائي (جزئياً). |
| **اللوائح الصحية الدولية (IHR 2005)** | 2005 | يلزم الدول بالإبلاغ عن الفاشيات والأحداث الصحية. | التقارير الدولية، نظام الترصد. |

## 2. التزامات المنصة بموجب القوانين السودانية

| الالتزام | الوصف | آلية التنفيذ في NQP |
| :--- | :--- | :--- |
| **حماية البيانات الصحية** | حماية البيانات الصحية للمواطنين من الوصول غير المصرح به. | تشفير البيانات، RBAC، سجلات التدقيق. |
| **الإبلاغ عن الأمراض المعدية** | الإبلاغ عن الحالات المؤكدة للأمراض المعدية للسلطات الصحية. | نظام الترصد الوبائي والتقارير التلقائية. |
| **الامتثال للوائح الجمركية** | تبادل البيانات مع الجمارك لإتمام عمليات الإفراج. | التكامل مع نظام الجمارك عبر API. |
| **حفظ السجلات** | الاحتفاظ بالسجلات الصحية والبيانات لمدة قانونية. | سياسة الاحتفاظ بالبيانات (5 سنوات). |
| **الإبلاغ عن الجرائم الإلكترونية** | الإبلاغ عن أي جرائم إلكترونية للسلطات المختصة. | خطة الاستجابة للاختراق، الإبلاغ عن الاختراقات. |
| **حماية حقوق المستخدمين** | حماية حقوق المستخدمين في الخصوصية والوصول إلى البيانات. | سياسة الخصوصية، شروط الاستخدام. |

## 3. الجهات التنظيمية السودانية

| الجهة | المسؤولية | علاقتها بـ NQP |
| :--- | :--- | :--- |
| **وزارة الصحة الاتحادية** | تنظيم القطاع الصحي وإدارة الصحة العامة. | المالك الرسمي للمنصة، جهة إصدار السياسات. |
| **الهيئة القومية للاتصالات (NTC)** | تنظيم الاتصالات والأمن السيبراني. | تنظيم أمن المنصة والاتصالات. |
| **الجهاز المركزي للإحصاء** | توفير البيانات الإحصائية الرسمية. | توفير البيانات الإحصائية للتقارير. |
| **هيئة الجمارك السودانية** | تنظيم عمليات الاستيراد والتصدير. | التكامل لإتمام الإفراج الجمركي. |
| **سلطات الطيران المدني** | تنظيم عمليات الطيران والنقل الجوي. | التكامل مع شركات الطيران. |
| **هيئة المواصفات والمقاييس** | وضع المواصفات القياسية للمنتجات. | التكامل للحصول على المواصفات الغذائية. |
| **النيابة العامة** | التحقيق في الجرائم الإلكترونية. | الإبلاغ عن الجرائم الإلكترونية (إن وجدت). |
