# سياسة الخصوصية (Privacy Policy) - NQP

## 1. مقدمة
تلتزم منصة الحجر الصحي القومي (NQP) بحماية خصوصية المستخدمين والامتثال لقوانين حماية البيانات السودانية والدولية. توضح هذه السياسة كيفية جمع البيانات واستخدامها ومشاركتها وحمايتها.

**آخر تحديث**: 26 يوليو 2024

## 2. البيانات التي نجمعها

### 2.1. البيانات الشخصية (Personal Data)
- الاسم الكامل.
- رقم جواز السفر.
- تاريخ الميلاد.
- الجنسية.
- معلومات الاتصال (البريد الإلكتروني، رقم الجوال).
- العنوان (في بعض الحالات).

### 2.2. البيانات الصحية (Health Data)
- الأعراض الصحية.
- التشخيصات الطبية.
- نتائج الفحوصات المخبرية.
- التطعيمات.
- التاريخ الطبي (الأمراض المزمنة، الحساسية).
- معلومات المتابعة الصحية (درجة الحرارة، SpO2، إلخ).

### 2.3. بيانات السفر (Travel Data)
- معلومات الرحلات (رقم الرحلة، شركة الطيران، المقعد).
- بلد القدوم والمغادرة.
- تاريخ الوصول والمغادرة.

### 2.4. بيانات الاستخدام (Usage Data)
- سجلات الدخول (Login Logs).
- عنوان IP.
- نوع المتصفح وجهاز المستخدم.
- الإجراءات التي يقوم بها المستخدم في المنصة.

## 3. كيفية استخدام البيانات

| الغرض | الوصف | الأساس القانوني |
| :--- | :--- | :--- |
| **تقديم الخدمات الصحية** | إجراء الفحص الصحي، التقييم، التشخيص، والمتابعة. | تنفيذ العقد (خدمات الحجر الصحي). |
| **إصدار الشهادات** | إصدار شهادات التعافي والإفراج الصحي. | التزام قانوني (IHR). |
| **الترصد الوبائي** | تجميع البيانات (مجهولة الهوية) للترصد والتحليل. | المصلحة العامة (الصحة العامة). |
| **التواصل** | التواصل مع المستخدم بشأن حالته الصحية أو التحديثات. | موافقة المستخدم. |
| **الامتثال القانوني** | الامتثال للقوانين واللوائح الصحية الدولية. | التزام قانوني. |
| **تحسين الخدمات** | تحليل البيانات لتحسين جودة الخدمات. | موافقة المستخدم (ضمن الشروط). |

## 4. مشاركة البيانات مع جهات خارجية

| الجهة | الغرض | نوع البيانات | أساس المشاركة |
| :--- | :--- | :--- | :--- |
| **وزارة الصحة** | التقارير الوطنية والسياسات الصحية. | بيانات مجمعة (مجهولة الهوية). | التزام قانوني. |
| **الجمارك** | شهادات الإفراج الغذائي. | بيانات الشحنات الغذائية. | التزام قانوني. |
| **منظمة الصحة العالمية (WHO)** | تقارير IHR و PHEIC. | بيانات مجمعة (مجهولة الهوية). | التزام قانوني (IHR). |
| **شركات الطيران** | قوائم الركاب (البيانات الأساسية). | بيانات السفر الأساسية. | تنفيذ العقد. |
| **المستشفيات** | الإحالات الطبية. | البيانات الصحية الكاملة. | موافقة المستخدم (ضمن الشروط). |
| **المختبرات المرجعية** | الفحوصات المخبرية المتقدمة. | بيانات العينة والمريض. | تنفيذ العقد. |
| **الجهات القضائية** | إذا طُلب ذلك قانونياً. | البيانات المطلوبة فقط. | التزام قانوني. |

## 5. حقوق المستخدم

| الحق | الوصف | آلية التنفيذ |
| :--- | :--- | :--- |
| **حق الوصول** | يمكنك الاطلاع على بياناتك الشخصية في أي وقت. | الملف الشخصي في بوابة المسافرين (2) وتطبيق الجوال. |
| **حق التصحيح** | يمكنك طلب تصحيح البيانات غير الصحيحة. | تحديث الملف الشخصي أو التواصل مع الدعم. |
| **حق النسيان** | يمكنك طلب حذف بياناتك (مع استثناءات قانونية). | التواصل مع الدعم الفني (support@nqp.gov.sd). |
| **حق الاعتراض** | يمكنك الاعتراض على معالجة بياناتك (لأسباب مشروعة). | التواصل مع الدعم الفني. |
| **حق تقييد المعالجة** | يمكنك طلب تقييد معالجة بياناتك. | التواصل مع الدعم الفني. |
| **حق نقل البيانات** | يمكنك طلب نقل بياناتك إلى نظام آخر (حيث ينطبق). | التواصل مع الدعم الفني. |

## 6. حماية البيانات (Security Measures)

| الإجراء | الوصف |
| :--- | :--- |
| **التشفير أثناء النقل** | استخدام TLS 1.3 لجميع الاتصالات. |
| **التشفير عند السكون** | تشفير قاعدة البيانات والملفات باستخدام AES-256. |
| **التحكم في الوصول** | استخدام نظام RBAC (إدارة الصلاحيات القائمة على الأدوار). |
| **سجلات التدقيق** | تسجيل جميع العمليات الحيوية في سجلات غير قابلة للتعديل. |
| **النسخ الاحتياطي المشفر** | تشفير النسخ الاحتياطية قبل التخزين. |
| **التدقيق الأمني** | إجراء اختبارات أمنية دورية (اختراق، ثغرات). |

## 7. سياسة الاحتفاظ بالبيانات (Data Retention)

| نوع البيانات | مدة الاحتفاظ | ما بعد المدة |
| :--- | :--- | :--- |
| **البيانات الصحية** | 5 سنوات من تاريخ آخر تحديث | الحذف الآمن أو الأرشفة (مجهولة). |
| **بيانات السفر** | 5 سنوات | الحذف الآمن. |
| **سجلات التدقيق** | 5 سنوات | الأرشفة (للرجوع إليها عند الحاجة). |
| **بيانات الاتصال** | 3 سنوات من آخر تفاعل | الحذف الآمن. |

## 8. تحديثات السياسة
- يتم تحديث هذه السياسة بشكل دوري (عند تغيير القوانين أو سياسات المنصة).
- سيتم إشعار المستخدمين بأي تغييرات جوهرية عبر البريد الإلكتروني والإشعارات في المنصة.
