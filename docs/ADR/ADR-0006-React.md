# ADR-0006: اعتماد React 19 + Vite للواجهة الأمامية

**التاريخ**: 2024-07-26  
**الحالة**: مقبول (Accepted)  
**المسؤول**: فريق Frontend / الهندسة المعمارية

---

## 1. السياق (Context)

تحتاج منصة NQP إلى إطار عمل للواجهة الأمامية (Frontend) يوفر:

- **أداء عالٍ**: سرعة تحميل واستجابة سريعة.
- **تفاعلية**: تجربة مستخدم غنية وسلسة.
- **قابلية التوسع**: دعم تطوير تطبيقات كبيرة ومعقدة.
- **دعم PWA**: إمكانية تحويل التطبيق إلى (Progressive Web App) للعمل دون اتصال.
- **سهولة التطوير**: أدوات حديثة وتجربة مطور ممتازة.
- **دعم TypeScript**: كتابة كود آمن وخالٍ من الأخطاء.

### الخيارات المتاحة (Options)

1. **React 19 + Vite**
2. **React 18 + Create React App (CRA)**
3. **Next.js (React Framework)**
4. **Vue.js 3 + Vite**
5. **Angular 17**

---

## 2. القرار (Decision)

**اعتماد React 19 + Vite + TypeScript كأساس للواجهة الأمامية، مع دعم PWA عبر (Vite PWA Plugin).**

---

## 3. الأسباب (Rationale)

| السبب | التوضيح |
| :--- | :--- |
| **React 19** | أحدث إصدار من React مع ميزات جديدة (React Compiler، Actions) وأداء محسّن. |
| **Vite** | أداة بناء سريعة جداً (Hot Module Replacement) وتجربة مطور ممتازة. |
| **TypeScript** | أمان كتابة (Type Safety) يكتشف الأخطاء أثناء التطوير، ويحسن جودة الكود. |
| **PWA** | دعم (Vite PWA Plugin) لتحويل التطبيق إلى (PWA) لدعم العمل دون اتصال. |
| **مجتمع كبير** | React لديه أكبر مجتمع، مع وفرة من المكتبات والأدوات. |
| **سهولة التكامل** | يتكامل بسهولة مع (REST APIs) عبر (Axios) و (Redux Toolkit). |
| **دعم (Material UI)** | React لديه دعم ممتاز لـ (Material UI) و (Tailwind CSS). |

---

## 4. العواقب (Consequences)

### إيجابية (Positive)
- أداء عالي وسرعة تحميل بفضل Vite.
- كتابة كود آمن بفضل TypeScript.
- دعم PWA للعمل دون اتصال.
- مجتمع كبير ومكتبات غنية.
- سهولة التكامل مع (APIs) و (State Management).

### سلبية (Negative)
- منحنى تعلم (خاصة مع React 19 الجديد).
- إدارة (State) قد تكون معقدة (يتم معالجته عبر Redux Toolkit).
- (PWA) يتطلب تكويناً إضافياً.

---

## 5. البدائل المرفوضة (Rejected Alternatives)

| البديل | سبب الرفض |
| :--- | :--- |
| **Create React App (CRA)** | بطيء في البناء والتطوير، ولا يدعم ميزات Vite الحديثة. |
| **Next.js** | مناسب لـ (SSR) و (SEO)، لكنه يزيد من التعقيد، والمنصة لا تحتاج (SSR) بشكل كبير. |
| **Vue.js** | أقل شيوعاً في السودان، ومجتمع أصغر من React. |
| **Angular** | ثقيل جداً، ومنحنى تعلم حاد، وغير مناسب للتطبيقات (SPA) الخفيفة. |
