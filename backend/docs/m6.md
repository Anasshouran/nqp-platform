## 4. Population (not auto)

`Sector.state_ids` is populated manually or via management command. Until populated,
STATE/LOCALITY users see nothing (fail-safe).

**Recommended one-time script for prod:**
```python
for sector in Sector.objects.all():
    state_ids = set(EntryPoint.objects.filter(sector=sector, is_active=True)
                    .values_list('state_id', flat=True))
    sector.state_ids.set(state_ids)
```
(requires EntryPoint.sector linkage in prod — verify via Q1 template).
